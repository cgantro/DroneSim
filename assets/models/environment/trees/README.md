# 장면 나무 모델

나무 위치는 수치지도에서 읽고, 화면 모양은 세 GLB 에셋으로 그립니다.

| 모델 | 화면에 쓰는 종류 |
| --- | --- |
| `mature-oak.glb` | 참나무 |
| `mature-scots-pine.glb` | 소나무 |
| `mature-sycamore.glb` | 플라타너스 계열 나무 |
