# 가상 훈련장 모델

산업 건물과 설비는 [Kenney 산업시설 묶음](https://kenney.nl/assets/city-kit-industrial)에서, 나무와 바위는 [Kenney 자연물 묶음](https://kenney.nl/assets/nature-kit)에서 가져왔습니다. 각 묶음의 제작자와 압축 파일에 포함된 이용 조건은 각 에셋 폴더의 안내를 따릅니다. 두 묶음은 CC0로 제공됩니다.

이 폴더의 모델은 현재 가상 훈련장에 배치하는 시각 에셋입니다. 실제 탄천 건물이나 시설물의 위치·모양을 나타내는 자료가 아니며, 자동 시험용 지도와도 별개입니다. 실제 지도 자료로 실행 장면을 바꾸면 여기서 더 쓰지 않는 에셋은 사용 여부와 저작권을 확인한 뒤 정리합니다.

현재 훈련장에 쓰는 GLB 모델과 산업 시설물이 함께 쓰는 질감만 보관합니다. 원본 압축 파일, 사용하지 않는 모델, 다른 형식의 중복 파일은 프로젝트에 넣지 않습니다.
