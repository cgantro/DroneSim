# 훈련장 시각 에셋

산업 건물과 설비는 [Kenney 산업시설 묶음](https://kenney.nl/assets/city-kit-industrial)에서, 나무와 바위는 [Kenney 자연물 묶음](https://kenney.nl/assets/nature-kit)에서 가져왔습니다. 각 묶음의 제작자와 압축 파일에 포함된 이용 조건은 각 에셋 폴더의 안내를 따릅니다. 두 묶음은 CC0로 제공됩니다.

이 폴더의 모델은 가상 훈련장에 배치하는 시각 에셋입니다. 실제 탄천 건물이나 시설물의 위치·모양을 나타내지 않습니다. 탄천 지형·건물 시험 자료는 [자동 시험 자료 안내](../../../tests/fixtures/maps/tancheon/README.md)에서 설명합니다.

모델 형식은 GLB이며, 원본 압축 파일은 포함하지 않습니다. 파일 출처와 이용 조건은 산업·자연 에셋 폴더의 `LICENSE.txt`에서 확인할 수 있습니다.
