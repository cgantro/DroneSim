# X500 V2 제조사 CAD

이 폴더에는 Holybro가 공개한 X500 V2 프레임과 AIR2216II 모터의 CAD 원본을 보관합니다. 화면에 표시하는 완성 기체는 PX4가 제공한 기존 모델을 계속 사용합니다. 프레임 CAD에는 화면 모델의 모터·프로펠러가 모두 들어 있지 않기 때문입니다.

- 출처: [Holybro X500 V2 다운로드](https://docs.holybro.com/drone-development-kit/px4-development-kit-x500v2/download)
- 제조사 제품 설명: [Holybro PX4 Development Kit X500 V2](https://holybro.com/collections/multicopter-kit/products/px4-development-kit-x500-v2)

제조사 다운로드 페이지에서 CAD를 받을 수 있지만, 별도의 CAD 재배포 허가 조건은 확인하지 못했습니다. 외부에 배포하기 전에는 제조사 이용 조건을 확인해야 합니다. 이 원본 자료는 시뮬레이터 실행 파일에 포함하지 않습니다.
