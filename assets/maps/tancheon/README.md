# 탄천 지도 자료 안내

## 지금 들어 있는 자료

현재 장면은 실제 탄천의 정밀 3D 지도가 아닙니다. 공개 지형 높이 자료와 OpenStreetMap의 건물·도로·하천 윤곽으로 만든 거친 시험 환경입니다.

| 자료 | 현재 상태 | 화면과 충돌에서 하는 일 |
| --- | --- | --- |
| 지형 | SRTM 높이 자료, 30m 간격 41×41 격자 | 지면 높이와 지형 충돌 계산 |
| 건물 | OpenStreetMap 외곽선 167개 | 화면에는 높이 자료가 있는 건물만 표시하고, 충돌은 외접 상자 사용 |
| 도로·하천 | OpenStreetMap 선과 영역 | 단색 화면 표시. 물은 충돌에 사용하지 않음 |
| 교량 | 세 곳의 평면 윤곽 | 위치 표시만 하며 상판·교각·충돌 형상은 없음 |
| 항공사진·위성사진 | 없음 | 지형과 건물에 입히는 실제 사진 무늬가 없음 |
| 정밀 3D 건물·교량 | 없음 | 실제 구조물처럼 보이거나 충돌하지 않음 |

따라서 지금 보이는 네모난 건물은 실제 건물 모델이 아니라 외곽선으로 만든 단순 모형입니다. 드론의 비행도 웹에서는 간이 운동학 계산을 사용합니다. 이 장면만으로 실제 탄천의 지형·구조물이나 기체 성능을 검증했다고 볼 수 없습니다.

기준점은 위도 37.4936231°, 경도 127.1018462°이며, 범위는 경도 127.0950°~127.1087°, 위도 37.4882°~37.4990°입니다. 지역 좌표는 기준점에서 동쪽·북쪽으로 잰 미터 단위입니다. 현재 지형 높이는 EGM96 기준입니다.

## 실제 탄천 지형과 사진 자료 받기

완성된 탄천 GLB를 공개 다운로드로 바로 구할 수 있다고 확인되지는 않았습니다. 현실적인 방법은 높이 자료와 정사영상을 받아 지형 GLB를 직접 만드는 것입니다. GLB의 굴곡은 DEM의 해상도를 넘을 수 없습니다. 현재 보유한 90m 공개 DEM으로 만들면 탄천 제방이나 도로 경계가 거의 드러나지 않으므로, 더 촘촘한 높이 자료의 제공 여부부터 확인해야 합니다.

### 1. 정사영상 받기

정사영상은 항공사진을 지도 좌표에 맞게 보정한 자료입니다. 지형 위에 올리면 도로·하천·공터처럼 위에서 보이는 지면의 실제 색과 무늬를 보여 줍니다. 건물 옆면이나 교량 하부 사진은 포함하지 않습니다.

1. [국토정보플랫폼 통합지도검색](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)을 엽니다.
2. 검색창에 `탄천교`를 입력하고 기준점 주변으로 지도를 옮깁니다.
3. `다각형`으로 위 표의 범위를 둘러싸는 영역을 선택합니다. 먼저 1.2km 안팎의 작은 구역만 받으면 파일 크기를 줄일 수 있습니다.
4. 왼쪽 자료 목록에서 `정사영상`을 선택합니다. `항공사진` 원본이 아니라 지도 좌표에 맞춘 정사영상을 고릅니다.
5. 검색 결과에서 탄천이 실제로 포함된 자료를 고르고 촬영 연도와 해상도를 확인한 뒤 내려받습니다.
6. 받은 자료의 이용 조건과 재배포 허용 여부를 확인합니다. 화면에 보인다고 해서 원본 사진을 공개 저장소에 올려도 된다는 뜻은 아닙니다.

국토정보플랫폼은 정사영상과 공개 DEM을 제공하지만, 공개 DEM은 현재 받은 자료처럼 90m 격자일 수 있습니다. 국토지리정보원 안내 자료는 더 세밀한 DEM도 설명하지만, 지역과 제공 등급에 따라 신청·이용 조건이 다를 수 있습니다. 이번에 받은 `37705`, `37709` 타일은 90m이고 수직 기준·단위가 확인되지 않아 현재 30m 지형을 대체하지 않았습니다. 더 촘촘한 DEM을 받더라도 수직 기준과 단위를 함께 확인해야 합니다.

### 2. DEM과 정사영상으로 지형 GLB 만들기

QGIS 플러그인 **Qgis2threejs**는 DEM을 입체 지형으로 만들고, 지도 화면의 색과 무늬를 표면에 입혀 GLB로 내보낼 수 있습니다. 즉 GLB는 자료를 내려받는 곳이 아니라 높이 자료와 사진을 합쳐 만드는 결과물입니다.

1. QGIS에서 사용할 DEM과 정사영상을 엽니다.
2. 두 자료를 같은 투영 좌표계와 같은 탄천 범위로 맞춥니다. 세로 높이 기준과 길이 단위도 기록합니다.
3. QGIS 플러그인 관리에서 `Qgis2threejs`를 설치합니다.
4. 프로젝트의 3D 보기에서 DEM을 지형으로, 정사영상을 지형 표면 무늬로 지정합니다.
5. 화면 미리보기에서 강·도로·교량 위치가 맞는지 확인한 뒤 `Save Scene As`의 `glTF (.gltf,.glb)`로 내보냅니다.
6. 결과 GLB를 Blender에서 열어 범위, 축, 단위, UV, 재질과 크기를 확인합니다. 원본 DEM·정사영상과 변환 설정도 함께 보관합니다.

Qgis2threejs는 [공식 플러그인 설명](https://plugins.qgis.org/plugins/Qgis2threejs/)과 [내보내기 안내](https://minorua.github.io/Qgis2threejs/docs/2.10/Exporter.html)를 참고합니다. 내보낸 GLB가 DroneSim에서 곧바로 열린다는 뜻은 아닙니다. 아래의 현재 GLB 제한과 좌표·충돌 일치 여부를 먼저 확인해야 합니다.

### 3. 건물과 교량 3D 모델 요청하기

정사영상만으로는 건물 외벽이나 교량 아래를 사실적으로 만들 수 없습니다. 실제 입체 모델은 서울시 S-Map의 3D 공간자료 제공 가능 여부를 확인해야 합니다.

1. [S-Map 오픈랩 문의 게시판](https://openlab.eseoul.go.kr/mobile/qna.do)을 엽니다.
2. 게시판 위쪽의 `S-Map 데이터 제공 관련 FAQ 안내`와 `서울특별시 공개제한 공간정보 민간 개방 안내`를 먼저 확인합니다.
3. 탄천교 주변에 필요한 자료를 구체적으로 문의합니다. 문의 제목은 `탄천교 주변 3D 건물·교량 모델과 텍스처 제공 및 이용 조건 문의`로 쓰면 됩니다.
4. 문의에는 아래 내용을 포함합니다.
   - 위치: 위 표의 경위도 범위와 기준점
   - 대상: 탄천교와 주변 건물, 하천 제방·도로
   - 목적: DroneSim의 드론 정찰·영상 수집 시뮬레이션과 포트폴리오 시연
   - 필요한 자료: 지형 DEM/메시, 건물·교량 3D 모델, 모델의 원본 텍스처
   - 원하는 형식: 가능하면 GLB/glTF, 아니면 OBJ·FBX와 재질·텍스처 파일
   - 확인할 조건: 좌표계, 높이 기준, 제작 시점, 모델 단위, 공개·수정·웹 배포·저장소 재배포 허용 범위
5. 제공 가능한 형식과 사용 허가를 답변받은 뒤 자료를 내려받습니다. 공개 문의글의 답변은 제공 FAQ를 안내하는 수준이므로, 실제 파일 형식·다운로드 가능 여부·허가 범위가 확인됐다고 가정하면 안 됩니다.

S-Map의 일반 사용자 안내에는 지도 데이터셋을 ZIP으로 내려받는 방법이 나와 있지만, 이 안내만으로 탄천 3D 모델 원본을 직접 받을 수 있다고 단정할 수는 없습니다. 모델 추출이나 저장소 공개가 제한되면 허용된 범위에서만 쓰고, 공개 데모에는 별도로 사용 허가를 받은 자료를 사용합니다.

## 받은 자료를 장면에 넣는 방법

### 지형 사진 무늬

1. QGIS에서 정사영상과 DEM을 엽니다. 둘 다 같은 지역인지, 좌표계와 고도 기준이 무엇인지 확인합니다.
2. DroneSim의 지도 범위로 두 자료를 잘라냅니다. 정사영상은 지형과 맞춰야 하므로 좌표 정보를 유지합니다.
3. 정사영상의 위·아래 방향과 색을 확인한 뒤, 지형 전체에 맞는 RGB PPM 그림으로 내보내 `assets/maps/tancheon/terrain.ppm`에 둡니다. 웹 실행에 포함되므로 처음에는 2048×2048 이하로 줄입니다.
4. 지형 격자와 사진의 기준점·범위·방향이 일치하는지 화면에서 확인합니다. 사진을 잘못 뒤집거나 다른 범위로 자르면 강과 도로가 지형과 어긋납니다.

현재 시뮬레이터는 `terrain.ppm`이 있으면 지형에 그림을 입히도록 준비되어 있습니다. 파일이 없으면 기존 단색 지형으로 표시합니다. PPM만 읽을 수 있으므로 PNG나 JPEG 파일을 그대로 이름만 바꿔 넣으면 안 됩니다.

### 3D 건물·교량 모델

현재 GLB 읽기 기능은 **메시 하나, 삼각형 묶음 하나, 노드 변환이 이미 적용된 파일**만 지원합니다. GLB에 들어 있는 재질·이미지를 자동으로 읽지 않으며, 지도 메시를 로드해 화면이나 충돌에 연결하는 기능도 아직 없습니다. 따라서 S-Map에서 받은 도시 전체 GLB를 그대로 넣어도 현재 장면에 나타나지 않습니다.

모델을 받으면 먼저 제공된 좌표계·단위·사용 허가를 확인하고, 필요한 구역만 따로 뽑아야 합니다. 여러 메시와 노드가 포함된 원본은 모델의 위치·회전·크기를 유지한 채 단순화해 엔진이 읽을 수 있는 형태로 변환해야 합니다. 화면용 메시와 충돌용 형상은 별도로 준비합니다. 화면에 보이는 상세 메시를 그대로 충돌 계산에 쓰면 계산량이 커질 수 있습니다.

3D 모델의 실제 표면 무늬가 필요하면 모델과 함께 제공되는 재질·텍스처 원본도 받아야 합니다. 정사영상은 지붕과 지면을 위에서 본 사진일 뿐, 외벽이나 교량 밑면의 질감을 대신하지 않습니다. 저작권과 재배포 허가를 확인하지 않은 사진·모델은 저장소나 웹 배포 파일에 포함하지 않습니다.

## 자료 출처와 사용 조건

- 지형 높이: [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)의 `N37E127.hgt.gz`, SRTM 약 30m 격자. Mapzen Terrain Tiles와 미국 지질조사국 자료 표시 조건을 따릅니다.
- 건물·도로·하천·교량 윤곽: [OpenStreetMap](https://www.openstreetmap.org/), ODbL 1.0. 배포물에는 `© OpenStreetMap contributors` 표시가 필요합니다.
- 공개 DEM: 국토정보플랫폼에서 받은 2025년 자료 두 장. EPSG:5179, 90m 격자이며 현재 장면에는 사용하지 않습니다.
- 정사영상과 3D 모델: 아직 받지 않았습니다. 제공 기관의 출처 표기와 사용·재배포 조건을 확인한 뒤 추가합니다.

## 자료가 들어오면 확인할 일

- 지형 사진과 높이 격자의 범위·좌표계·방향이 맞는지 확인합니다.
- 건물·교량이 실제 위치와 높이에 놓이는지 확인합니다.
- 보이는 형상과 충돌 형상의 위치가 맞는지 확인합니다.
- 웹에서 화면이 멈추지 않도록 메시와 텍스처 크기를 줄이고, 로딩 시간과 파일 크기를 측정합니다.
- 자료 출처·촬영 시기·좌표·높이 기준·사용 허가를 이 안내에 기록합니다.
