# 탄천 지형과 표면 사진 준비

## 현재 장면

시뮬레이터는 탄천교 주변을 30m 간격 높이 격자로 그리고, 같은 격자로 지면 충돌을 계산합니다. 건물은 공개된 외곽선과 높이 정보로 단순하게 표시합니다. 실제 항공사진 질감, 상세 건물·교량 모델, 지형 GLB는 아직 연결하지 않았습니다.

지형을 현실에 가깝게 바꾸려면 서로 다른 자료 세 가지가 필요합니다.

| 자료 | 무엇을 만드는가 | 어디서 얻는가 |
| --- | --- | --- |
| DEM | 지형의 높낮이와 지면 충돌 | 국토정보플랫폼의 공개 DEM 또는 별도 신청한 고해상도 DEM |
| 정사영상 | 지면에 입힐 실제 색과 무늬 | 국토정보플랫폼의 정사영상 TIFF |
| 건물·교량 3D | 외벽, 상판, 교각과 구조물 충돌 | S-Map 자료 신청 또는 별도 3D 모델 |

정사영상은 지붕과 지면을 위에서 찍은 사진입니다. 건물 외벽이나 교량 아래 구조를 만들지 않습니다. DEM으로 GLB를 만들면 땅의 굴곡은 표현되지만 건물과 교량은 따로 준비해야 합니다.

## 받은 DEM 두 장 확인 결과

두 압축파일 안의 IMG를 직접 읽어 공간정보를 확인했습니다. 둘 다 Float32 높이 자료이며, 좌표계는 EPSG:5179, 격자 간격은 동서·남북 90m, 결측값은 -9999입니다. 탄천교 기준점은 EPSG:5179 좌표로 약 동쪽 964,804m·북쪽 1,943,893m이며, 남쪽 도엽이 이 기준점을 포함합니다. 두 도엽을 합치면 현재 1.2km 시험 구역을 덮습니다.

다만 원본 메타데이터에서 높이 단위와 수직 기준은 읽히지 않았습니다. 높이값을 그대로 충돌 계산에 쓰기 전에 국토지리정보원 자료 설명에서 수직 기준을 확인해야 합니다. 정사영상과 DEM의 좌표가 맞아도 수직 기준이 다르면 화면과 지면 충돌이 어긋날 수 있습니다.

90m 격자는 1.2km 구역에 축마다 약 14개의 원본 표본만 둡니다. 기존 30m 화면 격자보다 성긴 자료라서 현재 화면을 더 세밀하게 만들 용도로 교체하지 않습니다. 90m 자료는 넓은 지형 높이를 확인하는 참고 자료로 쓸 수 있지만, 제방·도로 턱·교량 같은 작은 굴곡에는 맞지 않습니다. 국토지리정보원 안내 자료에서 1m·5m DEM의 일부는 공개 제한으로 분류되어 있으므로, 고해상도 자료는 제공 여부와 신청 조건을 별도로 확인해야 합니다.

## 1. 지형 높이와 사진 자료 받기

[국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 탄천교를 찾고, 처음에는 임무에 필요한 구역만 지정합니다. 광역 지도를 한 번에 내려받으면 파일과 브라우저 자원만 커집니다.

1. `공개DEM`에서 지정 구역을 덮는 자료를 받습니다. 90m보다 촘촘한 지형이 필요하면 국토지리정보원에 같은 위치의 1m 또는 5m 자료 제공 여부를 문의합니다.
2. 지도 검색 결과에서 해당 위치를 고른 뒤 오른쪽 검색 표시에서 `정사영상`을 선택합니다. 촬영 연도와 픽셀 크기를 확인하고, 가장 최근 자료의 TIFF를 신청합니다.
3. 국토지리정보원 정사영상 안내에는 도시 지역 12cm, 일반 지역 25cm 해상도와 TIFF 제공이 표시되어 있습니다. 신청 목록에서 탄천 구역의 실제 촬영 연도와 해상도를 다시 확인합니다. 내려받으려면 로그인이 필요하며, 대용량 전송 프로그램을 설치하라는 안내가 나올 수 있습니다.
4. 정사영상 자료 설명에는 무료 제공과 이용허락 제한 없음으로 표시되어 있습니다. 그래도 신청한 개별 자료의 조건과 출처 표기 요구를 확인하고, DEM·건물 자료에는 해당 자료의 조건을 따릅니다.
5. 자료별 좌표계, 높이 기준, 촬영·제작 시기, 해상도, 이용·배포 조건을 기록합니다. QGIS에 DEM과 정사영상을 함께 올려 두 자료가 같은 위치에 놓이는지 확인합니다. 기준점이나 범위가 다르면 GLB와 충돌 격자가 어긋납니다.

정사영상 TIFF를 받을 수 없다면 온라인 지도 화면을 캡처해 질감으로 쓰지 않습니다. 지도 화면은 원본 해상도와 사용·재배포 권한을 확인하기 어렵습니다. 국토정보플랫폼에 자료를 신청하거나, 사용 조건이 명확한 영상 자료를 확보합니다.

## 2. 상세 건물·교량 자료 받기

서울시는 [S-Map](https://smap.seoul.go.kr/)에 서울 전역의 건물 약 60만 동과 교량·고가·육교를 포함한 시설물, 지형 정보를 갖고 있습니다. 다만 웹 화면에서 보이는 모델이 내려받을 수 있는 원본 파일이라는 뜻은 아닙니다. 서울시는 주요 변화 지역의 드론 촬영 3D 모델과 정사영상도 만들어 S-Map을 갱신하고 있으므로, 탄천교 주변 자료가 있는지 먼저 문의할 가치가 있습니다.

[S-Map 오픈랩 자료 제공 FAQ](https://openlab.eseoul.go.kr/mobile/qna.do)와 [공개제한 공간정보 안내](https://openlab.eseoul.go.kr/mobile/notice.do)를 확인하고, 탄천교 주변의 지형·건물·교량 3D 자료를 요청합니다. 공개제한 자료는 법인 또는 사업자 등록과 보안 심사가 필요할 수 있어 개인 포트폴리오가 신청할 수 있는지 먼저 물어봐야 합니다. 서울시 공간정보과(02-2133-2835)에 데이터 범위·파일 형식·수정 및 웹 공개 허용 여부를 문의합니다. 드론으로 만든 교량 3D 모델이나 정사영상이 있는지는 [서울시 드론공간정보 담당 부서](https://news.seoul.go.kr/gov/archives/528178)(02-2133-2843)에도 확인할 수 있습니다.

자료를 받을 수 없다면 정사영상과 건물 외곽선은 장면의 주변 표현에 활용하고, 점검 대상 교량은 치수를 확인해 별도 모델로 만듭니다. 추정한 형상은 실제 교량 자료와 구분해 표시해야 합니다.

## 3. QGIS에서 지형 GLB와 질감 만들기

[QGIS](https://qgis.org/download/)에서 DEM과 정사영상을 같은 미터 단위 좌표계로 맞춘 뒤, 두 자료를 똑같은 사각형 범위로 자릅니다. 지형 높이 과장은 1로 둡니다. 비행 구역은 우선 약 1km 크기로 제한하고, 시험 범위를 벗어난 지형은 넣지 않습니다.

### 지형 GLB

QGIS 플러그인 [Qgis2threejs](https://plugins.qgis.org/plugins/Qgis2threejs/)는 DEM에서 지형 메시를 만들고 glTF/GLB로 내보냅니다. 플러그인 목록에서 현재 QGIS와 호환되는 버전을 고릅니다. 예를 들어 2026년 10월 기준 최신 3.3 버전은 QGIS 4가 필요하고, QGIS 3.4 이상에는 2.10.2 버전이 제공됩니다.

1. 내보내기 대상은 DEM 지형만 선택합니다. 주변 시설물을 한꺼번에 넣으면 메시가 커지고 현재 모델 읽기 조건에도 맞지 않을 수 있습니다.
2. QGIS의 동쪽·북쪽·위쪽 좌표를 DroneSim의 동쪽 X·위쪽 Y·남쪽 Z 좌표로 바꿉니다. Blender에서 X축 -90도 회전을 적용하면 `(동쪽, 북쪽, 위쪽)`이 `(동쪽, 위쪽, 남쪽)`으로 대응합니다.
3. 시뮬레이터의 지도 기준점인 위도 37.4936231°, 경도 127.1018462°가 X=0·Z=0이 되게 맞추고, 단위는 미터로 유지합니다. Y축 높이는 충돌 격자와 같은 높이 기준을 써야 합니다. GLB 높이를 임의로 0에 맞추면 지면 충돌 높이와 어긋날 수 있습니다. 회전·수평 이동·크기를 메시 정점에 적용한 뒤 GLB로 내보냅니다.
4. 현재 GLB 읽기는 노드 하나·메시 하나·삼각형 묶음 하나와 위치·법선·삼각형 인덱스를 요구합니다. 질감을 입히려면 추가로 UV 좌표가 필요합니다. Blender에서 지형을 하나의 메시로 합치고 변환을 적용합니다.

### 표면 사진 질감

현재 시뮬레이터는 GLB 안에 들어 있는 재질과 사진을 읽지 않습니다. GLB의 UV 좌표에 맞는 RGB 사진을 별도 PPM 파일로 준비해야 합니다.

1. 정사영상 TIFF를 지형 GLB와 똑같은 좌표계·경계로 자릅니다. 실제 원본 화소가 충분하면 1km 범위에서 2048픽셀은 약 0.5m/픽셀로 줄인 결과입니다. 작은 시설물을 가까이서 보려면 임무 구역을 더 작게 잘라 별도 질감을 만들어야 합니다.
2. QGIS에서 3개 색상 띠, 8비트 RGB로 내보냅니다. 먼저 2048×2048 크기로 맞추면 압축 전 크기는 약 12MiB입니다. 해상도가 더 필요하면 브라우저 다운로드와 메모리 사용량을 확인한 뒤 올립니다.
3. 저장 형식은 PPM의 `P6`, 최대 색상값은 `255`로 둡니다. 이 형식을 현재 시뮬레이터가 읽습니다.
4. QGIS에서 GLB와 PPM을 함께 열어 도로·하천·건물 위치가 맞는지 비교합니다. 사진이 위아래로 뒤집히거나 밀리면 영상 자르기 범위와 UV 방향을 확인합니다.

GLB에 사진이 들어 있어도 시뮬레이터가 자동으로 표시하지 않습니다. 사진을 GLB에만 포함한 채 적용 완료로 판단하지 말고, 별도 PPM 질감이 실제 화면에 나타나는지 확인합니다.

## 4. 충돌 지형도 함께 바꾸기

화면용 GLB는 보기 위한 형상이고, 드론의 지면 충돌은 별도의 높이 격자를 사용합니다. DEM만 바꾸거나 GLB만 바꾸면 화면과 충돌 결과가 달라집니다.

QGIS에서 같은 DEM과 같은 범위로 ESRI ASCII Grid를 내보내고, 저장소의 지형 격자 변환 도구로 충돌 자료를 다시 만듭니다. 입력 좌표계는 미터 단위 투영 좌표계로 맞춥니다. 도구는 원본 좌표계나 높이 기준을 알아서 변환하지 않으므로 기준점·간격·표고 기준을 직접 대조합니다. 화면 GLB와 충돌 격자는 같은 중심, 방향, 범위, 높이값을 가져야 합니다.

## 완료 전 확인

- DEM과 정사영상이 같은 영역과 좌표계에 놓이는가?
- 지도 기준점이 시뮬레이터 원점과 맞는가?
- GLB의 동쪽·위쪽·남쪽 축, 미터 단위, 지형 높이가 올바른가?
- 정사영상 질감이 지형에 맞게 표시되고 위치가 밀리지 않는가?
- 같은 DEM으로 충돌 높이 자료를 다시 만들었는가?
- 건물·교량 모양이 실제 측량 자료인지, 단순화하거나 추정한 형상인지 구분했는가?
- 원본 자료와 변환 결과를 저장소나 웹에 공개해도 되는지 이용 조건을 확인했는가?
