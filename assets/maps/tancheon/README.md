# 탄천교 주변 공간자료

탄천교를 중심으로 약 1.2km × 1.2km 범위의 OpenStreetMap 자료를 보관합니다. 원본과 화면·충돌 자료를 만들 때 쓸 수 있는 GeoJSON을 함께 두었습니다. GeoJSON에는 건물·도로·하천·다리의 평면 위치와 태그가 들어 있습니다.

- 기준점: 위도 37.4936231°, 경도 127.1018462°
- 요청 범위: 경도 127.0950°~127.1087°, 위도 37.4882°~37.4990°
- 내려받은 날: 2026년 10월 26일
- 출처: [OpenStreetMap](https://www.openstreetmap.org/)
- 이용 조건: [ODbL 1.0](https://www.openstreetmap.org/copyright)

원본에는 건물 외곽선 167개가 있습니다. 그중 69개는 높이, 24개는 층수 정보가 있고 74개는 높이 정보가 없습니다. `탄천교` 형상은 평면 위치만 있으며 교량 높이와 구조 치수는 제공하지 않습니다. 다리로 표시된 선 23개는 도로·자전거길의 조각일 수 있으므로 서로 다른 다리 23개라는 뜻이 아닙니다.

GeoJSON은 닫힌 건물·교량 외곽선과 도로·하천 선을 위도·경도 그대로 옮긴 자료입니다. 원본의 건물 다중 외곽선 관계 1개는 이 변환본에 포함하지 않았습니다.

이 원본은 아직 시뮬레이터 장면이나 충돌 형상으로 불러오지 않습니다. DEM과 함께 좌표·높이 기준을 확인한 뒤 화면용 형상과 충돌용 형상을 따로 구성해야 합니다. OSM에 없는 건물 높이나 교량 치수는 이 자료만으로 정할 수 없습니다.
