# 탄천 실제 지도 자료 준비

지금 장면은 30m 간격 지형 높이와 공개 건물·도로 선형을 바탕으로 만든 시험 환경입니다. 탄천의 실제 표면을 보이려면 **지형 높이 자료와 항공사진을 각각 받아 맞춰야** 합니다. 항공사진만으로는 땅의 높낮이가 생기지 않고, 지형 자료만으로는 땅의 색과 무늬가 생기지 않습니다.

## 현재 확인된 상태

| 자료 | 쓰임 | 저장소 상태 |
| --- | --- | --- |
| 지형 높이 | 지형 모양과 지면 충돌 | 기존에는 30m 간격 자료를 사용합니다. 전달받은 공개 DEM 두 장은 90m 간격이라 더 세밀한 지형으로 바꾸는 데 쓸 수 없습니다. |
| 정사영상 | 지형 위에 입히는 실제 항공사진 | 아직 받지 않았습니다. |
| 건물·교량 3D | 외벽, 상판, 교각과 충돌 형상 | 실제 3D 원본은 없습니다. 공개 건물 외곽선만 있습니다. |

현재 프로그램은 지형 모양과 사진을 따로 읽습니다. 사진을 지형 메시의 재질로 자동 가져오지는 않으므로, 사진을 별도 이미지로 준비해야 합니다. 충돌은 화면 메시가 아니라 별도 높이 자료를 사용합니다. 화면만 실제 사진으로 바꾸면 충돌 지형은 그대로 남습니다.

## 정사영상과 더 세밀한 높이 자료 받기

국토지리정보원의 [정사영상 자료 안내](https://www.data.go.kr/data/15059919/fileData.do)에서 다운로드 경로를 확인한 뒤 [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에 접속합니다. 정사영상 안내에는 TIFF 형식, 로그인, 대용량 전송 프로그램 사용이 적혀 있습니다. 자료는 무료이며 이용 조건은 포털의 최신 안내와 내려받은 자료의 메타데이터를 따릅니다.

1. 통합검색에서 `탄천교`를 찾고 지도에서 필요한 구역을 지정합니다.
2. 검색 표시를 선택하고 `정사영상` 항목을 엽니다. 탄천을 덮는 최신 TIFF를 선택합니다. 촬영 연도와 실제 화소 크기는 항목별 상세정보에서 확인합니다. 제작 기준은 도시 지역 12cm급, 일반 지역 25cm급이지만, 해당 구역에 실제 제공되는 영상의 정보가 기준입니다.
3. 같은 구역에서 `공개DEM`도 확인합니다. 공개 DEM 자료는 IMG 형식이고 다운로드에 로그인이 필요합니다. 전달받은 두 장은 90m 간격이어서 현재 쓰는 30m SRTM보다 거칩니다. 90m 자료를 더 작은 격자로 보간해도 실제 지형 세부 정보는 늘지 않습니다.
4. 정밀한 제방·둔치 모양이 필요하면 공개 항목 중 가장 촘촘한 자료를 확인하고, 없으면 국토지리정보원에 해당 구역의 1m 또는 5m DEM 제공 여부와 이용 조건을 문의합니다. 전국 어디서나 해당 해상도의 자료를 받을 수 있는 것은 아닙니다. [국토지리정보원 자료 안내](https://www.ngii.go.kr/lib/file/pr_01.pdf)는 1m·5m·10m DEM 구축 사례와 공개 범위를 설명합니다.
5. 원본과 함께 좌표계, 높이 기준, 촬영·제작 시기, 해상도, 이용 조건을 보관합니다. 수평 좌표와 높이 기준이 맞지 않으면 화면과 충돌 위치가 어긋납니다.

## QGIS에서 지형 GLB와 사진 질감 만들기

[QGIS](https://qgis.org/download/)에 받은 높이 자료와 정사영상 TIFF를 불러옵니다. 플러그인 관리에서 [Qgis2threejs](https://plugins.qgis.org/plugins/Qgis2threejs/)를 설치합니다. 이 플러그인은 DEM을 지형 메시로 만들고 glTF 또는 GLB로 내보낼 수 있습니다. 플러그인은 내보낼 장면에 이미지 재질을 설정하는 기능도 제공합니다. [공식 내보내기 안내](https://minorua.github.io/Qgis2threejs/docs/3.1/Exporter.html)를 참고하세요.

1. 프로젝트 좌표계를 미터 단위로 설정하고, 정사영상과 높이 자료가 지도에서 정확히 포개지는지 확인합니다. 처음에는 탄천교 주변의 작은 구역만 잘라 사용합니다.
2. 높이 자료를 지형 표면으로 내보냅니다. 현재 기준점은 위도 37.4936231°, 경도 127.1018462°이고 높이 원점은 EGM96 기준 18m입니다. 지형 중심을 이 점에 맞추고, GLB 정점은 동쪽 X+, 위쪽 Y+, 북쪽은 화면의 Z- 방향으로 둡니다. 좌표 단위는 미터입니다. 멀리 떨어진 지도 좌표를 그대로 넣으면 정밀도가 떨어질 수 있습니다.
3. 지형 메시에는 위치, 법선, 삼각형, UV 좌표가 있어야 합니다. 현재 GLB 읽기는 메시 하나와 삼각형 묶음 하나를 받으며, 노드에 남은 위치·회전·크기 변환은 적용하지 않습니다. 내보낸 결과가 이 조건과 다르면 Blender에서 메시를 합치고 변환을 적용한 뒤 GLB로 다시 내보냅니다.
4. 정사영상 TIFF는 지형과 같은 경계로 자른 뒤 RGB PPM 이미지로 변환합니다. 현재 렌더러는 이 별도 사진을 메시의 UV 좌표에 맞춰 입힙니다. GLB 안에 들어 있는 재질 이미지는 읽지 않습니다. 확장자만 바꾸지 말고 실제 이미지 변환을 해야 합니다.
5. 먼저 2048×2048 크기로 시험합니다. RGB 사진은 이 크기에서 약 12MB입니다. 화면이 뒤집히거나 밀리면 지형의 UV 방향과 사진의 위·아래 방향을 함께 확인합니다. 큰 해상도는 원본에 그만큼의 세부 정보가 있을 때만 선명도를 높입니다.
6. 변환한 지형 메시와 사진을 저장소의 탄천 지도 자료 위치에 넣고 실행합니다. 화면에서 지형과 영상의 범위·방향을 확인합니다. 웹 빌드에도 같은 자료가 포함되는지 확인해야 합니다.

정사영상은 위에서 본 땅의 사진입니다. 지형 GLB에 입혀도 건물 외벽, 교량 상판, 교각, 난간은 만들어지지 않습니다. 화면에 실제 구조물을 보이려면 별도 3D 자료가 필요합니다.

## 건물과 교량 3D 자료 받기

서울시는 [S-Map에 서울의 건물·교량·지형 3D 정보를 구축](https://news.seoul.go.kr/gov/archives/528155)했다고 안내하지만, 지도에서 보이는 모델을 바로 GLB로 내려받아 공개해도 된다는 뜻은 아닙니다. [S-Map 오픈랩의 자료 제공 안내](https://openlab.eseoul.go.kr/mobile/qna.do)와 [공개제한 공간정보 공지](https://openlab.eseoul.go.kr/mobile/notice.do)를 확인해 탄천교와 주변 시설물의 원본 제공 가능 여부를 문의해야 합니다.

문의할 때는 다음을 확인합니다.

- 탄천교 주변 지형·건물·교량의 원본 3D 자료를 제공하는가?
- 좌표계, 높이 기준, 제작 시기는 무엇인가?
- GLB 변환과 화면·충돌 용도로 편집할 수 있는가?
- 웹 공개와 포트폴리오 배포가 허용되는가?
- 원본은 비공개로 두고 변환한 결과만 배포할 수 있는가?

건물 외곽선이 더 필요하면 [국토교통부 건물 통합정보](https://www.data.go.kr/data/15029175/standard.do)를 사용할 수 있습니다. 이 자료는 건물의 공간정보와 속성을 제공하지만, 외벽 사진이나 교량 3D 모델은 제공하지 않습니다.

## 화면과 충돌을 함께 맞추기

GLB는 화면에 보이는 지형 메시이고, 충돌 높이는 별도 지형 격자입니다. 두 자료를 같은 높이 자료와 같은 좌표·범위에서 만들어야 드론이 화면에서 보이는 지면과 같은 곳에서 충돌합니다. 현재 지형 GLB를 넣어도 기존 충돌 높이 격자는 자동으로 바뀌지 않습니다. 새 DEM으로 충돌 격자를 다시 만들기 전에는 화면과 충돌이 다른 자료를 쓴다는 점을 유지해야 합니다.

실제 지형과 항공사진을 연결하려면 정사영상 TIFF와 30m보다 촘촘한 DEM이 필요합니다. 현재 받은 90m DEM 두 장은 더 좋은 지형을 만들지 못합니다. 자료를 받으면 원본 메타데이터와 함께 전달해야 좌표·높이 기준을 맞추고 실제 지형 메시로 연결할 수 있습니다.
