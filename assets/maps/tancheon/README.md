# 탄천 지형·영상 자료 준비

## 현재 장면

현재 탄천 장면은 실제 지형과 구조물을 정밀하게 복원한 지도가 아닙니다. 공개 높이 자료로 만든 낮은 해상도의 지형, OpenStreetMap의 건물·도로·하천 윤곽을 바탕으로 한 시험용 장면입니다. 항공 정사영상과 실제 건물·교량 3D 모델은 아직 들어 있지 않습니다.

| 항목 | 현재 상태 | 실제 자료가 필요한 이유 |
| --- | --- | --- |
| 지형 높이 | 기존 30m SRTM 격자를 사용 | 제방과 도로 높이 차를 표현하기에 거침 |
| 지면 무늬 | 실제 항공사진 없음 | 하천·도로·수풀의 모습이 단색으로 보임 |
| 건물·교량 | 지도 윤곽으로 만든 단순 형상 | 외벽, 교각, 상판과 하부 공간이 실제와 다름 |
| 충돌 | 기존 지형 높이와 단순 건물 형상 사용 | 새 자료를 충돌 계산에 연결하지 않은 상태 |

목표는 자료 하나를 GLB로 바꾸는 데서 끝나지 않습니다. 높이 자료는 지형 모양과 지면 충돌에, 정사영상은 지면 색과 무늬에, 건물·교량 3D 자료는 구조물 표시와 별도 충돌 형상에 사용해야 합니다.

## 먼저 받을 자료

| 목적 | 받을 자료 | 확인할 항목 |
| --- | --- | --- |
| 제방·지형 높이 | 탄천을 덮는 가장 세밀한 DEM | 격자 간격, 좌표계, 표고 기준, 단위, 포함 범위 |
| 땅의 실제 색과 무늬 | 항공 정사영상 | 촬영 연도, 해상도, 좌표계, 저장·웹 배포 허용 범위 |
| 건물·교량의 입체 형상과 표면 무늬 | 사용 허가가 확인된 3D 모델과 원본 재질·텍스처 | 위치·높이 기준, 제작 시점, 파일 형식, 수정·재배포 조건 |

**정사영상은 위에서 본 사진입니다.** 지붕과 땅의 무늬는 보여 주지만 건물 외벽이나 교량 밑면의 질감은 제공하지 않습니다. 외벽까지 실제처럼 보이려면 사진이 입혀진 3D 모델이 따로 필요합니다.

## 국토정보플랫폼에서 DEM과 정사영상 찾기

[국토정보플랫폼 통합지도검색](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 탄천 구역을 직접 지정해 자료를 찾습니다.

1. 검색 도구에서 `영역`을 고른 뒤 `사각형`이나 `다각형`으로 탄천교 주변을 둘러쌉니다. 장소 이름만 검색하면 지도 위치만 바뀌고 자료 목록은 다른 지역을 가리킬 수 있습니다.
2. 자료 종류에서 먼저 `정사영상`을 고릅니다. 결과의 촬영 연도와 도엽 위치를 확인하고 `메타정보` 또는 미리보기로 탄천이 실제로 포함되는지 확인합니다.
3. 목록에 `수원/37709004`, `수원/37709005`처럼 탄천과 무관한 위치가 나오면 선택하지 않습니다. 현재 확인한 화면도 송파구 탄천교를 표시하면서 정사영상 결과는 수원 도엽을 보여 주므로, 해당 결과를 탄천 자료로 볼 수 없습니다.
4. 위치가 맞는 정사영상 중 해상도와 촬영 연도를 확인합니다. 항공사진 원본이나 화면 캡처가 아니라, 좌표 정보가 포함된 정사영상 원본을 받습니다.
5. 같은 방법으로 `공개DEM`을 검색해 탄천을 덮는 타일을 찾습니다. 공개 자료가 90m 격자라면 현재 30m SRTM보다 지형이 더 거칠 수 있으므로, 해상도를 확인한 뒤 교체 여부를 결정합니다.
6. 다운로드에 로그인이 필요하면 로그인 후 진행합니다. 파일을 받으면 압축을 풀지 않은 원본과 함께 제공된 설명·메타정보·사용 조건을 보관합니다.

국토지리정보원 안내 자료에는 90m DEM은 일반 공개, 더 세밀한 1m·5m DEM은 제한 자료로 분류된 이력이 있습니다. 실제 제공 범위와 신청 조건은 바뀔 수 있으므로 현재 포털의 자료 정보와 이용 조건을 기준으로 판단합니다. 높은 해상도 숫자만 보고 내려받지 말고, 자료의 실제 위치와 수직 기준을 먼저 확인해야 합니다.

사용자가 받은 두 공개 DEM 압축파일에는 각각 `.img` 자료가 들어 있습니다. 압축 안에 별도 좌표계 파일이 보이지 않으므로, 자료가 탄천을 덮는지와 픽셀 간격·좌표계·높이 기준을 QGIS의 레이어 정보에서 확인해야 합니다. 정보가 확인되기 전에는 현재 지형 자료를 대체하거나 충돌 높이 계산에 넣지 않습니다.

## 정사영상으로 지형 GLB 만들기

탄천 지형에 맞는 GLB는 보통 다운로드하는 완제품이 아닙니다. **DEM으로 땅의 높이를 만들고 정사영상으로 표면을 칠한 뒤 내보내는 결과물**입니다. 이 방식으로 만든 지형 GLB에는 지면의 높낮이와 위에서 본 사진 무늬가 들어가지만, 건물 외벽이나 교량 구조까지 자동으로 만들어지지는 않습니다.

### 준비

- QGIS와 [Qgis2threejs 플러그인](https://plugins.qgis.org/plugins/Qgis2threejs/)을 설치합니다.
- DEM과 정사영상의 위치가 실제로 겹치는지 확인합니다. 서로 다른 지역의 파일이면 같은 좌표계로 변환해도 맞지 않습니다.
- 두 자료의 좌표계와 높이 단위를 확인하고, 작업 범위를 탄천교 주변의 필요한 크기로 자릅니다.
- DroneSim의 기준점은 위도 37.4936231°, 경도 127.1018462°입니다. 시뮬레이터의 지역 좌표는 이 기준점에서 동쪽·북쪽으로 잰 미터 단위입니다. 원본 자료의 좌표와 표고 기준을 기록하고, GLB의 축·원점·단위를 이 기준에 맞춰야 합니다.

### QGIS에서 내보내기

1. QGIS에서 확인된 DEM과 정사영상을 엽니다. DEM은 지형 레이어로, 정사영상은 지도 화면의 배경 레이어로 둡니다.
2. 지도 화면을 DroneSim이 사용할 탄천 범위로 맞춥니다. 영역이 커질수록 메시와 이미지가 커지므로, 처음에는 교량을 포함한 작은 시험 구역만 선택합니다.
3. Qgis2threejs를 열어 DEM을 지형으로 추가합니다. 지형 재질에는 지도 화면을 입히거나 정사영상을 이미지 재질로 지정합니다.
4. 미리보기에서 하천·도로·교량 위치가 겹치는지 확인합니다. 높이 자료를 촘촘히 보간해도 원본 DEM보다 실제 지형이 정확해지는 것은 아닙니다.
5. `File → Save Scene As → glTF (.gltf,.glb)`로 내보냅니다. 내보낸 GLB를 Blender에서 열어 크기, 축, 원점, 재질과 텍스처 포함 여부를 확인합니다.
6. 변환에 쓴 DEM·정사영상·QGIS 설정과 출처·촬영 시기·이용 조건을 함께 보관합니다.

QGIS에서 만든 GLB를 현재 DroneSim에 바로 넣을 수는 없습니다. 당장은 정사영상만 지형 사진으로 적용할 수 있습니다. 이때 QGIS에서 DEM의 같은 지도 범위로 정사영상을 잘라 RGB 색상 영상으로 내보내고, `PPM` 형식을 선택합니다. 긴 변은 우선 2048픽셀 이하로 두고, 지형 격자와 영상의 범위·위아래 방향이 같은지 확인합니다. PNG나 JPEG의 확장자만 바꿔서는 읽을 수 없습니다. 이 방법은 지면 사진만 바꾸며, 지형 높이와 충돌 형상은 기존 자료 그대로입니다.

[Qgis2threejs 내보내기 안내](https://minorua.github.io/Qgis2threejs/docs/2.10/Exporter.html)에는 GLB 내보내기와 지형 재질 설정이 나옵니다. 지도 화면을 지형 표면에 입히면 도로·하천·수풀 등 지면 무늬를 담을 수 있습니다. 웹 게시나 저장소 공개 전에는 원본 자료의 이용 조건을 확인합니다.

## 실제 3D 건물·교량과 표면 텍스처

서울시 [S-Map](https://smap.seoul.go.kr/)에서는 서울의 3D 지도와 연도별 배경·건물을 볼 수 있습니다. 그러나 웹에서 보이는 장면을 캡처하거나 타일을 긁어 GLB·텍스처로 저장해도 된다는 뜻은 아닙니다.

S-Map의 원본 3D 자료 제공은 별도 확인이 필요합니다. [오픈랩 데이터 제공 FAQ](https://openlab.eseoul.go.kr/mobile/qna.do)에서 제공 자료의 종류·확장자와 신청 조건을 확인합니다. 서울시 안내상 공개 제한 공간정보는 법인 또는 사업자 신청과 보안 심사를 거쳐 제공될 수 있으므로, 개인 포트폴리오 용도로 바로 받을 수 있다고 가정하지 않습니다. 필요하면 서울시 공간정보과에 탄천교 주변 공개 가능 자료, 개인 이용 자격, 파일 형식, 웹 공개·재배포 허용 여부를 문의합니다.

자료를 요청할 때는 다음을 한 번에 확인합니다.

- 탄천교와 주변 건물·제방을 포함하는 원본 지형 또는 3D 모델을 받을 수 있는지
- 텍스처가 모델 내부에 들어 있는지, 별도 이미지로 제공되는지
- 원점·좌표계·수직 기준·단위와 제작 시기
- 수정, GitHub 저장소 포함, 웹 데모 배포가 각각 허용되는지

원본 모델을 받을 수 없다면 다음 선택은 지형 DEM과 정사영상으로 지면만 구성하고, 건물·교량은 공개 허가가 확인된 개별 모델이나 직접 만든 단순 형상으로 표시하는 것입니다. 이 경우 화면에서 실제 구조물과 같은 정밀도를 갖췄다고 표현하지 않습니다.

## DroneSim에 넣을 때의 현재 한계

현재 앱은 기존 지형 메시를 코드에서 만들고, 선택 사항인 탄천 지면 사진은 RGB PPM 형식으로 읽습니다. 건물·교량이 포함된 GLB 장면을 통째로 불러와 표시하거나, GLB 안의 재질·텍스처를 자동으로 적용하는 기능은 아직 없습니다. 지도 높이와 충돌 계산도 새 GLB나 DEM에서 읽지 않습니다.

따라서 QGIS에서 GLB를 만들었다고 지금 화면이나 충돌이 실제 지형으로 바뀌지는 않습니다. 실제 자료를 받은 뒤에는 먼저 DEM을 지형 표시와 충돌 높이에 함께 연결하고, 정사영상을 화면에 입히는 작업이 필요합니다. 그 다음 건물·교량 모델을 표시하고 단순화한 별도 충돌 형상을 연결해야 합니다. GLB를 렌더링 전용으로 먼저 넣으면 화면과 충돌 지도가 서로 달라질 수 있습니다.

정사영상은 현재 지면 사진용으로 변환할 수 있지만, GLB 전체 장면은 엔진의 현재 파일 읽기 제한 때문에 바로 쓸 수 없습니다. 실제 자료 파일이 확보되기 전에는 형식 변환이나 충돌 연결이 끝났다고 기록하지 않습니다.

## 출처와 확인 기준

- 지형·항공사진·정사영상: [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)
- DEM의 공개·제한 등급 참고: [국토지리정보원 안내 자료](https://www.ngii.go.kr/lib/file/pr_01.pdf). 오래된 안내이므로 현재 신청 조건은 포털에서 다시 확인합니다.
- 서울 3D 공간정보: [S-Map](https://smap.seoul.go.kr/) 및 [S-Map 오픈랩 FAQ](https://openlab.eseoul.go.kr/mobile/qna.do)
- 지형 GLB 내보내기: [Qgis2threejs 공식 플러그인](https://plugins.qgis.org/plugins/Qgis2threejs/)과 [내보내기 안내](https://minorua.github.io/Qgis2threejs/docs/2.10/Exporter.html)
- 건물·도로·하천 윤곽: OpenStreetMap. 배포 시 출처 표기와 ODbL 조건을 지킵니다.

자료를 장면에 반영한 뒤에는 지도 위 기준점 몇 곳의 위치와 높이를 원본 자료에 대조하고, 화면 형상과 충돌 형상이 같은 위치에 있는지 확인합니다. 출처·촬영 시기·좌표계·표고 기준·이용 조건도 이 문서에 기록합니다.
