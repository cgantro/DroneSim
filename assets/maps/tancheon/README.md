# 탄천 지형·항공사진 자료 준비

## 먼저 준비할 자료

탄천 지형을 실제 모습에 가깝게 보이게 하려면 높이 자료와 항공사진이 모두 필요합니다.

| 자료 | 화면에 쓰는 곳 | 지금 확인된 내용 |
| --- | --- | --- |
| DEM(지형 높이) | 땅의 높낮이와 지형 충돌 | 받은 두 공개 DEM은 모두 90m 간격입니다. 현재 시뮬레이터의 30m 격자보다 거칠어 대체 자료로 쓰지 않습니다. |
| 정사영상(TIFF) | 지형 표면의 색과 무늬 | 국토지리정보원에서 내려받을 수 있습니다. 탄천 자료의 촬영일·실제 해상도는 검색 결과에서 확인해야 합니다. |
| 건물·교량 3D 원본 | 외벽·상판·교각의 입체 표현 | S-Map 원본 제공 여부와 사용 허가를 별도로 문의해야 합니다. |

정사영상은 위에서 본 사진입니다. 땅에 사진을 입히면 도로·하천·건물 지붕은 보이지만 건물 옆면이나 교량 아래가 생기지는 않습니다. 지형 GLB와 건물·교량 모델은 서로 다른 자료입니다.

## 자료를 받을 곳

### 탄천의 정사영상과 DEM

[국토정보플랫폼 통합지도검색](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 자료를 받을 수 있습니다. [정사영상 설명](https://www.data.go.kr/data/15059919/fileData.do)에는 TIFF 형식, 무료 제공, 다운로드 로그인 필요, 대용량 파일 전송 프로그램 필요라고 안내되어 있습니다. 자료 설명에는 도심 지역 12cm, 일반 지역 25cm 해상도로 제작한다고 나와 있지만, 탄천에서 받을 수 있는 자료의 촬영일과 픽셀 크기는 검색 결과의 메타정보가 기준입니다.

1. 국토정보플랫폼에 로그인하고 검색창에 `탄천교`를 입력합니다.
2. 검색 결과에서 위치를 선택하고 지도에 표시된 결과 마커를 엽니다.
3. 자료 종류에서 **정사영상**을 고릅니다. 항공사진 원본이 아니라 지형 왜곡을 보정한 정사영상을 받습니다.
4. 탄천교와 주변 비행 구역이 들어가는 도엽을 선택합니다. 자료 날짜, 픽셀 크기, 좌표계와 파일 크기를 확인합니다.
5. TIFF 원본과 함께 내려받은 메타정보를 보관합니다. 대용량 전송 프로그램을 설치하라는 안내가 나오면 국토정보플랫폼의 공식 안내를 따릅니다.

정사영상 자료 설명에는 이용허락 범위가 제한 없음으로 표시되어 있습니다. 실제 파일을 받을 때 표시되는 조건과 출처 표기 안내도 함께 확인하세요.

공개 DEM은 같은 지도 검색에서 **공개DEM**을 선택해 받습니다. 이번에 받은 `37705`, `37709` 두 타일은 실제 파일을 검사한 결과 모두 90m 격자였습니다. `37709`에 현재 지도 중심이 들어가며, `37705`는 인접한 북쪽 구역입니다. 두 타일을 촘촘한 격자로 다시 저장해도 높이 정보가 새로 생기지는 않습니다. 1m·5m급 DEM이 필요하면 국토지리정보원이나 서울시에 별도 제공 가능 여부와 신청 조건을 문의해야 합니다. [DEM 자료 설명](https://www.data.go.kr/data/15059920/fileData.do)

`KNGeoid24`는 지오이드 기준 높이와 타원체 기준 높이를 맞출 때 쓰는 자료입니다. 지표 높이가 들어 있는 DEM은 아닙니다. 높이 기준을 확인하기 전에는 서로 다른 자료의 고도를 섞지 마세요.

### 실제 3D 지형·건물·교량

서울시는 S-Map에 지형과 건물, 교량·고가 같은 시설물을 포함한 3D 공간정보가 있다고 안내합니다. 다만 지도 화면에 보이는 모델이 곧바로 내려받을 수 있는 GLB라는 뜻은 아닙니다. [S-Map 자료 제공 FAQ와 문의 게시판](https://openlab.eseoul.go.kr/mobile/qna.do)에서 탄천교 주변 원본 제공 여부를 먼저 확인하세요. FAQ의 문의처는 서울시 공간정보과 공간정보운영팀(02-2133-2852)입니다.

문의할 때는 다음 항목을 한 번에 확인합니다.

- 탄천교 주변 지형, 건물, 교량의 원본 자료가 있는지
- 받을 수 있는 형식과 GLB 변환 허용 여부
- 항공사진·표면 텍스처가 포함되는지, 별도 파일인지
- 좌표계, 기준점, 축 방향, 단위, 수직 기준과 제작 시점
- 편집, 개인 포트폴리오, GitHub 저장소, 웹 공개를 각각 허용하는지

S-Map 오픈랩 약관은 서울시 데이터 사용 시 출처를 표시하도록 하고, 제3자 권리가 포함된 자료에는 별도 조건이 적용된다고 안내합니다. 공개제한 공간정보는 법인 또는 사업자 신청과 보안 심사가 필요할 수 있습니다. 신청 자격과 재배포 허용 범위를 답변으로 확인하기 전에는 S-Map 화면이나 지도 타일을 모아 원본 모델처럼 사용하지 않습니다. [공개제한 자료 안내](https://openlab.eseoul.go.kr/mobile/notice.do)

## 정사영상으로 지형 GLB와 지면 사진 만들기

공개 자료만으로 지금 바로 만들 수 있는 현실적인 결과는 **DEM으로 굴곡을 만들고, 정사영상으로 지표면 색을 입힌 지형**입니다. QGIS와 Qgis2threejs 플러그인을 사용합니다. 플러그인은 DEM을 지형 메시로 만들고 GLB/glTF로 내보낼 수 있습니다. [QGIS 설치](https://qgis.org/download/) · [Qgis2threejs 설치 정보](https://plugins.qgis.org/plugins/Qgis2threejs/) · [GLB 내보내기 안내](https://minorua.github.io/Qgis2threejs/docs/3.1/Exporter.html)

1. QGIS를 설치한 뒤 **플러그인 관리**에서 Qgis2threejs를 설치합니다.
2. 받은 DEM과 정사영상 TIFF를 불러옵니다. 두 레이어가 지도에서 겹치는지, 좌표계가 무엇인지 확인합니다. 좌표계가 다르면 레이어를 재투영해 같은 미터 단위 좌표계로 맞춥니다. 좌표계 이름만 바꾸면 위치는 변환되지 않습니다.
3. 탄천교 주변의 작업 범위를 정하고 DEM과 정사영상을 같은 사각형으로 자릅니다. 먼저 작은 구역으로 시험합니다.
4. Qgis2threejs에서 DEM 지형만 선택해 GLB로 내보냅니다. 현재 GLB 로더는 노드 하나·메시 하나·삼각형 묶음 하나만 읽고, GLB 안의 재질과 그림은 사용하지 않습니다. 다른 지도 레이어를 함께 내보내지 말고, 저장한 GLB가 이 형식에 맞는지 확인합니다.
5. GLB의 위치와 방향을 현재 장면 기준에 맞춥니다. 기준점은 위도 37.4936231°, 경도 127.1018462°이고, 모델 좌표는 동쪽이 X+, 위쪽이 Y+, 남쪽이 Z+인 미터 단위의 지역 좌표여야 합니다. GLB에 노드 이동·회전·크기 값이 남아 있으면 현재 로더가 적용하지 못합니다. 필요하면 Blender에서 축과 원점을 맞추고 변환을 적용한 뒤 다시 내보냅니다.
6. 같은 범위의 정사영상은 QGIS에서 RGB 8비트 PPM(P6)으로 내보냅니다. 프로그램은 지형 사진 파일을 `assets/maps/tancheon/terrain.ppm`에서 읽습니다. 파일 확장자만 바꾸지 말고 실제 형식을 PPM으로 변환합니다. [GDAL PNM 형식 안내](https://gdal.org/en/stable/drivers/raster/pnm.html)
7. GLB와 PPM을 함께 넣어 실행한 뒤 지형의 북쪽 방향, 사진 위치, 높이와 가장자리 연결을 확인합니다. 사진이 뒤집히거나 밀리면 GLB의 UV 방향과 QGIS 내보내기 범위를 맞춥니다.

지형 모델 파일은 `assets/maps/tancheon/terrain.glb`에서 읽습니다. GLB가 없으면 현재 30m 높이 격자로 지형을 만듭니다. 프로그램은 별도 PPM 사진을 지형에 입히며, GLB 안에 넣은 그림은 읽지 않습니다. CMake는 이 두 파일이 있으면 웹 빌드 자료에도 포함합니다.

PPM은 압축되지 않습니다. 2048×2048 RGB 파일은 약 12MB이고, 4096×4096은 약 48MB입니다. 처음에는 2048×2048로 잘라 화면과 웹 로딩을 확인하세요. 큰 원본을 그대로 넣으면 웹 내려받기 용량이 커집니다.

## 화면과 충돌이 같은 지형을 가리키게 하기

현재 화면 지형은 `terrain.glb`가 있으면 그 메시를 그립니다. 충돌은 별도의 30m 높이 격자를 사용하므로 화면과 충돌 지형의 높이가 다를 수 있습니다. 정사영상은 색과 무늬만 바꾸며 충돌에는 영향을 주지 않습니다.

건물 충돌은 높이 출처에 따라 다르게 처리합니다. OSM에 실제 높이값이 있는 건물은 외곽선과 높이를 사용한 3D 충돌체로 등록합니다. 높이가 없거나 층수로 높이를 추정한 건물은 높이를 확인할 수 없으므로, 모든 고도에서 통과할 수 없는 수평 비행 금지 구역으로 처리합니다. 이는 누락을 막기 위한 보수적인 가정이며 실제 건물 높이나 입체 충돌을 재현한 결과는 아닙니다. 자동 경로도 같은 건물 외곽선을 피합니다.

교량은 OSM 외곽선만으로 실제 상판 높이와 교각 위치를 알 수 없습니다. 현재 교량은 화면에 선과 외곽선으로 보이지만 충돌체는 아닙니다. 높이·폭·상판 아래 공간을 확인할 수 있는 자료를 받으면 그 값으로 별도 충돌 형상을 만들어야 합니다. `layer=1` 같은 지도 태그는 미터 단위 높이가 아니므로 높이값으로 쓰지 않습니다.

정밀 DEM을 확보한 뒤에는 화면 GLB를 만든 원본 DEM과 같은 표고 자료로 충돌 격자도 갱신해야 합니다. 기준 좌표, 수직 기준, 격자 간격을 맞추고 여러 지점의 원본 표고와 시뮬레이터 표고를 비교합니다. 현재는 실제 DEM과 충돌 격자가 연결되어 있지 않으므로, GLB가 실제 지형처럼 보여도 지형 충돌까지 정확하다고 볼 수 없습니다.

파일을 프로젝트나 웹 공개본에 포함하기 전에 원본 데이터의 이용 조건을 확인하고, 출처·촬영 시기·해상도·좌표계·높이 기준을 기록합니다. S-Map 자료라면 서울시 출처 표기와 제3자 권리 조건도 따릅니다.

## 지금 필요한 자료

우선 [국토정보플랫폼에서 탄천교 주변 정사영상 TIFF](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)를 내려받아 이 대화에 첨부해 주세요. 로그인 후 **정사영상**을 선택하고, 가장 최근 촬영 자료 중 탄천교와 주변 비행 구역이 포함된 파일을 받으면 됩니다. `37705`, `37709` DEM은 이미 확인했고 둘 다 90m라 더 세밀한 지형을 만들 자료로는 부족합니다. 더 정밀한 DEM이나 실제 교량 GLB는 서울시·국토지리정보원에서 제공 여부와 사용 허가를 확인해야 합니다.
