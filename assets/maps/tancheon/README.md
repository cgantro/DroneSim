# 탄천 장면에 실제 지형과 항공사진 적용하기

## 지금 장면에 들어간 자료

현재 장면은 약 30m 간격 높이 격자로 땅을 그리고 충돌을 계산합니다. 건물은 공개 외곽선과 높이 자료를 단순한 입체 모양으로 표시합니다. 탄천의 항공사진 질감과 상세한 건물·교량 모델은 아직 연결하지 않았습니다.

실제 모습에 가까워지려면 자료 세 가지가 필요합니다.

| 자료 | 쓰임 | 현재 상태 |
| --- | --- | --- |
| 고도 자료(DEM) | 땅의 높낮이와 지면 충돌 | 받은 두 도엽은 90m 간격이라 세부 지형에 부족합니다. |
| 정사영상 | 지면에 입힐 항공사진 질감 | 아직 받지 않았습니다. |
| 건물·교량 3D 자료 | 외벽, 교량 상판·교각과 충돌 | S-Map에 자료가 있는지 확인해야 합니다. |

정사영상은 위에서 본 사진이라 건물 옆면이나 교량 밑면을 만들지 않습니다. 지형 높이를 촘촘히 표현하려면 DEM이, 실제 구조물 모양을 보이려면 별도 3D 자료가 필요합니다.

## 1. 가장 먼저 받을 자료

### 실제 건물·교량 모델

[S-Map 오픈랩 Q&A](https://openlab.eseoul.go.kr/mobile/qna.do)에는 `3D 실외 입체모형 데이터 제공 신청`, `한강 교량 3D 실외 입체모형 데이터 제공 문의`, `3차원 지형 및 건물 데이터 제공 문의` 사례가 올라와 있습니다. 자료 제공 FAQ를 먼저 읽고, 로그인 후 Q&A에서 탄천교 주변 자료를 직접 요청합니다. 웹 지도에 보이는 모델을 곧바로 내려받을 수 있다고 가정하지 않습니다.

요청할 때 아래 내용을 함께 적습니다.

- 대상: 탄천교 주변 약 1.2km × 1.2km
- 목적: C++ 드론 시뮬레이터의 화면 표시와 충돌 검증
- 필요한 자료: 지형 메시, 교량·건물 메시, 가능하면 항공사진 질감
- 바라는 형식: 질감이 포함된 GLB 또는 OBJ와 원본 질감 이미지
- 좌표 기준: EPSG:5179 등 평면 좌표계, 높이 기준, 미터 단위
- 함께 확인할 내용: 자료 제작 시기, 위치 정확도, 수정 가능 여부, 웹 공개와 재배포 허용 범위

문의 글은 아래처럼 작성하면 됩니다.

> DroneSim에서 사용할 탄천교 주변 3D 공간자료를 찾고 있습니다. 약 1.2km × 1.2km 범위의 지형, 건물, 교량 메시와 질감 자료가 있는지 확인 부탁드립니다. 개발용 시뮬레이터의 화면 표시와 충돌 검증에 사용할 예정입니다. 제공 가능한 원본 형식, 좌표계와 높이 기준, 제작 시기, 자료 수정 및 GitHub Pages 공개 가능 여부도 알려주세요.

GLB를 바로 받을 수 없다면 OBJ·FBX·CityGML 등 제공 가능한 원본 형식과 변환 허용 범위를 먼저 물어봅니다. 3D 타일처럼 웹 화면 전용으로 제공되는 자료는 현재 시뮬레이터가 직접 읽지 못하므로, 원본 메시 제공을 요청해야 합니다. 서울시 S-Map 담당 부서(02-2133-2835)에도 문의할 수 있습니다. 서울시가 드론으로 만든 3D 모델과 정사영상 자료는 [드론공간정보 담당 부서](https://news.seoul.go.kr/gov/archives/528178)(02-2133-2843)에 확인합니다.

### 지형 높이 자료

[국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 탄천교를 검색하고 `공개DEM`을 선택해 대상 구역의 도엽을 받습니다. 현재 받은 두 도엽은 90m 격자입니다. 넓은 지형의 높이를 확인하는 데는 쓸 수 있지만 제방·도로·교량 주변 지형을 자세히 표현하지는 못합니다.

더 촘촘한 높이가 필요하면 같은 구역의 1m 또는 5m DEM 제공 여부와 신청 조건을 국토지리정보원에 문의합니다. 과거 국토지리정보원 안내 자료는 1m·5m DEM 일부를 공개 제한 자료로 분류했습니다. 따라서 누구나 내려받을 수 있다고 단정하지 않습니다. S-Map에 지형 메시가 준비되어 있는지도 함께 문의합니다.

### 항공사진 질감

같은 국토정보플랫폼에서 탄천교를 검색한 뒤 지도 오른쪽의 검색 표시를 선택하고 `정사영상`을 고릅니다. 촬영 연도와 내려받을 수 있는 해상도를 먼저 확인합니다. 내려받을 때는 로그인이 필요하고, 대용량 전송 프로그램을 설치하라는 안내가 나올 수 있습니다. 공공데이터포털은 TIFF 제공과 도시 지역 12cm·일반 지역 25cm 항공사진을 활용한 제작을 안내합니다. 다만 12cm 영상은 공간정보 보안 규정에 따라 온라인에서 내려받지 못할 수 있습니다. 검색 결과에 25cm 자료만 있거나 자료 신청이 필요한 경우도 있으니, 선택한 도엽의 제공 조건을 기준으로 준비합니다. 공공데이터포털에는 무료·이용허락 제한 없음으로 표시되어 있어도, 지역별 공개 제한과 별도 보안 규정은 확인해야 합니다.

온라인 지도 화면을 캡처해 항공사진 대신 쓰지 않습니다. 원본 해상도와 이용·재배포 조건을 확인할 수 없기 때문입니다.

## 2. GLB와 질감 파일 만들기

자료를 받은 뒤 QGIS에서 DEM과 정사영상을 함께 열어 같은 위치에 놓이는지 확인합니다. 두 자료를 같은 좌표계와 같은 사각형 범위로 자릅니다. 높이 과장은 1로 두고, 처음에는 약 1.2km 구역만 만듭니다.

### QGIS에서 지형 메시 내보내기

QGIS에서 다음 순서로 준비합니다. 메뉴 이름은 설치 언어에 따라 조금 다를 수 있습니다.

1. DEM과 정사영상 TIFF를 불러옵니다. 프로젝트 좌표계를 EPSG:5179로 맞추고 두 자료가 겹치는지 확인합니다.
2. 처리 도구의 `래스터를 마스크 레이어로 자르기` 또는 범위 자르기를 사용해 두 자료를 같은 1.2km 사각형으로 자릅니다. 출력 해상도는 원본 DEM보다 촘촘하게 지정하지 않습니다.
3. `보기 → 3D 지도 보기 → 새 3D 지도 보기`를 엽니다. 3D 설정에서 지형 높이 자료는 DEM, 지도 질감은 정사영상이 표시된 2D 지도 화면으로 지정합니다. 수직 배율은 1로 둡니다.
4. 3D 지도 화면의 내보내기 메뉴에서 `3D 장면 내보내기`를 선택합니다. 지형과 질감 내보내기를 켜고, 메시·질감 해상도와 저장 폴더를 지정해 OBJ와 이미지 파일을 만듭니다.

QGIS는 지형과 벡터 요소를 OBJ로 내보내며 지형·질감 해상도를 지정할 수 있습니다. [QGIS 3D 지도 안내](https://docs.qgis.org/latest/en/docs/user_manual/map_views/3d_map_view.html#export-3d-scenes)에서 내보내기 항목을 확인할 수 있습니다.

QGIS 플러그인 [Qgis2threejs](https://plugins.qgis.org/plugins/Qgis2threejs/)도 DEM·벡터 자료를 3D로 만들고 glTF 형식으로 내보냅니다. 다만 이 프로그램의 출력이 현재 시뮬레이터가 바로 읽을 수 있는 구조라는 뜻은 아닙니다. 현재 GLB 읽기는 **노드 하나, 메시 하나, 삼각형 묶음 하나**를 요구합니다.

QGIS에서 OBJ나 glTF를 내보낸 뒤 Blender에서 지형만 남기고 하나의 메시로 합칩니다. 여러 조각이 서로 다른 재질을 쓰면 사진을 한 장으로 굽고 재질도 하나로 정리합니다. 위치·회전·크기 변환을 메시 정점에 적용한 뒤 GLB로 내보냅니다. UV 좌표, 법선, 삼각형 번호가 있어야 합니다. 곡선·선·카메라 같은 다른 요소는 지형 메시에서 제외합니다. [Blender GLB 내보내기 안내](https://docs.blender.org/manual/en/4.2/addons/import_export/scene_gltf2.html)

### 좌표를 시뮬레이터 기준에 맞추기

시뮬레이터 지도 원점은 위도 37.4936231°, 경도 127.1018462°입니다. 수평 좌표는 동쪽 X, 높이는 위쪽 Y, 북쪽은 음수 Z로 표현합니다. 원본이 동쪽·북쪽·높이 `(E, N, H)`라면 GLB 좌표는 `(E-E0, H, -(N-N0))`입니다. 현재 화면과 충돌 계산은 DEM의 기준 높이를 포함한 높이값을 사용하므로, GLB에서 임의의 높이를 빼면 안 됩니다. 모든 값은 미터 단위여야 합니다.

E0·N0은 원점 위도·경도를 원본의 평면 좌표계로 변환한 값입니다. GLB 높이는 충돌 격자와 같은 수직 기준의 절대 높이를 씁니다. 자료가 타원체고인지 정표고인지 확인하고, 서로 다르면 변환 자료를 적용해야 합니다. GLB와 정사영상의 범위·축 방향·수직 기준이 하나라도 다르면 사진이 밀리거나 드론이 보이는 지면을 뚫고 지나갑니다.

### 사진 질감을 현재 형식으로 준비하기

현재 시뮬레이터는 GLB 안에 든 사진이나 재질을 읽지 않습니다. GLB의 UV 좌표를 사용해 별도의 PPM 사진을 그립니다. 최종 결과는 `assets/maps/tancheon/terrain.glb`와 `assets/maps/tancheon/terrain.ppm`에 둡니다. 웹 빌드는 이 두 파일이 있으면 자산에 포함합니다. 따라서 GLB에 사진을 포함하는 것만으로는 화면에 나타나지 않습니다.

QGIS에서 GLB와 같은 범위로 자른 정사영상을 8비트 RGB 이미지로 내보냅니다. 처음에는 2048×2048 픽셀 정도로 시작합니다. 1.2km 구역 전체에 적용하면 한 픽셀이 약 0.6m라 가까운 교량 표면의 세부 질감에는 부족할 수 있습니다. 교량 주변을 작게 자른 고해상도 질감을 따로 만들면 더 선명하게 보입니다.

이미지 편집 프로그램에서 RGB·8비트·무압축 PPM 형식으로 저장합니다. GIMP에서는 `파일 → 다른 이름으로 내보내기`에서 PPM을 고릅니다. 형식 표시는 `P6`, 최대 색상값은 `255`여야 합니다. 사진과 GLB는 같은 영역으로 잘라야 하며, 위아래 방향도 맞춰야 합니다. 화면에서 도로·하천·건물 모서리를 비교해 사진이 뒤집히거나 밀리지 않았는지 확인합니다.

## 3. 충돌 지형도 같은 자료로 갱신하기

화면 지형과 충돌 지형은 서로 다른 자료를 읽습니다. 화면은 GLB 메시를, 지면 충돌은 높이 격자를 사용합니다. 따라서 화면만 바꾸면 드론은 예전 지형 높이로 충돌합니다.

QGIS에서 GLB와 같은 DEM·범위·수직 기준으로 충돌용 높이 격자를 다시 만듭니다. 격자 간격을 30m에서 더 촘촘하게 바꿔도 원본 DEM의 해상도가 그대로라면 실제 지형 정보가 늘지는 않습니다. 현재 받은 90m 자료를 보간해 1m 격자로 바꾸는 것도 정확도를 높이지 않습니다.

## 4. 자료를 받기 전후 확인할 점

- S-Map에서 해당 구역의 원본 메시를 제공하는지, 웹 타일만 제공하는지 확인합니다.
- DEM, 정사영상, 3D 모델의 좌표계·높이 기준·제작 시기·정확도를 기록합니다.
- 자료를 수정해 GLB·질감으로 변환할 수 있는지, GitHub Pages에 올려도 되는지 확인합니다.
- GLB에 삼각형 메시 하나와 UV가 있는지 확인합니다.
- GLB와 PPM 사진의 영역과 방향이 일치하는지 확인합니다.
- 화면 메시와 충돌 격자가 같은 DEM과 같은 높이 기준을 쓰는지 확인합니다.
