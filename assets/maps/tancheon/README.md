# 탄천 실제 지형과 영상 자료 준비

## 먼저 알아둘 점

탄천의 실제 지형을 GLB로 얻는 방법은 **높이 자료와 항공 정사영상을 겹쳐 GLB를 만드는 것**입니다. GLB 완제품을 바로 내려받는 방식이 아닙니다.

필요한 자료는 목적에 따라 다릅니다.

| 만들고 싶은 결과 | 필요한 자료 | 얻을 수 있는 것 |
| --- | --- | --- |
| 땅의 높낮이 | DEM | 지형 메시와 지면 높이 |
| 땅의 색과 무늬 | 항공 정사영상 | 지형 위에 입힐 사진 |
| 건물 외벽과 교량의 입체 모습 | 실제 3D 모델과 재질·텍스처 | 지붕뿐 아니라 옆면과 아래쪽 구조 |

DEM과 정사영상을 합치면 지형 GLB와 사진 질감을 만들 수 있습니다. 이 조합만으로 건물의 외벽이나 교량 밑면까지 실제처럼 만들 수는 없습니다. 그런 모습은 사진이 입혀진 3D 모델을 별도로 받아야 합니다.

## 현재 확보한 자료와 현재 화면

현재 장면은 30m 간격 SRTM 높이 격자와 OpenStreetMap 윤곽을 사용한 시험용 장면입니다. 실제 항공사진 질감이나 정밀한 교량·건물 모델은 아직 연결하지 않았습니다.

사용자가 받은 공개 DEM은 EPSG:5179 좌표계의 90m 격자입니다. 현재 장면에 쓰는 30m SRTM보다 거칠고 높이 기준 정보도 없어 교체 자료로 쓰지 않았습니다. 두 타일이 탄천교 주변을 모두 덮는지도 QGIS 지도에서 확인해야 합니다. 현재 화면은 30m SRTM 격자를 사용합니다.

현재 프로그램은 지형을 자체 높이 격자에서 만들고, 땅 사진은 PPM 형식으로 읽습니다. 일반적인 지형 GLB와 GLB 안의 재질·텍스처를 불러오는 기능은 아직 없습니다. 따라서 GLB를 만들어도 현재 프로그램 화면에 자동으로 반영되지는 않습니다.

## 자료를 받을 곳

### 지형 높이와 지면 사진

[국토정보플랫폼 통합지도검색](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 탄천교 주변을 기준으로 자료를 찾습니다.

1. 지도에서 탄천교 주변으로 이동하고, 자료 검색 범위를 탄천교와 필요한 비행 구역을 포함하도록 지정합니다.
2. 지형 높이는 `공개DEM`, 지면 사진은 `정사영상`을 선택합니다. `항공사진` 원본보다 지도처럼 보정된 정사영상을 받습니다.
3. 검색 결과의 도엽 위치와 지도 미리보기가 송파구 탄천을 가리키는지 확인합니다. 검색어로 위치만 이동한 상태와 자료의 실제 위치는 다를 수 있습니다.
4. 정사영상은 촬영 연도와 픽셀 크기를 확인하고, DEM은 격자 간격·좌표계·표고 기준을 확인합니다. 원본과 메타정보를 함께 보관합니다.
5. 파일 내려받기에 로그인이 요구되면 국토정보플랫폼 계정으로 로그인합니다. 미리보기에서 보인다는 이유만으로 원본 다운로드와 웹 재배포까지 허용된다고 판단하지 않습니다.

받은 DEM은 QGIS에서 열어 다음을 확인합니다.

- 지도 범위가 송파구 탄천과 겹치는지
- 좌표계와 단위가 무엇인지
- 가로·세로 격자 간격이 얼마인지
- 높이가 어떤 기준면을 따르는지
- 빈 값이나 끊긴 경계가 있는지

확인 전에는 기존 지형이나 충돌 계산을 이 자료로 바꾸지 않습니다. 특히 격자를 촘촘하게 다시 저장해도 원본 자료의 실제 정확도가 높아지지는 않습니다.

### 건물 외벽과 교량의 실제 3D 모델

서울시는 [드론 공간정보 구축 사업](https://news.seoul.go.kr/gov/archives/528178)에서 정사영상, 비스듬히 촬영한 사진, 3D 건물 모델을 만들고 일부 지역을 S-Map에 반영한다고 안내합니다. 탄천 자료가 있는지와 원본을 받을 수 있는지는 별도 문의가 필요합니다. [S-Map](https://smap.seoul.go.kr/) 화면에서 보이는 모델을 캡처하거나 타일로 저장하지 말고, 원본 자료의 제공 조건과 웹 공개 권한을 확인합니다.

[S-Map 오픈랩 데이터 제공 안내](https://openlab.eseoul.go.kr/mobile/qna.do)와 [공개제한 공간정보 안내](https://openlab.eseoul.go.kr/mobile/notice.do)를 확인한 뒤, 탄천교 주변 자료의 제공 가능 여부를 문의합니다. 서울시 안내에는 공개제한 자료를 받으려면 법인 또는 사업자 신청과 보안 심사가 필요한 경우가 있다고 나옵니다. 개인이 포트폴리오에 쓰거나 공개 웹에 올릴 수 있는지는 별도로 확인해야 합니다.

문의할 때는 아래 내용을 한 번에 확인합니다.

- 탄천교와 주변 지형·건물의 3D 원본을 제공하는지
- 탄천교 주변의 정사영상이나 비스듬한 항공사진이 있는지
- 받을 수 있는 형식이 GLB인지, 다른 형식이면 GLB로 변환해도 되는지
- 건물·교량 표면 텍스처가 포함되는지, 별도 이미지인지
- 좌표계·원점·높이 기준·단위와 제작 시점
- 편집, 저장소 포함, 웹 배포, 포트폴리오 게시가 각각 허용되는지

## DEM과 정사영상으로 지형 GLB 만들기

QGIS와 [Qgis2threejs 플러그인](https://plugins.qgis.org/plugins/Qgis2threejs/)을 사용하면 DEM 지형에 정사영상을 입혀 GLB로 내보낼 수 있습니다. Qgis2threejs는 지형의 재질에 지도 화면 레이어나 이미지 파일을 지정하고, 장면을 `.gltf` 또는 `.glb`로 저장할 수 있습니다. [플러그인 안내](https://minorua.github.io/Qgis2threejs/docs/2.10/Exporter.html)

### 준비

1. [QGIS 공식 다운로드](https://qgis.org/download/)에서 QGIS를 설치합니다.
2. QGIS 플러그인 관리에서 설치한 QGIS 버전과 맞는 Qgis2threejs를 설치합니다.
3. 받은 DEM과 정사영상을 QGIS에 불러옵니다.
4. 두 자료의 좌표계를 확인하고, 위치가 맞지 않으면 같은 미터 단위 좌표계로 변환합니다. 변환 뒤에도 서로 다른 지역의 자료가 겹쳐지지는 않으므로 지도에서 탄천교 위치를 확인합니다.
5. 작업 범위를 필요한 구역으로 자릅니다. 먼저 탄천교와 접근 구간만 포함한 작은 범위로 내보내 파일 크기와 모양을 확인합니다.

### 내보내기

1. QGIS 지도에서 정사영상과 필요한 선·면 레이어를 표시하고, DEM을 지형 레이어로 준비합니다.
2. Qgis2threejs에서 DEM을 지형으로 추가합니다.
3. 지형 재질에서 지도 화면 레이어를 사용하도록 설정합니다. 이 설정은 정사영상의 색을 지형 표면에 입힙니다.
4. 지형의 높이 배율은 실제 높이에 맞게 둡니다. 미리보기에서 하천·교량·도로 위치가 겹치는지 확인합니다.
5. 장면을 `.glb`로 저장합니다. 저장한 결과를 3D 뷰어에서 열어 지형의 위치·방향·높이와 텍스처가 함께 들어갔는지 확인합니다.
6. 사용한 DEM, 정사영상, 작업 범위, 좌표계, 높이 기준, 촬영 연도와 이용 조건을 기록합니다.

이 결과는 **사진이 입혀진 땅의 표면**입니다. 정사영상이 위에서 촬영한 사진이므로 건물 옆면·교각·교량 아래쪽은 만들지 않습니다. 실제 입체 구조가 필요하면 제공 허가가 확인된 3D 모델을 더해야 합니다.

## 텍스처를 따로 준비할 때

현재 프로그램의 지면 사진 입력은 RGB PPM 형식입니다. QGIS에서 정사영상을 DEM과 같은 좌표계·범위로 자른 뒤, `래스터 → 변환 → 형식 변환`에서 PPM/PNM으로 내보내면 기존 지면 텍스처 경로에 사용할 수 있습니다. 출력은 8비트 RGB여야 합니다. GDAL은 이진 PPM을 만들 수 있으며, 프로그램은 P6·최대값 255 형식을 읽습니다. [GDAL PNM 안내](https://gdal.org/en/stable/drivers/raster/pnm.html) PNG나 JPEG 파일의 확장자만 바꾸는 방식은 변환이 아닙니다.

텍스처가 지형과 어긋나지 않도록 DEM과 같은 좌표계·범위·방향으로 잘라야 합니다. 크기를 줄일 때는 원본을 덮어쓰지 말고 별도 결과를 만들어 확인합니다. 지면 텍스처만 바꾸면 화면의 색과 무늬만 달라지고, 지형 높이와 충돌 형상은 그대로입니다.

GLB에 포함된 텍스처를 현재 프로그램에서 읽으려면 별도의 일반 GLB 장면 로딩과 재질 처리 기능이 먼저 필요합니다. 현재 드론 모델을 읽는 기능을 지형 GLB도 지원한다고 볼 수 없습니다.

## 화면·충돌·자료 허가 확인

자료를 프로그램에 넣기 전에 아래를 점검합니다.

| 확인 | 기준 |
| --- | --- |
| 위치 | DEM, 정사영상, 건물·교량 모델이 탄천의 같은 구역을 가리킴 |
| 좌표 | 기준점과 동·북·위 방향, 미터 단위가 프로그램과 일치함 |
| 높이 | DEM과 구조물의 높이 기준이 일치하거나 변환 근거가 있음 |
| 표면 사진 | 정사영상의 촬영 연도와 해상도를 알고 있음 |
| 입체 모델 | GLB와 텍스처의 출처, 제작 시점, 사용 허가를 확인함 |
| 충돌 | 화면용 메시와 별도로 지형·건물·교량의 충돌 형상을 준비함 |

화면에 모델이 보이는 것만으로 충돌이 검증된 것은 아닙니다. 현재 프로그램은 새 GLB 지형을 충돌 계산에 사용하지 않습니다. 실제 지형과 같은 GLB를 만들고 텍스처를 넣은 뒤에도, 프로그램에 가져오는 기능과 충돌 형상을 연결하고 별도로 시험해야 합니다.
