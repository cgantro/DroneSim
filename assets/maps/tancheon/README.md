# 탄천 장면에 실제 지형과 항공사진 넣기

## 현재 장면과 필요한 자료

현재 화면에는 약 30m 간격의 지형 높이와 OpenStreetMap 건물 외곽선을 단순하게 올려 둔 상태입니다. 항공사진 질감과 탄천의 실제 건물·교량 3D 모델은 아직 없습니다. 그래서 지형은 평평하고 건물은 네모 상자처럼 보입니다.

실제 모습에 가까워지려면 서로 다른 자료 세 가지가 필요합니다.

| 받을 자료 | 어디에 쓰나 | 확인할 점 |
| --- | --- | --- |
| 더 촘촘한 DEM | 지면 높낮이와 지면 충돌 | 격자 간격, 좌표계, 높이 기준 |
| 정사영상 TIFF | 지면에 입힐 실제 항공사진 | 촬영 시기, 해상도, 온라인 공개 조건 |
| 건물·교량 3D 원본 | 실사에 가까운 구조물 모양 | 좌표·높이 기준, 수정·웹 배포 허용 범위 |

정사영상은 위에서 찍은 사진이라 건물 옆면이나 교량 밑을 만들지 않습니다. DEM과 정사영상으로 만드는 GLB는 **땅의 표면**입니다. 실제 건물과 교량 모양은 별도 3D 자료가 있어야 합니다.

## 1. 항공사진 질감 받기

[국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 정사영상을 받을 수 있습니다. 내려받으려면 로그인과 대용량 전송 프로그램이 필요합니다. 파일은 TIFF 형식입니다.

1. 지도에서 `탄천교`를 검색합니다.
2. 검색 결과의 위치를 선택하고 자료 목록에서 `정사영상`을 엽니다.
3. 프로젝트 중심인 위도 37.4936231°, 경도 127.1018462° 주변 약 1.2km 정사각형을 덮는 자료를 고릅니다. 화면의 드론 임무 구역이 다른 곳이면 그 구역을 기준으로 받습니다.
4. 촬영 날짜와 실제 해상도를 확인하고, 내려받을 수 있는 자료 중 **25cm급을 우선 선택**합니다. 도시 지역의 12cm급 자료는 온라인 공개가 제한될 수 있어 웹 배포용으로 전제하지 않습니다.
5. 원본 TIFF와 함께 제공되는 좌표·촬영 시기·이용 조건 정보를 보관합니다.

국토지리정보원은 정사영상이 TIFF로 제공되고, 내려받을 때 로그인이 필요하다고 안내합니다. 도시 지역의 제작 해상도는 12cm, 일반 지역은 25cm라고 설명하지만, 이는 탄천 자료의 실제 제공 해상도를 보장하지 않습니다. 특히 12cm 자료는 공개 제한 안내가 있으므로, 선택한 자료의 다운로드 가능 여부와 GitHub Pages 재배포 조건을 직접 확인해야 합니다.

온라인 지도 화면을 캡처해 쓰지 않습니다. 지도 서비스의 화면 이미지는 원본 해상도와 재배포 권한을 확인할 수 없기 때문입니다.

## 2. 실제 지형 GLB 만들기

### 필요한 도구

- **QGIS:** DEM과 정사영상을 같은 좌표계와 범위로 맞추고, 사진을 입힌 지형을 OBJ로 내보냅니다.
- **Blender:** OBJ를 하나의 지형 메시로 정리하고 GLB로 저장합니다.

QGIS는 3D 장면에서 지형과 질감을 OBJ 및 이미지로 내보낼 수 있습니다. 내보내기 때 지형 해상도와 질감 해상도를 지정할 수 있습니다. 자세한 메뉴는 [QGIS 3D 장면 내보내기 안내](https://docs.qgis.org/latest/en/docs/user_manual/map_views/3d_map_view.html#export-3d-scenes)를 참고하세요.

### 작업 순서

1. QGIS에서 DEM과 정사영상 TIFF를 엽니다. 각 자료의 좌표계를 확인한 뒤 두 자료가 지도에서 정확히 겹치는지 봅니다. 좌표계를 모른 채 EPSG:5179로 지정하지 않습니다.
2. 두 자료를 같은 범위로 자릅니다. 처음에는 약 1.2km 정사각형을 사용하고, 원본보다 높은 해상도로 DEM을 보간하지 않습니다.
3. QGIS의 `3D 지도 보기`에서 DEM을 지형 높이로, 정사영상을 지면 질감으로 지정합니다. 높이 배율은 1로 둡니다.
4. `3D 장면 내보내기`에서 지형과 질감을 함께 OBJ와 이미지로 내보냅니다.
5. Blender에서 내보낸 지형만 남기고 위치·회전·크기 변환을 적용합니다. 지형을 메시 하나와 삼각형 재질 하나로 합쳐 GLB로 저장합니다.
6. GLB의 UV 좌표가 사진을 가리키는지 확인합니다. 화면에서 도로·하천 굽이와 건물 위치가 항공사진과 겹쳐야 합니다.

현재 시뮬레이터의 GLB 읽기는 **노드 하나, 메시 하나, 삼각형 묶음 하나**를 전제로 합니다. GLB 안의 재질이나 사진은 읽지 않습니다. 아래에서 설명하는 별도 PPM 질감 파일도 같이 준비해야 합니다.

### 좌표와 높이 맞추기

시뮬레이터 좌표는 동쪽이 X, 위쪽이 Y, 북쪽이 음수 Z이며 단위는 미터입니다. QGIS·Blender에서 다른 축이나 단위를 사용했다면 변환을 적용한 뒤 GLB로 내보냅니다.

수평 좌표계뿐 아니라 높이 기준도 맞아야 합니다. DEM의 높이 기준과 충돌 격자의 기준이 다르면 드론이 화면에서 지면 위에 떠 있거나 지면을 뚫습니다. 받은 자료의 높이 기준이 불명확하면 임의로 보정하지 말고 자료 제공처에 확인합니다. `KNGeoid24`도 입력 높이의 기준이 확인된 뒤에만 사용합니다.

## 3. 지형 질감 만들기

현재 시뮬레이터는 일반 이미지 형식이나 GLB 내부 질감을 읽지 않고, 별도 **PPM(P6, RGB 8비트)** 이미지 하나를 지형 UV에 입힙니다.

1. QGIS에서 정사영상을 GLB와 같은 범위·방향으로 잘라 RGB 이미지로 내보냅니다.
2. 이미지 편집 프로그램에서 PPM의 `P6`, 최대 색상값 `255` 형식으로 저장합니다.
3. 사진의 위아래가 뒤집히거나 위치가 밀리지 않았는지 확인합니다.

처음에는 2048×2048 크기로 변환하는 편이 좋습니다. 압축하지 않는 PPM은 이 크기에서 약 12MiB이고, 4096×4096이면 약 48MiB입니다. 더 큰 파일은 웹 첫 로딩과 GPU 메모리를 크게 늘립니다. 1.2km 전체를 한 장으로 덮으면 저고도에서 흐릿할 수 있습니다. 가까이 볼 구역까지 선명하게 만들려면 좁은 영역별 질감 타일을 읽도록 렌더러를 확장해야 합니다.

## 4. 실제 건물·교량 3D 모델 받기

서울시는 S-Map에 건물·지형·교량을 포함한 3D 공간정보를 구축했다고 안내합니다. 다만 공개 안내에서 탄천 구역의 원본 GLB를 바로 내려받는 경로는 확인되지 않았습니다.

[S-Map 오픈랩 자료 제공 FAQ](https://openlab.eseoul.go.kr/mobile/qna.do)에서 데이터 종류와 신청 조건을 확인한 뒤, 탄천교 주변의 **실사형 건물·교량 메시와 지형 원본**, 제공 형식(가능하면 GLB 또는 OBJ), 좌표계·높이 기준, 제작 시기, 웹 공개·재배포 허용 여부를 문의합니다. 공개제한 자료는 신청 자격과 보안 심사가 필요할 수 있습니다. 서울시의 [공개제한 공간정보 안내](https://openlab.eseoul.go.kr/mobile/notice.do)와 [S-Map 소개](https://news.seoul.go.kr/gov/archives/528155)를 함께 확인하세요.

문의할 때는 이렇게 적으면 됩니다.

> DroneSim 포트폴리오의 탄천 시설물 정찰 장면에 사용할 탄천교 주변 3D 공간자료를 찾고 있습니다. 약 1.2km × 1.2km 범위의 지형·건물·교량 원본 메시와 항공사진 또는 재질 이미지를 받을 수 있는지 문의드립니다. 시뮬레이터 화면 표시와 충돌 검증에 사용하려 합니다. 제공 형식, 좌표계, 높이 기준, 제작 시기, 수정 가능 여부, GitHub Pages 공개 및 재배포 허용 범위, 신청 자격과 보안 심사 조건을 알려주시면 감사하겠습니다.

원본 모델을 받을 수 없다면 OSM 외곽선으로 만든 건물은 임시 표현으로 남습니다. 그 결과를 실제 건물 모델이라고 부르지 않습니다. 화면에 보이는 건물·교량과 충돌체도 별도 자료로 맞춰야 합니다.

## 5. 충돌 지형도 함께 갱신하기

화면의 GLB와 충돌용 높이 격자는 별도로 읽습니다. 화면 모델만 바꾸면 보이는 지면과 충돌 지면이 어긋날 수 있습니다.

새 DEM을 적용할 때는 같은 범위와 높이 기준으로 충돌용 격자도 다시 만듭니다. 90m 간격 자료를 1m 간격으로 보간해도 원래 측량 정밀도는 좋아지지 않습니다. 현재 받은 두 DEM 도엽은 90m 간격이므로 세밀한 제방이나 교량 주변 지형을 만들 자료로 쓰기 어렵습니다.

정사영상은 화면 색상에만 영향을 줍니다. 건물·교량 충돌은 해당 구조의 별도 충돌 형상이 있어야 합니다.

## 지금 필요한 파일

먼저 [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 프로젝트 중심을 덮는 25cm급 정사영상 TIFF를 내려받아 첨부해 주세요. 로그인과 대용량 전송 프로그램이 필요합니다. DEM은 5m 또는 그보다 촘촘한 자료가 실제로 제공되는지 확인해 주세요. 이미 받은 90m DEM 두 도엽은 더 정밀한 자료가 아닙니다.

S-Map 모델은 즉시 다운로드할 수 있는 링크가 확인되지 않아, 오픈랩에 제공 가능 여부를 먼저 문의해야 합니다. 답변이나 받은 원본 모델을 보내 주시면 좌표·질감·충돌 자료를 함께 맞추겠습니다.
