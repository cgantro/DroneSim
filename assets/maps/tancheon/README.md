# 탄천 지도 자료 받기와 적용하기

현재 화면은 탄천교 주변의 30m 간격 높이 격자와 OSM 건물·도로 정보를 씁니다. 실제 지형과 색을 입히려면 **높이 자료(DEM)**와 **정사영상**을 각각 준비해야 합니다. DEM은 땅의 높낮이를 만들고, 정사영상은 위에서 본 땅의 사진을 제공합니다.

실제 건물·교량 GLB는 지형 GLB와 별개입니다. 지형 GLB만으로 건물 외벽, 교량 상판·교각이 생기지 않으며, 정사영상도 구조물의 옆면이나 높이를 제공하지 않습니다.

## 지금 저장소에서 쓰는 자료

| 자료 | 쓰임 | 현재 상태 |
| --- | --- | --- |
| 높이 격자 | 지형 표시와 지면 충돌 | 30m 간격, 기준점 37.4936231°N·127.1018462°E |
| 지형 GLB | 높이 격자보다 촘촘한 화면용 지형 | 별도 자료가 없으면 높이 격자로 화면 메시 생성 |
| 정사영상 | 지형 표면의 실제 색과 무늬 | 아직 연결하지 않음 |
| 건물 | 화면 표시와 장애물 판정 | OSM 외곽선·높이 기반 단순 형상 |
| 교량 | 위치 표시 | OSM 도로 선형만 표시. 상판·교각 3D와 충돌 형상은 없음 |

네이티브와 웹은 같은 지형 높이 격자를 지면 판정에 씁니다. 화면용 GLB만 바꾸면 충돌 지형은 바뀌지 않습니다. 이번에 추가한 격자 변환기는 미터 단위 ESRI ASCII 격자를 읽고 소수점 높이를 보존해 저장합니다. 화면용 GLB와 충돌 격자에 같은 DEM·범위·기준점을 사용해야 서로 맞습니다.

## 1. 정사영상과 DEM 받기

국토지리정보원의 [정사영상 안내](https://www.data.go.kr/data/15059919/fileData.do)를 확인하고 [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 자료를 신청합니다. 내려받기에는 계정 로그인이 필요할 수 있고, TIFF 대용량 자료는 전송 프로그램을 요구할 수 있습니다. 제공되는 촬영 연도·화소 크기·이용 조건은 자료마다 다르므로 신청 화면과 원본 메타데이터를 기준으로 삼습니다.

1. 지도에서 `탄천교`를 검색하고 필요한 범위를 지정합니다. 처음에는 탄천교 주변 약 1km 구간만 준비합니다.
2. 자료 종류에서 `정사영상`을 골라 범위를 덮는 TIFF를 신청합니다. 촬영 시기와 화소 크기를 확인합니다.
3. 같은 범위에서 `공개DEM`을 검색하고 받을 수 있는 자료 중 격자 간격이 가장 작은 것을 선택합니다. IMG 압축파일을 받으면 원본과 부속 메타데이터를 함께 보관합니다.
4. 정사영상과 DEM의 좌표계, 높이 기준, 제작 시기, 해상도, 이용 조건을 기록합니다. 수평 좌표가 맞아도 높이 기준이 다르면 화면과 충돌 위치가 어긋납니다.

받은 공개 DEM 압축파일은 IMG 형식입니다. 압축파일 이름이나 크기만으로 격자 간격과 좌표계를 판단할 수 없습니다. QGIS에서 열어 레이어 속성의 좌표계·화소 크기·범위·높이 기준을 확인한 뒤 사용합니다. 현재 30m 격자보다 촘촘한 자료라면 지형 GLB와 충돌 격자를 같은 원본에서 다시 만들어야 합니다. 거친 DEM을 보간해 격자 간격만 줄여도 실제 지형 세부 정보가 늘지는 않습니다.

정밀한 제방·둔치가 필요하면 국토지리정보원에 해당 범위의 1m·5m DEM 제공 여부와 사용 조건을 확인합니다. [국토지리정보원 자료 안내](https://www.ngii.go.kr/lib/file/pr_01.pdf)는 여러 격자 간격의 DEM 구축 사례를 소개하지만, 탄천 자료가 모두 공개된다는 뜻은 아닙니다.

## 2. 상세 건물·교량 3D 자료 받기

서울시는 [S-Map](https://smap.seoul.go.kr/)에 서울 3D 공간정보를 운영하지만, 화면에 보이는 자료가 원본 GLB로 공개된다는 뜻은 아닙니다. [S-Map 오픈랩 자료 제공 FAQ](https://openlab.eseoul.go.kr/mobile/qna.do)와 [공개제한 공간정보 안내](https://openlab.eseoul.go.kr/mobile/notice.do)를 먼저 확인합니다. 공개제한 자료는 신청과 보안 심사가 필요할 수 있고, 공지에는 법인 또는 사업자 등록자 대상 절차가 안내되어 있습니다. 개인 포트폴리오에 제공되는지는 서울시 공간정보과에 먼저 문의해야 합니다.

문의할 때는 탄천교 주변 범위와 함께 다음을 확인합니다.

- 지형, 건물, 교량 가운데 어떤 자료를 받을 수 있는가?
- 받을 수 있는 파일 형식과 좌표계·높이 기준은 무엇인가?
- 화면용 GLB로 변환·수정해도 되는가?
- GitHub Pages와 포트폴리오에 변환 결과를 공개해도 되는가?
- 원본은 비공개로 두고 변환 결과만 배포할 수 있는가?

원본 제공을 받을 수 없다면 현실적인 대안은 **정사영상 + 공개 건물 외곽선·높이 + 별도로 만든 교량 모델**입니다. [건물 통합정보](https://www.data.go.kr/data/15029175/standard.do)는 외곽선과 속성 자료이지, 외벽 사진이 있는 3D 모델이 아닙니다. 현재 화면의 건물 덩어리도 실제 외관을 재현하지 않습니다.

## 3. QGIS에서 지형 GLB와 표면 사진 만들기

[QGIS](https://qgis.org/download/)와 [Qgis2threejs](https://plugins.qgis.org/plugins/Qgis2threejs/)를 사용합니다. 플러그인은 DEM으로 3D 지형을 만들고 glTF/GLB로 내보냅니다. [공식 내보내기 설명](https://minorua.github.io/Qgis2threejs/docs/3.1/Exporter.html)과 [공식 튜토리얼](https://minorua.github.io/Qgis2threejs/docs/3.2/Tutorial.html)을 참고합니다.

1. QGIS에 DEM과 정사영상 TIFF를 불러옵니다. 두 자료가 같은 위치에 포개지는지 확인합니다.
2. 좌표계를 미터 단위 투영 좌표계로 정하고, 탄천교 중심 기준으로 정사각형 범위를 자릅니다. 기준점은 37.4936231°N·127.1018462°E입니다. GLB 원점은 이 기준점에 맞추고 높이 과장은 1로 둡니다.
3. Qgis2threejs에서 DEM 지형만 선택해 GLB로 저장합니다. 주변 지도나 전체 서울을 넣지 말고 비행 시험 구역만 내보냅니다. 장면 원점은 선택 영역 중심에 둡니다. 이 방법으로 만드는 GLB는 실제 DEM 높이를 담은 지표면 모델입니다. 건물 외벽이나 교량 구조가 함께 생기는 것은 아닙니다.
4. 정사영상은 국토정보플랫폼에서 같은 구역을 받아 QGIS에 추가합니다. DEM과 같은 좌표계로 맞추고, 지형과 동일한 경계로 잘라냅니다. 지형에 사진을 얹을 때 Qgis2threejs의 지형 재질에서 지도 화면 또는 영상 레이어를 선택할 수 있습니다. 다만 현재 DroneSim은 GLB 안에 든 재질 사진을 읽지 않으므로 별도 사진도 저장해야 합니다.
5. QGIS에서 정사영상을 3개 색상 띠, 8비트 RGB로 내보냅니다. `레이어 내보내기 → 다른 이름으로 저장`의 파일 형식에서 PNM을 선택하면 PPM으로 저장할 수 있습니다. GDAL의 PNM 형식은 RGB PPM을 지원합니다. [GDAL PNM 안내](https://gdal.org/en/stable/drivers/raster/pnm.html)를 참고하세요. 결과는 헤더가 `P6`, 최대 색상값이 `255`인 파일이어야 합니다. 처음에는 2048×2048로 확인합니다. 이 크기는 압축 전 약 12MiB이며, 더 큰 파일은 웹 로딩을 늦출 수 있습니다.
6. 사진을 GLB의 UV에 맞춥니다. 위치가 밀리거나 상하가 뒤집히면 QGIS에서 잘라낸 경계와 이미지 방향을 확인합니다. 사진의 픽셀 수를 늘려도 원본 영상에 없는 세부 정보가 생기지는 않습니다.
7. QGIS 지도는 보통 동쪽 X·북쪽 Y·높이 Z 축을 씁니다. DroneSim은 동쪽 X·높이 Y·남쪽 Z 축을 씁니다. Blender에서 지형을 X축으로 90도 돌려 축을 바꾼 뒤, 회전과 크기를 적용하고 중심을 원점에 둡니다. 높이는 기준 해발고도를 뺀 상대값이 아니라 현재 지형 격자에 저장된 기준 고도를 포함한 값이어야 합니다.
8. 현재 GLB 읽기는 위치·법선·UV가 있는 삼각형 메시 하나만 지원합니다. Qgis2threejs 결과가 여러 메시나 삼각형 묶음으로 나뉘면 Blender에서 하나로 합쳐 저장합니다. 변환한 GLB를 다시 열어 방향·크기·UV가 맞는지 확인합니다.

파일은 기존 자산 위치에 다음 이름으로 둡니다.

| 파일 | 내용 |
| --- | --- |
| `assets/maps/tancheon/terrain.glb` | 화면에 그릴 지형 메시 |
| `assets/maps/tancheon/terrain.ppm` | GLB UV에 맞춘 표면 사진 |
| `assets/maps/tancheon/terrain.aerotrn` | 네이티브·웹 충돌에 쓰는 높이 격자 |

GLB와 사진만 바꾸고 높이 격자를 그대로 두면 드론은 옛 지형에서 충돌합니다. QGIS에서 같은 DEM을 ESRI ASCII Grid로 내보낸 다음, 프로젝트의 지형 격자 변환 도구에 입력합니다. 입력 자료는 정사각형 격자여야 하며 좌표계와 셀 간격은 미터 단위여야 합니다. 변환 도구는 ASCII Grid의 좌표계를 판독하지 않으므로, QGIS에서 투영 좌표계와 원점·범위를 먼저 맞춰야 합니다. 중심 위도·경도에는 지형 중심의 실제 좌표를 넣고, 기준 높이에는 DEM과 같은 수직 기준의 중심 고도를 넣습니다. 높이 기준이 서로 다르면 자동으로 변환되지 않습니다.

## 4. 적용 뒤 확인할 점

- 지형 GLB와 높이 격자의 중심·범위·격자 간격이 같은가?
- 정사영상이 GLB 표면에 뒤집히거나 밀리지 않고 맞는가?
- 지면 높이와 충돌 높이가 같은 기준을 쓰는가?
- 건물·교량 모델의 공개·수정·재배포 허가를 확인했는가?
- 웹 배포 파일 용량이 감당할 만한가? 정사영상 PPM은 압축되지 않아 원본 해상도에 따라 커질 수 있습니다.

받은 두 IMG 압축파일은 아직 QGIS에서 범위·좌표계·격자 간격·높이 기준을 확인하고 저장소 지형과 겹쳐 보지 않았습니다. 따라서 새 자료가 현재 30m 격자를 대체할 수 있다고 아직 판정하지 않았습니다. 탄천교 주변을 덮는지 확인하고, 같은 구역의 정사영상도 준비해야 실제 사진을 입힌 지형 GLB를 만들 수 있습니다. 현재 저장소에는 정사영상, 새 지형 GLB, 탄천교 상세 3D 모델이 없습니다.
