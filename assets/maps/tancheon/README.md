# 탄천 시험 장면 자료

## 현재 장면

시뮬레이터는 탄천교 주변 약 1.2km 정사각형을 보여줍니다. 중심은 위도 37.4936231°, 경도 127.1018462°입니다. 화면에는 2025년 항공 정사영상의 질감을 입히고, 공개 수치표고모델로 지면 높이를 구성했습니다.

정사영상은 위에서 본 사진입니다. 지면의 도로와 하천 모습은 실제와 가까워졌지만 건물 옆면과 교량의 높이·교각 구조는 별도 자료가 필요합니다. 탄천교의 평면 외곽선은 국토지리정보원 1:1,000 수치지도에서 가져왔습니다. 자료에는 이름과 함께 연장 308m, 폭 42m, 1985년 12월 설치, 콘크리트 재질이 기록되어 있고, 두 개의 상판 외곽선이 있습니다.

추가로 받은 2025년 1:1,000 지도에서 장면과 겹치는 건물 외곽선 112개와 교량 도형 3개를 확인했습니다. 정사영상과 도로 중심선을 대조하는 과정에서 건물 자료에 도로·진입로 표면이 건물로 들어간 경우 51개를 찾아 제외했습니다. 이 도형들은 높이가 붙은 건물과 충돌 장애물로 처리되던 항목입니다. 현재 장면 자료에는 건물 외곽선 713개가 있으며, 이 가운데 222개는 국토지리정보원 수치지도에서 가져왔습니다. 이 수는 지도 도형의 개수이지 현장에 있는 건물을 모두 확인한 수는 아닙니다. 나머지 세 도엽은 장면 범위와 겹치지 않아 적용하지 않았습니다. 자료 좌표를 장면 좌표로 옮겼지만, 현장 측량값과 대조한 위치 정확도 검사는 하지 않았습니다. 원본 압축 묶음 일부는 손상되어 건물·교량 등 필요한 자료만 골라 읽고, 정상적으로 열리는지 확인한 뒤 반영했습니다.

높이 자료는 건물마다 다릅니다. 713개 중 210개에는 높이값이 있고, 278개에는 층수 정보가 있습니다. 둘 다 있는 건물은 204개이며, 둘 다 없는 429개는 화면과 경로 계산에서 임시로 6m 높이를 씁니다. 이 6m는 실제 건물 높이가 아닙니다. 그래서 높이 자료가 없는 아파트 동과 큰 건물은 실제보다 낮게 보일 수 있습니다.

수치지도에는 교각 위치나 상판 높이가 없습니다. 화면과 충돌 계산에는 교량 외곽선 안에 지면 평균보다 6m 높은 상판과 0.8m 두께를 적용합니다. 긴 교량은 외곽선 길이를 기준으로 약 45m마다 교각 두 개를 배치하고, 각 교각은 길이 2.4m·너비 1.8m로 만듭니다. 화면에 그리는 교각과 충돌 판정에 넣는 교각은 같은 형상 자료를 씁니다. 다만 상판 높이·두께와 교각 위치·크기는 실측값이 아니라 시연용 추정치입니다. 교량 양끝의 교대는 아직 만들지 않았으므로 실제 구조물과 충돌 위치가 다를 수 있습니다.

하천 물가는 지도에 기록된 물 영역을 바탕으로 화면에 그립니다. 경계는 약 3m 간격으로 나눈 면으로 표현하고, 각 점의 높이는 현재 지형 높이에 맞춥니다. 실제 수위 자료는 없어 수면 높이를 측량값으로 볼 수 없습니다.

## 정찰 임무와 출발 후보

임무는 사람이 지정한 건물 외벽·교량 밑·강 주변 위치로 드론을 보내 영상을 확보하는 시연입니다. 드론이 파손 여부를 판정하지 않습니다. `탄천 물길` 임무는 수면 위에서 강 주변을 보는 경로이고, 물속으로 들어가는 임무는 아닙니다.

지상통제 창에서 드론을 추가한 뒤 `편대 정찰 동시 출발`을 누르면 각 드론에 건물, 탄천교 하부, 강 주변 위치를 나눠 보내고 상태를 편대 목록에 표시합니다. 교량 밑과 강 주변은 장면 지형과 교량 외곽선으로 만든 시험점입니다. 교각 사이 통로와 실제 상판 높이를 재현한 임무는 아닙니다. 여러 드론의 경로와 도착 상태를 확인할 수 있지만, 영상 저장과 전달은 아직 주 드론 기준입니다.

현재 출발 후보는 서울 송파구 삼학사로2길 49의 탄천유수지 체육시설 주변입니다. 이 주소는 공공 체육시설 주소를 기준으로 정한 **시뮬레이션 배치 후보**입니다. 시작 지점 뒤쪽에 체육관 건물이 가까워 화면에서 드론을 가릴 수 있어, 지도 중심 기준 동쪽 -410m·북쪽 457m 지점으로 옮겼습니다. 이전 좌표인 동쪽 -472m·북쪽 442m는 1:1,000 수치지도에서 건물 외곽선 안에 들어가 경로 시작점으로 쓸 수 없습니다. 지상 측량이나 주소 좌표 대조는 하지 않았으며, 실제 드론 이륙 장소로 확인되거나 허가된 곳이 아닙니다. 실제 운용 위치로 쓰기 전에는 현장 접근, 비행 제한, 소유자 허가와 안전 구역을 따로 확인해야 합니다. [서울시 체육시설 안내](https://sports.seoul.go.kr/main/facilities/facilities_view.do?ft_idx=1668&tr_code=sweb)

서울시설공단 도로시설처도 교량·터널 등 도로 시설 점검에 드론과 열화상 장비를 활용한다고 공개했습니다. 서울교통공사 정보통신처는 GPS가 닿기 어려운 터널과 철도 교량·교각 안쪽의 드론 점검 방안을 소개했습니다. [서울시설공단 점검 안내](https://news.seoul.go.kr/gov/archives/575174), [서울교통공사 드론 점검 안내](https://news.seoul.go.kr/traffic/archives/510150)

이번 조사에서 송파구가 직접 추진하는 같은 종류의 드론 교량·시설 점검 사업은 공식 공개자료로 확인하지 못했습니다. 이는 공개자료 검색 결과이며, 사업이 없다는 뜻은 아닙니다.

정사영상은 원본 전체를 작은 화면 크기에 맞춰 줄인 것이 아닙니다. 원본에서 탄천교 주변 4800×4800픽셀을 잘랐습니다. 원본 해상도로 계산하면 4800픽셀 × 0.25m = 1200m이며, 지면과 영상이 각각 동서·남북 1200m를 차지합니다. 실행용 JPEG로 저장하며 픽셀 수만 3072×3072로 줄였기 때문에 한 픽셀은 약 39cm를 나타냅니다. 사진의 크기와 지면 크기는 맞지만, 원본 TIFF에 지리 좌표가 없어 위치 오차는 별도 측량으로 확인하지 않았습니다.

지형 격자의 첫 행은 북쪽입니다. 화면 지형을 만들 때도 첫 행을 북쪽 경계에 놓아, 정사영상·높이 자료·건물 윤곽의 남북 방향을 맞춥니다.

정사영상 원본 여섯 장 중 현재 장면 범위와 겹치는 도엽 37709004·37709005를 사용했습니다. 나머지 네 장은 같은 장면 범위 밖에 있어 실행 자료에 넣지 않았습니다. 자료 출처는 [국토지리정보원 정사영상 안내](https://www.data.go.kr/data/15059919/fileData.do), [국토지리정보원 DEM 안내](https://www.data.go.kr/data/15059920/fileData.do), [국토정보플랫폼 도엽 색인](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total), [OpenStreetMap 저작권 안내](https://www.openstreetmap.org/copyright)에서 확인할 수 있습니다. 공공데이터포털은 두 국토지리정보원 자료의 이용허락범위를 제한 없음으로 표시합니다. 화면이나 배포물에는 자료 출처를 함께 표시합니다.

### 건물 위치와 높이 자료

브이월드 송파구 건물정보와 건축물대장에 더해, 2026년 10월 기준 건물통합정보를 읽어 높이·층수·이름을 보완합니다. 큰 압축 자료는 전체를 메모리에 풀지 않고 장면 주변 도형만 골라 씁니다. 기존 건물 모양과 이름은 유지하고, 자료의 PNU와 외곽선 위치가 모두 분명하게 맞는 경우에만 높이·층수를 반영합니다.

2026년 건물통합정보에는 건물 ID, 필지번호, 이름, 높이, 지상층수가 기록되어 있습니다. 새 자료의 외곽선을 기존 건물과 대조해 한 건물로 분명하게 겹치는 항목만 보완했습니다. 위치가 여러 건물에 걸쳐 겹치거나 어느 건물인지 나눌 수 없는 항목은 임의로 연결하지 않았습니다.

현재 변환 결과에는 건물 외곽선 713개가 있습니다. 이 가운데 이름은 192개, 높이는 210개, 지상층수는 278개에 기록되어 있습니다. 브이월드 건물 정보·건축물대장·건물통합정보의 값을 모두 무조건 합치지 않고, 같은 건물로 연결할 수 있는 경우에만 반영합니다. 두 자료의 층수가 다른 건물 34개와 높이가 다른 건물 3개는 이전 값도 함께 남겼습니다. 화면에는 건물통합정보 값을 표시합니다. 값은 자료에 적힌 정보이며 현장에서 측량해 확인한 값은 아닙니다.

높이가 없는 건물은 기존 층수 자료로 높이를 계산하고, 높이와 층수가 모두 없으면 6m를 임시로 씁니다. 건물은 여전히 평면 외곽선을 높이만큼 올린 단순 모형입니다. 실제 외벽·지붕 3D 모델이나 사진 질감은 아닙니다. 데이터 출처는 [브이월드 건물통합정보](https://www.data.go.kr/data/15083092/fileData.do)와 [행정표준코드관리시스템](https://www.code.go.kr/stdcode/regCodeL.do)에서 확인할 수 있습니다.

## 실제 건물과 교량 모델을 구하려면

S-Map 화면에서 서울의 3D 건물과 지형을 볼 수 있지만, 화면에 보이는 모델을 파일로 내려받을 수 있는 것은 아닙니다. 서울시 공간정보과에 전화로 확인한 결과, 3D 에셋은 보안 자료라 파일로 제공하지 않고 **API를 통해 이용해야 합니다.** 따라서 OBJ·FBX·GLB 파일을 신청해 받거나, 화면을 캡처해 시뮬레이터 모델로 쓰는 방식은 이번 자료 확보 경로가 아닙니다.

현재 확인된 API 이용 경로는 다음과 같습니다.

1. [S-Map 오픈랩](https://openlab.eseoul.go.kr/)에서 개발자 안내와 데이터 제공 FAQ를 확인합니다. 오픈랩에는 개발자 등록과 앱 승인, API·데이터 이용 조건이 별도로 있습니다.
2. 서울시 공간정보과 공간정보운영팀(02-2133-2852)에 탄천교 주변 모델을 쓸 목적과 범위를 설명하고, 사용할 API와 신청 절차를 확인합니다. 전화 안내에서 API 이용이 필요하다는 점은 확인했지만, 공개 웹 안내에서는 해당 3D API의 주소와 요청 형식까지 확인되지 않았습니다.
3. API 신청 전에 응답에 건물·교량의 3D 형상과 외벽 재질·질감이 실제로 포함되는지 확인합니다. 좌표계, 높이 기준, 단위, 갱신 시점, 인증키 발급, 호출 제한, 웹·네이티브 접근 허용 여부도 함께 묻습니다.
4. 응답 데이터를 DroneSim에서 바로 사용할 수 있는지 확인한 뒤 연동 방식을 정합니다. API가 화면 타일이나 스트리밍만 제공한다면 이를 GLB 파일로 바꿀 수 있다고 가정하지 않습니다. 가공·저장·배포가 허용되는 범위도 승인 내용에 맞춥니다.

[오픈랩 Q&A](https://openlab.eseoul.go.kr/mobile/qna.do)의 공식 답변은 3D 자료 문의를 데이터 제공 FAQ와 공개제한 공간정보 안내로 연결합니다. 오픈랩 안내에는 QGIS 플러그인용 인증키 발급 절차가 있지만, 이 키가 3D 건물 모델 API에도 쓰인다는 설명은 찾지 못했습니다. 두 기능을 같은 API라고 간주하지 않습니다.

[서울시 공개제한 공간정보 안내](https://openlab.eseoul.go.kr/mobile/notice.do)는 공개제한 공간정보 신청에 법인 또는 사업자 등록과 자료 생산 부서의 보안심사가 필요하다고 설명합니다. 전화로 안내받은 API가 이 보안 절차와 어떻게 연결되는지는 담당 부서에 확인해야 합니다. 공개 가능한 API 주소, 신청 양식, 인증 방법, 허용된 저장·재배포 범위가 확인되기 전까지는 실제 3D 모델을 확보한 것으로 기록하지 않습니다.

오픈랩 약관은 서울시 또는 제3자가 자료의 저작권을 보유하며, API를 이용해도 저작권이 사용자에게 넘어가는 것은 아니라고 안내합니다. API 응답을 로컬에 저장하거나 GLB로 변환해 웹에 배포할 수 있는지는 별도 허가가 필요합니다. [오픈랩 이용약관과 API·데이터 이용 조건](https://openlab.eseoul.go.kr/)

### 건물 외벽 질감이 있는 3D 데이터를 쓰려면

`LoD4`는 외벽 사진 질감을 뜻하지 않습니다. 예전 CityGML 2.0에서 LoD4는 방·문·가구 같은 실내 구조까지 표현한 모델을 가리켰습니다. CityGML 3.0은 LoD4라는 단계를 없애고, 실내와 실외 구조를 LoD0~3 표현에 담습니다. 외벽의 실제 색과 무늬는 LoD 숫자만으로 정해지지 않습니다. [OGC CityGML 안내](https://docs.ogc.org/guides/20-066.html)

서울시 공간정보과에 API 응답이 외벽 질감과 UV 좌표까지 포함하는지 확인합니다. 전화로 확인된 것은 3D 에셋이 보안 자료이며 API 경로로 이용해야 한다는 점입니다. API가 실제 형상·재질·질감을 모두 제공하는지, 아니면 지도 화면용 데이터만 제공하는지는 아직 확인되지 않았습니다. `LoD4`라는 표현만 쓰기보다 실외 3D 형상, 외벽 질감, 재질 정보, 좌표계와 높이 기준을 구체적으로 물어봅니다. 실내 점검을 구현할 때만 실내 구조를 문의합니다. 공개 API 주소, 인증, 이용 허가와 저장·배포 조건이 확인되면 그 조건에 맞춰 연동 방식을 정합니다. [S-Map 오픈랩](https://openlab.eseoul.go.kr/) · [S-Map 담당 부서](https://news.seoul.go.kr/gov/archives/528155)

현재 시뮬레이터는 로컬 GLB의 기본색 재질과 파일 안에 든 PNG/JPEG 질감을 읽습니다. 질감 모델에는 `TEXCOORD_0` 좌표가 필요합니다. 외부 이미지 경로, 별도 data URI, 다른 UV 채널, 압축 메시와 일부 고급 재질은 지원하지 않습니다. S-Map API 연동은 아직 구현하지 않았고, API 응답이 이 GLB 불러오기 경로에 바로 연결될 수 있는지도 확인되지 않았습니다. 현재 탄천 건물은 수치지도 외곽선과 임시 질감으로 표시하며, S-Map 실제 3D 모델을 사용하지 않습니다.

현재 쓰는 X500 참고 모델에도 재질·이미지·UV 좌표가 들어 있지 않습니다. 화면에서는 별도 탄소섬유 무늬를 좌표축 투영 방식으로 입혀 구분합니다. 제조사 외관 질감을 적용한 결과는 아닙니다. 실제 질감 모델을 받으면 GLB 안에 재질·이미지·UV 좌표가 함께 들어 있는지 확인해야 합니다. 충돌 형상은 화면 모델과 별도로 단순화해 준비합니다.

## 더 촘촘한 지형 높이가 필요하면

현재 장면의 기본 높이 자료는 90m 간격 공개 DEM입니다. 여기에 1:1,000 수치지도의 등고선과 1:1,000·1:5,000 수치지도의 표고점을 넣어 5m 간격 지형 격자를 만들었습니다. 격자점마다 90m DEM과 주변 등고선·표고점의 높이 차를 거리 가중 방식으로 보간합니다. 1:5,000 지도에서 장면 안에 들어오는 표고점 103개를 더해 총 121개를 사용합니다. 등고선이 없는 곳도 90m DEM과 가까운 표고점으로 보정하지만, 자료가 드문 곳의 세부 굴곡까지 복원하지는 못합니다.

표고점 121개를 하나씩 보정에서 빼고 예측했습니다. 같은 입력에서 90m DEM만 썼을 때 평균 절대 오차는 3.14m, 제곱평균제곱근 오차는 4.53m였습니다. 등고선과 표고점을 반영한 뒤에는 각각 1.85m, 3.29m였습니다. 이 값은 같은 수치지도 자료의 점으로 확인한 결과라 독립 측량 정확도를 뜻하지 않습니다. 실제 지면의 높이 정확도를 확인한 결과로 해석하면 안 됩니다. 5m는 결과 격자 간격이지, 받은 DEM의 해상도가 아닙니다.

받은 공개 DEM의 원본 격자 간격은 90m입니다. 국토정보플랫폼의 공개 DEM 목록에서 내려받은 2025년 도엽 37709도 90m로 확인했습니다. 현재 지형은 이 DEM에 등고선과 표고점을 보태 만든 근사 자료이며, 별도의 5m DEM을 받은 것은 아닙니다.

국토지리정보원 공개 DEM 안내는 90m 자료를 제공 대상으로 설명합니다. 국토정보플랫폼에서도 2025년 도엽 37709 공개 DEM을 확인했으며, 기존에 받은 90m 자료와 같은 종류입니다. 별도의 5m 파일은 찾지 못했습니다.

다만 공공데이터포털의 `항공사진 수치표고성과 내역`에는 37709004·37709005 도엽의 2009년 성과가 `1m × 1m` 격자로 등록돼 있습니다. 이는 고해상도 자료가 제작됐다는 메타데이터 기록입니다. 내려받은 파일은 성과 목록 CSV이며 실제 격자 높이 파일은 포함하지 않습니다. 따라서 이 기록만으로 원본을 내려받거나 현재 장면의 지형을 1m 정확도로 만들 수 있다고 판단할 수 없습니다. 원본 제공 여부와 신청 조건을 국토지리정보원에 확인해야 합니다. [항공사진 수치표고성과 내역](https://www.data.go.kr/data/15067637/fileData.do)

환경공간정보 자료목록에는 전국 `수치표고모델`이 5m로 등록되어 있고, 제공처는 국토지리정보원, 연결 화면은 국토정보플랫폼으로 나옵니다. 이 목록은 자료의 종류와 해상도를 안내하지만 DEM 원본 파일을 제공하지는 않습니다. [환경공간정보 자료목록](https://data.neins.go.kr/bbs/list)

2026년 10월 28일 국토정보플랫폼에서 탄천 도엽 `37709005`를 조회했을 때는 연도별 공개 DEM 6개가 표시됐고, 화면은 로그인 상태가 아니었습니다. 현재 저장소에 받은 2025년 공개 DEM은 90m 격자입니다. 따라서 목록에 등록된 5m DEM 원본을 실제로 확보하기 전까지는 90m DEM에 등고선과 표고점을 보태 만든 근사 지형을 사용합니다. 이 근사 자료의 5m는 결과 격자 간격이며, 원본 DEM의 해상도가 아닙니다. ## 좌표와 높이

- 지도 중심: 위도 37.4936231°, 경도 127.1018462°
- 장면 좌표: 중심에서 동쪽·북쪽·위쪽을 미터로 계산합니다. 화면에서는 동쪽이 X, 위쪽이 Y, 북쪽이 -Z입니다.
- 정사영상: TIFF에 좌표 태그가 없어 국토정보플랫폼의 도엽 경계와 25cm 해상도로 위치를 정했습니다. 37709004와 37709005 원본은 약 100m 겹칩니다. 겹치는 도로와 지형을 대조해 두 영상의 위치를 맞춘 뒤, 겹친 부분을 부드럽게 섞었습니다. 지상 기준점을 측량해 절대 위치 오차를 검증한 자료는 아닙니다.
- DEM: 원본 좌표계는 EPSG:5179입니다. 고도 자료의 수직 기준은 함께 받은 보조 정보에서 확인되지 않아 해발고도라고 단정하지 않습니다. DEM에서 장면 중심과 주변의 높이 차를 구해 지면 모양에 반영했습니다. 시뮬레이션 원점은 기존 동작을 유지하도록 18m에 두었습니다. 이 값은 해발고도가 아닙니다.

## 원본 보관

받은 TIFF 6장과 메타데이터, DEM 압축 원본은 가공 근거로 보관합니다. TIFF 원본은 약 1.9GB라 실행 자료와 분리해 로컬 원본 보관 영역에 두며 Git에는 올리지 않습니다. 프로그램은 1.2km 구간을 잘라 만든 JPEG만 읽습니다. 두 정사영상의 약 102m 겹치는 곳은 부드럽게 섞었습니다. TIFF에 지리 좌표 태그가 없어 도엽 색인으로 위치를 맞췄고, 지상 기준점으로 위치 오차를 측량하지는 않았습니다.

정사영상과 높이 격자는 서로 다른 역할을 합니다. 정사영상은 색과 표면 무늬를 제공하고, 높이 격자는 지면 굴곡과 지면 충돌을 계산합니다. 높이 격자는 90m DEM과 1:1,000 등고선·표고점을 섞어 만든 근사 자료입니다. 건물이나 교량과 드론의 충돌에는 별도 형상이 필요합니다.
