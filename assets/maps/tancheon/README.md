# 탄천 장면에 실제 지형과 항공사진 적용하기

## 지금 장면에 들어간 자료

현재 장면은 저장소에 있는 약 30m 간격 높이 격자로 땅을 그리고, OSM 건물 외곽선은 단순한 입체 모양으로 표시합니다. 탄천 항공사진과 상세한 건물·교량 모델은 없습니다. 사용자가 받은 DEM 두 도엽은 90m 간격이며 아직 장면에 넣지 않았습니다. 격자 보조 정보에서도 높이 기준을 확인하지 못해 기존 지형을 대체하는 데 쓰지 않았습니다.

실제 모습에 가까워지려면 자료 세 가지가 필요합니다.

| 자료 | 쓰임 | 현재 상태 |
| --- | --- | --- |
| 고도 자료(DEM) | 땅의 높낮이와 지면 충돌 | 현재 장면은 약 30m 간격 자료를 씁니다. 받은 두 도엽은 90m 간격이고 높이 기준도 확인되지 않아 아직 적용하지 않았습니다. |
| 정사영상 | 지면에 입힐 항공사진 질감 | 아직 받지 않았습니다. |
| 건물·교량 3D 자료 | 외벽, 교량 상판·교각과 충돌 | S-Map에 자료가 있는지 확인해야 합니다. |

정사영상은 위에서 본 사진이라 건물 옆면이나 교량 밑면을 만들지 않습니다. 실제 탄천처럼 보이려면 정사영상이 필요하고, 제방 높낮이와 교량 구조까지 맞추려면 더 세밀한 DEM과 별도 3D 자료가 필요합니다. 사진이나 웹 지도 화면만으로 교량 충돌 모양을 만들 수는 없습니다.

## 1. 가장 먼저 받을 자료

### 실제 건물·교량 모델

[서울시 S-Map](https://news.seoul.go.kr/gov/archives/528155)은 지형, 건물, 교량을 포함한 3D 공간정보를 운영하지만, 공개 웹 지도에서 원본 GLB를 바로 내려받는 방법은 확인되지 않았습니다. [오픈랩 Q&A의 자료 제공 안내](https://openlab.eseoul.go.kr/mobile/qna.do)와 [공개제한 공간정보 안내](https://openlab.eseoul.go.kr/mobile/notice.do)를 먼저 확인하고, 필요한 구역의 원본 파일을 받을 수 있는지 문의합니다. 공개제한 자료는 신청 자격과 보안 심사가 붙을 수 있습니다.

요청할 때 아래 내용을 함께 적습니다.

- 대상: 탄천교 주변 약 1.2km × 1.2km
- 목적: C++ 드론 시뮬레이터의 화면 표시와 충돌 검증
- 필요한 자료: 지형 메시, 교량·건물 메시, 가능하면 항공사진 질감
- 바라는 형식: 지형·교량·건물 메시 원본(OBJ, FBX, CityGML 등)과 정사영상 또는 재질 이미지. 가능하면 GLB도 요청
- 좌표 기준: EPSG:5179 등 평면 좌표계, 높이 기준, 미터 단위
- 함께 확인할 내용: 자료 제작 시기, 위치 정확도, 수정 가능 여부, 웹 공개와 재배포 허용 범위

문의 글은 아래처럼 작성하면 됩니다.

> DroneSim에서 사용할 탄천교 주변 공간자료를 찾고 있습니다. 약 1.2km × 1.2km 범위의 지형·건물·교량 원본 메시와 정사영상 또는 재질 이미지를 받을 수 있는지 확인 부탁드립니다. 화면 표시와 충돌 시험에 사용할 예정입니다. 제공 형식, 좌표계, 수평·수직 기준, 제작 시기와 정확도, 파일 수정 및 GitHub Pages 공개·재배포 가능 여부, 신청 자격과 보안 심사 조건도 알려주세요.

GLB를 바로 받을 수 없다면 OBJ·FBX·CityGML 등 원본 형식과 변환 허용 범위를 확인합니다. 웹 지도 타일을 캡처하거나 서비스 통신을 우회해 모델을 추출하지 않습니다. 서울시 S-Map 담당 부서(02-2133-2835) 또는 [드론공간정보 담당 부서](https://news.seoul.go.kr/gov/archives/528178)(02-2133-2843)에 문의할 수 있습니다. 서울시는 드론으로 만든 3D 모델과 정사영상을 보유하지만, 이것만으로 탄천교 원본 제공이나 재배포 허가가 확인된 것은 아닙니다.

### 지형 높이 자료

[국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 `탄천교`를 검색한 뒤 오른쪽 자료 목록에서 `공개DEM`을 선택합니다. 대상 범위를 덮는 도엽 중 가장 작은 격자 간격을 확인해 받습니다. 이미 받은 `37705`, `37709` 두 도엽은 90m 간격으로, 넓은 지형 윤곽을 보는 용도입니다. 제방·도로·교량 주변을 자세히 표현하기에는 거칠며 현재 장면에도 적용하지 않았습니다.

검색 결과에 1m·5m 자료가 없으면 국토지리정보원에 탄천교 범위의 고해상도 DEM 보유 여부와 제공 자격을 문의합니다. 고해상도 자료는 공개 제한이나 신청 조건이 붙을 수 있습니다. 받은 파일은 QGIS에서 좌표계, 격자 간격, NoData 값, 높이 단위와 수직 기준을 확인합니다. 높이 기준을 모르면 `KNGeoid24`를 임의로 적용하지 않습니다. S-Map에도 같은 범위의 지형 메시가 있는지 함께 문의합니다.

### 항공사진 질감

같은 플랫폼에서 `탄천교`를 검색하고 검색 결과의 위치 표시를 누른 다음 `정사영상`을 선택합니다. 촬영 시기와 실제 내려받을 수 있는 해상도를 확인하고 필요한 도엽을 받습니다. 다운로드에는 로그인이 필요하며 대용량 전송 프로그램을 설치하라는 안내가 나올 수 있습니다. [국토지리정보원 정사영상 안내](https://www.data.go.kr/data/15059919/fileData.do)는 결과 파일이 TIFF이고 도시 지역은 12cm, 일반 지역은 25cm 항공사진을 바탕으로 제작된다고 설명합니다. 이 수치는 제작 기준이지 탄천에서 그 해상도 파일을 내려받을 수 있다는 보장은 아닙니다. 공공데이터포털의 일반 이용허락 표시와 별개로, 선택한 자료의 공개·변경·웹 재배포 조건을 확인합니다.

온라인 지도 화면을 캡처해 항공사진 대신 쓰지 않습니다. 원본 해상도와 이용·재배포 조건을 확인할 수 없기 때문입니다.

## 2. GLB와 질감 파일 만들기

자료를 받은 뒤 QGIS에서 DEM과 정사영상을 함께 열어 도로·하천 굽이·건물 모서리가 겹치는지 확인합니다. 같은 좌표계와 약 1.2km 범위로 자르고, 높이 과장은 1로 둡니다. 받은 지형을 GLB로 만드는 것은 별도 메시 생성 단계입니다. 정사영상만으로는 지형 높이가 생기지 않습니다.

### QGIS에서 지형 메시 내보내기

QGIS에서 다음 순서로 준비합니다. 메뉴 이름은 설치 언어에 따라 조금 다를 수 있습니다.

1. DEM과 정사영상 TIFF를 불러옵니다. 자료의 원본 좌표계를 확인한 다음 프로젝트를 EPSG:5179로 맞추고 두 자료가 겹치는지 확인합니다. 원본 좌표계를 확인하지 않고 EPSG:5179라고 가정하지 않습니다.
2. 처리 도구의 `래스터를 마스크 레이어로 자르기` 또는 범위 자르기를 사용해 두 자료를 같은 1.2km 사각형으로 자릅니다. 출력 해상도는 원본 DEM보다 촘촘하게 지정하지 않습니다.
3. `보기 → 3D 지도 보기 → 새 3D 지도 보기`를 엽니다. 3D 설정에서 지형 높이 자료는 DEM, 지도 질감은 정사영상이 표시된 2D 지도 화면으로 지정합니다. 수직 배율은 1로 둡니다.
4. 3D 지도 화면의 내보내기 메뉴에서 `3D 장면 내보내기`를 선택합니다. 지형과 질감 내보내기를 켜고, 메시·질감 해상도와 저장 폴더를 지정해 OBJ와 이미지 파일을 만듭니다.

QGIS는 지형과 벡터 요소를 OBJ로 내보내며 지형·질감 해상도를 지정할 수 있습니다. [QGIS 3D 지도 안내](https://docs.qgis.org/latest/en/docs/user_manual/map_views/3d_map_view.html#export-3d-scenes)에서 내보내기 항목을 확인할 수 있습니다.

[Qgis2threejs](https://plugins.qgis.org/plugins/Qgis2threejs/)는 DEM과 벡터 자료를 3D로 만들고 glTF로 내보낼 수 있습니다. 다만 현재 시뮬레이터가 읽는 GLB는 **노드 하나, 메시 하나, 삼각형 묶음 하나**여야 하며, GLB 안의 재질·사진은 읽지 않습니다. QGIS나 플러그인 결과를 그대로 넣기보다 Blender에서 지형을 한 메시로 합치고 변환을 적용한 뒤, 질감 이미지는 별도 파일로 저장해야 합니다.

QGIS에서 OBJ나 glTF를 내보낸 뒤 Blender에서 지형만 남기고 하나의 메시로 합칩니다. 여러 조각이 서로 다른 재질을 쓰면 사진을 한 장으로 굽고 재질도 하나로 정리합니다. 위치·회전·크기 변환을 메시 정점에 적용한 뒤 GLB로 내보냅니다. UV 좌표, 법선, 삼각형 번호가 있어야 합니다. 곡선·선·카메라 같은 다른 요소는 지형 메시에서 제외합니다. [Blender GLB 내보내기 안내](https://docs.blender.org/manual/en/4.2/addons/import_export/scene_gltf2.html)

### 좌표를 시뮬레이터 기준에 맞추기

시뮬레이터 지도 원점은 위도 37.4936231°, 경도 127.1018462°입니다. 수평 좌표는 동쪽 X, 높이는 위쪽 Y, 북쪽은 음수 Z로 표현합니다. 원본이 동쪽·북쪽·높이 `(E, N, H)`라면 GLB 좌표는 `(E-E0, H, -(N-N0))`입니다. 현재 화면과 충돌 계산은 DEM의 기준 높이를 포함한 높이값을 사용하므로, GLB에서 임의의 높이를 빼면 안 됩니다. 모든 값은 미터 단위여야 합니다.

E0·N0은 원점 위도·경도를 원본의 평면 좌표계로 변환한 값입니다. GLB 높이는 충돌 격자와 같은 수직 기준의 절대 높이를 씁니다. 자료가 타원체고인지 정표고인지 확인하고, 서로 다르면 변환 자료를 적용해야 합니다. GLB와 정사영상의 범위·축 방향·수직 기준이 하나라도 다르면 사진이 밀리거나 드론이 보이는 지면을 뚫고 지나갑니다.

### 정사영상을 화면 질감으로 준비하기

현재 시뮬레이터는 GLB 안에 든 사진이나 재질을 읽지 않습니다. GLB의 UV 좌표를 사용해 별도의 PPM 사진을 그립니다. 최종 결과는 `assets/maps/tancheon/terrain.glb`와 `assets/maps/tancheon/terrain.ppm`에 둡니다. 웹 빌드는 이 두 파일이 있으면 자산에 포함합니다. 따라서 GLB에 사진을 포함하는 것만으로는 화면에 나타나지 않습니다.

QGIS에서 GLB와 같은 사각형 범위로 자른 정사영상을 8비트 RGB 이미지로 내보냅니다. 1.2km 전체를 2048×2048 한 장으로 만들면 한 픽셀이 약 0.6m입니다. 전체 장면을 위에서 볼 때는 쓸 수 있지만, 낮게 비행하면 지면 질감이 흐려집니다. 현재 렌더러는 지형에 사진 한 장만 입히므로 교량 주변만 더 선명하게 만들려면 여러 질감 구역을 지원하는 코드 작업이 추가로 필요합니다. 이미지 크기만 키우면 웹 다운로드와 GPU 메모리 사용량도 함께 늘어납니다.

이미지 편집 프로그램에서 RGB·8비트·무압축 PPM 형식으로 저장합니다. GIMP에서는 `파일 → 다른 이름으로 내보내기`에서 PPM을 고릅니다. 형식은 `P6`, 최대 색상값은 `255`여야 합니다. 사진과 GLB는 같은 사각형 범위를 써야 하며, 위아래 방향도 맞춰야 합니다. 화면에서 도로·하천·건물 모서리가 겹치는지 확인합니다. GLB에 질감이 포함되어도 현재 코드에서는 표시되지 않으므로 별도 PPM 이미지를 함께 준비해야 합니다.

## 3. 충돌 지형도 같은 자료로 갱신하기

화면 지형과 충돌 지형은 서로 다른 자료를 읽습니다. 화면은 GLB 메시를, 지면 충돌은 높이 격자를 사용합니다. 따라서 GLB만 바꾸면 화면과 충돌 지면이 어긋납니다. 반대로 정사영상은 화면 색상만 바꾸며 충돌 계산에는 쓰이지 않습니다.

QGIS에서 화면용 메시와 같은 DEM·범위·수직 기준으로 충돌용 높이 격자를 다시 만듭니다. 격자 간격을 원본보다 촘촘하게 보간해도 측량 정보가 늘지는 않습니다. 현재 받은 90m 자료를 1m 간격으로 바꿔도 실제 지형 정확도는 90m 수준입니다. 교량·건물 충돌은 별도 충돌 모양으로 등록해야 합니다. 화면에 보이는 GLB가 자동으로 충돌체가 되지는 않습니다.

## 4. 자료를 받기 전후 확인할 점

- S-Map에서 해당 구역의 원본 메시를 제공하는지, 웹 타일만 제공하는지 확인합니다.
- DEM, 정사영상, 3D 모델의 좌표계·높이 기준·제작 시기·정확도를 기록합니다.
- 자료를 수정해 GLB·질감으로 변환할 수 있는지, GitHub Pages에 올려도 되는지 확인합니다.
- GLB가 노드 하나·메시 하나·삼각형 묶음 하나로 되어 있고, 정점에 UV와 법선이 있는지 확인합니다.
- GLB와 PPM 사진의 영역과 방향이 일치하는지 확인합니다.
- 화면 메시와 충돌 격자가 같은 DEM과 같은 높이 기준을 쓰는지 확인합니다.
