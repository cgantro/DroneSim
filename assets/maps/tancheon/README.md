# 탄천 지형과 항공사진 준비

화면을 실제 탄천과 비슷하게 만들려면 **지형 높이 자료(DEM)**와 **정사영상**이 필요합니다. DEM은 땅의 높낮이를 만들고, 정사영상은 위에서 찍은 실제 사진을 지표에 입힙니다. 사진만으로 제방 높이나 교량 구조가 생기지는 않습니다.

## 자료 내려받기

### 국토지리정보원 자료

[국토정보플랫폼 통합지도검색](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 탄천교를 검색한 다음, 같은 위치에서 DEM과 정사영상을 각각 받습니다.

1. 지도에서 `탄천교`를 검색하고 탄천교와 주변 비행 구역이 함께 들어오도록 화면을 맞춥니다.
2. 자료 종류에서 **공개DEM**을 고릅니다. 검색 결과의 격자 간격과 제작 시기를 확인하고, 가장 촘촘한 자료를 선택합니다. 파일 이름에 있는 숫자만으로 해상도를 판단하지 마세요.
3. 같은 화면 범위에서 **정사영상**을 선택합니다. 항공사진 원본이 아니라 지도 좌표에 맞게 보정된 영상이며, 결과의 촬영 시기·픽셀 크기·좌표계를 확인합니다.
4. 원본 파일과 함께 제공되는 메타정보를 보관합니다. 좌표계와 높이 기준이 확인되지 않으면 기존 지도와 섞지 않습니다.

국토지리정보원 자료 설명은 [공개 DEM](https://www.data.go.kr/data/15059920/fileData.do)과 [정사영상](https://www.data.go.kr/data/15059919/fileData.do)에서 확인할 수 있습니다. 정사영상은 로그인과 대용량 파일 전송 프로그램 설치가 필요할 수 있습니다. 다운로드 화면의 이용 조건과 출처 표기도 함께 보관하세요.

현재 받은 공개 DEM 두 장은 검사 결과 모두 **90m 격자**입니다. 현 저장소의 높이 격자는 30m 간격이므로, 받은 파일을 더 촘촘한 격자로 다시 저장해도 실제 지형 정보가 늘어나지 않습니다. [국토지리정보원 자료](https://www.ngii.go.kr/lib/file/pr_01.pdf)에는 서울·경기 일부의 1m DEM이 소개되어 있지만 공개 자료로 제공된다고 보장할 수 없습니다. 원본 공간정보 신청도 공공기관·지자체 공문 접수로 제한될 수 있습니다. 따라서 더 세밀한 자료는 [국토지리정보원에 제공 지역·신청 자격·이용 조건을 확인](https://www.ngii.go.kr/nlsc/service/method)한 뒤 확보 여부를 판단합니다. `KNGeoid24`는 높이 기준을 바꾸는 자료이며 DEM을 대신하지 않습니다.

### 실제 3D 건물과 교량

DEM과 정사영상으로 만들 수 있는 것은 **사진이 입혀진 지형 표면**입니다. 건물 외벽, 교량 상판과 교각까지 실제 모양으로 보이려면 별도의 3D 모델이 필요합니다.

서울시 [S-Map 오픈랩 문의 게시판](https://openlab.eseoul.go.kr/mobile/qna.do)에 탄천교 주변 지형·건물·교량 모델의 제공 가능 여부를 문의하세요. 화면에서 보이는 모델을 바로 내려받을 수 있다고 가정하지 않습니다. 문의할 때는 원본 형식, 좌표계와 높이 기준, 변환·편집 허용 여부, 포트폴리오와 웹 공개 가능 여부를 함께 확인합니다. 서울시 공개제한 공간정보는 별도 신청이나 보안 심사를 요구할 수 있습니다. 자료 사용 조건은 [S-Map 공지](https://openlab.eseoul.go.kr/mobile/notice.do)에서 확인합니다.

## DEM으로 지형 GLB 만들기

S-Map에서 바로 쓸 수 있는 GLB를 받지 못해도, DEM에서 지형 메시를 만들 수 있습니다. [QGIS](https://qgis.org/download/)와 [Qgis2threejs](https://plugins.qgis.org/plugins/Qgis2threejs/)를 사용합니다. 이 플러그인은 DEM을 3D 지형으로 보여 주고 GLB로 내보냅니다. [내보내기 안내](https://minorua.github.io/Qgis2threejs/docs/3.1/Exporter.html)

1. QGIS에서 DEM과 정사영상을 엽니다. 두 자료가 같은 위치에 겹치는지 확인합니다. 다르면 좌표계를 변환해 한쪽에 맞춥니다.
2. 프로젝트 좌표계를 미터 단위 좌표계로 설정하고 탄천교 주변의 작업 범위를 고릅니다. DEM과 정사영상은 **같은 경계와 중심**으로 자릅니다. 우선 작은 범위로 시험합니다.
3. Qgis2threejs의 DEM 항목만 켜고 GLB로 내보냅니다. 사진을 GLB 재질에 넣어도 현재 프로그램은 그 재질과 내장 이미지를 읽지 않으므로, 아래 절차대로 사진 파일을 따로 준비합니다.
4. GLB를 Blender에서 열어 지형 외의 객체를 제거하고 메시를 하나로 합칩니다. 회전·이동·크기를 적용한 뒤 GLB로 저장합니다. 현재 로더는 메시 1개와 삼각형 묶음 1개를 요구하며 위치·법선·삼각형 번호를 읽습니다. 사진을 입히려면 UV 좌표도 있어야 합니다. 변환값이 정점에 적용되지 않은 GLB는 그대로 읽지 못합니다.
5. 장면 기준점은 위도 `37.4936231°`, 경도 `127.1018462°`입니다. 모델은 미터 단위로 두고 동쪽은 X+, 위쪽은 Y+, 북쪽은 Z- 방향으로 맞춥니다. 모델의 수평 중심은 장면 원점에 놓고, 높이는 `terrain.aerotrn`과 같은 기준점·수직 기준을 사용합니다. 현재 충돌 높이의 원본은 EGM96 기준 SRTM이므로, 다른 수직 기준의 자료를 변환 없이 섞지 않습니다.
6. 저장한 모델을 3D 뷰어로 확인합니다. 기준점이 원점에 있고, 북쪽 방향과 높이가 맞으며, 경계가 잘리지 않는지 확인한 뒤 `assets/maps/tancheon/terrain.glb`에 둡니다.

QGIS에서 만든 GLB는 **화면에 보이는 지형**입니다. 현재 드론의 지면 충돌은 별도 높이 격자를 사용하므로, 이 GLB만 바꾸면 화면 지형과 충돌 높이가 달라질 수 있습니다. 두 결과를 맞추려면 동일한 원본 DEM과 좌표·높이 기준으로 충돌 격자도 갱신해야 합니다. 현재 저장소에는 GeoTIFF에서 충돌 격자를 자동 생성하는 변환 절차가 없으므로, 새 DEM을 받으면 이 연결 작업도 필요합니다.

## 정사영상으로 지형 사진 만들기

화면에 입힐 사진은 앞에서 받은 정사영상 TIFF를 사용합니다. 별도 사진 사이트의 지도 타일을 이어 붙이지 말고, 같은 작업 범위와 좌표계를 가진 원본을 준비합니다.

1. QGIS에서 정사영상 TIFF를 DEM과 같은 범위로 자르고, 같은 미터 단위 좌표계로 변환합니다. 자른 경계가 지형 GLB의 바닥 경계와 일치해야 합니다.
2. 저장 옵션에서 **PNM/PPM**, RGB 8비트 형식으로 내보냅니다. 확장자만 바꾸지 말고, 실제 PPM(P6) 파일인지 확인합니다. QGIS가 PPM 저장을 제공하지 않으면 [GDAL PNM 변환 안내](https://gdal.org/en/stable/drivers/raster/pnm.html)를 참고합니다.
3. 처음에는 2048×2048 픽셀로 저장해 용량과 화질을 확인합니다. 4096×4096 RGB PPM은 약 48MB이며 웹 빌드에 그대로 포함되므로 로딩이 느려질 수 있습니다.
4. 파일을 지형 GLB와 함께 실행해 사진이 뒤집히거나 밀리지 않는지 확인합니다. 사진 방향이 맞지 않으면 파일을 임의로 회전하기보다 GLB의 UV 좌표와 QGIS 내보내기 방향을 함께 확인합니다.

프로그램은 이 PPM을 지형의 UV 좌표에 맞춰 입힙니다. PPM은 색과 무늬만 바꾸며 지형 높이나 충돌 계산에는 영향을 주지 않습니다. 변환한 사진은 `assets/maps/tancheon/terrain.ppm`에 둡니다. GLB와 사진은 네이티브 및 웹 빌드에서 함께 읽습니다.

## 장면에 넣기 전 확인할 점

- GLB와 정사영상의 촬영·제작 범위가 같은가?
- 좌표계, 동서·남북 방향, 미터 단위, 높이 기준을 확인했는가?
- QGIS GLB를 Blender에서 메시 하나로 합치고 변환값을 적용했는가?
- 지형 사진이 GLB 경계에 맞고 방향이 올바른가?
- 충돌 격자도 같은 DEM에서 만들었는가? 아직 아니라면 화면과 충돌 높이가 다를 수 있음을 표시했는가?
- 원본 자료의 출처, 촬영 시기, 해상도, 좌표·높이 기준과 공개 허가를 기록했는가?

현재 저장소에는 실제 항공사진과 지형 GLB가 없습니다. 탄천을 실제처럼 보이게 하려면 먼저 국토정보플랫폼에서 정사영상 TIFF를 내려받아 첨부해야 합니다. 받은 공개 DEM은 90m라 고해상도 지형을 만들기에는 부족합니다. 실제 교량 모양과 충돌까지 맞추려면 상판·교각 치수를 확인할 수 있는 별도 3D 자료도 필요합니다.
