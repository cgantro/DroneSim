# 탄천 실제 지형 자료 받기와 적용하기

## 지금 장면에 부족한 자료

현재 탄천 장면에는 실제 항공사진 질감과 상세 3D 건물·교량 모델이 없습니다. 저장소의 지형 격자는 약 30m 간격이며, 최근 받은 두 공개 DEM 도엽은 약 90m 간격입니다. 두 자료 모두 제방·교량 주변을 세밀하게 표현하기에는 거칩니다. DEM 격자를 촘촘하게 보간해도 원본 지형의 정확도가 높아지지는 않습니다.

실제 모습에 가까운 장면을 만들려면 아래 자료가 필요합니다.

| 자료 | 쓰임 | 받을 곳 |
| --- | --- | --- |
| 세밀한 DEM | 지면 높낮이와 지면 충돌 | [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total) |
| 정사영상 원본 | 실제 지면 색과 도로·하천 모양 | [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total) |
| 건물·교량 3D 원본 | 건물 옆면, 교량 상판·교각·하부 | [S-Map 오픈랩 자료 안내](https://openlab.eseoul.go.kr/mobile/qna.do) |

정사영상은 위에서 찍은 사진입니다. 지면을 실제처럼 보이게 하지만 건물 옆면이나 교량 아래쪽을 만들지는 않습니다. DEM과 정사영상으로 만들 수 있는 GLB는 지표면 모델이며, 구조물 모양은 별도의 3D 자료가 있어야 합니다.

## 항공사진과 DEM 받기

1. [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)을 엽니다.
2. 탄천교 주변을 검색한 뒤, 프로젝트 중심인 위도 37.4936231°, 경도 127.1018462°를 덮는 범위를 지정합니다. 기본 범위는 약 1.2km 정사각형입니다.
3. 자료 목록에서 `정사영상`을 선택하고, 촬영 시기와 해상도가 표시된 항목을 확인해 TIFF 원본을 받습니다.
4. 같은 지역의 `공개DEM`도 확인합니다. 가능하면 5m 또는 그보다 촘촘한 자료를 찾고, 실제 격자 간격과 높이 기준을 기록합니다. 현재 받은 두 도엽은 약 90m 간격이라 제방과 교량 주변을 표현하기에 거칩니다.

탄천 구간에 더 촘촘한 DEM이 없으면 [서울시 1:1,000 수치지형도 안내](https://news.seoul.go.kr/gov/archives/528208)에서 수치지형도 자료도 확인할 수 있습니다. 이 지도에는 지형선과 표고 정보가 포함될 수 있으므로, 실제 받은 자료에 등고선·표고점이 있는지, 등고 간격·좌표계·높이 기준이 무엇인지 확인한 뒤 보조 지형으로 가공합니다. 축척이 1:1,000이라고 해서 DEM 해상도나 높이 정확도가 같은 수준이라는 뜻은 아닙니다.

국토지리정보원 안내에 따르면 정사영상은 TIFF로 제공되며 다운로드에는 로그인이 필요합니다. 플랫폼이 대용량 전송 프로그램을 안내할 수 있습니다. 도시 지역은 12cm, 일반 지역은 25cm 항공사진을 사용해 정사영상을 만들지만, 탄천에서 실제로 받을 수 있는 해상도와 촬영 시기는 검색 결과에서 확인해야 합니다. 데이터 포털에는 무료·이용허락 제한 없음으로 등록되어 있어도, 실제 내려받는 항목의 조건과 공개 가능한 범위는 함께 확인해 주세요.

정사영상 자료 설명은 [공공데이터포털의 국토지리정보원 정사영상 안내](https://www.data.go.kr/data/15059919/fileData.do), DEM 형식과 다운로드 방법은 [국토지리정보원 DEM 안내](https://www.data.go.kr/data/15059920/fileData.do)에서 확인할 수 있습니다. 지도 화면을 캡처해 텍스처로 쓰면 원본 해상도와 사용 허가를 확인할 수 없으므로 사용하지 않습니다.

## 탄천 건물·교량 3D 자료 받기

서울시는 S-Map에 서울시 전역의 지형·건물·교량 모델을 구축했고, 탄천을 포함한 주요 하천 주변 자료도 갱신했다고 안내합니다. 다만 공개 웹페이지에서 해당 지역의 원본 GLB를 바로 내려받는 주소는 찾지 못했습니다. [S-Map 자료 제공 FAQ와 문의 게시판](https://openlab.eseoul.go.kr/mobile/qna.do)에서 탄천교 주변 자료의 원본 제공 여부를 확인해야 합니다.

문의할 때는 아래 조건을 한 번에 보내세요.

> DroneSim에서 탄천교 주변 드론 정찰 장면을 만들려고 합니다. 위도 37.4936231°, 경도 127.1018462° 중심 약 1.2km 범위의 지형·건물·교량 3D 원본과 정사영상 제공 여부를 문의드립니다. 가능한 원본 형식(GLB, OBJ, CityGML 등), 좌표계, 수직 기준, 제작 시기, 모델의 수정·웹 공개·재배포 허용 범위, 신청 자격을 알려 주세요. 교량은 상판과 교각, 하부 공간이 구분된 자료가 필요합니다.

서울시 공개제한 공간정보에 해당하는 자료라면 신청 자격과 보안 심사가 따로 적용됩니다. 서울시 안내에는 법인 또는 사업자 등록을 한 신청자와 보안심사가 명시되어 있습니다. 개인 포트폴리오에서 사용할 수 있는 공개 자료가 있는지 먼저 문의하고, 승인 전에는 웹에 올리거나 저장소에 넣지 않습니다. 세부 조건은 [서울시 공개제한 공간정보 안내](https://openlab.eseoul.go.kr/mobile/notice.do)에서 확인할 수 있습니다.

서울시가 2024년 항공·드론·라이다 자료를 갱신하고 탄천을 포함한 하천 주변 시설물을 실감형 공간정보로 보완했다는 안내는 [서울시 S-Map 최신 자료 소개](https://mediahub.seoul.go.kr/archives/2013136)에 있습니다. 이는 해당 모델의 원본 파일이 누구나 내려받을 수 있다는 뜻은 아닙니다.

## 받은 자료로 지형 GLB와 텍스처 만들기

정사영상과 DEM을 확보하면 QGIS에서 지형 GLB의 원본을 만들 수 있습니다. QGIS 3D 장면 내보내기는 지형과 지도 레이어를 OBJ 장면과 텍스처 이미지로 내보냅니다. 이어 Blender에서 지형 메시를 GLB로 저장합니다. QGIS와 Blender 설치는 [QGIS 내려받기](https://qgis.org/download/)와 [Blender 내려받기](https://www.blender.org/download/)에서 할 수 있습니다. 메뉴와 내보내기 설정은 [QGIS 3D 장면 내보내기 안내](https://docs.qgis.org/3.44/ko/docs/user_manual/map_views/3d_map_view.html)와 [Blender GLB 내보내기 안내](https://docs.blender.org/manual/en/4.2/addons/import_export/scene_gltf2.html)를 참고하세요.

1. QGIS에서 받은 DEM과 정사영상의 좌표계·범위가 맞는지 확인합니다. 좌표계가 표시되지 않거나 수직 기준을 모르면 임의로 지정하지 말고 제공처에 확인합니다.
2. 두 자료를 같은 범위로 자르고 정사영상을 지형의 표면 질감으로 설정합니다. DEM의 실제 격자보다 더 촘촘하게 내보내도 지형 정확도가 높아지지 않습니다.
3. QGIS 3D 지도 보기에서 지형 높이 배율을 1로 두고, 지형과 텍스처를 OBJ 및 이미지로 내보냅니다.
4. Blender에서 위치·회전·크기를 적용한 뒤 지형을 하나의 삼각형 메시로 정리하고 GLB로 내보냅니다. 내보낸 GLB의 이미지 좌표가 항공사진과 맞는지 도로·하천 모양을 대조합니다.
5. 텍스처 이미지는 현재 프로그램이 읽는 PPM(P6, RGB 8비트) 형식으로 따로 저장합니다. GLB 안에 들어 있는 재질 이미지는 현재 읽지 않으므로, GLB 내장 텍스처만 있으면 화면에는 적용되지 않습니다.

화면과 충돌 지형이 같은 곳에 놓이도록 좌표와 높이 기준을 맞춰야 합니다. 시뮬레이터의 지면 좌표는 동쪽·북쪽·위쪽을 미터로 쓰고, 화면에서는 동쪽이 X, 위쪽이 Y, 북쪽이 -Z입니다. 지형 모델은 지도 중심을 원점으로 옮기고 축을 변환해 저장합니다. 수직 기준과 기준 고도도 충돌 격자와 맞춰야 합니다. 맞지 않으면 화면의 땅과 실제 충돌 높이가 달라집니다.

현재 GLB 읽기는 노드 하나·메시 하나·삼각형 묶음 하나로 만든 지형을 받습니다. 넓은 장면을 큰 단일 이미지로 만들면 내려받기와 웹 시작이 느려질 수 있습니다. 우선 1.2km 범위는 2048×2048 정도로 시험하고, 가까이서 선명하게 볼 탄천교 주변만 별도 고해상도 영역으로 받는 편이 좋습니다. 2048×2048 PPM은 약 12MiB, 4096×4096은 약 48MiB입니다.

## 파일을 받은 뒤 확인할 항목

자료를 받을 때 원본과 함께 제공되는 좌표·월드 파일도 보관하고, 아래 정보를 기록해 주세요.

- 촬영일 또는 제작일, 원본 해상도, 실제 격자 간격
- 좌표계와 높이 기준, 단위
- 이용 조건과 출처 표기 방법, 웹 배포 허용 여부
- GLB/OBJ 모델의 범위와 기준점, 축 방향, 단위
- 모델이 지형인지 건물·교량인지, 충돌에 쓸 형상이 포함됐는지

먼저 필요한 자료는 탄천교 주변의 정사영상 TIFF입니다. 로그인 후 내려받아 이 대화에 첨부해 주세요. S-Map 3D 모델은 위 문의를 통해 원본 제공과 개인 포트폴리오 사용 가능 여부를 확인한 뒤 보내 주시면, 좌표·재질·충돌 자료를 맞춰 실제 장면에 연결하겠습니다.
