# 탄천 지형과 항공사진 준비

현재 장면은 30m 간격의 높이 격자와 건물·도로 외곽선을 바탕으로 그립니다. 실제 항공사진 질감과 세밀한 지형 모양을 내려면 **정사영상**과 더 촘촘한 **DEM**이 필요합니다. 정사영상은 땅의 색과 무늬를 보여 주고, DEM은 땅의 높낮이를 만듭니다. 둘 중 하나만으로는 실제 건물 외벽이나 교량 상판·교각이 생기지 않습니다.

## 먼저 받을 자료

| 자료 | 어디에 쓰나 | 지금 확인된 상태 |
| --- | --- | --- |
| 정사영상 TIFF | 지형 표면에 항공사진을 입힘 | 저장소에 없음 |
| DEM | 지형 모양과 지면 높이를 만듦 | 받은 공개 DEM 두 장은 90m 격자라 세부 지형 표현에 부족함 |
| 건물·교량 3D 자료 | 건물 외벽과 교량 구조를 표시하고 충돌 형상을 만듦 | OSM 외곽선만 있으며 실제 3D 자료는 없음 |

원본 파일과 함께 촬영·제작 시기, 격자 간격 또는 화소 크기, 좌표계, 높이 기준, 사용 조건이 적힌 정보를 보관하세요. 확대 저장은 실제 세부 정보를 늘리지 않습니다.

## 정사영상과 DEM 받기

[국토정보플랫폼 통합검색](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 탄천교를 검색하고 필요한 지역을 지정합니다. 자료를 내려받으려면 로그인이 필요하며, 대용량 전송 프로그램을 설치하라는 안내가 나올 수 있습니다. [정사영상 안내](https://www.data.go.kr/data/15059919/fileData.do)와 [DEM 안내](https://www.data.go.kr/data/15059920/fileData.do)에서도 파일 형식과 이용 방법을 확인할 수 있습니다.

1. **정사영상**을 선택하고 작업 지역을 덮는 TIFF를 받습니다. 항목에 표시된 촬영 연도와 화소 크기를 확인하세요. 국토지리정보원은 도시 지역에 12cm급, 일반 지역에 25cm급 영상을 제작한다고 안내하지만, 탄천에 실제로 제공되는 항목의 정보가 기준입니다.
2. 같은 화면 범위에서 **공개DEM**을 선택합니다. 격자 간격과 높이 기준을 확인하고, 제공되는 것 중 가장 촘촘한 자료를 받습니다. 현재 받은 두 장은 90m 격자입니다. 이 파일을 5m나 1m 간격으로 다시 저장해도 원래 없던 지형 정보는 생기지 않습니다.
3. 받은 자료의 좌표계와 높이 기준을 확인합니다. 값이 없거나 기존 자료와 다르면 변환 방법을 먼저 확인합니다. 수평 위치가 맞아도 높이 기준이 다르면 지형과 드론의 충돌 높이가 어긋납니다.

더 세밀한 DEM은 공개 검색 결과에서 제공되는지 먼저 확인하세요. [국토지리정보원 자료](https://www.ngii.go.kr/lib/file/pr_01.pdf)에는 1m·5m 격자 DEM 제작 사례가 있지만 모든 지역의 원본을 공개한다는 뜻은 아닙니다. 탄천 자료가 목록에 없으면 [국토지리정보원에 제공 여부와 신청 조건을 문의](https://www.ngii.go.kr/nlsc/service/method)하세요. 지금 가진 90m DEM만으로는 실제 제방이나 둔치의 세부 굴곡을 만들 수 없습니다.

## 실제 건물·교량 자료 요청하기

서울시는 [S-Map에 서울 전역의 지형·건물·일부 시설물 3D 정보를 구축](https://news.seoul.go.kr/gov/archives/528155)했다고 안내합니다. 하지만 지도 화면에서 볼 수 있다는 사실만으로 원본 파일을 내려받거나 다른 웹사이트에 공개할 수 있다는 뜻은 아닙니다.

[S-Map 오픈랩의 데이터 제공 FAQ](https://openlab.eseoul.go.kr/mobile/qna.do)와 [공개제한 공간정보 제공 안내](https://openlab.eseoul.go.kr/mobile/notice.do)를 먼저 확인하세요. 공개제한 자료는 서울시에 신청하고 보안 심사를 거쳐야 하며, 안내문에는 신청 자격을 법인 또는 사업자 등록자로 적고 있습니다. 개인은 신청할 수 있는 공개 자료가 있는지 서울시 공간정보과에 별도로 확인해야 합니다.

문의할 때는 탄천교와 주변 구역을 지정하고 다음을 물어보세요.

- 지형·건물·교량 모델의 원본 파일을 제공하는가?
- 좌표계와 높이 기준, 제작 시기는 무엇인가?
- 모델을 편집해 GLB로 바꿀 수 있는가?
- 개인 포트폴리오와 GitHub Pages에 공개해도 되는가?
- 원본을 저장소에 포함하지 않고 변환 결과만 공개할 수 있는가?

실제 3D 자료를 받을 수 없다면 정사영상은 지형 사진에, 공개 DEM은 낮은 정밀도의 지형에 사용하고, 건물·교량은 단순화한 시험 형상으로 남겨야 합니다. 이 경우 실제 시설물의 모양이나 충돌을 재현했다고 표현하지 않습니다.

## QGIS에서 지형 GLB와 사진 만들기

[QGIS](https://qgis.org/download/)에서 정사영상과 DEM을 함께 열고, 두 자료가 같은 위치에 포개지는지 확인합니다. QGIS의 플러그인 관리 창에서 [Qgis2threejs](https://plugins.qgis.org/plugins/Qgis2threejs/)를 설치하면 DEM을 3D 표면으로 만들고 GLB로 내보낼 수 있습니다. 이 플러그인의 [내보내기 안내](https://minorua.github.io/Qgis2threejs/docs/3.1/Exporter.html)는 지형 표면에 지도 화면이나 영상 레이어를 재질로 입히는 방법도 설명합니다.

1. QGIS 프로젝트 좌표계를 미터 단위의 평면 좌표계로 정합니다. 정사영상과 DEM을 같은 작업 범위로 자르고, 외곽선이 정확히 포개지는지 확인합니다. 처음에는 비행 임무 주변의 작은 구역만 사용하세요.
2. Qgis2threejs에서 DEM 지형만 선택해 GLB로 내보냅니다. 좌표를 큰 숫자 그대로 유지하지 말고, 시뮬레이터의 기준점에 맞춰 지형 중심을 원점으로 옮깁니다. 프로젝트 좌표계의 동·북 방향을 시뮬레이터의 동쪽 X+, 위쪽 Y+, 북쪽 Z- 축에 맞춥니다.
3. 정사영상은 지형 GLB와 **같은 경계와 방향**으로 잘라 별도 이미지로 저장합니다. 현재 렌더러는 GLB 안의 재질 이미지를 읽지 않고 P6 형식의 PPM 사진을 따로 읽습니다. QGIS에서 PNM/PPM으로 내보낼 수 없다면 GDAL의 [PNM 변환 안내](https://gdal.org/en/stable/drivers/raster/pnm.html)를 따라 RGB P6 파일로 변환합니다. 확장자만 바꾸면 안 됩니다.
4. 처음에는 2048×2048 픽셀로 만들어 화면을 확인합니다. RGB PPM은 2048 크기에서 약 12MB, 4096 크기에서 약 48MB입니다. 웹 화면의 첫 로딩을 고려해 작은 시험 구역부터 시작하세요.
5. GLB에 위치·법선·UV·삼각형 정보가 들어 있는지 확인합니다. 현재 로더는 메시와 삼각형 묶음이 각각 하나인 단순한 GLB만 받습니다. 여러 조각으로 나뉘었거나 위치·회전·크기 변환이 노드에 남아 있으면 Blender에서 메시를 하나로 합치고 변환을 적용한 뒤 다시 내보내야 합니다.
6. 화면에서 사진의 방향과 위치, 지형의 높이를 확인합니다. GLB와 충돌 지형이 같은 기준점·좌표계·높이 기준을 쓰는지도 비교합니다.

지형 GLB와 사진만 바꾸면 화면은 달라져도 드론의 지면 충돌은 그대로입니다. 현재 충돌 높이 자료는 별도 30m SRTM 격자이며, 새 DEM에서 충돌용 높이 격자를 만드는 변환 도구는 아직 없습니다. 두 자료를 맞추려면 같은 DEM으로 충돌 자료도 다시 만들어야 합니다.

## 화면에서 건물이 네모 상자로 보이는 이유

정사영상은 위에서 본 땅의 사진이라 건물 옆면을 만들지 않습니다. OSM 외곽선과 건물 높이로 만든 현재 형상도 단순한 건물 덩어리입니다. 실제 외벽 사진과 지붕 모양까지 보이려면 질감이 포함된 건물 3D 모델이 필요합니다. 교량도 상판·교각·난간 자료를 따로 받아야 화면과 충돌 검사를 함께 맞출 수 있습니다.

## 자료를 장면에 넣기 전 확인

- DEM과 정사영상의 범위가 같고, 지도에서 서로 어긋나지 않는가?
- 미터 단위 좌표계와 높이 기준을 확인했는가?
- GLB 원점·축 방향이 시뮬레이터 기준과 맞는가?
- 사진이 지형 표면과 같은 경계에 놓이고 뒤집히거나 밀리지 않는가?
- 새 DEM으로 충돌 높이도 다시 만들었는가? 아직이라면 화면 지형과 충돌 지형이 다르다는 점을 표시했는가?
- 원본 자료의 사용 조건이 웹 공개와 변환 결과 배포를 허용하는가?

현재 저장소에는 실제 정사영상과 지형 GLB가 없습니다. 먼저 국토정보플랫폼에서 탄천 주변 정사영상 TIFF를 받아야 사진 질감을 적용할 수 있습니다. 지형을 실제처럼 굴곡지게 만들려면 공개 검색에서 90m보다 촘촘한 DEM을 찾거나 제공 기관에 신청해야 합니다. 받은 자료를 이 대화에 첨부하면 저장소에서 지원하는 좌표·파일 형식에 맞춰 변환하고 화면과 충돌 높이를 확인할 수 있습니다.
