# 탄천 실제 지형 자료 받기와 적용하기

## 지금 장면에 부족한 자료

현재 탄천 장면에는 실제 항공사진 질감과 상세 3D 건물·교량 모델이 없습니다. 저장소의 지형 격자는 약 30m 간격이고, 받은 공개 DEM은 90m 간격입니다. 받은 DEM은 기존 지형보다 거칠어 교체 자료로 쓰지 않습니다. 격자를 보간해도 원본보다 정확해지지 않습니다.

실제 모습에 가까운 장면을 만들려면 아래 자료가 필요합니다.

| 자료 | 쓰임 | 받을 곳 |
| --- | --- | --- |
| 더 세밀한 DEM | 지면 높낮이와 지면 충돌 | [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total) |
| 정사영상 원본 | 실제 지면 색과 도로·하천 모양 | [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total) |
| 건물·교량 3D 원본 | 건물 옆면, 교량 상판·교각·하부 | [S-Map 오픈랩 자료 안내](https://openlab.eseoul.go.kr/mobile/qna.do) |

정사영상은 위에서 찍은 사진입니다. 지면을 실제처럼 보이게 하지만 건물 옆면이나 교량 아래쪽을 만들지는 않습니다. DEM과 정사영상으로 만들 수 있는 GLB는 지표면 모델이며, 구조물 모양은 별도의 3D 자료가 있어야 합니다.

## 항공사진과 DEM 받기

1. [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)을 엽니다.
2. 탄천교 주변을 검색한 뒤, 프로젝트 중심인 위도 37.4936231°, 경도 127.1018462°를 덮는 범위를 지정합니다. 기본 범위는 약 1.2km 정사각형입니다.
3. 자료 목록에서 `정사영상`을 선택하고, 촬영 시기와 해상도가 표시된 항목을 확인해 TIFF 원본을 받습니다.
4. 같은 지역의 `공개DEM`을 확인합니다. 일반 공개 자료는 90m 간격이므로, 30m 이하 간격 자료가 검색되지 않는다면 받은 90m 도엽을 그대로 사용합니다. 1m·5m급 정밀 DEM은 지역과 신청 목적에 따라 제공이 제한될 수 있습니다. 국토정보플랫폼에 탄천 구간의 이용 자격, 승인 절차, 웹 공개 가능 여부를 먼저 문의합니다.

탄천 구간에 더 촘촘한 DEM이 없으면 [서울시 1:1,000 수치지형도 안내](https://news.seoul.go.kr/gov/archives/528208)에서 수치지형도 자료도 확인할 수 있습니다. 이 지도에는 지형선과 표고 정보가 포함될 수 있으므로, 실제 받은 자료에 등고선·표고점이 있는지, 등고 간격·좌표계·높이 기준이 무엇인지 확인한 뒤 보조 지형으로 가공합니다. 축척이 1:1,000이라고 해서 DEM 해상도나 높이 정확도가 같은 수준이라는 뜻은 아닙니다.

정사영상은 TIFF로 제공되며 내려받으려면 국토정보플랫폼 로그인이 필요합니다. 플랫폼이 대용량 전송 프로그램을 안내할 수 있습니다. 국토지리정보원 자료는 제작에 사용한 항공사진 해상도로 도시 지역 12cm, 일반 지역 25cm를 안내하지만, 탄천에서 실제로 받을 수 있는 해상도와 촬영 시기는 검색 결과에서 확인해야 합니다. 내려받은 항목의 이용 조건과 웹 공개 가능 범위도 확인합니다.

정사영상 자료 설명은 [공공데이터포털의 국토지리정보원 정사영상 안내](https://www.data.go.kr/data/15059919/fileData.do), DEM 형식과 다운로드 방법은 [국토지리정보원 DEM 안내](https://www.data.go.kr/data/15059920/fileData.do)에서 확인할 수 있습니다. 지도 화면을 캡처해 텍스처로 쓰면 원본 해상도와 사용 허가를 확인할 수 없으므로 사용하지 않습니다.

## 탄천 건물·교량 3D 자료 받기

서울시는 탄천을 포함한 하천 주변 공간정보를 S-Map에 반영했다고 안내합니다. 다만 공개 페이지에서 해당 지역의 원본 GLB를 내려받는 메뉴는 확인되지 않았습니다. S-Map 화면을 캡처하거나 웹 통신에서 모델을 추출해 저장소에 넣지 말고, 서울시에 원본 제공과 사용 허가를 요청합니다. 서울시 안내에는 지상 시설물과 지형 자료가 있다고 나와 있지만, 이것만으로 외부 파일을 받을 수 있거나 웹 배포가 허용된다는 뜻은 아닙니다.

1. [S-Map 오픈랩 문의 게시판과 자료 제공 FAQ](https://openlab.eseoul.go.kr/mobile/qna.do)를 확인합니다. 자료 제공과 이용 조건 담당 부서는 [서울시 공간정보 안내](https://news.seoul.go.kr/gov/archives/528155)에 공개된 공간정보과 연락처로 문의할 수 있습니다.
2. 필요한 지역을 탄천교 주변 약 1.2km 구역으로 한정합니다. 큰 원본을 받으면 웹에서 내려받고 여는 데 시간이 많이 듭니다.
3. 모델이 있으면 GLB, glTF, OBJ, 3D Tiles 중 제공 가능한 원본 형식을 받습니다. OBJ라면 질감 이미지와 재료 파일도 함께 요청합니다.
4. 좌표계, 높이 기준, 길이 단위, 제작 시기, 포함 범위와 이용 허가를 함께 확인합니다. 교량은 상판·교각·하부 공간이 나뉘어 있는지 확인합니다.
5. 개인 포트폴리오와 GitHub Pages 웹 공개를 각각 허용하는지 묻습니다. 허용 범위가 확인되기 전에는 원본을 공개 저장소에 올리지 않습니다.

아래 문장을 문의에 사용할 수 있습니다.

> DroneSim에서 탄천교 주변 드론 정찰 시뮬레이션을 만들고 있습니다. 위도 37.4936231°, 경도 127.1018462° 중심 약 1.2km 범위의 지형·건물·교량 모델을 개인 포트폴리오와 GitHub Pages 웹 시연에 사용할 수 있는지 문의드립니다. 제공 가능한 원본 형식(GLB, OBJ, 3D Tiles 등), 좌표계와 수직 기준, 제작 시기, 수정·웹 공개·재배포 조건, 신청 자격을 알려 주세요. 교량은 상판·교각·하부가 구분된 모델이 필요합니다.

서울시 공개제한 자료라면 신청 자격과 보안 심사가 따로 적용될 수 있습니다. [공개제한 공간정보 안내](https://openlab.eseoul.go.kr/mobile/notice.do)를 읽고 개인 신청이 가능한지 먼저 확인합니다. 서울시가 2024년에 탄천을 포함한 하천 주변 자료를 갱신했다는 [자료 소개](https://mediahub.seoul.go.kr/archives/2013136)는 실제 원본의 제공 허가를 대신하지 않습니다.

서울시가 보유한 원본을 받을 수 없다면, 드론 촬영 사진과 측량 자료로 직접 3D 모델을 제작하거나 사용 허가가 명확한 별도 모델을 구해야 합니다. 정사영상만으로 교량 옆면·교각·하부 구조가 생기지는 않습니다.

## 받은 자료로 지형 GLB와 텍스처 만들기

정사영상은 실제 지면 색을 입히고, DEM은 땅의 높낮이를 만듭니다. 두 자료를 합치면 실제 지형에 가까운 지면 GLB와 사진 질감을 만들 수 있습니다. 이 작업으로 건물 옆면이나 교량 아래가 만들어지지는 않습니다.

### 자료 받기

1. [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 지역이나 장소를 검색하고, 검색 결과의 위치 표시를 선택합니다. 탄천교 주변 약 1.2km가 들어가도록 영역을 지정합니다.
2. 자료 종류에서 `정사영상`을 골라 촬영 시기를 확인한 뒤 TIFF 원본을 내려받습니다. 다운로드에는 로그인이 필요합니다. 원본과 함께 제공되는 좌표·월드 파일, 촬영 시기, 이용 조건을 보관합니다.
3. 같은 구역의 DEM을 받습니다. 이미 받은 공개 DEM은 90m 격자라 현재 30m 지형 격자보다 거칩니다. 국토지리정보원 자료 안내에는 서울 일부의 1m·5m급 DEM이 공개 제한 자료로 분류되어 있습니다. 더 촘촘한 자료가 필요하면 신청 자격과 웹 공개 허가를 먼저 문의합니다.
4. TIFF의 좌표계와 높이 기준이 자료 설명에 없거나 DEM과 다르면 변환하지 말고 제공처에 확인합니다. 좌표계를 모른 채 억지로 맞추면 지도 위치와 고도가 틀어집니다.

국토지리정보원의 [정사영상 자료 안내](https://www.data.go.kr/data/15059919/fileData.do), [DEM 자료 안내](https://www.data.go.kr/data/15059920/fileData.do), [자료 제품 설명](https://www.ngii.go.kr/lib/file/pr_01.pdf)에서 파일 형식과 격자 간격을 확인할 수 있습니다. 정사영상은 TIFF이며, 내려받기 경로와 로그인 필요 여부가 자료 안내에 적혀 있습니다. 지역·연도별 해상도와 이용 조건은 신청 화면에서 다시 확인합니다.

### QGIS에서 지형과 사진 질감 내보내기

1. [QGIS](https://qgis.org/download/)에서 DEM과 정사영상 TIFF를 엽니다. 두 레이어를 같은 좌표계로 맞추고 탄천교 주변의 같은 범위로 자릅니다.
2. 3D 지도 보기를 열어 DEM을 지형으로, 정사영상을 지표면 이미지로 설정합니다. 지형 높이 배율은 `1`로 둡니다.
3. 3D 장면을 OBJ로 내보내며 지형과 질감 이미지를 함께 저장합니다. QGIS 공식 안내에는 이 내보내기가 OBJ와 질감 이미지로 후처리용 장면을 만든다고 나와 있습니다. 지형 해상도는 우선 기본값으로 두고, 질감 해상도는 2048로 시작합니다. 웹에서 파일 크기와 사진 선명도를 확인한 뒤 부족할 때만 질감 해상도를 높입니다.
4. 내보낸 폴더에서 OBJ가 참조하는 MTL 재료 파일과 질감 이미지를 함께 확인합니다. 그 질감 이미지를 `terrain.png` 또는 `terrain.jpg`로 복사해 둡니다. 원본 TIFF를 직접 이름만 바꾸지 말고, QGIS가 내보낸 이미지나 좌표 정보를 유지해 변환한 PNG/JPEG를 사용합니다.
5. 내보낸 장면을 QGIS에서 다시 열어 땅의 형태·사진 방향·색이 맞는지 확인합니다. 정사영상의 글자·경계선·투영 흔적이 남으면 해당 레이어 범위와 질감 해상도를 조정합니다.

자세한 메뉴는 [QGIS 3.44 3D 지도 안내](https://docs.qgis.org/3.44/ko/docs/user_manual/map_views/3d_map_view.html)에 있습니다. QGIS는 GLB가 아니라 OBJ를 내보내므로 Blender에서 한 번 변환해야 합니다.

### Blender에서 GLB로 바꾸기

1. [Blender](https://www.blender.org/download/)에서 QGIS가 만든 OBJ를 엽니다. OBJ가 MTL 파일과 질감 이미지를 찾도록 같은 폴더에 둡니다. 사진 질감은 Blender에서 미리보기만 확인하고, 엔진용 외부 PNG/JPEG 파일도 보관합니다.
2. 지형을 하나의 메시로 합치고 위치·회전·크기를 적용합니다. 프로젝트 좌표 기준은 동쪽 X, 위쪽 Y, 북쪽 -Z이며 단위는 미터입니다. 지도 중심을 원점으로 옮깁니다.
3. 면이 뒤집히거나 질감이 세로로 뒤집히지 않았는지 확인한 뒤, 선택한 지형 메시를 바이너리 glTF(GLB)로 내보냅니다. 재료 이미지 내장 여부와 관계없이 외부 질감 파일도 따로 준비합니다.
4. 내보낸 모델을 Blender에서 다시 열어 크기, 방향, 사진 질감, 파일 용량을 확인합니다. 이 확인을 마친 모델만 시뮬레이터 입력으로 사용합니다.

Blender의 가져오기·내보내기 방법은 [glTF 2.0 안내](https://docs.blender.org/manual/en/4.2/addons/import_export/scene_gltf2.html)를 참고합니다. 현재 프로그램은 GLB에서 지형 형상을 읽고, 별도 PNG·JPEG·PPM 파일에서 지면 사진을 읽습니다. GLB 안에 든 질감은 사용하지 않습니다.

### 프로그램에 넣고 실행하기

지형 모델은 `assets/maps/tancheon/terrain.glb`로 둡니다. 사진 질감은 같은 폴더에 `terrain.png` 또는 `terrain.jpg`로 둡니다. PNG, JPEG, PPM을 읽으며 PNG를 먼저 찾고, 파일이 없으면 JPG, JPEG, PPM 순서로 사용합니다. 웹 빌드도 선택된 이미지 한 장만 포함하므로, 같은 이름으로 여러 형식을 동시에 두지 않습니다.

지형 GLB는 현재 메시 하나와 삼각형 묶음 하나여야 합니다. 여러 지형 조각을 내보냈다면 Blender에서 하나로 합칩니다. 렌더링 형상과 충돌 형상은 역할이 다릅니다. GLB는 화면에 지형을 그리고, 충돌 계산은 `terrain.aerotrn` 높이 격자를 사용합니다. GLB를 바꿔도 충돌 지형은 자동으로 바뀌지 않으므로 두 자료의 위치·축·높이 기준을 맞춰야 합니다.

화면과 충돌 지형이 같은 곳에 놓이도록 좌표와 높이 기준을 맞춰야 합니다. 시뮬레이터의 지면 좌표는 동쪽·북쪽·위쪽을 미터로 쓰고, 화면에서는 동쪽이 X, 위쪽이 Y, 북쪽이 -Z입니다. 지형 모델은 지도 중심을 원점으로 옮기고 축을 변환해 저장합니다. 수직 기준과 기준 고도도 충돌 격자와 맞춰야 합니다. 맞지 않으면 화면의 땅과 실제 충돌 높이가 달라집니다.

1.2km 전체를 가장 높은 질감 해상도로 만들면 웹 내려받기와 그래픽 메모리 사용량이 커집니다. 처음에는 2048 해상도로 시작하고, 실제 브라우저에서 로딩 시간과 화면 선명도를 본 뒤 필요한 곳만 높입니다. 현재는 지형 조각 여러 개를 따로 읽지 않으므로 하나의 GLB로 합쳐야 합니다.

## 파일을 받은 뒤 확인할 항목

자료를 받을 때 원본과 함께 제공되는 좌표·월드 파일도 보관하고, 아래 정보를 기록해 주세요.

- 촬영일 또는 제작일, 원본 해상도, 실제 격자 간격
- 좌표계와 높이 기준, 단위
- 이용 조건과 출처 표기 방법, 웹 배포 허용 여부
- GLB/OBJ 모델의 범위와 기준점, 축 방향, 단위
- 모델이 지형인지 건물·교량인지, 충돌에 쓸 형상이 포함됐는지

다음 작업에 필요한 자료는 탄천교 주변 정사영상 TIFF와 좌표·촬영 정보입니다. [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에 로그인해 `정사영상`에서 위 좌표를 포함하는 가장 선명한 원본을 내려받고, 함께 받은 좌표 파일과 이용 조건을 이 대화에 첨부해 주세요. 5m급 DEM이나 S-Map 3D 원본은 제공처 승인과 웹 공개 권한까지 확인한 뒤 보내 주세요. 자료를 받으면 좌표와 크기를 확인하고, 지형 GLB와 질감을 만들어 화면에 연결하겠습니다.
