# 탄천 시험 장면 자료

## 현재 장면

시뮬레이터는 탄천교 주변 약 1.2km 정사각형을 보여줍니다. 중심은 위도 37.4936231°, 경도 127.1018462°입니다. 화면에는 2025년 항공 정사영상의 질감을 입히고, 공개 수치표고모델로 지면 높이를 구성했습니다.

정사영상은 위에서 본 사진입니다. 지면의 도로와 하천 모습은 실제와 가까워졌지만 건물 옆면, 교량 상판·교각·하부 형상까지 생기는 것은 아닙니다. 시설물의 실제 3D 모델은 별도 자료가 필요합니다.

## 이번에 반영한 자료

| 자료 | 장면에 쓰는 방식 | 해상도와 한계 |
| --- | --- | --- |
| 국토지리정보원 2025년 정사영상 | 탄천교 주변 지면 질감 | 원본은 25cm 해상도입니다. 장면용으로 1.2km 구간을 잘라 2048×2048 JPEG로 만들었으며, 화면에 놓인 픽셀 간격은 약 59cm입니다. |
| 국토지리정보원 공개 DEM 도엽 37709 | 지면 모양과 지면 충돌 | 원본 격자는 90m입니다. 30m 간격의 41×41 지점에 보간해 쓰므로 실제 높이 정보도 90m보다 촘촘해지지는 않습니다. |
| OpenStreetMap 발췌 자료 | 도로·건물 윤곽 등 보조 요소 | 항공사진에서 건물의 높이와 옆면을 얻은 것은 아닙니다. |

정사영상 원본 여섯 장 중 현재 장면 범위와 겹치는 도엽 37709004·37709005를 사용했습니다. 나머지 네 장은 같은 장면 범위 밖에 있어 실행 자료에 넣지 않았습니다. 자료 출처는 [국토지리정보원 정사영상 안내](https://www.data.go.kr/data/15059919/fileData.do), [국토지리정보원 DEM 안내](https://www.data.go.kr/data/15059920/fileData.do), [국토정보플랫폼 도엽 색인](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total), [OpenStreetMap 저작권 안내](https://www.openstreetmap.org/copyright)에서 확인할 수 있습니다. 공공데이터포털은 두 국토지리정보원 자료의 이용허락범위를 제한 없음으로 표시합니다. 화면이나 배포물에는 자료 출처를 함께 표시합니다.

## 실제 건물과 교량 모델을 구하려면

서울시의 S-Map은 서울의 건물과 교량을 포함한 3D 공간정보를 서비스합니다. 다만 공개 안내에서는 시내 3D 지도를 볼 수 있다고 설명할 뿐, 탄천 구역의 원본 모델 파일을 내려받는 방법이나 재배포 조건까지 확인할 수는 없습니다. 화면에서 보이는 3D 지도를 캡처해 모델 자료로 대신하지 않습니다.

서울시의 [드론 공간정보 담당 부서](https://news.seoul.go.kr/gov/archives/528178)에 탄천교 주변 자료 제공을 문의할 수 있습니다. 서울시 안내에 나온 전화는 02-2133-2843입니다. 요청할 범위는 탄천교·수서IC교·광평교와 주변 1.2km 구역입니다. 건물·교량의 3D 형상 파일과 함께 좌표계, 높이 기준, 제작 시점, 사용·재배포 조건을 확인해야 합니다. 가능하면 GLB/glTF, CityGML, 3D Tiles처럼 형상과 위치를 함께 옮길 수 있는 파일을 요청합니다. [S-Map 공간정보 소개](https://world.seoul.go.kr/policy/smart-city/spatial-data/)는 3D 건물·교량 데이터의 제공 범위를 설명하지만, 공개 파일의 직접 다운로드 주소는 안내하지 않습니다.

## 더 촘촘한 지형 높이가 필요하면

현재 받은 공개 DEM의 원본 간격은 90m입니다. 화면에서 격자를 더 잘게 나누어도 작은 언덕이나 제방의 높이는 새로 생기지 않습니다. [국토지리정보원 DEM 안내](https://www.data.go.kr/data/15059920/fileData.do)에서 현재 공개 자료와 내려받기 조건을 확인하고, 더 세밀한 높이 자료가 필요하면 탄천 구역의 1m·5m DEM 또는 DSM 제공 가능 여부를 국토지리정보원에 문의해야 합니다. DEM은 맨땅 높이, DSM은 건물과 나무를 포함한 표면 높이를 담으므로 용도에 맞춰 요청합니다. 높이 기준과 좌표계도 자료와 함께 받아야 합니다.

## 좌표와 높이

- 지도 중심: 위도 37.4936231°, 경도 127.1018462°
- 장면 좌표: 중심에서 동쪽·북쪽·위쪽을 미터로 계산합니다. 화면에서는 동쪽이 X, 위쪽이 Y, 북쪽이 -Z입니다.
- 정사영상: TIFF에 좌표 태그가 없어 국토정보플랫폼의 도엽 경계와 25cm 해상도로 위치를 정했습니다. 37709004와 37709005 원본은 약 100m 겹칩니다. 겹치는 도로와 지형을 대조해 두 영상의 위치를 맞춘 뒤, 겹친 부분을 부드럽게 섞었습니다. 지상 기준점을 측량해 절대 위치 오차를 검증한 자료는 아닙니다.
- DEM: 원본 좌표계는 EPSG:5179입니다. 고도 자료의 수직 기준은 함께 받은 보조 정보에서 확인되지 않아 해발고도라고 단정하지 않습니다. DEM에서 장면 중심과 주변의 높이 차를 구해 지면 모양에 반영했습니다. 시뮬레이션 원점은 기존 동작을 유지하도록 18m에 두었습니다. 이 값은 해발고도가 아닙니다.

## 원본 보관

받은 TIFF 6장과 메타데이터, DEM 압축 원본은 가공 근거로 보관합니다. TIFF 원본은 약 1.9GB라 실행 자료와 분리해 로컬 원본 보관 영역에 두며 Git에는 올리지 않습니다. 프로그램은 1.2km 구간을 잘라 만든 JPEG만 읽습니다. 두 정사영상의 약 102m 겹치는 곳은 부드럽게 섞었습니다. TIFF에 지리 좌표 태그가 없어 도엽 색인으로 위치를 맞췄고, 지상 기준점으로 위치 오차를 측량하지는 않았습니다.

정사영상과 DEM은 서로 다른 역할을 합니다. 정사영상은 색과 표면 무늬를 제공하고, DEM은 지면 높이와 지면 충돌을 계산합니다. 현재 DEM은 넓은 지역의 지형만 표현하며, 건물이나 교량과 드론의 정밀 충돌은 아직 별도 3D 충돌 형상이 필요합니다.
