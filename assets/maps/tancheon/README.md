# 탄천 실제 지형 자료 받기와 적용하기

## 지금 장면에 부족한 자료

현재 탄천 장면에는 실제 항공사진 질감과 상세 3D 건물·교량 모델이 없습니다. 저장소의 지형 격자는 약 30m 간격이고, 받은 공개 DEM은 90m 간격입니다. 받은 DEM은 기존 지형보다 거칠어 교체 자료로 쓰지 않습니다. 격자를 보간해도 원본보다 정확해지지 않습니다.

실제 모습에 가까운 장면을 만들려면 아래 자료가 필요합니다.

| 자료 | 쓰임 | 받을 곳 |
| --- | --- | --- |
| 더 세밀한 DEM | 지면 높낮이와 지면 충돌 | [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total) |
| 정사영상 원본 | 실제 지면 색과 도로·하천 모양 | [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total) |
| 건물·교량 3D 원본 | 건물 옆면, 교량 상판·교각·하부 | [S-Map 오픈랩 자료 안내](https://openlab.eseoul.go.kr/mobile/qna.do) |

정사영상은 위에서 찍은 사진입니다. 지면을 실제처럼 보이게 하지만 건물 옆면이나 교량 아래쪽을 만들지는 않습니다. DEM과 정사영상으로 만들 수 있는 GLB는 지표면 모델이며, 구조물 모양은 별도의 3D 자료가 있어야 합니다.

## 항공사진과 DEM 받기

1. [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)을 엽니다.
2. 탄천교 주변을 검색한 뒤, 프로젝트 중심인 위도 37.4936231°, 경도 127.1018462°를 덮는 범위를 지정합니다. 기본 범위는 약 1.2km 정사각형입니다.
3. 자료 목록에서 `정사영상`을 선택하고, 촬영 시기와 해상도가 표시된 항목을 확인해 TIFF 원본을 받습니다.
4. 같은 지역의 `공개DEM`을 확인합니다. 일반 공개 자료는 90m 간격이므로, 30m 이하 간격 자료가 검색되지 않는다면 받은 90m 도엽을 그대로 사용합니다. 1m·5m급 정밀 DEM은 지역과 신청 목적에 따라 제공이 제한될 수 있습니다. 국토정보플랫폼에 탄천 구간의 이용 자격, 승인 절차, 웹 공개 가능 여부를 먼저 문의합니다.

탄천 구간에 더 촘촘한 DEM이 없으면 [서울시 1:1,000 수치지형도 안내](https://news.seoul.go.kr/gov/archives/528208)에서 수치지형도 자료도 확인할 수 있습니다. 이 지도에는 지형선과 표고 정보가 포함될 수 있으므로, 실제 받은 자료에 등고선·표고점이 있는지, 등고 간격·좌표계·높이 기준이 무엇인지 확인한 뒤 보조 지형으로 가공합니다. 축척이 1:1,000이라고 해서 DEM 해상도나 높이 정확도가 같은 수준이라는 뜻은 아닙니다.

정사영상은 TIFF로 제공되며 내려받으려면 국토정보플랫폼 로그인이 필요합니다. 플랫폼이 대용량 전송 프로그램을 안내할 수 있습니다. 국토지리정보원 자료는 제작에 사용한 항공사진 해상도로 도시 지역 12cm, 일반 지역 25cm를 안내하지만, 탄천에서 실제로 받을 수 있는 해상도와 촬영 시기는 검색 결과에서 확인해야 합니다. 내려받은 항목의 이용 조건과 웹 공개 가능 범위도 확인합니다.

정사영상 자료 설명은 [공공데이터포털의 국토지리정보원 정사영상 안내](https://www.data.go.kr/data/15059919/fileData.do), DEM 형식과 다운로드 방법은 [국토지리정보원 DEM 안내](https://www.data.go.kr/data/15059920/fileData.do)에서 확인할 수 있습니다. 지도 화면을 캡처해 텍스처로 쓰면 원본 해상도와 사용 허가를 확인할 수 없으므로 사용하지 않습니다.

## 탄천 건물·교량 3D 자료 받기

서울시는 S-Map에서 서울의 3D 지형·건물·교량을 보여 줍니다. 하지만 공개 웹페이지에서 탄천 주변 원본 GLB를 내려받는 기능은 확인하지 못했습니다. 화면에 보이는 장면을 캡처하거나 웹 화면의 내부 자료를 추출해 저장소에 넣지 않습니다. [S-Map 오픈랩 문의 게시판](https://openlab.eseoul.go.kr/mobile/qna.do)에 원본 자료 제공 여부와 개인 포트폴리오·웹 배포 허용 범위를 문의합니다. 파일이 GLB가 아니어도 원본 형식으로 받으면 변환할 수 있습니다.

문의할 때는 필요한 범위와 최종 사용처를 함께 적으세요.

> DroneSim에서 탄천교 주변 드론 정찰 시뮬레이션을 만들고 있습니다. 위도 37.4936231°, 경도 127.1018462° 중심 약 1.2km 범위의 지형·건물·교량 모델을 개인 포트폴리오와 GitHub Pages 웹 시연에 사용할 수 있는지 문의드립니다. 제공 가능한 원본 형식(GLB, OBJ, 3D Tiles 등), 좌표계와 수직 기준, 제작 시기, 수정·웹 공개·재배포 조건, 신청 자격을 알려 주세요. 교량은 상판·교각·하부가 구분된 모델이 필요합니다.

서울시 공개제한 공간정보에 해당하는 자료라면 신청 자격과 보안 심사가 따로 적용됩니다. 서울시 안내에는 법인 또는 사업자 등록을 한 신청자와 보안심사가 명시되어 있습니다. 개인 포트폴리오에서 사용할 수 있는 공개 자료가 있는지 먼저 문의하고, 승인 전에는 웹에 올리거나 저장소에 넣지 않습니다. 세부 조건은 [서울시 공개제한 공간정보 안내](https://openlab.eseoul.go.kr/mobile/notice.do)에서 확인할 수 있습니다.

서울시가 2024년 항공·드론·라이다 자료를 갱신하고 탄천을 포함한 하천 주변 시설물을 실감형 공간정보로 보완했다는 안내는 [서울시 S-Map 최신 자료 소개](https://mediahub.seoul.go.kr/archives/2013136)에 있습니다. 이는 해당 모델의 원본 파일이 누구나 내려받을 수 있다는 뜻은 아닙니다.

## 받은 자료로 지형 GLB와 텍스처 만들기

정사영상과 DEM을 받으면 지형 GLB를 만들 수 있습니다. 이 과정에서 만들어지는 것은 지면 모양과 위에서 본 사진 질감입니다. 건물 옆면과 교량 상판·교각·하부는 별도 3D 모델이 있어야 합니다. QGIS는 3D 장면을 OBJ와 질감 이미지로 내보내며, Blender에서 이를 GLB로 변환합니다. QGIS는 [여기](https://qgis.org/download/), Blender는 [여기](https://www.blender.org/download/)에서 받을 수 있습니다. 자세한 메뉴는 [QGIS 3D 장면 내보내기 안내](https://docs.qgis.org/3.44/ko/docs/user_manual/map_views/3d_map_view.html)와 [Blender GLB 내보내기 안내](https://docs.blender.org/manual/en/4.2/addons/import_export/scene_gltf2.html)에 있습니다.

1. QGIS에서 DEM과 정사영상의 좌표계·범위·촬영 시기를 확인합니다. 좌표계나 높이 기준이 자료에 없으면 임의로 정하지 말고 제공처에 묻습니다.
2. 두 자료를 같은 영역으로 자르고 DEM을 지형 높이로, 정사영상을 표면 질감으로 설정합니다. QGIS 3D 지도 보기에서 지형 높이 배율은 1로 둡니다.
3. 3D 장면을 OBJ와 질감 이미지로 내보냅니다. QGIS의 내보내기 메뉴에서 지형 해상도와 질감 해상도를 따로 정할 수 있습니다.
4. Blender에서 OBJ와 질감 이미지를 열어 위치 기준점을 프로젝트 중심으로 옮깁니다. 모델 축은 동쪽이 X, 북쪽이 -Z, 위쪽이 Y인 시뮬레이터 기준과 맞춥니다. 장면을 한 메시와 한 삼각형 묶음으로 정리해 GLB로 내보냅니다.
5. 질감 이미지는 PPM(P6, RGB 8비트)으로 별도 저장합니다. 현재 프로그램은 GLB 내부의 재질 이미지를 읽지 않고, 외부 PPM 이미지를 불러옵니다.

화면과 충돌 지형이 같은 곳에 놓이도록 좌표와 높이 기준을 맞춰야 합니다. 시뮬레이터의 지면 좌표는 동쪽·북쪽·위쪽을 미터로 쓰고, 화면에서는 동쪽이 X, 위쪽이 Y, 북쪽이 -Z입니다. 지형 모델은 지도 중심을 원점으로 옮기고 축을 변환해 저장합니다. 수직 기준과 기준 고도도 충돌 격자와 맞춰야 합니다. 맞지 않으면 화면의 땅과 실제 충돌 높이가 달라집니다.

현재 모델 읽기는 노드 하나·메시 하나·삼각형 묶음 하나인 GLB와 외부 PPM 질감 한 장을 사용합니다. 넓은 구역 전체를 최고 해상도 한 장으로 만들면 웹 초기 내려받기와 GPU 메모리 사용량이 커집니다. 주변 지형은 낮은 해상도로, 탄천교는 별도 고해상도 장면으로 나누는 편이 낫습니다. 다만 지금 로더는 여러 장면 조각을 나눠 읽지 않으므로, 실제 데이터를 받으면 우선 하나의 장면 크기와 웹 시작 시간을 확인한 뒤 필요한 만큼 로더를 고쳐야 합니다.

## 파일을 받은 뒤 확인할 항목

자료를 받을 때 원본과 함께 제공되는 좌표·월드 파일도 보관하고, 아래 정보를 기록해 주세요.

- 촬영일 또는 제작일, 원본 해상도, 실제 격자 간격
- 좌표계와 높이 기준, 단위
- 이용 조건과 출처 표기 방법, 웹 배포 허용 여부
- GLB/OBJ 모델의 범위와 기준점, 축 방향, 단위
- 모델이 지형인지 건물·교량인지, 충돌에 쓸 형상이 포함됐는지

다음 작업에 필요한 자료는 탄천교 주변 정사영상 TIFF와 좌표·촬영 정보입니다. [국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에 로그인해 `정사영상`에서 위 좌표를 포함하는 가장 선명한 원본을 내려받고, 함께 받은 좌표 파일과 이용 조건을 이 대화에 첨부해 주세요. 5m급 DEM이나 S-Map 3D 원본은 제공처 승인과 웹 공개 권한까지 확인한 뒤 보내 주세요. 자료를 받으면 좌표와 크기를 확인하고, 지형 GLB와 질감을 만들어 화면에 연결하겠습니다.
