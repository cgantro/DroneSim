# DroneSim

DroneSim은 가상 훈련장에서 네 대의 드론이 편대 비행과 정찰을 수행하는 시뮬레이터입니다. 사람은 정찰 지점을 정하고, 드론은 지정된 곳에서 영상과 위치 정보를 모읍니다.

시뮬레이션은 절차 생성한 가상 훈련장과 가상 통신 환경에서 동작합니다. 영상 속 사람이나 시설물의 파손을 자동으로 판정하지 않으며, 가상 시험 결과를 실제 비행의 안전성으로 해석해서도 안 됩니다.

## 먼저 실행하기

1. Visual Studio에서 저장소를 엽니다.
2. 구성 목록에서 **Ninja Release**를 선택하고 빌드합니다. 첫 빌드에는 필요한 라이브러리를 받기 위해 인터넷 연결이 필요할 수 있습니다.
3. 시뮬레이터를 실행하고 **전체 임무 시작 (M01 → M02 → M03)**을 눌러 편대 이동, 분산 정찰, 재집결과 복귀를 살펴봅니다.

화면 구성과 조작 방법은 [실행 안내](docs/public/시작하기.md)에 있습니다.

## 이 프로젝트에서 확인하는 것

- 네 대가 편대 경로를 따라 이동하고 정찰 지점을 나눠 맡는 과정
- 거리와 건물 가림을 반영한 드론·지상통제소 간 직접 통신
- 통신을 차단했을 때 마지막으로 받은 상태를 유지하고, 연결 복구 뒤 새 상태를 받는 과정
- 같은 조건을 반복 실행하는 자동 시험과 성능 측정

## 기체와 짐벌 카메라 참고

PX4의 Gazebo 예제에는 Holybro X500 아래에 3축 짐벌 카메라를 단 구성이 있습니다. 아래 이미지는 그 예제의 모습입니다.

![PX4 Gazebo의 X500 짐벌 카메라 예시](https://docs.px4.io/main/assets/x500_gimbal.CwN7c78T.png)

PX4 모델의 짐벌 부품 이름은 `cgo3_*`이며, 카메라가 달린 링크도 CGO3 이름을 사용합니다. 따라서 **Yuneec CGO3 형태를 본뜬 시뮬레이션 모델**로 볼 수 있습니다. 실제 CGO3 제품과 외형·무게·화질이 완전히 같다는 뜻은 아닙니다. [PX4 기체 모델](https://github.com/PX4/PX4-gazebo-models/blob/main/models/x500_gimbal/model.sdf) · [PX4 짐벌 모델](https://github.com/PX4/PX4-gazebo-models/blob/main/models/gimbal/model.sdf)

| 구분 | 확인된 내용 |
| --- | --- |
| 짐벌 움직임 | 롤 ±45°, 피치 약 -135°~+45°, 요 연속 회전 |
| Gazebo 카메라 센서 | 수평 시야각 2 rad(약 115°), 1280×720, 초당 30프레임 |
| 실제 CGO3 제품 안내 | 3축 짐벌 일체형 카메라, 4K 영상 지원 |

위 수치는 PX4 시뮬레이터 설정과 CGO3 제품 안내를 구분해 적었습니다. DroneSim에는 PX4 모델의 짐벌 외형과 카메라 위치·해상도·시야각을 반영했습니다. 현재 짐벌은 중립 각도로 고정되어 기체 자세를 따라갑니다. 기체와 독립적으로 짐벌을 조종하는 기능은 포함하지 않습니다. PX4 설정에는 수직 시야각이 따로 적혀 있지 않아, 16:9 영상에서 수평 2 rad와 같은 화면이 되도록 환산했습니다. [CGO3 제품 설명서](https://www.bhphotovideo.com/lit_files/155735.pdf) · [PX4 자산 사용 허가](https://github.com/PX4/PX4-gazebo-models/blob/main/LICENSE)

## 임무와 시험 시나리오

**임무**는 드론이 할 일입니다. 예를 들어 편대 이동, 정찰 지점 방문, 복귀와 착륙이 한 임무입니다. **시험 시나리오**는 그 임무를 어떤 조건에서 실행하고 성공을 어떻게 판단할지 정합니다. 드론의 시작 위치와 기체 상태, 바람이나 통신 끊김, 실행 시간, 마지막 위치 같은 조건이 여기에 들어갑니다.

JSON은 이 시험 조건을 적어 두는 형식일 뿐, 임무를 JSON으로 구현한다는 뜻은 아닙니다. 예를 들어 통신 끊김 시험은 두 드론의 시작 위치와 이륙 명령, 한 드론의 연결을 끊을 시점, 연결이 돌아올 시점, 마지막에 기대하는 상태를 기록합니다. 실행기는 같은 모의 규칙으로 시험을 반복하고 결과를 판정합니다.
