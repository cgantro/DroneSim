# DroneSim

DroneSim은 여러 대의 드론이 협력 임무를 수행하고, 통신이나 기체 장애가 생겼을 때 임무가 어떻게 달라지는지 시험하는 시뮬레이터입니다. 드론은 사람이 지정한 지점을 찾아 영상과 위치 정보를 확보합니다. 영상 속 시설물의 파손 여부는 사람이 판단합니다.

## 현재 일부 구현된 기능

- 네 대의 드론을 위한 편대 이동, 지점 정찰, 재집결·복귀 흐름을 구현하고 있습니다.
- 가상 통신망에서 다중 홉 전달과 일부 통신 장애를 시험할 수 있습니다.
- 훈련장, 드론별 카메라 화면, 비행·통신 상태를 확인할 수 있습니다.

임무 전체와 장애 대응은 아직 끝까지 검증되지 않았습니다. 기능별 구현 상태와 실제 시험 결과는 [기능 현황](SPEC.md)을 확인하세요.

## 시험 환경과 한계

현재 장면은 500m × 400m 크기의 가상 훈련장입니다. 실제 탄천이나 특정 도시를 재현한 지도는 아니며, 실제 무선 전파도 계산하지 않습니다. Windows 프로그램은 AirSim 강체 물리를 쓰고 웹 프로그램은 단순화한 운동학 계산을 쓰므로 두 환경의 비행 결과를 같은 모델의 결과로 비교할 수 없습니다. 카메라 영상은 화면에 표시하지만 임무 자료의 저장·전달은 아직 연결되지 않았습니다.

3. 임무·통신·비행 계산의 연결은 [기술 구조](docs/public/기술구조.md)를 보세요.

다른 문서는 [문서 길잡이](docs/public/README.md)에서 주제별로 찾을 수 있습니다. 프로젝트가 만들 결과와 범위는 [개발 목표](GOAL.md)에 정리했습니다.
