# DroneSim

DroneSim은 네 대의 드론이 함께 이동하고, 사람이 정한 지점을 정찰한 뒤, 장애 상황에 대응하는 과정을 시험하는 시뮬레이터입니다. 임무 경로와 가상 통신망을 바꾸며 기체 이탈·통신 단절이 결과에 미치는 영향을 살펴봅니다.

드론은 지정된 지점에서 영상과 위치 정보를 모읍니다. 영상 속 파손 여부는 사람이 판단합니다.

## 현재 상태

기본 장면은 실제 도시 지도가 아닌 약 500m × 400m 훈련장입니다. Windows 네이티브는 AirSim 강체 물리를 쓰고, 웹 빌드는 단순화한 운동학을 씁니다. 두 환경은 같은 물리 조건으로 비교할 수 없습니다.

편대·정찰·통신 기능은 일부 구현됐습니다. 2026년 10월 28일 Release 자동 시험 32개가 통과했습니다. 다만 여러 시작 위치와 속도에서 충돌 회피 안전성을 확인하거나, GUI에서 장애 대응부터 복귀까지 전체 임무를 검증하는 작업은 남아 있습니다. 현재 기능과 확인 범위는 [기능 현황](SPEC.md)을 보세요.

## 실행

저장소를 Visual Studio에서 열고 `ninja-release` 구성을 선택합니다. `aerosimlab_simulator` 대상을 빌드한 뒤 생성된 `DroneSim.exe`를 실행하세요. 조작과 임무 시작은 [실행 안내](docs/public/시작하기.md)에 설명되어 있습니다.
