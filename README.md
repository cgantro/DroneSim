# DroneSim

DroneSim은 여러 대의 드론이 임무를 나누어 수행하는 과정을 가상 환경에서 시험하는 시뮬레이터입니다. 편대 이동, 사람이 지정한 지점의 정찰, 재집결과 복귀를 실행하고 통신 장애가 임무에 미치는 영향을 살펴봅니다.

드론은 정찰 지점의 영상과 위치 정보를 확보합니다. 영상 속 파손 여부는 사람이 판단합니다. 현재 장면은 500m × 400m 수식 지형에 GLB 시설물을 고정 배치한 시험장입니다. 실제 도시 지도나 실제 전파를 재현하지 않습니다.

## 처음 시작할 때

1. [실행과 화면 조작](docs/public/시작하기.md)에서 프로그램을 켜고 기본 임무를 실행합니다.
2. [현재 기능과 확인 결과](SPEC.md)에서 되는 일과 아직 시험하지 않은 일을 확인합니다.
3. [계산과 데이터 흐름](docs/public/기술구조.md)에서 비행·통신·화면이 연결되는 방식을 살펴봅니다.

## 꼭 알아둘 점

- Windows 프로그램은 AirSim 강체 물리를 사용합니다. 웹 프로그램은 단순화한 운동학 계산을 사용하므로 두 결과를 같은 물리 모델의 결과로 비교할 수 없습니다.
- 자동 시험은 통신망과 임무 단계 판정의 일부를 확인했습니다. 장애 상황에서 GUI 임무가 처음부터 끝까지 복구되는지는 아직 확인하지 않았습니다.
- 카메라 영상은 화면에 표시됩니다. 임무별 자료 저장·전달 흐름은 아직 연결되지 않았습니다.
