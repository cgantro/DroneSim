# DroneSim

DroneSim은 한 프로그램 안에서 네 대의 드론이 편대 이동, 지점 정찰, 재집결을 수행하는 과정을 시험하는 시뮬레이터입니다. 리더가 경로와 임무를 조정하고, 가상 통신망의 단절이나 기체 이탈이 임무에 미치는 영향을 살펴봅니다.

정찰 지점은 사람이 정합니다. 드론은 그곳에서 영상과 위치 정보를 모으며, 파손 여부는 사람이 영상으로 판단합니다.

## 지금 알아둘 점

- 기본 장면은 실제 도시가 아닌 약 500m × 400m 가상 훈련장입니다.
- Windows 네이티브는 AirSim 강체 물리를 사용하고, 웹은 단순화한 운동학을 사용합니다. 두 결과는 같은 물리 모델의 검증으로 볼 수 없습니다.
- 네 대 임무와 통신 시험은 일부 확인됐습니다. 모든 임무를 GUI에서 실행해 복귀까지 마치는 과정은 아직 검증 중입니다.

현재 기능과 확인 결과는 [기능 현황](SPEC.md)에서 확인하세요.

## 빌드와 실행

저장소를 Visual Studio에서 열고 `ninja-release` 구성을 선택합니다. `aerosimlab_simulator` 대상을 빌드하면 `DroneSim.exe`가 생성됩니다. 화면 조작과 임무 실행 순서는 [실행 안내](docs/public/시작하기.md)에 있습니다.
