# DroneSim

DroneSim은 한 장면 안에서 여러 대의 가상 드론이 임무를 나누고, 통신 단절이나 기체 고장에 어떻게 대응하는지 시험하는 시뮬레이터를 목표로 합니다.

## 현재 상태

저장소에는 탄천을 배경으로 한 기존 시제품이 남아 있습니다. 시뮬레이터와 지상통제 프로그램은 별도 실행이며, 드론 사이의 실제 모의 통신망과 새 산업·산악 훈련장은 아직 구현되지 않았습니다. 새 목표와 현재 구현의 차이는 [프로젝트 기능과 진행 상태](SPEC.md)에서 확인할 수 있습니다.

따라서 지금 실행되는 기능을 새 군집 시뮬레이션의 완료 기능으로 보지 않습니다. 기존 장면 파일은 현재 실행에서 사용 중이므로 대체 장면과 연결을 마친 뒤, 새 목표에 필요하지 않은 자료와 중간 산출물을 정리합니다. 내려받은 원본은 재사용 가치와 출처를 확인해 보관 여부를 정합니다.

## 전환 원칙

- 기존 코드에서 다시 쓸 기능은 먼저 확인하고 활용합니다.
- 기본 장면과 임무가 바뀌면 사용하지 않는 파일·에셋·코드도 함께 제거합니다.
- 원본 자료와 생성 결과를 구분하고, 생성 결과는 다시 만들 수 있는지 확인한 뒤 정리합니다.
- 새 기능은 구현과 시험이 끝난 범위만 완료로 표시합니다.
