# DroneSim

DroneSim은 가상 훈련장에서 네 대의 드론을 함께 움직이며 편대 비행, 정찰, 통신 중계와 장애 대응을 시험하는 시뮬레이터입니다. 사람은 정찰 지점과 확인할 대상을 정하고, 드론은 지정된 곳에서 영상과 위치 정보를 모읍니다.

시뮬레이션은 절차 생성한 가상 훈련장과 가상 통신 환경에서 동작합니다. 영상 속 사람이나 시설물의 파손을 자동으로 판정하지 않으며, 가상 시험 결과를 실제 비행의 안전성으로 해석해서도 안 됩니다.

## 먼저 실행하기

1. Visual Studio에서 저장소를 엽니다.
2. 구성 목록에서 **Ninja Release**를 선택하고 빌드합니다. 첫 빌드에는 필요한 라이브러리를 받기 위해 인터넷 연결이 필요할 수 있습니다.
3. 시뮬레이터를 실행하고 **전체 임무 시작 (M01 → M02 → M03)**을 눌러 편대 이동, 분산 정찰, 재집결과 복귀를 살펴봅니다.

화면 구성과 조작 방법은 [실행 안내](docs/public/시작하기.md)에 있습니다.

## 이 프로젝트에서 확인하는 것

- 네 대가 편대 경로를 따라 이동하고 정찰 지점을 나눠 맡는 과정
- 거리와 건물 가림을 반영한 가상 통신 경로 및 다중 홉 중계
- 통신 단절이나 기체 고장 뒤의 임무 재배정과 복귀 동작
- 같은 조건을 반복 실행하는 자동 시험과 성능 측정
