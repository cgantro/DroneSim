# DroneSim

DroneSim은 여러 드론의 편대 비행, 분산 정찰, 가상 통신망과 장애 복구를 한 화면에서 시험하는 C++ M&S 프로그램입니다. 영상 속 대상이나 시설물의 상태를 자동 판정하지 않습니다. 사람은 정찰 지점을 정하고, 드론은 영상과 위치 정보를 수집합니다.

## 지금 확인할 수 있는 것

- 네 대가 편대 이동, 정찰 지점 분담, 재집결과 복귀를 수행하는 자동 시험
- 직접 통신·리더 경유·고정 다중 홉·장애 적응 다중 홉의 메시지 전달
- 링크 단절, 한 방향 차단, 라디오 차단과 패킷 손실 주입
- 드론별 상태와 카메라, 통신 경로, 최근 통신 사건을 한 실행 창에서 확인
- Release CTest 33개 통과. 새로 추가한 시드 기반 지연 흔들림 시험도 포함합니다.

기본 장면은 약 500m × 400m의 가상 산업·자연 복합 훈련장입니다. 실제 탄천 지도나 실제 무선 전파를 모의하지 않습니다. Windows 네이티브는 AirSim 강체 물리를 사용하고 웹은 단순화된 운동학을 사용하므로 두 결과를 같은 물리 모델로 비교할 수 없습니다. 전체 구현 상태와 검증 범위는 [현재 구현과 시험 상태](SPEC.md)를 보세요.

## 시작하기

저장소를 Visual Studio에서 열고 CMake 구성 `ninja-release`를 선택해 실행 파일을 빌드하고 실행합니다. 조작과 시험 절차는 [실행 안내](docs/public/시작하기.md)에 있습니다.
