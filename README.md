# DroneSim

DroneSim은 한 프로그램에서 네 대의 드론을 운용하며, 정찰 임무와 통신·기체 장애를 시험하는 시뮬레이터입니다. 사람이 정찰 지점과 확인할 대상을 정하면 드론이 해당 위치로 이동해 영상과 위치 정보를 모읍니다.

영상 속 사람이나 시설물 파손을 자동 판정하지 않습니다. 가상 통신과 비행 결과는 실제 기체의 안전성이나 현장 운용을 입증하지 않습니다.

## 시작하기

Windows에서 Visual Studio로 저장소를 열고 `Ninja Release` 구성을 빌드한 다음 시뮬레이터를 실행합니다. 첫 빌드에는 인터넷 연결이 필요할 수 있습니다. 실행 후 비행 상태 패널에서 **전체 임무 시작 (M01 → M02 → M03)**을 누르면 편대 이동, 지점 정찰, 재집결·복귀를 차례로 볼 수 있습니다.

자세한 실행과 조작 방법은 [실행 안내](docs/public/시작하기.md)를 보세요.
