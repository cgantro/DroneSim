# DroneSim

DroneSim은 네 대의 드론이 편대 이동, 지점 정찰, 재집결과 복귀를 수행하는 과정을 시험하는 시뮬레이터입니다. 리더가 경로와 임무를 나누고, 드론은 이웃 기체를 통해 메시지를 주고받습니다. 통신 단절이나 리더 이탈 같은 상황을 넣어 임무가 어떻게 바뀌는지 살펴볼 수 있습니다.

드론은 사람이 정한 지점에서 영상과 위치 정보를 모읍니다. 영상에 파손이나 이상이 있는지는 사람이 판단합니다.

## 지금 확인된 상태

네이티브와 웹은 서로 다른 비행 계산을 사용합니다. 네이티브는 AirSim 강체 물리, 웹은 단순화한 운동학을 사용합니다. 두 실행 환경의 결과를 같은 물리 모델로 비교할 수 없습니다.

현재 장면은 실제 도시 지도가 아니라 500m × 400m 크기의 고정 가상 훈련장입니다. 화면에서 보이는 드론·장애물과 자동 시험이 확인한 동작은 서로 다른 검증 범위입니다. 자세한 현황은 [기능과 시험 결과](SPEC.md)에서 확인하세요.

## 바로 시작하기

Windows에서는 Visual Studio에서 `ninja-release` 구성을 선택하고 `aerosimlab_simulator` 대상을 빌드합니다. 실행 파일 이름은 `DroneSim.exe`입니다. 화면 조작과 기본 임무 실행 순서는 [실행 안내](docs/public/시작하기.md)에 있습니다.
