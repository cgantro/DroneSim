# DroneSim

DroneSim은 여러 대의 가상 드론이 편대를 이루어 비행하고, 통신·기체 장애에 대응하는 과정을 시험하는 시뮬레이터입니다. 현재 화면에는 산업시설과 자연물 에셋을 놓은 가상 훈련장이 표시됩니다.

## 지금 구현된 범위

- Flecs 기반 시뮬레이션과 60Hz 고정 Tick
- 네이티브 AirSim 강체 비행, 웹의 간단한 운동학 비행
- 네 대의 X500 드론과 가상 산업·산악 훈련장
- 장면·EO 카메라·비행 상태를 나눠 보는 시뮬레이터 화면
- 편대 이동 시작과 V자·일렬·횡대 선택
- 별도 지상통제 프로그램과 시나리오 실행기

드론 사이의 모의 무선망, 다중 홉 전달, 장애 복구, 임무 자동 재배정은 아직 구현 중입니다. 실제 도시를 재현한 지도도 현재 기본 장면에 포함하지 않습니다.

## 빌드

Windows에서는 Visual Studio의 CMake 프로젝트 열기 기능으로 저장소를 연 뒤 `ninja-release` 구성을 선택하고 `aerosimlab_simulator` 대상을 빌드·실행합니다. 첫 구성에는 외부 라이브러리 내려받기가 필요할 수 있습니다.

자세한 순서와 조작 방법은 [실행 안내](docs/public/시작하기.md)를 참고하세요.
