# DroneSim

DroneSim은 네 대의 드론이 함께 이동하고, 사람이 정한 지점을 정찰한 뒤, 장애 상황에 대응하는 과정을 시험하는 시뮬레이터입니다. 임무 경로와 가상 통신망을 바꾸며 기체 이탈·통신 단절이 결과에 미치는 영향을 살펴봅니다.

드론은 지정된 지점에서 영상과 위치 정보를 모읍니다. 영상 속 파손 여부는 사람이 판단합니다.

## 현재 상태

기본 장면은 실제 도시 지도가 아닌 약 500m × 400m 훈련장입니다. Windows 네이티브는 AirSim 강체 물리를, 웹은 단순화한 운동학을 사용합니다. 두 환경의 비행 결과를 같은 물리 모델로 비교할 수 없습니다.

편대·정찰·가상 통신망은 개발 중입니다. 2026년 10월 28일 기준 이전 Release 빌드의 자동 시험 32개는 모두 통과했지만, 이후 추가한 전체 임무 통합 시험은 리더 장애 뒤 대체 기체를 찾지 못해 실패했습니다. 따라서 이전 통과 결과를 현재 작업 중인 전체 임무의 검증으로 볼 수 없습니다. 현재 확인 상태와 실패 조건은 [기능 현황](SPEC.md)에 정리했습니다.

## 실행

저장소를 Visual Studio에서 열고 `ninja-release` 구성을 선택합니다. `aerosimlab_simulator` 대상을 빌드한 뒤 생성된 `DroneSim.exe`를 실행하세요. 조작과 임무 시작은 [실행 안내](docs/public/시작하기.md)에 설명되어 있습니다.
