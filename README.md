# DroneSim

DroneSim은 여러 가상 드론이 편대로 이동하고, 정찰 지점을 나눠 방문한 뒤, 통신 장애가 임무에 미치는 영향을 시험하는 시뮬레이터입니다. 목적은 실제 비행을 인증하는 것이 아니라 같은 조건을 반복해 임무 결과를 비교하는 것입니다.

## 지금 알아둘 점

- 기준 기체는 PX4 X500 네 대입니다.
- Windows 프로그램은 AirSim 강체 물리를 사용하고, 웹판은 단순화한 운동학 계산을 사용합니다. 두 결과는 같은 물리 모델이 아닙니다.
- 통신망은 거리·건물 가림·설정한 지연과 손실을 계산하는 가상 모델입니다. 실제 무선 전파나 장비 성능을 재현하지 않습니다.
- 정찰 대상과 파손 여부는 사람이 정하고 판단합니다. 드론은 지정된 곳으로 이동해 영상과 위치 정보를 확보하는 역할입니다.
- 시험장은 산업시설과 자연물 에셋으로 만든 가상 훈련장입니다. 실제 탄천이나 특정 도시의 디지털 트윈이 아닙니다.

## 첫 실행

Visual Studio에서 저장소를 열고 CMake 구성 `ninja-release`를 선택한 다음 `aerosimlab_simulator` 대상을 빌드해 실행합니다. 처음 구성할 때는 의존성을 받기 위해 인터넷 연결이 필요할 수 있습니다. 조작 방법은 [시작 안내](docs/public/시작하기.md)를 참고하세요.
