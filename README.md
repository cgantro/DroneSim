# DroneSim

DroneSim은 드론이 접근하기 어려운 시설물 주변을 정찰하고, 촬영한 영상과 위치 정보를 지상통제 화면에 전달하는 과정을 시험하는 M&S 프로그램입니다. 정찰 지점과 확인할 대상은 사람이 정합니다. 영상에 파손이나 이상이 있는지도 사람이 판단합니다.

## 현재 상태

기본 장면은 실제 탄천 지도가 아니라 약 500m × 400m 크기의 가상 훈련장입니다. 탄천 지도 자료는 자동 시험용으로만 들어 있고 실행 장면에는 아직 연결되지 않았습니다. Release 자동 시험에서는 M01 이동부터 M02 정찰, M03 복귀와 네 대 착륙까지 확인했습니다. 실제 지도 화면에서 위치·모양을 대조하거나 임무를 눈으로 확인한 결과는 아닙니다. 나머지 구현과 시험 범위는 [현재 구현 상태](SPEC.md)에 정리했습니다.

Windows 네이티브는 AirSim 강체 물리를 사용하고 웹은 단순화한 운동학을 사용합니다. 두 환경은 같은 비행 물리로 비교할 수 없습니다.

## 실행

저장소를 Visual Studio에서 열고 `ninja-release` 구성을 선택해 시뮬레이터를 빌드하고 실행합니다. 조작 방법은 [실행 안내](docs/public/시작하기.md)를 보세요.
