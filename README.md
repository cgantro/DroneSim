# DroneSim

DroneSim은 네 대의 가상 드론이 편대를 이루어 이동하고 정찰하는 과정을 시험하는 시뮬레이터입니다. 드론 사이의 가상 통신망에 장애를 넣어 메시지가 전달되거나 끊기는 상황도 살펴봅니다.

현재 훈련장은 실제 도시 지도가 아니라 산업시설과 자연물 에셋으로 구성한 가상 공간입니다. 네이티브 실행은 AirSim 강체 물리를 쓰고, 웹 실행은 단순화한 운동학 계산을 씁니다. 두 실행 환경의 물리 결과는 같지 않습니다.

## 현재 구현

- 60Hz 고정 Tick으로 네 대의 X500 상태를 갱신합니다.
- 편대 대형을 고르고, 리더가 만든 이동 목표를 가상 통신망으로 전달합니다.
- 서로 다른 시험 지점을 네 대에 나눠 주는 분산 정찰을 시작할 수 있습니다.
- 드론 사이 거리와 건물 가림을 반영해 이웃을 찾고 여러 홉으로 메시지를 전달합니다.
- 비행 중 두 드론 사이의 링크를 끊거나 복구할 수 있습니다. 상태 패널에는 전달·중계·폐기 수와 최근 통신 사건이 표시됩니다.
- 장면, EO 카메라, 비행 상태를 한 창의 패널로 나누어 확인합니다.

통신 장애 뒤 우회 경로 탐색은 자동 시험으로 확인했습니다. 분산 정찰은 목표별 경로 이동과 착륙까지 지원하며, 촬영 자료 저장·전달과 임무 자동 재배정은 아직 연결하지 않았습니다. 기체 고장과 무작위 패킷 손실·지연도 화면에서 주입할 수 없습니다. 현재 통신 사건 기록은 실행 중 최근 항목을 보여 주며 파일로 저장하지 않습니다.

## 빌드

Windows에서는 Visual Studio로 저장소를 열고 `ninja-release` 구성을 선택한 뒤 `aerosimlab_simulator` 대상을 빌드하고 실행합니다. 처음 구성할 때는 외부 라이브러리를 내려받을 수 있도록 인터넷이 필요합니다. 상세 순서는 [실행 안내](docs/public/시작하기.md)에 있습니다.
