# DroneSim

DroneSim은 네 대의 드론이 편대로 이동하고, 정찰 지점을 나눠 맡고, 통신이나 기체 고장에 대응하는 과정을 시험하는 시뮬레이터입니다. 사람은 정찰할 장소를 정하고, 드론은 그곳의 영상과 위치 정보를 모읍니다. 영상 속 사람이나 시설물 파손을 자동으로 판별하지는 않습니다.

## 처음 시작할 때

1. [실행과 조작 안내](docs/public/시작하기.md)에서 프로그램을 여는 순서와 화면 조작을 확인합니다.
2. 시뮬레이터를 실행한 뒤 비행 상태 화면에서 **전체 임무 시작 (M01 → M02 → M03)**을 누릅니다.
3. 어떤 기능이 시험됐는지 궁금하면 [현재 구현과 시험 상태](SPEC.md)를 확인합니다.

처음 빌드할 때는 라이브러리를 내려받기 위해 인터넷 연결이 필요할 수 있습니다.

## 지금 확인된 범위

- Windows Release 자동 시험에서 네 대의 정상 임무와 추종 드론 고장 뒤 목표 재배정·복귀 흐름을 확인했습니다.
- M02 중 리더가 고장 나고 관제소와 연결되는 경로도 없는 경우에는 임무를 중단하고 안전 착륙을 요청합니다. 이 조건에서 새 리더가 임무를 이어 가는 기능은 확인되지 않았습니다.
- 화면에서 통신·카메라·로터 장애를 설정할 수 있습니다. 로터별 강체 물리는 Windows 네이티브에서만 동작합니다.
- 네이티브는 AirSim 강체 물리, 웹은 단순화한 운동학을 사용합니다. 두 환경은 같은 물리 모델이 아닙니다.
- 기본 장면은 가상 훈련장입니다. 실제 탄천의 지도나 디지털 트윈으로 볼 수 없습니다.

실제 기체의 안전성, 실제 무선 통신, 웹 화면 품질은 이 자동 시험으로 확인하지 않았습니다. 자세한 시험 범위는 [현재 구현과 시험 상태](SPEC.md)를 보세요.
