# DroneSim

DroneSim은 여러 대의 드론이 함께 임무를 수행하는 과정을 시험하는 시뮬레이터입니다. 사람이 정한 지점에서 영상과 위치 정보를 모으고, 통신이나 기체에 문제가 생겼을 때 임무가 어떻게 달라지는지 살펴봅니다. 영상에 보이는 시설물의 상태는 사람이 판단합니다.

## 지금 확인할 수 있는 것

- 네 대의 드론을 위한 편대 이동, 지점 정찰, 재집결·복귀 흐름
- 거리와 건물 가림을 반영하는 가상 다중 홉 통신망
- 통신 장애를 넣는 기능과 드론별 카메라 화면
- Windows의 AirSim 강체 물리와 웹의 단순 운동학 계산

임무 전체의 화면 시연과 장애 복구는 아직 모두 검증되지 않았습니다. 확인한 범위는 [현재 기능과 시험 결과](SPEC.md)에 적었습니다.

## 실행과 문서

- 처음 실행하고 조작하려면 [실행 안내](docs/public/시작하기.md)를 보세요.
- 비행·임무·통신 계산이 연결되는 방식은 [기술 구조](docs/public/기술구조.md)를 보세요.
- 성능 수치와 시험 조건은 [성능 검증](docs/public/성능검증.md)을 보세요.
- 기록된 문제와 해결 과정은 [문제 해결 기록](docs/public/문제해결.md)을 보세요.

프로젝트의 목표와 범위는 [개발 목표](GOAL.md), 구현 상태와 미확인 항목은 [기능 현황](SPEC.md)에 있습니다. 전체 문서의 용도는 [문서 길잡이](docs/public/README.md)에서 확인할 수 있습니다.

## 현재 장면의 한계

장면은 500m × 400m 크기의 가상 훈련장입니다. 실제 탄천 지도를 재현하지 않으며, 실제 무선 전파도 계산하지 않습니다. 카메라 영상은 화면에 표시하지만 임무별 저장과 지상통제소 전달은 아직 연결되지 않았습니다. Windows와 웹은 서로 다른 비행 계산을 사용하므로 결과를 같은 물리 모델로 비교할 수 없습니다.
