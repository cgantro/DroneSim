# DroneSim

DroneSim은 네 대의 가상 드론이 편대로 이동하고 정찰하는 과정을 시험하는 시뮬레이터입니다. 드론 사이의 가상 통신에 장애를 넣어 메시지 전달과 경로 변경도 확인합니다.

현재 훈련장은 실제 도시 지도가 아니라 산업시설과 자연물 에셋으로 구성한 가상 공간입니다. 네이티브 실행은 AirSim 강체 물리를 쓰고, 웹 실행은 단순화한 운동학 계산을 씁니다. 두 실행 환경의 물리 결과는 같지 않습니다.

## 지금 확인할 내용

프로젝트는 네 대의 X500으로 편대 이동, 지점별 정찰, 각 출발점 복귀를 구현하고 있습니다. 정찰 목표는 사람이 미리 지정하며, 카메라가 시설물 파손이나 새 목표를 판정하지 않습니다.

분산 정찰과 복귀는 코드와 자동 시험에 연결됐지만, 실제 창에서 시작부터 착륙까지 확인하지 않았습니다. 현재 구현과 미완성 항목은 [기능 현황](SPEC.md), 프로젝트가 목표로 하는 최종 흐름은 [개발 목표](GOAL.md)에서 확인하세요.

## 빌드

Windows에서는 Visual Studio에서 저장소를 열고 Release 구성을 선택해 시뮬레이터를 빌드하고 실행합니다. 처음 구성할 때는 외부 라이브러리를 내려받도록 인터넷이 필요할 수 있습니다. 자세한 순서는 [실행과 조작](docs/public/시작하기.md)에 있습니다.
