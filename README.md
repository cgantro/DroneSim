# DroneSim

DroneSim은 한 번의 실행에서 네 대의 가상 드론이 편대로 이동하고, 정찰 지점을 나눠 방문하며, 통신 장애에 대응하는 과정을 시험하는 시뮬레이터입니다. 임무 흐름과 가상 통신망의 변화를 같은 조건으로 반복해 비교하는 것이 목적입니다.

현재 시험장은 산업시설과 자연물 에셋으로 만든 가상 훈련장입니다. 실제 탄천이나 특정 도시를 재현한 지도는 아닙니다. 정찰 목표와 파손 여부는 사람이 정하며, 드론은 카메라 영상과 위치 정보를 확보해 전달하는 역할을 합니다.

## 실행 전에 알아둘 점

- Windows 네이티브는 AirSim 강체 물리를 사용합니다. 웹 실행은 단순화한 운동학 계산을 사용하므로 두 결과는 같은 물리 모델로 비교할 수 없습니다.
- 코드에는 편대 이동부터 정찰·재집결·복귀까지 잇는 전체 임무 시작 기능이 추가되어 있습니다. 실제 창에서 끝까지 수행되는지는 아직 확인 중이며, 확인 결과는 기능 현황에 기록합니다.
- 통신 장애와 다중 홉은 거리·가림·설정한 지연과 손실을 사용하는 가상 모델입니다. 실제 무선 장비나 전파 환경을 검증하지 않습니다.

## 빌드

Windows에서는 Visual Studio에서 저장소를 열고 CMake 구성으로 `ninja-release`를 선택한 뒤 시뮬레이터 대상을 빌드합니다. 처음 구성할 때는 의존성 내려받기에 인터넷 연결이 필요할 수 있습니다. 자세한 순서는 [시작 안내](docs/public/시작하기.md)에 있습니다.
