# DroneSim

DroneSim은 여러 가상 드론이 임무를 나눠 수행하는 과정을 시험하는 시뮬레이터입니다. 편대 이동, 지점 정찰, 재집결을 이어 실행하고, 통신 장애가 경로와 임무에 어떤 영향을 주는지 살펴봅니다.

## 프로젝트가 다루는 범위

- 기본 시험은 PX4 X500 네 대와 고정된 가상 훈련장을 사용합니다.
- Windows판은 AirSim 강체 물리를, 웹판은 단순화한 운동학 계산을 사용합니다. 두 환경의 결과는 같은 물리 모의 결과가 아닙니다.
- 드론 사이 통신은 거리, 장애물 가림, 설정한 지연과 손실을 적용하는 가상 모델입니다. 실제 무선 장비나 전파 환경을 재현하지 않습니다.
- 정찰 지점과 파손 여부는 사람이 정합니다. 드론은 지정 지점으로 이동해 영상과 위치 정보를 확보합니다.
- 훈련장은 산업시설과 자연물 에셋을 배치한 가상 공간입니다. 실제 탄천이나 도시 전체를 본뜬 디지털 트윈이 아닙니다.

## 첫 실행

Visual Studio에서 저장소를 연 뒤 CMake 구성 `ninja-release`를 선택하고 `aerosimlab_simulator` 대상을 빌드해 실행합니다. 첫 구성에는 의존성 다운로드를 위한 인터넷 연결이 필요할 수 있습니다. 조작 순서는 [시작 안내](docs/public/시작하기.md)에 있습니다.

문서는 [읽기 안내](docs/public/README.md)에서 목적별로 찾아볼 수 있습니다.
