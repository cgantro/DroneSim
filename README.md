# DroneSim

DroneSim은 여러 대의 드론이 임무를 나눠 수행하고, 통신이나 기체에 문제가 생겼을 때 임무가 어떻게 달라지는지 시험하는 시뮬레이터입니다. 드론은 사람이 지정한 곳에서 영상과 위치 정보를 모읍니다. 영상 속 시설물의 상태는 사람이 판단합니다.

## 현재 상태

네이티브 프로그램에는 편대 이동, 지점 정찰, 재집결·복귀와 가상 통신 장애 기능이 있습니다. 자동 시험은 일부 경로를 확인했지만, 네 대의 드론이 GUI에서 임무를 처음부터 끝까지 수행하는 모습은 아직 확인하지 않았습니다. 자세한 구현 상태와 시험 범위는 [기능 현황과 확인 결과](SPEC.md)에서 볼 수 있습니다.

## 시작하기

처음 실행하거나 기본 임무를 살펴보려면 [실행 안내](docs/public/시작하기.md)를 따라가세요. 화면 조작과 통신 장애를 넣는 방법도 여기에 있습니다.

## 알아둘 한계

현재 장면은 실제 탄천 지도가 아니라 500m × 400m 크기의 가상 훈련장입니다. 실제 무선 전파도 계산하지 않습니다. Windows 네이티브는 AirSim 강체 물리를, 웹은 단순화한 운동학 계산을 사용하므로 두 환경의 비행 결과를 같은 물리 모델로 비교할 수 없습니다. 카메라 영상의 임무별 저장과 지상통제소 전달도 아직 연결되지 않았습니다.
