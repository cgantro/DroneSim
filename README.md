# DroneSim

DroneSim은 한 프로그램에서 네 대의 드론을 편대로 이동시키고, 정찰 지점을 나눠 맡기고, 다시 모여 복귀시키는 과정을 시험하는 시뮬레이터입니다. 통신이 끊기거나 카메라에 문제가 생겼을 때 임무가 어떻게 달라지는지도 살펴볼 수 있습니다.

사람이 정찰할 곳과 확인할 대상을 정합니다. 드론은 그곳으로 이동해 영상과 위치 정보를 모읍니다. 영상 속 대상이나 시설물 상태를 자동으로 판정하지는 않습니다.

## 지금 가능한 것

- Windows 네이티브 프로그램에서 네 대의 임무와 장애 조작을 실행합니다.
- 가상 통신망에서 직접 통신, 리더 경유, 다중 홉 경로를 시험합니다.
- 패킷 손실, 지연 흔들림, 링크·라디오 차단, 카메라 고장을 넣을 수 있습니다. 일부 장애 조작은 기록해 다시 적용할 수 있습니다.
- 네이티브는 AirSim 강체 물리, 웹은 단순화한 운동학을 사용합니다. 두 환경의 결과는 같은 물리 모델로 비교할 수 없습니다.

현재 임무 흐름은 자동 시험으로 확인했지만, 장애를 넣은 전체 임무와 실제 화면에서의 복구 과정은 아직 모두 확인하지 않았습니다. 이 프로그램은 실제 기체나 무선 장비의 안전성을 입증하지 않습니다.

## 처음 시작할 때

1. Visual Studio에서 이 프로젝트 폴더를 엽니다.
2. CMake 구성에서 **Ninja Release**를 선택합니다.
3. **모두 빌드**한 뒤 시뮬레이터 실행 항목을 시작합니다.
4. 화면이 열리면 비행 상태 패널에서 **전체 임무 시작 (M01 → M02 → M03)**을 누릅니다.

게임패드 연결과 화면 조작은 [실행과 조작 안내](docs/public/시작하기.md)에 설명했습니다. 처음 빌드할 때는 필요한 라이브러리를 받기 위해 인터넷 연결이 필요할 수 있습니다.
