# AeroSimLab

AeroSimLab은 가상 드론의 비행, 카메라 영상, 지상통제 명령을 한곳에서 시험하는 C++ 시뮬레이터입니다.

처음이라면 [시작 안내](docs/public/시작하기.md)부터 읽어 주세요. 공개용 문서는 사용자가 실행하고 조작하는 데 필요한 내용만 담습니다. 내부 작업 기록과 개발 기준은 별도 영역에 둡니다.

## 지금 할 수 있는 일

- 드론을 이륙시키고, 이동시키고, 착륙시킵니다.
- 장면을 위에서 보는 화면과 드론 카메라 화면으로 확인합니다.
- 카메라 고장, 통신 지연·손실 같은 시험 상황을 재현합니다.
- 지상통제 프로그램에서 UDP로 명령을 보냅니다.
- RGB 영상의 밝기·대비·선명도 추정값을 확인합니다.

비행은 교육·시험용 단순 모의입니다. 실제 기체의 공기역학이나 조종 성능을 예측하지 않습니다. AI 영상 추론과 실제 Xbox 조종기 검증도 아직 포함하지 않았습니다.
