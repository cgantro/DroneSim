# DroneSim

DroneSim은 여러 드론이 편대를 이루어 이동하고, 사람이 정한 지점을 정찰하며, 통신이나 기체 장애에 대응하는 과정을 시험하는 시뮬레이터입니다. 임무 명령과 드론 사이 메시지 전달을 함께 살펴봅니다.

드론은 지정된 곳으로 이동해 영상과 위치 정보를 모읍니다. 영상에 파손이나 이상이 있는지는 사람이 판단합니다.

## 지금 확인할 점

기본 장면은 실제 도시 지도가 아닌 약 500m × 400m 훈련장입니다. Windows 네이티브는 AirSim 강체 물리를 사용하고, 웹은 단순화한 운동학을 사용합니다. 두 환경의 비행 결과는 같은 물리 모델로 비교할 수 없습니다.

편대·정찰·가상 통신망은 개발 중입니다. 현재 전체 임무 통합 시험은 지점 정찰 단계(M02)에서 대체 리더를 찾지 못해 실패합니다. 이전 Release에서 통과한 시험은 이 전체 임무 흐름을 검증한 결과가 아닙니다. 최신 상태와 확인 범위는 [구현 상태와 시험 결과](SPEC.md)에서 확인하세요.

## 실행해 보기

저장소를 Visual Studio에서 열고 `ninja-release` 구성을 선택한 뒤 `aerosimlab_simulator` 대상을 빌드합니다. 생성된 `DroneSim.exe`를 실행하세요. 게임패드 조작과 임무 시작은 [실행 안내](docs/public/시작하기.md)에 정리했습니다.
