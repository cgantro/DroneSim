# DroneSim

DroneSim은 한 프로그램에서 네 대의 드론을 편대로 운용하고, 정찰 임무와 통신·기체 장애를 시험하는 시뮬레이터입니다. 정찰 장소와 확인할 대상은 사람이 정합니다. 드론은 지정된 곳으로 이동해 영상과 위치 정보를 모읍니다.

영상 속 사람이나 시설물 파손을 자동으로 찾아내지는 않습니다. 가상 통신망과 시뮬레이션 결과도 실제 기체의 안전성이나 현장 운용을 입증하지 않습니다.

## 먼저 해볼 일

Windows에서 프로젝트를 Visual Studio로 열고 `Ninja Release` 구성을 선택해 빌드한 뒤 시뮬레이터를 실행합니다. 처음 빌드할 때는 외부 라이브러리를 받기 위해 인터넷 연결이 필요할 수 있습니다.

실행 후 비행 상태 패널에서 **전체 임무 시작 (M01 → M02 → M03)**을 누르면 편대 이동, 지점 정찰, 재집결·복귀 순서로 진행합니다.

## 현재 시험 결과

- 2026년 10월 28일 Windows Release에서 CTest 35개가 모두 통과했습니다.
- 추종 드론 고장 뒤 목표 재배정과 복귀를 확인했습니다.
- 리더 고장 뒤 교체·재배정·복귀는 통신을 넓게 보장한 시험망에서 확인했습니다. 실제 거리와 건물 가림을 적용한 경우는 아직 시험하지 않았습니다.
- 기본 장면은 절차적으로 만든 약 500m × 400m 훈련장입니다. 실제 탄천이나 특정 지역의 지도가 아닙니다.
- Windows 네이티브는 AirSim 강체 물리를 쓰고, 웹은 단순화한 운동학을 씁니다. 두 환경의 물리 결과는 같지 않습니다.
