# DroneSim

DroneSim은 가상 훈련장에서 여러 드론의 임무와 통신 장애를 함께 시험하는 시뮬레이터입니다. 네 대의 PX4 X500을 기준으로 편대 이동, 지점별 정찰, 재집결과 복귀를 이어서 실행합니다.

드론은 사람이 정한 정찰 지점에서 영상과 위치 정보를 모읍니다. 영상 속 파손 여부를 자동으로 판정하지는 않습니다. 통신망은 거리·장애물 가림·설정한 지연과 손실을 사용하는 시험 모델이며, 실제 무선 전파를 재현하지 않습니다.

## 현재 기준

- 훈련장은 산업시설·자연물 에셋으로 만든 고정 가상 공간입니다. 실제 탄천이나 특정 도시를 본뜬 디지털 트윈이 아닙니다.
- Windows 네이티브는 AirSim 강체 물리를 사용하고, 웹 빌드는 단순화한 운동학 계산을 사용합니다. 두 환경의 비행 결과는 같은 물리 모델로 비교할 수 없습니다.
- 편대·정찰 경로를 통신망으로 전달하는 기능은 일부 구현되어 있습니다. 앱 전체에서 장애 복구까지 이어지는 시험은 남아 있습니다.
- 드론별 카메라 영상, 임무별 영상 저장·전송, 리더·중계기 고장 대응은 기능마다 구현·검증 범위가 다릅니다. 세부 현황은 [기능 현황](SPEC.md)에서 확인하세요.
