# DroneSim

DroneSim은 한 프로그램에서 네 대의 드론을 움직이며 편대 임무와 통신·기체 장애를 시험하는 시뮬레이터입니다. 사람은 정찰 지점을 지정하고, 드론은 그곳의 영상과 위치 정보를 수집합니다. 영상 속 대상이나 시설물 파손을 자동 판별하지는 않습니다.

## 시작

Visual Studio에서 저장소를 열고 `Ninja Release` 구성을 빌드한 뒤 시뮬레이터를 실행합니다. 비행 상태 패널에서 **전체 임무 시작 (M01 → M02 → M03)**을 누르면 편대 이동, 정찰, 복귀 순서로 진행합니다. 첫 빌드에는 인터넷 연결이 필요할 수 있습니다.

## 현재 범위

- 정상 조건의 네 대 임무와 가상 통신망의 경로 탐색·장애 시험을 자동 시험으로 확인했습니다.
- 통신·카메라·로터 장애를 화면에서 설정할 수 있습니다. 로터별 물리는 Windows 네이티브에서만 작동합니다.
- 장애를 넣은 임무의 재배정·복귀 흐름과 화면 품질은 확인 중입니다.
- 네이티브는 AirSim 강체 물리, 웹은 단순화한 운동학을 사용합니다. 두 결과는 같은 물리 기준으로 비교할 수 없습니다.

실기체의 안전성이나 실제 무선 성능을 검증하는 도구는 아닙니다. 기능별 확인 결과는 [현재 구현과 시험 상태](SPEC.md)를 기준으로 보세요.
