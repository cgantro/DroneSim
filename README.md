# DroneSim

DroneSim은 네 대의 가상 X500이 편대로 이동하고, 사람이 지정한 구역을 나눠 정찰한 뒤 복귀하는 과정을 시험하는 시뮬레이터입니다. 드론 사이 가상 통신이 끊겼을 때 메시지가 어떻게 전달되고 경로가 어떻게 바뀌는지도 확인합니다.

현재 훈련장은 산업시설과 자연물 에셋을 배치한 가상 공간입니다. 실제 탄천이나 특정 도시를 재현한 지도는 아닙니다. 정찰 지점은 사람이 정하고, 영상으로 파손 여부를 판정하는 일도 사람이 합니다.

## 현재 알아둘 점

- 네이티브 실행은 AirSim 강체 물리를 사용합니다. 웹 실행은 단순화한 운동학 계산을 사용하므로 두 결과는 같지 않습니다.
- 편대 이동, 분산 정찰, 각 출발점 복귀는 각각 시작할 수 있습니다. 세 단계를 자동으로 잇는 임무와 공통 집결은 아직 없습니다.
- 링크 장애 시험은 가상 통신 모델 안에서 동작합니다. 실제 무선 장비의 전파나 실기체의 안전성을 검증하지 않습니다.

기능의 세부 상태와 마지막 확인 결과는 [기능 현황](SPEC.md)을 기준으로 확인하세요.

## 빌드

Windows에서는 Visual Studio에서 저장소를 열고 `ninja-release` 구성을 선택한 뒤 `aerosimlab_simulator`를 빌드하고 실행합니다. 처음 구성할 때는 인터넷 연결이 필요할 수 있습니다. 전체 순서는 [시작하기](docs/public/시작하기.md)에 있습니다.
