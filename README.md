# AeroSimLab

AeroSimLab은 가상 드론의 비행과 카메라 화면, 지상통제 명령을 시험하는 프로그램입니다. 실제 드론을 조종하거나 실제 비행 성능을 예측하지는 않습니다.

처음 사용하는 분은 [처음 실행하고 조작하기](docs/public/시작하기.md)부터 읽어 주세요.

## 문서

- [사용 안내](docs/public/시작하기.md): 빌드, 실행, 조작, 시나리오 사용법
- [사용 문제 해결](docs/public/문제해결.md): 실행·화면·통신 문제 점검
- [개발 문서 안내](docs/private/개발안내.md): 기술 설계, 개발 기록, 개발 문제 해결 문서의 목차
- [프로젝트 목표](GOAL.md)와 [MVP 명세](SPEC.md): 방향, 요구사항, 구현 상태

## 현재 가능한 일

- 가상 드론을 이륙시키고 이동·회전·착륙시킵니다.
- 주변을 보는 화면과 드론에 달린 카메라 화면을 함께 띄웁니다.
- 지상통제 프로그램에서 명령을 보내고 응답을 확인합니다.
- 통신 지연·손실과 카메라 고장 상황을 시나리오로 재현합니다.
- 카메라 화면의 밝기·대비·선명도를 간단히 계산합니다.

비행 움직임은 위치와 속도를 중심으로 계산하는 단순 모의입니다. 실제 공기 흐름, 모터, 센서 오차는 계산하지 않습니다. 실제 게임패드, 실제 카메라 영상, AI 영상 분석은 아직 확인되거나 구현되지 않았습니다.
