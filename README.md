# DroneSim

DroneSim은 한 프로그램에서 네 대의 드론을 운용하며 편대 이동, 지점 정찰, 재집결과 복귀를 시험하는 시뮬레이터입니다. 통신이 끊기거나 기체에 문제가 생겼을 때 임무가 어떻게 달라지는지도 확인합니다.

사람이 정찰 지점과 확인할 대상을 정합니다. 드론은 그곳으로 이동해 영상과 위치 정보를 모읍니다. 영상 속 사람이나 시설물의 상태를 자동으로 판별하지는 않습니다.

## 현재 확인된 범위

- Windows 네이티브 프로그램에서 네 대의 정상 임무를 자동 시험으로 확인했습니다.
- 가상 통신망에서 직접 통신, 리더 경유, 다중 홉과 장애 뒤 경로 변경을 시험할 수 있습니다. 중요 경로 명령은 목적지 확인 응답과 제한 재전송을 사용합니다.
- 통신·카메라·로터 장애를 화면에서 조작할 수 있습니다. 로터 장애는 AirSim 강체 모의를 사용하는 Windows 네이티브에서만 작동합니다.
- 네이티브는 AirSim 강체 물리, 웹은 단순화한 운동학을 사용합니다. 두 실행 환경의 물리 결과는 같은 기준으로 비교할 수 없습니다.

장애를 넣은 전체 임무의 복구와 착륙, 실제 무선 장비와의 일치, 화면 품질은 확인이 더 필요합니다. 이 프로그램은 실기체 안전성이나 실제 무선 성능을 보증하지 않습니다.

## 처음 실행하기

Visual Studio에서 저장소를 열고 `Ninja Release` 구성을 선택한 뒤 모두 빌드합니다. 시뮬레이터를 실행하고 비행 상태 패널에서 **전체 임무 시작 (M01 → M02 → M03)**을 누르면 대표 임무를 볼 수 있습니다. 첫 빌드에는 라이브러리를 받기 위한 인터넷 연결이 필요할 수 있습니다.

조작과 장애 시험 방법은 [실행과 조작 안내](docs/public/시작하기.md)를 보세요.
