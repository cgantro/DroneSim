# DroneSim

DroneSim은 여러 드론이 통신하며 임무를 수행하는 과정을 가상 훈련장에서 시험하는 모델링·시뮬레이션 프로젝트입니다. PX4 X500 네 대를 기준으로 **편대 이동 → 지점별 정찰 → 재집결과 복귀**를 구성하고, 통신 장애가 임무에 미치는 영향을 확인합니다.

정찰 지점은 사람이 지정합니다. 드론은 그곳으로 이동해 영상과 위치 정보를 확보하는 것이 목표이며, 파손 여부는 사람이 판단합니다. 가상 통신망은 거리·장애물·설정한 지연과 손실을 이용하므로 실제 무선 전파를 재현하지 않습니다.

## 현재 알아둘 점

- 훈련장은 산업시설과 자연물 에셋을 배치한 가상 공간입니다. 실제 도시를 옮긴 지도는 아닙니다.
- Windows 네이티브는 AirSim 강체 물리를, 웹은 단순화한 운동학 계산을 사용합니다. 두 결과는 같은 물리 모델로 비교할 수 없습니다.
- 편대 상태 보고는 M01에서 통신 경로를 사용합니다. 정찰·복귀 등 모든 임무가 드론별 메시지만으로 동작하는 것은 아니며, 전체 임무의 장애 복구 시험도 남아 있습니다.
- 카메라 화면은 표시하지만, 정찰 자료를 임무별 파일로 저장하고 지상통제소까지 전달하는 흐름은 아직 연결되지 않았습니다.
- 화면 실행 시험은 창이 뜨는지 확인하는 수준입니다. 카메라 배치와 전체 임무 흐름을 직접 확인한 결과는 [기능 현황](SPEC.md)에 구분해 적었습니다.
