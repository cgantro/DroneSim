# DroneSim

DroneSim은 한 프로그램 안에서 네 대의 드론 임무와 가상 통신망을 시험하는 시뮬레이터입니다. 편대 이동, 지점별 정찰, 재집결·복귀 과정에서 통신 장애가 임무에 미치는 영향을 살펴봅니다.

사람이 정찰 지점과 확인할 대상을 정합니다. 드론은 지정된 곳으로 이동해 영상과 위치 정보를 모읍니다. 영상 속 대상이나 시설물의 상태를 자동 판정하지는 않습니다.

## 먼저 볼 문서

처음 프로젝트를 살펴본다면 다음 순서로 읽으면 됩니다.

1. [개발 목표](GOAL.md)에서 프로젝트의 범위와 완료 기준을 확인합니다.
2. [실행과 조작 안내](docs/public/시작하기.md)를 따라 프로그램을 실행합니다.
3. [현재 구현과 시험 상태](SPEC.md)에서 실제로 동작하는 기능과 아직 확인하지 않은 부분을 봅니다.

## 현재 시험 범위

- 약 500m × 400m 크기의 가상 산업·자연 복합 훈련장에서 네 대의 드론을 모의합니다.
- 전체 임무는 편대 이동(M01), 분산 정찰(M02), 재집결·복귀(M03) 순서로 진행합니다.
- 직접 통신, 리더 경유, 다중 홉 통신을 선택하고 링크·라디오·패킷 장애를 넣을 수 있습니다. 화면에서 방식별 결과를 자동 집계하지는 않습니다.
- Windows 네이티브는 AirSim 강체 물리를, 웹은 단순화한 운동학을 사용합니다. 두 환경의 비행 결과는 같은 물리 모델을 기준으로 비교할 수 없습니다.
- 기본 장면은 실제 탄천을 재현하지 않으며, 가상 통신망도 실제 무선 전파를 대신하지 않습니다.

구현 상태와 시험 결과는 [현재 구현과 시험 상태](SPEC.md)에 적혀 있습니다. 자동 시험 통과는 실제 비행 안전이나 현장 통신 성능을 증명하지 않습니다.
