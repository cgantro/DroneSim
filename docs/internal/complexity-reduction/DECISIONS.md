## 안전 문제와 현재 상태

- 경로 첫 경유점 누락: `ac98068c`에서 네 임무 호출부를 수정했고 정찰 경로 시험을 보강했다.
- 저전력 복귀 정찰 판정: `693a7dbb`에서 보수적으로 임무 중단을 반환한다. 도착 전후 구분과 실제 4대 장애 시나리오는 추가 검증이 필요하다.
- 직접 통신 전환은 기존 메시지 경로를 우회하거나 통신 거리를 늘리지 않는다. 훈련장의 출발점·목표·가림을 실제 링크 조건으로 검증한다.

## 검증과 미확인

- 변경 전 기준은 `VERIFICATION.md`, 파일별 근거는 `AUDIT_*.md`와 `INVENTORY.tsv`에 있다.
- `vector too long`의 최초 발생 위치와 원인은 미확인이다. 재현 시 스택과 입력을 기록하고 미해결이면 완료로 표시하지 않는다.
- 목록의 비공개 문서는 본문을 공개 안내의 필수 자료로 사용하지 않는다.
