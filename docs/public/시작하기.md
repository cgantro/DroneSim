# 실행하고 조작하기

이 안내는 Windows에서 시뮬레이터를 실행하고 현재 구현된 조작을 확인하는 방법입니다. 실제 도시를 재현하는 지도는 제공하지 않습니다.

## 프로그램 실행

1. Visual Studio에서 저장소를 엽니다.
2. CMake 구성에서 `ninja-release`를 선택합니다.
3. `aerosimlab_simulator` 대상을 빌드하고 실행합니다.
4. 3D 장면, 비행 상태, 주 드론 카메라가 보이는지 확인합니다.

처음 구성할 때는 라이브러리를 내려받기 위해 인터넷 연결이 필요할 수 있습니다.

## 화면 살펴보기

- **장면:** 훈련장과 드론을 보여 줍니다.
- **카메라:** 주 드론에 설정된 EO 카메라 영상을 보여 줍니다.
- **비행 상태:** 비행 모드, 위치, 모의 시간, 임무 진행을 보여 줍니다.
- **통신 사건:** 메시지 전달·중계·폐기와 최근 네트워크 사건을 보여 줍니다. 최근 사건은 실행 중 최대 64개까지 메모리에 보관하며 파일로 저장하지 않습니다.

패널 제목을 끌어 위치를 옮기고, 패널 사이 경계를 끌어 크기를 조절할 수 있습니다. 자동 화면 시험은 프로그램 시작까지만 확인합니다. 패널 이동과 실제 버튼 조작은 자동 검증 범위가 아닙니다.

## 게임패드 조작

게임패드를 연결한 뒤 시뮬레이터를 실행합니다.

| 입력 | 동작 |
| --- | --- |
| A 버튼 | 이륙 |
| B 버튼 | 착륙 |
| 왼쪽 스틱 | 앞·뒤·좌·우 이동 |
| 오른쪽 스틱 가로축 | 좌우 회전 |
| 왼쪽·오른쪽 트리거 | 하강·상승 |

Windows에서 게임패드가 인식되는지 확인하려면 `Win + R`을 누르고 `joy.cpl`을 실행합니다. 처음에는 스틱과 트리거를 조금씩 움직여 기체 반응을 확인하세요.

## 편대 이동과 링크 시험

1. 비행 상태 패널에서 V자·일렬·횡대 중 하나를 선택합니다.
2. **편대 이동 시작**을 누릅니다. 모든 드론이 지상에 있어야 합니다.
3. 이동 중 **송신 드론**과 **상대 드론**을 선택합니다.
4. **링크 끊기**를 눌러 가상 연결을 끊고, 통신 사건에서 경로 탐색과 메시지 전달 상태를 확인합니다.
5. **링크 복구**를 눌러 연결을 복구합니다.

이 시험은 거리와 장애물 가림을 사용하는 가상 통신 모델을 확인합니다. 실제 무선 장비나 전파 환경을 시험하지 않습니다.

## 여러 드론 정찰과 복귀

모든 드론이 지상에 있고 다른 임무를 수행하지 않을 때 비행 상태 패널에서 **여러 드론 정찰 시작**을 누릅니다. 시뮬레이터는 미리 지정된 정찰 지점을 드론 순서대로 나눠 주고 각 지점으로 이동시킨 뒤 착륙시킵니다.

정찰 목표를 방문하는 것과 영상을 별도 자료로 저장·전달하는 것은 다릅니다. 현재 화면 흐름에는 드론별 촬영 자료 전달과 장애 뒤 목표 재배정이 연결되지 않았습니다. 파손 여부는 영상으로 사람이 판단합니다.

정찰을 마친 드론이 모두 착륙하면 **출발 지점으로 복귀**를 눌러 각자 처음 출발한 위치로 보냅니다. 이 수동 흐름은 공통 집결을 거치지 않습니다. 편대 이동·정찰·복귀를 따로 시험할 때 사용하세요.

## 전체 임무 한 번에 시작

비행 상태 패널에는 **전체 임무 시작 (M01 → M02 → M03)** 버튼도 있습니다. 모든 드론이 지상에 있고 다른 임무가 없을 때 사용할 수 있습니다. 먼저 **편대 대형**에서 V자·일렬·횡대 중 하나를 고른 다음 버튼을 누릅니다.

코드에서 연결한 진행 순서는 편대 이동, 드론별 정찰과 착륙, 공통 집결, 처음 출발한 위치로 복귀입니다. 각 단계의 진행 상태는 비행 상태 패널에서 확인하도록 되어 있습니다. 이 기능은 최근 추가된 것으로, 현재 작업본에서 창을 열어 처음부터 복귀까지 완료되는지 아직 확인하지 않았습니다. 실제 시연 전에 기능 현황의 최신 검증 결과를 확인하세요.

## 실행 환경 차이와 제한

- Windows 네이티브 실행은 AirSim 강체 물리를 사용하고, 웹 실행은 단순화한 운동학 계산을 사용합니다. 비행 결과는 서로 같지 않습니다.
- 정찰은 사람이 지정한 지점을 방문하는 기능입니다. 영상으로 파손을 판정하거나 새 목표를 찾지 않습니다.
- 링크 장애 뒤 경로 재탐색과 별도 임무 재할당 시험은 존재하지만, 이들이 하나의 GUI 임무 흐름으로 연결된 상태는 아닙니다.
- 구현 및 미검증 항목은 [기능 현황](../../SPEC.md)에서 확인합니다.
