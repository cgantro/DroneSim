# DroneSim 실행과 기본 조작

이 안내는 Windows에서 시뮬레이터를 빌드하고 네 대의 드론을 움직여 보는 순서입니다. 현재 장면은 실제 도시 지도가 아니라 코드로 만든 가상 훈련장입니다.

## 실행하기

필요한 환경은 Visual Studio의 C++ 데스크톱 개발 도구와 CMake입니다. 저장소의 외부 라이브러리를 처음 내려받을 때는 인터넷 연결이 필요합니다.

1. Visual Studio에서 DroneSim 저장소 폴더를 엽니다.
2. CMake 구성으로 `ninja-release`를 선택하고 구성이 끝날 때까지 기다립니다.
3. 시작 대상에서 `aerosimlab_simulator`를 선택하고 실행합니다.
4. 창에 장면, 카메라, 비행 상태가 표시되는지 확인합니다.

첫 실행 때는 의존 라이브러리를 내려받고 빌드하므로 시간이 걸릴 수 있습니다. 구성이나 실행에 실패하면 [문제 해결 기록](문제해결.md)을 살펴보세요.

## 화면 보기

- **장면** 패널은 훈련장과 드론을 보여 줍니다.
- **카메라** 패널은 선택된 주 드론에 달린 EO 카메라 화면을 보여 줍니다.
- **비행 상태** 패널은 비행 모드, 위치, 모의 시간과 편대 상태를 보여 줍니다.
- 패널 제목을 끌어 창 안에서 옮길 수 있고, 경계를 끌어 크기를 바꿀 수 있습니다.

산업시설과 자연물은 GLB 에셋으로 표시하고, 코드로 만든 지형과 장애물 형상을 충돌 계산에 사용합니다. 실제 송파구나 다른 도시의 정확한 배치·높이를 재현한 장면은 아닙니다.

## 드론 움직이기

표준 게임패드를 연결한 뒤 시뮬레이터를 실행합니다.

| 입력 | 동작 |
| --- | --- |
| A 버튼 | 이륙 |
| B 버튼 | 착륙 |
| 왼쪽 스틱 | 앞·뒤·좌·우 이동 |
| 오른쪽 스틱 가로축 | 좌우 회전 |
| 왼쪽·오른쪽 트리거 | 하강·상승 |

처음에는 스틱을 조금씩 움직여 반응을 확인하세요. 게임패드가 연결되지 않으면 Windows에서 `Win + R`을 누르고 `joy.cpl`을 실행해 장치와 입력을 확인할 수 있습니다.

비행 상태 패널에서 **편대 대형**을 고르고 **편대 이동 시작**을 누르면 네 대가 함께 출발합니다. 현재는 V자·일렬·횡대를 고를 수 있습니다. 요청한 대형의 경로가 막히면 일렬 경로를 다시 찾습니다. 리더는 추종 드론의 목표를 가상 통신망으로 보냅니다. 이동 중 대형을 자동으로 바꾸는 기능은 아직 없습니다.

## 현재 알아둘 점

- 네이티브 Windows 빌드는 AirSim 강체 물리를 사용합니다. 웹 빌드는 간단한 운동학 계산을 사용하므로 물리 결과가 같지 않습니다.
- 지상통제 프로그램은 시뮬레이터와 별도 실행입니다. 편대 이동에는 거리·건물 가림을 반영한 드론 간 가상 통신망을 사용합니다. GUI에서 링크 장애를 넣거나 통신 방식별 성능을 비교하는 기능은 아직 없습니다.
- 정찰 기능은 등록된 시험 위치를 방문하는 기존 시연입니다. 정찰 지점 자동 탐지나 시설물 파손 판정은 하지 않습니다.
- 최근 전체 자동 시험은 27개 중 26개가 통과했습니다. 남은 실패는 기존 정찰 임무의 촬영 기한·기체 자세·안전거리 검사입니다.

전체 기능 상태는 [기능 명세](../../SPEC.md), 프로젝트 목표는 [GOAL.md](../../GOAL.md)에서 확인할 수 있습니다.
