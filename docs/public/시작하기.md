# 실행과 조작

이 안내는 Windows에서 시뮬레이터를 실행하고 네 대 임무를 확인하는 방법을 설명합니다. 기본 장면은 절차 생성한 약 500m × 400m 가상 훈련장입니다. 실제 지형이나 실제 무선 통신을 재현하지 않습니다.

## 시뮬레이터 실행

1. Visual Studio에서 저장소 폴더를 엽니다.
2. CMake 구성에서 **Ninja Release**를 고릅니다.
3. **빌드 > 모두 빌드**를 실행합니다. 처음 빌드할 때는 외부 라이브러리를 받도록 인터넷 연결이 필요할 수 있습니다.
4. 시작 항목에서 시뮬레이터를 실행합니다. 3D 장면과 비행 상태 패널이 나타나면 실행된 것입니다.

창이 열리지 않으면 Visual Studio의 오류 목록에서 구성·빌드 오류를 확인합니다. 시험으로 확인한 기능은 [구현 현황](../../SPEC.md)에서 볼 수 있습니다.

## 화면 살펴보기

| 화면 | 표시 내용 |
| --- | --- |
| 장면 | 훈련장과 드론, 경로·장애물 |
| 카메라 | 드론별 EO 화면을 두 열로 표시합니다. 화면 크기는 각 카메라 모델의 영상 비율에 맞춥니다. |
| 비행 상태 | 기체별 비행 모드와 위치, 모의 시간, 임무 진행 |
| 통신 상태 | 선택한 통신 방식, 경로와 최근 전달·중계·폐기 수 |

장면·카메라 패널은 제목을 끌어 위치를 옮기고 가장자리를 끌어 크기를 바꿀 수 있습니다. 창 크기에 따라 카메라 화면도 함께 늘거나 줄어듭니다. 통신 방식 선택, 장애 주입, 기록과 다시 보기는 비행 상태 패널에서 다룹니다.

## 게임패드 조작

Xbox 게임패드를 연결한 뒤 프로그램을 실행합니다.

| 입력 | 동작 |
| --- | --- |
| A 버튼 | 이륙 |
| B 버튼 | 착륙 |
| 왼쪽 스틱 | 앞·뒤·좌·우 이동 |
| 오른쪽 스틱 가로축 | 좌우 회전 |
| 왼쪽·오른쪽 트리거 | 하강·상승 |

게임패드가 보이지 않으면 Windows의 **게임 컨트롤러 설정**에서 장치가 인식되는지 먼저 확인합니다. 처음에는 스틱과 트리거를 조금씩 움직여 기체 반응을 살펴봅니다.

## 네 대 임무 실행

1. 모든 드론이 지상에 있는지 확인합니다.
2. 비행 상태 패널에서 **전체 임무 시작 (M01 → M02 → M03)**을 누릅니다.
3. 편대 이동, 지점 정찰, 재집결·복귀가 차례로 진행되는지 확인합니다.

정찰 지점과 확인할 대상은 사람이 정합니다. 드론은 지정된 위치에서 영상과 위치 정보를 모읍니다. 영상 속 대상이나 시설물 파손 여부는 사람이 확인합니다.

## 통신과 기체 장애 시험

가상 통신은 드론과 지상통제소 사이의 직접 연결만 다룹니다. 연결 여부는 거리와 건물 가림으로 계산합니다. 다른 드론을 거치는 중계는 하지 않습니다.

비행 상태 패널에서 시험할 드론을 고른 뒤 **이 드론 통신 차단**을 누르면 그 드론의 송수신이 모두 멈춥니다. 비행은 계속되며 지상통제소에는 마지막으로 받은 위치가 남습니다. **이 드론 통신 복구**를 누르면 새 상태가 다시 도착합니다. 끊긴 동안 보낸 상태를 모아 두었다가 한꺼번에 보내지는 않습니다.

## 네이티브와 웹의 차이

네이티브와 웹은 모두 AirSim 강체 물리를 사용합니다. 실행 환경이 다르므로 수치 결과가 완전히 같다고 볼 수는 없습니다. 웹 빌드와 브라우저 실행의 최신 확인 상태는 [구현 현황](../../SPEC.md)에 적혀 있습니다.
