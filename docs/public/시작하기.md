# AeroSimLab 시작하기

이 안내는 시뮬레이터를 처음 실행하는 사람을 위한 것입니다. AeroSimLab은 실제 드론을 조종하는 프로그램이 아니라, 가상 비행과 지상통제 연동을 시험하는 C++ 프로젝트입니다.

## 화면 프로그램 실행

1. Visual Studio에서 **C++를 사용한 데스크톱 개발**과 CMake 도구를 준비합니다.
2. Windows 환경 변수에 `VCPKG_ROOT`를 추가하고 vcpkg가 설치된 폴더를 지정합니다.
3. Visual Studio에서 프로젝트 폴더를 엽니다.
4. CMake 구성에서 **Ninja Release**를 선택하고 빌드한 다음 시뮬레이터를 실행합니다.
5. 자동 시험은 Visual Studio의 테스트 창에서 실행합니다.

환경 변수 등록 뒤 Visual Studio를 다시 열어야 설정이 적용됩니다. 프로젝트를 열면 필요한 라이브러리를 CMake가 준비합니다.

## 화면 조작

기본 화면은 주변을 보는 장면과 드론에 붙은 카메라 화면으로 나뉩니다. 지상통제 프로그램을 따로 실행하면 이륙·정지·착륙, 경유점 이동, 카메라 켜기·끄기·고장·복구를 시험할 수 있습니다. 기본 통신 포트는 `27015`입니다.

게임패드가 연결되어 있으면 A 버튼으로 이륙하고 B 버튼으로 착륙합니다. 왼쪽 스틱은 이동, 오른쪽 스틱 가로축은 방향 회전, 트리거는 높이 조절에 사용합니다. 실제 기기 연결은 아직 확인하지 않았습니다.

## 시뮬레이션에서 확인할 점

모의는 1초에 60번 같은 간격으로 진행됩니다. 화면이 잠깐 늦어져도 드론 이동 속도가 달라지지 않도록 하기 위한 방식입니다. 현재 드론은 속도와 위치를 단순 계산하며 바람, 모터, 공기 저항은 계산하지 않습니다.

카메라 영상은 화면에서 만든 RGB 픽셀을 메모리에서 처리합니다. OpenCV가 밝기·대비·선명도를 계산하지만, 이 값만으로 실제 영상 품질이나 초점을 판정할 수는 없습니다. 영상 파일 저장과 AI 추론은 아직 구현하지 않았습니다.
