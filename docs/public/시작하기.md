# AeroSimLab 처음 실행하기

AeroSimLab은 가상 드론의 움직임과 카메라 화면, 지상통제 명령을 시험하는 프로그램입니다. 실제 드론을 조종하거나 실제 비행의 안전성을 보증하지 않습니다.

## 실행 준비

현재는 설치 프로그램 대신 Visual Studio에서 직접 빌드해 실행합니다. Windows용 C++와 CMake 개발 기능을 설치하고, vcpkg와 C++20을 지원하는 컴파일러를 준비해 주세요. 처음 빌드할 때는 외부 라이브러리를 받기 위해 인터넷이 필요합니다.

1. Visual Studio에서 프로젝트 폴더를 엽니다.
2. CMake 구성이 끝날 때까지 기다립니다. 처음에는 의존성 설치 때문에 시간이 걸릴 수 있습니다.
3. 실행 대상에서 그래픽 시뮬레이터를 골라 시작합니다.
4. 지상통제 창을 함께 사용하려면 실행 대상에서 지상통제 프로그램을 골라 시작합니다.

두 프로그램은 같은 컴퓨터에서 기본 UDP 포트 27015로 통신합니다. Visual Studio 실행 설정에서 작업 폴더를 빌드 결과 폴더로 지정해야 화면 자원을 찾을 수 있습니다.

## 화면과 조작

왼쪽 화면은 장면을 바라보는 시점이고, 오른쪽은 드론에 달린 EO 카메라 시점입니다. 지원되는 게임패드가 연결되면 다음처럼 조작할 수 있습니다.

| 입력 | 동작 |
| --- | --- |
| A 버튼 | 이륙 |
| B 버튼 | 착륙 |
| 왼쪽 스틱 | 앞·뒤·좌·우 이동 |
| 오른쪽 스틱 가로축 | 방향 회전 |
| 양쪽 트리거 | 높이 조절 |

기기마다 버튼 배치가 다를 수 있습니다. Windows에서 게임패드가 보이지 않으면 `Win + R`을 누르고 `joy.cpl`을 입력해 연결 상태를 확인하세요. 게임패드와 지상통제 명령을 동시에 조작하지 마세요.

지상통제 창에서는 이륙·정지·착륙, 목표 위치 입력, 카메라 켜기·끄기, 장애 상태 설정·복구, 입력 기록과 재생을 할 수 있습니다. 창 위쪽에는 연결 상태와 주 드론의 현재 상태·위치가 표시됩니다. 상태는 0.25초마다 자동으로 새로고침됩니다. 입력 기록은 실행 중 메모리에만 보관됩니다.

**드론 추가**를 누르면 주 드론 주변 지면에 새 드론이 생깁니다. 한 번에 최대 8대까지 실행할 수 있고, 아래 목록에서 각 드론의 상태와 위치를 확인할 수 있습니다. 추가한 드론은 현재 따로 조종하거나 임무를 지정할 수 없습니다. 비행 명령은 주 드론에만 전달됩니다.

시뮬레이터 화면 왼쪽 위에는 주 드론의 비행 상태와 위치, 시뮬레이션 시간, 게임패드와 지상통제 입력이 최근에 들어왔는지가 표시됩니다. 편대에 드론을 추가하면 같은 곳에서 각 드론의 상태도 볼 수 있습니다.

## 물리와 지형

- 네이티브 시뮬레이션은 AirSim을 사용해 로터 힘, 모터 지연, 기체 이동과 회전, 충돌 뒤 반응을 계산합니다.
- 지형과 장애물에 닿았는지는 시뮬레이션 장면이 확인해 물리 계산에 전달합니다. 지형은 약 30m 간격의 높이 자료를 사용합니다.
- 산의 높낮이를 화면에서 잘 볼 수 있도록 지형과 주변 물체를 세로로 두 배 크게 그립니다. 비행과 충돌 계산에는 원래 높이를 사용합니다.
- 건물 높이 자료가 없는 곳은 시연을 위해 3m 상자로 표시합니다. 실제 높이가 아닙니다.
- 물리 계수는 공개 자료를 참고했지만 실제 비행 기록과 비교하지 않았습니다.
- WebAssembly와 운동학 시나리오는 단순한 기준 모델을 사용합니다. 이 모델은 모터와 관성, 추력을 계산하지 않습니다.

실행 중 문제가 생기면 [문제 해결 안내](문제해결.md)를, 기술 선택과 측정 결과는 [기술 검토](기술검토.md)를 읽어 주세요.
