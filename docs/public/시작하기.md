# DroneSim 실행과 조작

이 안내는 Windows에서 시뮬레이터를 열고 기본 임무와 통신 장애 조작을 살펴보는 순서입니다. 기능의 전체 구현 상태는 [기능 현황](../../SPEC.md)에서 확인하세요.

## 프로그램 실행

Visual Studio에서 저장소를 열고 CMake 구성 `ninja-release`를 선택합니다. `aerosimlab_simulator` 대상을 빌드하면 `DroneSim.exe`가 만들어집니다. 실행하면 3D 장면과 비행 상태 패널이 나타납니다. 첫 구성에는 의존성 내려받기를 위해 인터넷 연결이 필요할 수 있습니다.

## 화면 살펴보기

- **장면:** 훈련장과 드론 위치를 보여 줍니다.
- **카메라:** 드론별 시점을 표시합니다. 각 영상은 해당 카메라 설정의 가로·세로 비율을 따릅니다.
- **비행 상태:** 모드, 위치, 모의 시간, 임무 진행을 보여 줍니다.
- **통신 상태:** 라우팅 표와 최근 전달된 패킷을 확인할 수 있습니다. 통신 사건은 실행 중 최대 64개까지 보관하며 파일로 저장하지 않습니다.

장면이나 카메라 창의 제목을 끌면 위치를 바꿀 수 있고, 창 경계를 끌면 크기를 조절할 수 있습니다. Viewer 시작 시험은 창이 열리는지만 확인하므로 실제 화면 배치와 영상 비율은 프로그램에서 살펴봐야 합니다.

## 게임패드 사용

게임패드를 연결한 뒤 프로그램을 실행합니다.

| 조작 | 동작 |
| --- | --- |
| A 버튼 | 이륙 |
| B 버튼 | 착륙 |
| 왼쪽 스틱 | 앞·뒤·좌·우 이동 |
| 오른쪽 스틱 가로축 | 좌우 회전 |
| 왼쪽·오른쪽 트리거 | 하강·상승 |

Windows에서 `Win + R`을 누르고 `joy.cpl`을 입력하면 운영체제가 게임패드를 인식하는지 확인할 수 있습니다. 처음 조작할 때는 스틱과 트리거를 조금씩 움직여 반응을 살펴보세요.

## 전체 임무 실행

모든 드론이 지상에 있을 때 비행 상태 패널의 **전체 임무 시작 (M01 → M02 → M03)**을 누릅니다. 편대 이동, 지점 분담 정찰, 재집결과 복귀 순서로 진행합니다. 정찰 지점은 사람이 정하며, 드론은 해당 지점의 영상과 위치 정보를 확보합니다. 파손 여부는 사람이 영상으로 판단합니다.

경로 확인 응답이 오지 않으면 60 Tick 간격으로 최대 10회까지 다시 보냅니다. 이 재전송 동작은 통신망 시험으로 확인했습니다. 장애를 주입한 상태에서 GUI 임무가 처음부터 끝까지 복구되는지는 아직 확인하지 않았습니다.

## 조종 입력과 EO 영상 기록

비행 상태 패널에서 **기록과 다시 보기**를 펼칩니다.

- **조종 입력 기록 시작:** 모든 드론이 지상에 있고 임무가 없을 때 주 드론의 조종 입력을 기록합니다. 기록을 마치면 같은 패널에서 처음부터 재생할 수 있습니다. 이 기록은 현재 실행 중 메모리에만 남으므로 프로그램을 닫으면 사라집니다.
- **EO 영상 녹화 시작:** 카메라가 켜져 있고 자동 임무가 실행 중이 아닐 때 수동 녹화를 시작합니다. 같은 패널에서 녹화를 마칩니다. 정찰 임무가 시작한 자동 녹화는 임무가 직접 마무리합니다.

영상은 저장소 안의 `output/recordings`에 MP4로 저장합니다. 같은 이름의 JSONL 파일에는 촬영 시각과 카메라 정보를, 목록 파일에는 저장 프레임 수와 파일 확인값을 기록합니다. GUI에서 저장된 영상을 지상통제 화면으로 전달하고 확인하는 기능은 아직 연결하지 않았습니다.

## 통신 장애 조작

편대 이동 또는 전체 임무가 진행 중일 때 **통신 장애 시험** 영역을 사용합니다.

1. **패킷 손실률**을 0보다 높여 일부 메시지를 버립니다.
2. 송신 드론과 상대 드론을 고릅니다.
3. **링크 끊기**로 두 드론 사이 경로를 막거나 **선택 드론 송수신 차단**으로 한 드론의 통신을 멈춥니다.
4. 통신 사건과 경로 정보를 살펴봅니다.
5. **링크 복구** 또는 **선택 드론 라디오 복구**를 누르고 패킷 손실률을 0으로 돌립니다.

같은 임무에서 장애 조작 순서를 남기려면 **기록과 다시 보기**의 **장애 기록 시작**을 누른 뒤, 패킷 손실률·링크·라디오를 조작하고 **장애 기록 저장**을 누릅니다. 기록은 프로그램 실행 파일 옆 `output/scenarios/fault-timeline.json`에 저장됩니다. 다시 적용할 때는 기록 당시와 같은 임무 종류와 드론 구성으로 임무를 먼저 시작한 다음 **저장한 장애 다시 적용**을 누릅니다. 저장한 각 조작은 기록된 Tick 간격에 맞춰 적용됩니다.

이 기능은 장애 조작만 저장합니다. 임무 경로와 조종 입력, 시작 상태까지 함께 저장해 임무 전체를 똑같이 재현하지는 않습니다. 프로그램을 닫아도 파일은 남지만, 다른 드론 구성이나 임무 종류에서는 재생할 수 없습니다.

이 기능은 거리, 건물 가림, 설정한 지연과 손실을 이용하는 가상 통신입니다. 실제 전파나 무선 장비는 시험하지 않습니다. 자동 통합 시험은 리더 장애 뒤 대체 리더를 지정하고 정찰 지점을 재배정하는 흐름을 확인합니다. 응답할 드론이 없으면 비행 중인 편대에 착륙 명령을 내리는 것도 확인했습니다. GUI 버튼 조작과 실제 착륙 완료까지 포함한 전체 임무 시연은 아직 확인하지 않았습니다.

## 네이티브와 웹의 차이

- Windows 네이티브는 AirSim 강체 물리를 사용합니다.
- 웹은 단순화한 운동학 계산을 사용합니다.
- 두 환경은 서로 다른 비행 계산을 사용하므로 결과를 같은 물리 모델로 비교할 수 없습니다.
