# 처음 실행하고 조작하기

이 안내는 Visual Studio로 AeroSimLab을 실행하는 순서를 설명합니다. 프로그램은 가상 드론을 계산하고 화면에 그립니다. 실제 비행이나 실제 조종기 연결을 확인하는 도구는 아닙니다.

## 실행 준비

다음 환경이 필요합니다.

- Windows와 Visual Studio
- Visual Studio 설치 항목의 **C++를 사용한 데스크톱 개발**과 CMake 도구
- vcpkg 설치 위치를 가리키는 `VCPKG_ROOT` 환경 변수
- 처음 구성할 때 필요한 인터넷 연결

`VCPKG_ROOT`에는 vcpkg의 최상위 폴더를 지정합니다. Visual Studio를 연 뒤 프로젝트 폴더를 열고, CMake 구성 목록에서 **Ninja Release**를 선택합니다. 구성이 끝나면 시작 항목으로 **aerosimlab_simulator**를 골라 실행합니다. 첫 구성은 필요한 라이브러리를 받느라 시간이 걸릴 수 있습니다.

## 화면 조작

화면 왼쪽은 드론 주변을 보여 주고, 오른쪽은 드론에 달린 카메라가 보는 장면을 보여 줍니다. 지원되는 게임패드가 연결되어 있으면 다음처럼 조작할 수 있습니다.

| 입력 | 동작 |
| --- | --- |
| A 버튼 | 이륙 |
| B 버튼 | 착륙 |
| 왼쪽 스틱 | 앞·뒤·좌·우 이동 |
| 오른쪽 스틱 가로축 | 방향 회전 |
| 왼쪽·오른쪽 트리거 | 높이 낮추기·높이 올리기 |

지상통제 창을 사용하려면 시뮬레이터와 지상통제 프로그램을 함께 실행합니다. 두 프로그램은 기본적으로 UDP 포트 `27015`로 통신합니다. 게임패드와 지상통제 창을 동시에 조종 입력으로 쓰지는 않습니다.

## 모의가 표현하는 것

비행 계산은 초당 60번 고정된 간격으로 진행합니다. 화면 그리기가 늦어져도 이 계산 간격은 그대로 유지합니다. 현재 드론은 속도와 위치를 바탕으로 움직이며, 바람·모터·공기 저항은 계산하지 않습니다.

카메라 화면은 프로그램이 만든 RGB 픽셀입니다. 밝기·대비·선명도 값은 화면을 단순하게 요약한 숫자이며, 실제 영상의 초점이나 품질을 판정하지 않습니다. 실제 카메라 영상 파일 입력과 저장, AI 분석은 아직 지원하지 않습니다.

## 실행이 안 될 때

- 구성이 실패하면 Visual Studio의 CMake 출력에서 처음 나온 오류를 확인합니다. `VCPKG_ROOT`가 vcpkg 폴더를 가리키는지 확인한 뒤 Visual Studio를 다시 엽니다.
- 화면 창이 바로 닫히면 Visual Studio의 출력 창에서 오류 내용을 확인합니다.
- 지상통제 명령에 응답이 없으면 두 프로그램이 실행 중인지, 같은 UDP 포트 `27015`를 사용 중인지 확인합니다.
- 게임패드가 반응하지 않으면 게임패드가 Windows에서 인식되는지 확인하고 시뮬레이터를 다시 실행합니다. 실제 게임패드 조합은 모두 검증된 것이 아닙니다.
