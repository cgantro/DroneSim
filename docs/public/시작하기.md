# DroneSim 실행과 조작

이 안내는 Windows에서 시뮬레이터를 실행하고 네 대 임무와 통신 장애를 살펴보는 순서입니다. 기본 장면은 약 500m × 400m의 가상 훈련장입니다. 실제 탄천이나 실제 무선 통신을 재현하지 않습니다.

## 프로그램 열기

1. Visual Studio에서 프로젝트 폴더를 엽니다. 처음 열면 CMake가 구성을 마칠 때까지 기다립니다.
2. 상단의 CMake 구성에서 **Ninja Release**를 선택합니다.
3. **빌드 > 모두 빌드**를 선택합니다. 처음 빌드할 때는 라이브러리를 받기 위해 인터넷 연결이 필요할 수 있습니다.
4. 시작 항목에서 시뮬레이터를 선택하고 실행합니다. 3D 장면과 비행 상태 패널이 나타나면 준비가 끝난 것입니다.

화면이 열리지 않으면 먼저 Visual Studio의 오류 목록에서 CMake 구성이나 빌드 오류를 확인하세요. 기능 상태와 자동 시험 범위는 [현재 구현과 시험 상태](../../SPEC.md)에 정리했습니다.

## 화면과 조종

| 화면 | 확인할 내용 |
| --- | --- |
| 장면 | 훈련장 안의 드론과 주변 지형·장애물 |
| 카메라 | 선택한 드론에 장착된 카메라 시점 |
| 비행 상태 | 비행 모드, 위치, 모의 시간, 임무 진행 |
| 통신 상태 | 라우팅 표와 최근 전달된 패킷 |

장면이나 카메라 패널의 제목을 끌어 위치를 바꾸고, 가장자리를 끌어 크기를 조절할 수 있습니다. 통신 상태에는 최근 사건 일부가 표시됩니다. 상세한 장애 조작 순서는 기록 기능으로 파일에 남길 수 있습니다.

Xbox 게임패드를 연결한 뒤 프로그램을 실행합니다.

| 입력 | 동작 |
| --- | --- |
| A 버튼 | 이륙 |
| B 버튼 | 착륙 |
| 왼쪽 스틱 | 앞·뒤·좌·우 이동 |
| 오른쪽 스틱 가로축 | 좌우 회전 |
| 왼쪽·오른쪽 트리거 | 하강·상승 |

게임패드가 인식되지 않으면 Windows 검색에서 **게임 컨트롤러 설정**을 열어 운영체제가 장치를 찾는지 먼저 확인하세요. 처음에는 스틱과 트리거를 조금씩 움직여 반응을 살펴보세요.

## 대표 임무 실행

1. 모든 드론이 지상에 있는지 확인합니다.
2. 비행 상태 패널에서 **전체 임무 시작 (M01 → M02 → M03)**을 누릅니다.
3. M01 편대 이동, M02 정찰 지점 분담, M03 재집결·복귀 순으로 진행되는지 확인합니다.

정찰 지점과 확인할 대상은 사람이 지정합니다. 드론은 해당 위치에서 영상과 위치 정보를 모읍니다. 영상에 대상이 제대로 담겼는지, 시설물이 파손됐는지는 사람이 확인합니다.

자동 시험에서는 정상 조건에서 네 대가 세 단계를 마치고 착륙하는 흐름을 확인했습니다. 실제 창에서 모든 카메라 영상과 화면 배치를 확인한 것은 아니며, 통신 장애를 넣은 전체 임무도 아직 검증하지 않았습니다.

## 영상과 기록

비행 상태 패널의 **기록과 다시 보기**에서 조종 입력 기록과 EO 영상 녹화를 시작하거나 끝냅니다. 조종 입력 기록은 현재 실행 중 메모리에만 남아 프로그램을 닫으면 사라집니다. EO 영상은 MP4로 저장되며 촬영 시각과 카메라 정보도 함께 기록합니다.

영상과 관련 정보는 프로젝트 안의 `output/recordings` 폴더에 저장됩니다. 녹화 영상이 지상통제 화면으로 전송되는 기능은 아직 연결되지 않았습니다.

## 통신·카메라 장애 시험

비행 상태 패널에서 임무를 시작하기 전에 통신 방식을 고릅니다. 네 방식 모두 같은 가상 통신망을 사용하지만 경로를 고르고 장애에 반응하는 규칙이 다릅니다.

| 방식 | 메시지 전달 |
| --- | --- |
| 직접 통신 | 송신 드론과 목적 드론이 직접 연결될 때 전달합니다. |
| 리더 경유 | 메시지를 현재 리더를 거쳐 전달합니다. |
| 고정 다중 홉 | 처음 찾은 여러 드론 경로를 사용하고, 경로가 끊겨도 다른 길을 찾지 않습니다. |
| 장애 적응 다중 홉 | 경로가 끊기거나 만료되면 다른 경로를 찾습니다. |

**통신 장애 시험** 영역에서 패킷 손실률과 지연 흔들림을 조절하고, 두 드론 사이 링크나 선택 드론의 라디오를 끊을 수 있습니다. 링크는 양방향 또는 한 방향만 막을 수 있습니다. 선택 드론의 카메라 고장 주입·복구도 할 수 있습니다.

장애 조작 순서를 남기려면 **기록과 다시 보기**에서 장애 기록을 시작하고 조작을 마친 뒤 저장합니다. 저장한 기록을 다시 적용할 때는 같은 임무 종류와 드론 구성으로 임무를 시작한 다음 재생을 누릅니다. 재생 기록에는 장애 조작만 들어갑니다. 임무 경로·조종 입력·초기 상태까지 포함한 전체 실행 재현은 지원하지 않습니다.

장애를 넣은 전체 임무에서 복구와 착륙까지 이어지는지는 아직 확인하지 않았습니다. 네 통신 방식의 성능을 같은 조건에서 자동으로 비교하는 화면도 없습니다. 현재 시험 범위는 [현재 구현과 시험 상태](../../SPEC.md), 통신망의 계산 방식은 [기술 구조](기술구조.md)에서 확인하세요.

## 네이티브와 웹의 차이

Windows 네이티브는 AirSim 강체 물리를, 웹은 단순화한 운동학 계산을 사용합니다. 비행 모델이 다르므로 두 환경의 움직임을 같은 물리 결과로 비교할 수 없습니다.
