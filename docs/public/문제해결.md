# 주요 문제 해결 기록

실제 동작을 추적하고 다시 확인한 큰 문제만 정리했습니다. 각 글은 증상, 처음 세운 가설, 확인 과정, 수정과 남은 한계를 설명합니다. 간단한 빌드 오류나 설정 실수는 따로 보관하지 않습니다.

- [EO 카메라 화면에서 간헐적으로 프레임이 멈춘 문제](문제해결/화면-프레임-지연.md): 비동기 픽셀 읽기 적용 뒤에도 긴 프레임이 남은 이유와 CPU 표본 기록
- [기체가 기울어도 EO 영상의 위쪽이 고정된 문제](문제해결/카메라-기울기-반영.md): 탑재 위치와 시선·위쪽 방향 반영
- [기록 재생 뒤 EO 화면이 갱신되지 않던 문제](문제해결/카메라-재생-프레임.md): GPU 읽기 대기열과 Tick 초기화 순서
