# 주요 문제 해결 기록

각 문서는 한 가지 주요 문제의 증상, 원인 확인, 수정과 재검증을 다룹니다. 당시 코드와 환경에서 벌어진 일이라 현재 기능의 상태를 뜻하지는 않습니다. 탄천 지형과 이전 임무 목표에 관한 기록도 과거 사례로 보관합니다. 지금 구현된 기능과 시험 결과는 [현재 구현과 시험 상태](../../SPEC.md), 성능 시험의 목적과 적용 범위는 [성능 검증](성능검증.md)에서 확인하세요.
