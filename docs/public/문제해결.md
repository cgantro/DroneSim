# 사용 중 문제가 생기면

아래 순서로 확인해 보세요. 문제가 계속되면 어떤 화면에서, 어떤 조작 직후에 생겼는지 알려주면 원인을 찾기 쉽습니다.

## 프로그램이 열리지 않아요

- Visual Studio에서 저장소 폴더를 열고 CMake 구성이 끝났는지 확인합니다.
- 처음 빌드하는 중이라면 인터넷 연결과 vcpkg 설정을 확인합니다. 외부 라이브러리를 내려받을 때 네트워크가 필요합니다.
- Visual Studio의 출력 창에서 처음 나타난 오류를 확인합니다. 마지막 오류만 보면 원인을 놓칠 수 있습니다.

## 화면이 검거나 비어 있어요

- 그래픽 드라이버가 OpenGL 3.3을 지원하는지 확인합니다.
- 프로그램을 다시 실행하고 Visual Studio 출력 창에 화면 자원이나 그래픽 초기화 오류가 있는지 봅니다.
- 자동 시작 확인은 창이 열리는지 점검합니다. 장면과 조작이 모두 정상인지 확인하는 시험은 아닙니다.

## Xbox 게임패드가 반응하지 않아요

1. `Win + R`을 누르고 `joy.cpl`을 입력합니다.
2. 게임패드가 목록에 있는지 확인하고, 속성 화면에서 버튼과 스틱 값이 바뀌는지 봅니다.
3. 목록에 없으면 USB 케이블과 포트를 바꿔 봅니다. 충전만 되는 케이블은 입력을 전달하지 못할 수 있습니다.
4. 연결되면 창 제목이 `게임패드 연결됨`으로 바뀝니다. `게임패드 형식 미지원`과 장치 이름이 보이면 창은 장치를 찾았지만 버튼 배치를 모르는 상태입니다. 제목이 계속 `드론 관찰 · EO 영상`이면 창이 장치를 찾지 못한 상태이므로, 게임패드를 먼저 연결한 뒤 시뮬레이터를 다시 실행해 보세요.

지상통제 명령을 처리하거나 입력 기록을 재생하는 동안에는 게임패드 조작이 잠시 멈춥니다. 기본 버튼은 A로 이륙하고 B로 착륙합니다.

## 지상통제 명령에 응답이 없어요

- 시뮬레이터와 지상통제 프로그램을 모두 실행했는지 확인합니다.
- 두 프로그램의 주소와 포트가 같은지 확인합니다. 기본 연결은 이 컴퓨터 안에서 UDP 27015번 포트를 사용합니다.
- 방화벽이나 다른 프로그램이 해당 포트를 막거나 사용 중인지 확인합니다.
- 응답 대기 시간이 끝나도 명령이 적용됐을 수 있습니다. 드론 상태를 확인한 다음 명령을 다시 보냅니다.

## 명령이 거부돼요

- 이륙은 지상에서, 이동·회전·착륙은 비행 중에 사용할 수 있습니다.
- 위치와 속도는 미터와 초 단위입니다. 회전 속도는 라디안/초 단위입니다.
- 속도는 초당 5m, 회전 속도는 초당 1.5라디안까지입니다.
- 지상통제 프로그램을 두 개 함께 쓰면 명령 번호가 겹칠 수 있습니다. 한 번에 하나만 사용해 보세요.

## 카메라나 시나리오 결과가 이상해요

- 카메라 장애는 복구 동작을 보내야 해제됩니다. 카메라를 켜는 동작만으로 장애가 풀리지는 않습니다.
- 시나리오 결과에서 `issues`는 실패 이유, `events`는 실행 중 일어난 일을 보여 줍니다.
- 결과의 통과 여부가 거짓이면 기대한 상태와 실제 마지막 상태를 비교해 보세요.

## 지형이나 건물에 닿는 결과가 이상해요

- 북한산 높이 자료는 약 30m 간격이라 좁은 경사와 작은 시설을 정확하게 나타내지 못합니다.
- OpenStreetMap 건물에는 높이 정보가 없어, 현재 화면과 충돌 계산에서 3m 상자를 시연용으로 씁니다. 실제 건물 높이가 아닙니다.
- 화면에 보이는 형상과 충돌에 쓰는 단순 모양은 다를 수 있습니다. 실제 비행 안전성을 확인하는 용도로 사용할 수 없습니다.

현재 동작과 확인하지 않은 기능은 [프로젝트 명세](../../SPEC.md)에서 확인할 수 있습니다.
