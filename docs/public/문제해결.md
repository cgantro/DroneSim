# 주요 문제 해결 기록

실제 동작을 추적하고 다시 확인한 주요 문제를 모았습니다. 각 기록은 증상, 확인 과정, 수정과 검증 결과를 설명합니다. 과거 시험과 현재 자동 시험의 범위도 구분했습니다. 근거가 남지 않은 추측은 싣지 않았으며, 단순 빌드 오류와 설정 실수는 별도로 기록하지 않았습니다.
