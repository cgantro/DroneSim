# 주요 문제 해결 기록

실제 동작을 추적하고 다시 확인한 주요 문제를 정리했습니다. 각 글은 증상과 확인 과정을 따라가며, 당시 가설이 기록된 경우에는 그 판단도 함께 설명합니다. 현재 코드가 하는 일과 과거에 확인했던 시험, 지금 남아 있는 자동 시험의 범위를 구분합니다. 자료가 남지 않은 생각이나 시행착오는 덧붙이지 않았고, 간단한 빌드 오류나 설정 실수는 별도 기록으로 만들지 않습니다.
