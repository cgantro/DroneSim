# 주요 문제 해결 기록

이 색인은 과거에 확인한 주요 문제와 수정 과정을 모읍니다. 각 글은 그 당시의 증상, 원인 확인, 수정과 시험 결과를 설명합니다. 현재 코드에서도 같은 문제가 발생한다는 뜻은 아니므로, 지금 기능 상태는 [기능 현황](../../SPEC.md)에서 확인하세요. 단순 빌드·설정 실수는 별도 기록으로 늘리지 않았습니다.
