# 문제 해결 기록

각 글은 당시 확인한 문제와 수정 과정을 설명합니다. 현재 동작 여부는 [구현 현황과 시험 범위](../../SPEC.md)에서 확인하세요. 성능 시험의 목적과 방법은 [성능 검증](성능검증.md)에 정리했습니다.
