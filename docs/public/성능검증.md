# 성능 시험

성능 시험은 편대 임무가 정해진 시간 안에 끝나는지, 통신 장애를 얼마나 빨리 복구하는지, 드론 수가 늘 때 계산량이 얼마나 커지는지 확인합니다. 기능 시험 통과만으로 성능이 좋아졌다고 판단하지 않습니다.

## 측정 항목

| 확인할 내용 | 기록할 값 |
| --- | --- |
| 임무 완료와 비행 안전 | 완료 여부·시간, 경로 이탈, 최소 기체 간격, 안전 중단 횟수 |
| 통신 장애 | 전달률, 지연, 직접 연결 단절 감지, 상태 갱신 중단과 복구 시간 |
| 계산량 | 고정 주기 계산 시간 p50·p95·p99, 주기 초과 횟수, 메모리 사용량 |
| EO 화면 | 카메라 영상 생성·화면 갱신 시간과 프레임 누락 수 |

## 비교 방법

비교할 때는 같은 빌드 종류, 장면, 임무 경로, 초기 상태, 장애 조건과 난수 시드를 사용합니다. 준비 실행은 측정에서 빼고, 각 조건을 여러 번 반복합니다. 드론 수나 통신 방식처럼 비교하려는 조건 하나만 바꿉니다.

화면을 그리는 시험과 화면을 끈 계산 시험은 측정 대상이 다르므로 서로 비교하지 않습니다. CPU 처리 시간, GPU 처리 시간, 모의 시간도 각각 구분해 기록합니다.

## 현재 기준선

새 군집 임무를 기준으로 한 성능 측정은 아직 없습니다. 이전 개발 단계의 벤치마크 원자료와 임시 실행 기록은 저장소 정리 과정에서 삭제했습니다. 새 결과는 이 문서의 조건에 맞춰 측정한 뒤에만 기준선으로 기록합니다.
