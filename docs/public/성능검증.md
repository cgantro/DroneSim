# 성능 시험 안내

이 문서는 현재 시뮬레이터의 성능을 확인할 때 무엇을 재고, 결과를 어떻게 읽을지 설명합니다. 현재 물리 구현으로 같은 조건에서 측정한 기준값은 아직 없습니다.

## 확인할 항목

| 목적 | 기록할 값 |
| --- | --- |
| 정해진 시간 안에 모의를 갱신하는지 확인 | 고정 Tick 처리 시간의 p50·p95·p99, 16.67ms 초과 횟수 |
| 드론 수가 늘 때 계산량이 어떻게 바뀌는지 확인 | 드론 수별 Tick 처리 시간과 메모리 사용량 |
| 임무가 끝까지 수행되는지 확인 | 완료 여부, 걸린 모의 시간, 최소 기체 간격 |
| 화면이 끊기지 않는지 확인 | 실제 창의 프레임 시간과 측정 FPS |

p50은 측정값의 가운데입니다. p95와 p99는 각각 표본의 95%, 99%가 그 시간 안에 끝났다는 뜻입니다. 평균만 보면 드물게 길어지는 프레임을 놓칠 수 있어 분포와 최대값도 함께 기록합니다.

## 비교할 때 맞출 조건

변경 전후를 비교하려면 실행 파일 종류, 컴퓨터, 장면, 드론 수, 임무, 시작 상태, 측정 시간과 반복 횟수를 같게 둡니다. 결과에는 코드 리비전과 시험 입력도 함께 남깁니다. 조건이 다르면 숫자를 나란히 놓더라도 성능 개선율로 해석하지 않습니다.

Tick 처리 시간은 시뮬레이션 한 번을 계산하는 데 걸린 시간입니다. 화면 프레임 시간이나 GPU가 실제로 작업한 시간과는 다릅니다. 화면을 숨긴 측정 결과도 사용자가 보는 화면의 부드러움을 대신하지 않습니다.

## 현재 상태

현재 구현의 성능 기준값은 새 조건으로 측정해야 합니다. 과거 물리 구현에서 얻은 숫자는 지금 코드의 기준선으로 사용하지 않습니다. 새 측정 결과를 기록할 때는 목적, 실행 조건, 반복 횟수와 결과를 함께 적습니다.
