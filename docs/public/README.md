## 문서를 읽을 때

- 개발 목표는 앞으로 확인할 결과를 설명합니다. 현재 기능은 [기능 현황](../../SPEC.md)에서 확인하세요.
- 기술 구조는 현재 코드의 흐름을 설명합니다. 세부 기능이 아직 통합되지 않았을 수 있으니 기능 현황과 함께 읽으세요.
- 성능 측정과 문제 해결 기록은 작성 당시의 코드·환경·시험 결과입니다. 지금도 같은 결과가 난다는 뜻은 아닙니다.
- 시험하지 않은 GUI 흐름이나 성능 수치는 검증된 것으로 취급하지 않습니다.
