# 문서 안내

처음 사용하는 경우 [실행과 조작](시작하기.md)부터 읽으세요. 나머지 문서는 각자 다른 질문에 답합니다.

| 찾는 내용 | 안내 |
| --- | --- |
| 지금 되는 기능과 남은 작업 | [기능과 진행 상태](../../SPEC.md) |
| 프로그램 구성, 비행 계산, 통신 흐름, 기술 선택 이유 | [기술 구조](기술구조.md) |
| 성능 시험의 목적과 측정 결과 | [성능 검증](성능검증.md) |
| 재현된 주요 문제와 해결 과정 | [문제 해결 기록](문제해결.md) |
| 프로젝트가 만들 최종 결과 | [프로젝트 목표](../../GOAL.md) |

목표와 기능 현황은 저장소 첫 화면의 [개발 목표](../../GOAL.md)와 [기능 현황](../../SPEC.md)에 있습니다. 여기에는 사용법과 기술 설명, 과거 시험 기록만 둡니다. 과거 기록은 당시 조건을 설명하므로 현재 상태를 대신하지 않습니다.
