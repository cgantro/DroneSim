## 문서를 읽을 때

- 목표에 적힌 내용이 현재 구현됐는지는 기능 현황에서 확인하세요.
- 시험 통과는 표에 적힌 조건까지만 뜻합니다. 사람이 화면에서 확인한 결과와 자동 시험 결과는 따로 표시합니다.
- 문제 해결 글은 작성 당시의 코드와 시험 조건을 기록합니다. 현재도 같은 결과가 난다는 보장은 아닙니다.
- 성능 수치는 시험 환경과 입력이 다르면 서로 직접 비교할 수 없습니다.
