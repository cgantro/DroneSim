# 개발 문서

프로젝트의 첫 안내와 구현 현황은 저장소 첫 화면에서 확인합니다. 이 폴더에는 실행 방법, 코드 흐름, 시험 결과와 과거 문제 해결 기록을 둡니다.

## 실행과 구조

- [실행 안내](시작하기.md): 프로그램을 열고 기본 임무를 살펴봅니다.
- [기술 구조](기술구조.md): 한 번의 시뮬레이션 단계와 비행·통신·화면의 연결을 설명합니다.

## 시험과 문제 해결

- [성능 검증](성능검증.md): 측정 목적, 조건, 결과와 해석 범위를 설명합니다.
- [문제 해결 기록](문제해결.md): 주요 문제별 증거와 수정 과정을 찾아봅니다.
- [측정 원자료 안내](../../benchmarks/results/README.md): 실행별 성능 자료를 찾습니다.

앞으로 만들 목표와 현재 구현 상태는 저장소 첫 화면의 안내에서 각각 확인하세요. 예전 문제 해결 기록은 당시 상황을 설명하며, 지금도 같은 문제가 있는지는 현재 기능 현황과 코드 시험으로 판단합니다.
