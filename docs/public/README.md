# 문서 읽는 순서

DroneSim 문서는 프로젝트의 목표, 지금 되는 기능, 실행 방법, 동작 원리와 과거 확인 기록으로 나뉩니다. 현재 상태를 먼저 확인한 뒤 필요한 안내를 읽으면 됩니다.

## 처음 보는 분

1. [프로젝트 소개](../../README.md)에서 DroneSim의 용도와 시험 범위를 확인합니다.
2. [기능 현황](../../SPEC.md)에서 구현된 기능과 아직 확인하지 않은 부분을 봅니다.
3. 직접 실행하려면 [시작 안내](시작하기.md)를 따라갑니다.

## 개발 내용을 확인하려는 분

| 궁금한 내용 | 안내 |
| --- | --- |
| 프로젝트가 최종적으로 확인하려는 것 | [개발 목표](../../GOAL.md) |
| 임무·통신·비행 계산이 이어지는 방식 | [기술 구조](기술구조.md) |
| 과거 측정이 무엇을 확인했고 어디까지 해석할 수 있는지 | [성능 검증 기록](성능검증.md) |
| 과거 주요 오류의 증상·원인·수정·검증 | [문제 해결 기록](문제해결.md) |

## 문서의 기준

- 현재 기능과 시험 결과는 기능 현황을 기준으로 확인합니다.
- 개발 목표는 앞으로 완성할 결과를 설명합니다. 목표를 현재 구현으로 간주하지 않습니다.
- 성능 검증과 문제 해결 문서는 과거 코드와 시험 환경의 기록입니다. 현재 버전의 동작을 보장하는 안내가 아닙니다.
- 실행 절차는 시작 안내 한 곳에서 관리합니다. 다른 문서에서는 같은 절차를 반복하지 않고 이곳으로 연결합니다.
