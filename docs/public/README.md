# 문서 안내

필요한 내용부터 찾아볼 수 있게 문서를 목적별로 모았습니다. 프로젝트를 처음 보거나 지금 어디까지 구현됐는지 궁금하면 저장소 첫 화면의 [DroneSim 안내](../../README.md)부터 읽으세요.

## 프로그램을 실행하려면

[실행 안내](시작하기.md)에서 Windows 실행 순서, 화면 구성, 게임패드 조작과 통신 장애 시험 방법을 확인하세요.

## 프로젝트가 어떻게 동작하는지 보려면

[개발 목표](../../GOAL.md)는 만들려는 결과와 제외 범위를 설명합니다. [기술 구조](기술구조.md)는 임무·통신·비행 계산이 이어지는 방식과 좌표 기준을 설명합니다.

## 구현 상태와 시험 근거를 확인하려면

[기능과 시험 결과](../../SPEC.md)에서 동작이 확인된 범위와 남은 일을 보세요. [성능 검증](성능검증.md)에는 측정 목적·조건·해석을, [측정 자료 안내](../../benchmarks/results/README.md)에는 실행별 원자료를 정리했습니다.

## 과거 문제의 원인과 해결을 찾으려면

[문제 해결 기록](문제해결.md)에서 화면, 비행·충돌, 통신, 시험 문제를 주제별로 찾을 수 있습니다. 각 기록은 당시 상태를 다루므로 지금 동작하는지는 기능 현황과 최신 시험 결과를 기준으로 판단하세요.
