# 개발 문서 안내

처음 온 독자는 [실행과 기본 조작](시작하기.md)부터 읽으면 됩니다. 이 문서 모음은 프로그램을 이해하고, 시험 결과와 과거 문제를 찾아볼 때 사용합니다.

## 문서 찾아보기

| --- | --- |
