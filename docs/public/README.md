# DroneSim 문서 안내

문서는 읽는 목적에 따라 나눴습니다. 프로젝트를 처음 보신다면 저장소 첫 화면의 [DroneSim 안내](../../README.md)부터 읽고, 현재 구현 상태를 [기능 현황](../../SPEC.md)에서 확인하세요.

## 실행하고 싶다면

[실행 안내](시작하기.md)에서 Windows 빌드 구성, 화면 조작, 임무 시작과 통신 장애 조작 순서를 확인할 수 있습니다.

## 설계와 개발 범위를 알고 싶다면

[개발 목표](../../GOAL.md)는 만들려는 결과와 완료 기준을 설명합니다. [기술 구조](기술구조.md)는 지금 코드에서 시뮬레이션·통신·비행 계산이 어떻게 이어지는지 설명합니다. 목표와 현재 구현이 다를 때는 기능 현황을 기준으로 판단하세요.

## 시험 결과를 확인하고 싶다면

[성능 검증](성능검증.md)에는 측정 목적과 조건, 해석을 적었습니다. 실행별 원본은 [측정 결과 안내](../../benchmarks/results/README.md)에서 찾을 수 있습니다. 예전 측정값은 당시 코드와 조건의 결과이며 현재 성능을 뜻하지 않습니다.

## 과거 문제의 원인을 찾고 싶다면

[문제 해결 기록](문제해결.md)에서 화면·카메라, 비행·충돌, 임무·통신 문제를 주제별로 찾아볼 수 있습니다. 각 글은 당시의 조사 기록입니다. 지금도 해결되지 않았는지는 [기능 현황](../../SPEC.md)의 최신 상태를 확인하세요.
