# 문서 안내

읽는 목적에 맞춰 필요한 안내를 골라 보세요. 프로젝트의 목표와 현재 상태는 저장소 첫 화면에서 확인할 수 있습니다.

## 프로그램을 실행하려면

[실행 안내](시작하기.md)에서 프로그램을 여는 방법, 화면 구성과 기본 임무를 확인하세요.

## 코드 흐름을 이해하려면

[기술 구조](기술구조.md)는 한 번의 시뮬레이션 단계에서 임무·통신·비행 계산이 어떻게 이어지는지 설명합니다.

## 시험 결과를 확인하려면

[성능 검증](성능검증.md)에서 무엇을 재고 왜 비교했는지 확인하세요. 실행별 원자료는 [측정 자료 안내](../../benchmarks/results/README.md)에 있습니다.

## 과거 문제를 찾아보려면

[문제 해결 기록](문제해결.md)에서 화면, 비행, 통신, 시험 문제를 주제별로 찾을 수 있습니다. 각 기록은 당시의 코드와 시험 조건을 설명하므로, 현재 동작 여부는 [기능 현황](../../SPEC.md)과 최신 시험 결과를 기준으로 확인하세요.
