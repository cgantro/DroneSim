# 문서 안내

문서는 독자가 하려는 일에 따라 나눴습니다. 지금 되는 기능은 기능 현황에서, 만드는 방법은 시작 안내에서 확인하세요.

| 궁금한 내용 | 읽을 문서 |
| --- | --- |
| 프로그램을 실행하고 조작하는 방법 | [시작하기](시작하기.md) |
| 구현된 기능과 남은 일 | [기능 현황](../../SPEC.md) |
| 프로젝트가 만들려는 결과와 범위 | [개발 목표](../../GOAL.md) |
| 시뮬레이션 흐름과 기술 선택 이유 | [기술 구조](기술구조.md) |
| 성능 측정의 목적·조건·결과 | [성능 검증](성능검증.md) |
| 과거 주요 문제의 원인과 해결 과정 | [문제 해결 기록](문제해결.md) |

기능 현황은 현재 상태를 판단하는 기준입니다. 성능 측정과 문제 해결 기록은 당시 실행 조건을 설명하는 자료이므로 현재 동작을 보증하지 않습니다.
