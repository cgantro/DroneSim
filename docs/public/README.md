## 목표와 현재 상태 구분하기

[개발 목표](../../GOAL.md)는 앞으로 만들 결과와 범위를 설명합니다. [기능 현황](../../SPEC.md)은 현재 코드와 실제 시험에서 확인한 상태를 설명합니다. 목표에 적힌 기능이 이미 구현됐다는 뜻은 아닙니다.

문제 해결 기록과 성능 자료는 작성 당시의 코드와 시험 조건을 담습니다. 지금도 같은 결과가 난다고 단정할 수 없으므로, 현재 상태는 기능 현황에서 확인하세요.
