## 문서의 범위

- 개발 목표는 앞으로 도달할 상태를 설명합니다. 현재 구현 여부는 기능 현황에서 확인하세요.
- 기술 구조는 현재 코드의 데이터 흐름을 설명합니다. 아직 일부 임무에만 적용된 기능은 적용 범위를 함께 적습니다.
- 성능 검증과 문제 해결 기록은 작성 당시의 코드와 실행 조건을 바탕으로 합니다. 현재도 같은 결과가 난다고 보장하지 않습니다.
- 자동 시험, 창 실행, 사람이 직접 화면을 본 결과는 서로 다른 확인 방법입니다. 문서에서 각각 구분합니다.
