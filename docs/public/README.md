## 문서 읽을 때 참고할 점

개발 목표는 만들려는 결과를 설명하며, 구현 완료를 뜻하지 않습니다. 현재 상태는 기능 현황에서 확인하세요. 시험 결과에는 실제 실행한 범위만 적습니다. 문제 해결 기록은 당시 코드와 실행 조건에 관한 기록이므로, 같은 문제가 현재도 발생하는지는 현재 기능 현황과 코드로 확인해야 합니다.
