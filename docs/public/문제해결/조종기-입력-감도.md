# 게임패드 조작이 너무 민감했던 문제

## 증상

사용자가 스틱을 조금 움직여도 드론 속도가 빠르게 바뀌어 조종하기 어렵다고 보고했습니다. 실제 PX4 Position 모드와 비슷한 느낌인지도 질문했습니다.

## 원인

기존 입력 변환은 데드존 밖의 스틱 값을 속도 한도에 거의 바로 대응시켰습니다. 스틱 가운데를 조금 벗어난 입력도 큰 속도 명령으로 이어질 수 있었습니다. 또한 이 조종은 PX4 Position 모드의 가속 입력과 위치 제어를 그대로 실행하는 구조가 아닙니다.

## 수정

스틱 가운데는 세밀하게 반응하고 끝에서는 최대 속도에 도달하도록 입력 곡선을 완만하게 했습니다. 수평 속도는 초당 3m, 상승은 초당 1m, 하강은 초당 1.5m, 회전은 초당 약 45도로 제한했습니다.

## 확인 결과와 한계

스틱 입력 곡선, 속도 상한, 회전 변환을 자동 시험으로 확인했습니다. 실제 Xbox 게임패드를 사용한 감도 검수나 PX4 실기체와의 조작감 비교는 하지 않았습니다. 이 값은 조작을 부드럽게 하기 위한 시뮬레이터 설정이지 PX4 기본값 복제가 아닙니다.
