# 카메라 자세와 기록·재생 시점이 어긋난 문제

## 증상과 의심한 부분

드론이 이동·회전해도 카메라 위치와 자세가 이전 상태에 남을 수 있었습니다. 좌우로 기울여도 영상의 위쪽이 화면에 고정되는 문제도 있었습니다. 녹화나 재생을 시작해 시뮬레이션 Tick이 0으로 돌아간 뒤에는 카메라 프레임이 이전 실행의 Tick에 머물기도 했습니다.

## 원인과 수정

카메라의 시선만 드론 자세를 따라가고 영상의 위쪽 방향은 월드 위쪽을 쓰고 있었습니다. 카메라 위치·시선·위쪽 방향을 모두 드론 자세에서 계산하도록 고쳤습니다. 고정 Tick 뒤, 초기 자세 변경·초기화·주 드론 교체 뒤에도 자세를 다시 맞춥니다.

녹화·재생 문제는 별도 원인이었습니다. 시뮬레이션 Tick은 0으로 돌아갔지만 GPU 픽셀 읽기의 마지막 Tick 번호는 이전 값으로 남았습니다. 새 Tick을 오래된 값과 비교하면서 화면 읽기를 건너뛰었습니다. 세션을 초기화하기 전에 진행 중인 GPU 읽기를 끝내고, 새 실행의 Tick 기준을 초기화하도록 바꿨습니다.

## 확인 결과

운동학·강체 모드의 Tick 진행과 초기화, 자세·위쪽 방향, 재생 중 카메라 Tick을 자동 시험으로 확인합니다. 재생 전후 불일치 시험은 수정 뒤 10회 연속 통과했고, 당시 Release 전체 시험 20개도 통과했습니다. 여러 자세의 실제 화면을 장시간 관찰한 결과는 없습니다.
