# 시뮬레이션과 카메라 자세가 어긋난 문제

## 증상

드론이 이동하거나 회전한 뒤에도 카메라의 위치와 자세가 이전 상태에 남을 수 있었습니다. 초기화하거나 주 드론을 바꾸는 경우에도 카메라가 새 상태를 따라야 했습니다.

## 원인과 수정

카메라의 탑재 위치와 방향을 드론의 현재 자세에서 갱신하는 경로가 분명하지 않았습니다. 고정 Tick이 끝난 뒤, 초기 자세를 바꾼 뒤, 초기화한 뒤, 주 드론을 교체한 뒤 카메라 자세를 다시 맞추도록 했습니다.

## 확인 결과

운동학과 강체 모드에서 Tick 진행·초기 자세 설정·초기화 뒤 카메라 위치와 자세가 주 드론과 일치하는지 자동 시험으로 확인합니다. 사용자 화면에서 장시간 추적한 결과는 따로 없습니다.
