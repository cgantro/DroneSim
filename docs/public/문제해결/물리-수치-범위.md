# 물리 계산에 잘못된 수치가 들어간 문제

## 증상과 위험

강체 물리 엔진은 내부에서 일부 값을 32비트 실수로 받습니다. 입력에 무한대·숫자가 아닌 값·표현 범위를 넘는 값이 있으면 변환 결과가 깨질 수 있습니다. 방향을 나타내는 네 값도 크기가 너무 크면 float 변환 뒤 길이 계산이 넘칠 수 있습니다.

이 문제는 보통 정상 비행에서 나타나는 화면 증상이 아니라, 경계값을 넣는 시험에서 드러난 수치 안정성 문제입니다. 사용자가 보고한 접근 위반의 원인으로 확인된 것은 아닙니다.

## 원인과 수정

검사 전에 값을 float으로 바꾸거나, float으로 바꾼 뒤 방향값을 정규화하면 유한한 큰 값도 무한대로 바뀔 수 있었습니다. 먼저 double 범위에서 값이 유한하고 허용 범위 안인지 확인하도록 했습니다. 방향값은 가장 큰 성분으로 먼저 나눈 다음 정규화해 변환 중 overflow를 막았습니다.

## 확인 결과

유효하지 않은 값, float 범위를 넘는 값, 매우 큰 유한 방향값을 넣는 자동 시험을 추가했습니다. 따라서 확인 범위는 해당 물리 입력 경로의 경계값입니다. 모든 계산이나 장시간 비행에서 수치 안정성을 보장한다는 뜻은 아닙니다.
