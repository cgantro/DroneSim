# 물리 계산에 표현 범위를 벗어난 값이 들어간 문제

## 증상과 위험

강체 물리 엔진은 내부에서 일부 값을 32비트 실수로 받습니다. 무한대·숫자가 아닌 값·표현 범위를 넘는 값을 그대로 보내면 변환 결과가 깨질 수 있습니다. 큰 자세값을 방향으로 바꾸거나 로터 힘을 계산할 때도 입력 범위가 잘못되면 유한하지 않은 수가 나올 수 있습니다.

이 문제는 보통 정상 비행에서 나타나는 화면 증상이 아니라, 경계값을 넣는 시험에서 드러난 수치 안정성 문제입니다. 사용자가 보고한 접근 위반의 원인으로 확인된 것은 아닙니다.

## 확인 과정과 수정

처음에는 입력값이 유한한지만 확인하면 충분하다고 보기 쉽습니다. 하지만 double에서 유한한 큰 값도 float 변환 뒤 무한대가 될 수 있습니다. 방향값은 float 변환 뒤 길이를 구하면 제곱 과정에서 넘칠 수도 있습니다. 입력은 변환 전에 허용 범위까지 확인하고, 방향값은 가장 큰 성분으로 먼저 나눈 다음 정규화하도록 했습니다. 로터 힘 계산도 유효하지 않은 입력과 결과를 경계에서 걸러냅니다.

## 확인 결과

유효하지 않은 값, float 범위를 넘는 값, 매우 큰 유한 방향값과 로터 힘 경계값을 넣는 시험으로 확인했습니다. 이는 해당 입력 경로의 경계값 검사입니다. 모든 계산이나 장시간 비행의 수치 안정성을 보증하지 않으며, 보고된 접근 위반과 연결된다는 증거도 없습니다.
