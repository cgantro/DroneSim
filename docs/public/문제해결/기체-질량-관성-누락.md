# X500 강체 모델에서 로터 질량과 관성이 빠진 문제

## 증상: 기준 비행의 착륙 위치가 달라졌다

같은 입력을 준 강체 비행 시나리오의 마지막 위치가 예상한 기준과 달랐습니다. 당시에는 목표 위치나 모터 응답이 달라졌을 가능성도 있었지만, 제어기부터 조정하면 물리 모델의 오류를 가릴 수 있습니다. 먼저 X500에 넣은 질량과 관성이 모델에 기록된 기체 구성과 맞는지 확인했습니다.

그 결과 시뮬레이션은 X500 전체를 하나의 강체로 계산하면서 가운데 기체의 질량과 관성만 사용하고 있었습니다. 실제 구성에 포함된 네 로터의 질량, 자체 관성, 중심에서 떨어진 위치에 따른 관성이 빠져 있었습니다. 따라서 이 문제는 단순히 총중량이 조금 다른 문제가 아닙니다. 같은 로터 힘에서도 상승 가속도가 달라지고, 같은 회전 토크에서도 자세가 바뀌는 속도가 달라집니다.

## 원인 확인: 부품별 물성을 강체 기준으로 합치지 않았다

공개 X500 설정에서 확인한 값은 중심 기체 질량 2.0kg, 로터 한 개 질량 약 0.01608kg입니다. 네 로터를 더하면 총 질량은 약 2.06431kg입니다. 중심 기체 값만 넣었던 모델에서는 약 0.06431kg, 전체의 약 3.1%가 빠져 있었습니다.

관성도 부품 자체의 관성만 더해서는 끝나지 않습니다. 중심에서 떨어진 부품의 질량은 회전축에서 멀리 분포한 만큼 전체 관성을 키웁니다. 각 로터의 관성을 중심 기체 기준으로 옮길 때 평행축 정리를 적용합니다.

| 항목 | 중심 기체만 사용 | 네 로터를 포함한 합산값 |
| --- | ---: | ---: |
| 질량 | 2.0kg | 약 2.06431kg |
| X축 관성 | 약 0.02167kg·m² | 약 0.02384669kg·m² |
| Y축 관성 | 약 0.02167kg·m² | 약 0.02394962kg·m² |
| Z축 관성 | 약 0.04000kg·m² | 약 0.04399995kg·m² |

계산에는 중심에서 약 0.174m 떨어진 로터 위치와 기준면보다 약 0.06m 높은 위치를 사용했습니다. X축과 Y축 결과가 조금 다른 것은 원본 부품 배치와 링크 관성값을 그대로 합산했기 때문입니다. 이 차이가 실제 기체에서 측정된 비대칭을 뜻하지는 않습니다.

## 수정: 네 로터의 질량과 위치까지 한 강체에 반영

강체 파라미터를 만들 때 중심 기체와 네 로터의 질량·관성을 기체 중심 기준으로 합산하도록 바꿨습니다. 로터 위치의 높이도 0으로 두지 않고 공개 설정에서 확인한 0.06m를 사용합니다. 그 결과 질량, 무게중심을 기준으로 한 관성, 균형 호버에 필요한 추력이 같은 기체 구성을 나타내게 됩니다.

이 계산은 물리 엔진에 전달할 단일 강체의 근사 모델입니다. 로터를 각각 독립된 회전체로 시뮬레이션하지 않으며, 회전자의 자이로 효과도 더하지 않습니다. 배터리, 배선, 탑재 카메라와 추가 장비의 질량도 포함하지 않았습니다.

## 결과와 검증 범위

변경 당시에는 합산 질량·관성·로터 위치를 직접 비교하는 단위 시험과, 같은 초기 조건으로 강체 비행 시나리오를 다시 실행하는 확인을 했습니다. 모델 값이 달라지면서 기준 시나리오의 예상 최종 위치도 함께 갱신했습니다.

기준 위치를 새 결과에 맞춘 것은 회귀 기준을 현재 모델에 맞게 고친 것입니다. 실제 X500의 착륙 오차가 줄었다는 뜻은 아닙니다. 제조사 측정값이나 실기체 비행 기록과 비교하지 않았기 때문입니다.

현재 시험 묶음을 핵심 시나리오 위주로 줄이면서 합산된 질량과 관성을 독립적으로 감시하던 수치 시험은 빠졌습니다. 현재 강체 시험은 모터 응답, 좌표계, 지형·건물 접촉을 확인하지만, 이 페이지에 적은 네 수치가 바뀌지 않았는지는 직접 확인하지 않습니다. 현재 검증 상태를 설명할 때 과거 시험 이력과 지금 남아 있는 회귀 시험을 구분해야 합니다.

## 남은 확인 사항

- 공개 X500 설정이 사용자가 보유한 실물 기체의 부품 구성과 같은지 확인해야 합니다.
- 배터리와 탑재물까지 포함한 실제 질량·무게중심·관성 자료가 생기면 출처와 측정 조건을 함께 기록해야 합니다.
- 질량·관성 수치가 다시 변경될 때는 현재 자동 시험이 이를 감지하지 못한다는 점을 고려해 계산을 별도로 검토해야 합니다.
- 실기체 비행 궤적과 대조하기 전까지 이 모델을 실기체와 일치하는 디지털 트윈이라고 부를 수 없습니다.
