# 강체 질량과 관성에서 로터를 빠뜨린 문제

## 증상

X500 비행 결과가 기준 시나리오에서 예상한 착륙 위치와 달라졌습니다. 기체의 질량과 회전 저항을 계산할 때 실제 구성보다 가벼운 값이 쓰이고 있었습니다.

## 원인과 수정

초기 모델은 가운데 기체의 질량과 관성만 사용하고 네 로터의 질량과 관성은 더하지 않았습니다. 로터의 질량과 배치 위치를 중심 기체 기준으로 옮겨 전체 질량과 관성에 합쳤습니다.

## 확인 결과와 한계

자동 시험은 합산한 질량·관성 값과 균형 로터의 추력을 확인합니다. 기준 비행 시나리오의 예상 결과도 새 모델에 맞게 갱신했습니다. 실제 X500 비행 기록과 비교한 검증은 아닙니다.
