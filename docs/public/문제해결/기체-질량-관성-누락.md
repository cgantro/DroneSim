# 강체 질량과 관성에서 로터를 빠뜨린 문제

## 처음 의심한 부분

X500 비행 결과가 기준 시나리오의 착륙 위치와 달랐습니다. 처음에는 제어 목표나 모터 반응을 의심했지만, 기체가 예상보다 가볍게 계산되고 있음을 확인했습니다.

## 원인과 수정

초기 모델은 가운데 기체만 계산하고 네 로터의 질량과 관성은 더하지 않았습니다. 로터의 질량과 위치가 빠지면 총 질량뿐 아니라 회전 관성도 달라집니다. 각 로터의 값을 기체 중심 기준으로 옮겨 전체 질량과 관성에 합쳤습니다.

## 확인 결과와 한계

자동 시험은 합산한 질량·관성 값과 균형 로터의 추력을 확인합니다. 기준 비행 시나리오의 예상 결과도 새 모델에 맞게 갱신했습니다. 실제 X500 비행 기록과 비교한 검증은 아닙니다.
