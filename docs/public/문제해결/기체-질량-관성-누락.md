# X500 강체 모델에서 로터 질량과 관성이 빠진 문제

## 증상과 확인이 시작된 이유

강체 비행 시나리오의 착륙 위치가 기준 결과와 달랐습니다. 당시에는 제어 목표나 모터 반응이 원인일 수 있다고 보았지만, 그보다 먼저 물리 모델에 넣은 기체 제원이 실제 구성과 맞는지 확인했습니다. 이 과정에서 시뮬레이션은 X500을 하나의 강체로 계산하면서 가운데 기체의 값만 쓰고, 네 로터의 질량과 관성을 합치지 않은 사실을 찾았습니다.

이 문제는 단순히 기체가 몇십 그램 가벼운 데서 끝나지 않습니다. 질량은 같은 추력에서 상승 가속도를 바꾸고, 관성은 같은 토크에서 기체가 회전하는 정도를 바꿉니다. 따라서 이륙·이동·착륙 궤적의 차이가 제어기 설정 때문인지 물리 제원 때문인지 구분하기 어려워집니다.

## 원인과 계산

참조한 공개 X500 구성에서 중심 기체는 2.0kg이고, 로터 하나의 질량은 약 0.01608kg입니다. 네 로터를 빼면 전체 질량이 약 2.06431kg이 됩니다. 모델이 중심 기체 질량만 사용하면 약 64g, 전체 질량의 약 3.1%가 계산에서 사라집니다.

관성은 각 부품의 자체 관성에 더해, 중심 기체에서 떨어진 위치 때문에 생기는 관성도 합쳐야 합니다. 이때 평행축 정리를 사용합니다.

```text
전체 관성 = 중심 기체 관성 + 각 로터 자체 관성 + 로터 위치에 따른 추가 관성
```

로터 중심은 기체 중심에서 약 0.174m 떨어져 있고 기준면보다 약 0.06m 위에 있습니다. 네 로터의 위치와 대칭 배치를 반영해 계산한 주축 관성은 약 `0.02384669`, `0.02394962`, `0.04399995 kg·m²`입니다. 기존 중심 기체 값인 약 `0.02167`, `0.02167`, `0.04000 kg·m²`보다 커졌습니다. 서로 다른 X·Y 값은 원본 설정의 로터 배치·링크 관성을 그대로 합산한 결과이며, 실제 기체를 측정한 값은 아닙니다.

## 수정한 내용

물리 파라미터를 만들 때 중심 기체와 네 로터의 질량·관성을 하나의 강체 기준으로 합산하도록 바꿨습니다. 로터 위치도 높이 0으로 두지 않고 공개 모델에서 확인한 0.06m를 반영했습니다. 이 값은 물리 계산에 들어가는 단순화된 단일 강체의 제원입니다. 로터 회전자의 자이로 효과나 배터리·탑재물 구성은 별도로 계산하지 않습니다.

모델을 고친 뒤 강체 비행 시나리오의 착륙 예상 위치도 바뀌었습니다. 기대 위치를 새 결과에 맞춘 것은 시나리오의 기준을 수정한 일이지, 실제 X500과의 오차가 줄었다는 검증은 아닙니다.

## 검증 결과와 현재 범위

당시에는 합산 질량·관성 값과 로터 위치를 수치로 확인하는 시험을 추가했고, 동일한 초기 조건의 강체 비행 시나리오에서 새 최종 상태를 확인했습니다. 별도의 제조사 질량 측정이나 실제 비행 로그 대조는 하지 않았습니다.

시험을 약 20개 핵심 시나리오로 줄이는 과정에서 정확한 질량·관성 숫자를 직접 비교하던 단위 시험이 제거됐습니다. 현재 물리 시험은 로터 응답과 좌표·접촉 동작을 확인하지만, 이 숫자들이 유지되는지 직접 감시하지 않습니다. 강체 비행 시나리오도 넓은 동작 회귀를 확인할 뿐, 질량 누락을 독립적으로 찾아내는 시험은 아닙니다.

## 남은 확인 사항

- 공개 X500 설정이 현재 보유한 실물 기체의 부품 구성과 같은지 확인해야 합니다.
- 배터리와 탑재 장비를 포함한 실제 질량·무게중심·관성 자료가 생기면 모델에 반영하고 출처를 기록해야 합니다.
- 현재 시험 구성에서는 질량·관성 합산값에 대한 직접 회귀 검사가 없습니다. 이 값을 다시 바꾸는 작업에서는 수치 기준을 별도로 확인해야 합니다.
- 실제 비행 궤적과의 비교를 하기 전에는 디지털 트윈이나 실기체 정확도라고 표현할 수 없습니다.
