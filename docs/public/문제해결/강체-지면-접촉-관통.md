# 지면 접촉 뒤 기체가 지형에 파고든 문제

## 증상과 기대 동작

강체 모의에서 드론을 높이 격자 위로 떨어뜨리면 지면에서 멈추기는 하지만, 멈춘 뒤 기체 중심이 예상보다 낮았습니다. 높이 2m인 평평한 격자 위에 기체를 2m 더 높은 곳에서 놓고 60Hz로 240 Tick 진행하는 시험에서 중심 높이는 2.1562m였습니다. X500 기준점은 지면에서 0.24m 위에 있어야 하므로 기대 높이는 2.24m였고, 두 값의 차이는 약 8.4cm였습니다. 수직 속도는 정지 허용 범위 안에 들어왔지만, 충돌 상자는 지면을 지나친 상태였습니다.

지면 높이가 0m가 아닌 장소에서도 기체가 지면을 관통하지 않고, 멈춘 뒤 중심 높이가 지면 높이와 기체 기준점 높이에 맞아야 합니다. 화면에서 멈춰 보이는지만으로는 이 조건을 확인할 수 없어 실제 강체 상태를 읽는 시험이 필요했습니다.

## 원인 확인

시험은 먼저 높이 격자가 충돌에 전달되는지 확인하도록 3×3 격자 전체를 2m로 설정했습니다. 첫 실행에서는 높이 격자 경로로 바닥을 찾았지만, 드론은 기대 높이보다 8.4cm 낮은 곳에서 멈췄습니다. 이는 높이 격자를 무시해 z=0 평면에 닿은 결과와는 달랐습니다.

AirSim 충돌 처리를 확인하니 지면 고정이 시작될 때 접촉 정보의 현재 기체 위치를 다음 위치로 그대로 사용했습니다. 일반 충돌에서는 겹친 깊이를 위치 보정에 반영하지만, 지면 고정 경로에서는 그 값으로 위치를 올리지 않았습니다. 그래서 60Hz 한 단계 사이에 지면을 통과한 양이 기체 위치에 남았습니다.

## 수정

AirSim 물리 계산이 끝난 뒤 기체가 처음 지면 고정 상태로 바뀐 경우에만 충돌 상자와 지면의 겹친 깊이를 다시 계산합니다. 가장 깊이 들어간 만큼 기체를 위로 옮기고, 부동소수점 반올림으로 다시 겹치지 않도록 아주 작은 여유를 더합니다.

보정 여부는 직전 물리 단계의 지면 고정 상태와 비교합니다. 지면에 계속 놓여 있는 동안 매 Tick마다 충돌 상자를 다시 검사하지 않으므로, 착륙 순간에만 추가 계산이 실행됩니다. 외부에서 강체 상태를 다시 지정할 때는 이전 지면 고정 상태도 초기화해 다음 접촉을 새로 판정합니다.

## 검증 결과와 범위

기존 물리 시험 하나에 두 조건을 넣었습니다. 높이 격자가 없는 z=0 바닥과 높이 2m의 3×3 격자에서 각각 드론을 2m 위에서 떨어뜨렸습니다. 두 경우 모두 지면 높이와 X500 기준점 높이를 더한 값에서 3cm 안에 멈추고, 수직 속도도 정지 조건을 만족했습니다. CTest 시나리오 수는 20개로 유지했으며, Windows Release 전체 시험 20개가 통과했습니다.

시험은 수평으로 놓인 기체가 평평한 바닥에 내려앉는 경우를 다뤘습니다. 경사면 충돌, 바닥과 건물에 동시 접촉, 여러 차례 튀는 상황은 확인하지 않았고 지면 보정의 성능 변화도 측정하지 않았습니다.

## 다음에 확인할 점

경사 방향이 다른 높이 격자에서 착륙 자세와 지면 접촉을 확인하고, 바닥과 장애물이 동시에 가까운 경우에도 깊은 접촉 하나만 선택하는 현재 방식이 안정적인지 검증해야 합니다.
