# 연결된 게임패드를 프로그램이 찾지 못한 문제

## 증상

사용자는 Xbox 게임패드를 USB로 연결했다고 했지만, 실행 중 게임패드 입력이 확인되지 않았습니다. 장치 모델과 연결 방식은 알려졌지만, 해당 PC에서 앱이 읽은 장치 목록이나 조작 시험 결과는 남아 있지 않습니다.

## 현재 프로그램의 확인 방식

프로그램은 GLFW가 게임패드로 인식하는 장치를 찾아 표준 버튼·축 값을 읽습니다. Windows 장치 목록에는 있어도 GLFW가 표준 게임패드 형식으로 읽지 못하면 입력이 들어오지 않을 수 있습니다. 창 제목에는 연결 여부 또는 형식 미지원 상태가 표시됩니다.

## 해결 상태

현재 기록만으로는 USB 연결, Windows 입력, GLFW 인식 중 어느 단계에서 막혔는지 확정하지 못했습니다. 해당 Xbox 장치에서 수정이 확인됐다고 말할 근거도 없습니다.

## 다시 확인할 때

Windows 게임 컨트롤러 속성에서 버튼과 스틱 값이 움직이는지 확인하고, 시뮬레이터 창 제목과 장치 이름을 함께 기록합니다. Windows에서는 읽히지만 프로그램에서는 연결되지 않으면 장치 이름, 창 제목, 게임패드 속성 화면을 보존해야 원인을 좁힐 수 있습니다.
