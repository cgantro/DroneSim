# EO 카메라 화면에 탑재 기체가 보이지 않는 이유

## 보고된 현상

사용자는 시뮬레이터의 카메라 화면에서 드론을 볼 수 없다고 보고했습니다. 화면에서 기대한 대상이 자기 기체인지 다른 기체인지는 기록만으로 확인되지 않았습니다.

## 현재 카메라가 보는 방향

이 화면은 드론에 달린 EO 카메라의 시야를 보여줍니다. 카메라는 기체 중심보다 앞쪽에 달려 있고, 기체가 향한 방향을 바라봅니다. 따라서 카메라가 달린 자기 기체는 보통 시야 뒤쪽에 있어 화면에 나오지 않습니다. 다른 드론이 카메라 앞에 있을 때는 장면에 따라 보일 수 있습니다.

## 확인 상태

현재 카메라 위치와 방향 계산은 코드에서 확인했습니다. 보고 당시의 화면 캡처나 재현 순서는 남아 있지 않아, 카메라가 주변 장면을 제대로 비췄는지까지 확인할 수는 없습니다. 자기 기체를 화면에 보이게 하려면 EO 카메라 시야와 별도로 외부 추적 화면을 두거나, 기체 일부가 보이도록 카메라 장착 위치와 방향을 바꿔야 합니다. 어느 쪽이 필요한지는 아직 정해지지 않았습니다.
