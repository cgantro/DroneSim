# 실행 위치에 따라 모델을 찾지 못한 문제

## 증상

시뮬레이터를 저장소 루트에서 열면 X500 화면 모델을 찾지 못하고 시작하지 않았습니다. 실행 파일이 있는 빌드 폴더에서 열면 자산을 찾을 수 있었습니다.

## 원인과 수정

모델, 지형, 텍스처와 셰이더 경로를 실행 파일 위치가 아니라 현재 작업 폴더 기준으로 읽고 있었습니다. 프로그램을 어느 폴더에서 실행했는지에 따라 같은 자산 경로가 서로 다른 위치를 가리킨 것이 원인입니다. 자산 경로를 실행 파일이 있는 폴더 기준으로 만들도록 바꿨습니다. 웹 빌드는 미리 불러온 자산 경로를 그대로 사용합니다.

## 확인 상태

자산 경로를 읽는 코드와 빌드 후 자산을 실행 파일 옆에 복사하는 설정을 확인했습니다. Release 빌드와 20개 CTest가 통과했고, 저장소 루트에서 실행한 Viewer 스모크 검사와 실제 창 실행도 통과했습니다.
