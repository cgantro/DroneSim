# PX4 비행 기록을 재생할 때 로터 입력이 실제 회전수와 달랐던 문제

## 증상

PX4 X500 V2의 100~104초 구간을 강체 시뮬레이션에서 재생하면 위치와 자세가 기록에서 크게 벗어났습니다. 처음에는 시작할 때 로터 회전수가 맞지 않는 문제를 발견해 고쳤지만, 그 뒤에도 자세 오차가 61.46°였고 로터 회전수 오차도 217.16rad/s였습니다.

## 원인 확인

첫 문제는 초기 회전수를 AirSim 물리 모델에 전달하는 순서였습니다. 프로젝트 쪽 모터 상태에는 초기값이 들어 있었지만, AirSim 로터의 입력 필터는 0에서 시작했습니다. 첫 물리 계산에서는 필터 출력으로 힘을 계산한 뒤 새 입력을 반영해, 시뮬레이션이 첫 Tick에 회전수 0을 사용했습니다. AirSim 시계가 첫 Tick만큼 진행된 뒤 로터 필터를 준비하도록 고쳐 첫 계산부터 초기 회전수를 사용하게 했습니다.

이 수정 뒤에도 오차가 컸습니다. 재생 도구가 PX4의 `actuator_motors.control`을 추력 비율로 읽고, `√추력 비율 × 최대 회전수`로 로터 속도를 만들고 있었습니다. 그러나 이번 로그에는 실제 ESC 회전수도 기록되어 있었습니다. PX4는 `esc_rpm`을 RPM 단위로 정의합니다([EscReport 설명](https://docs.px4.io/main/en/msg_docs/EscReport)). 두 값을 직접 대조하니 명령으로 환산한 회전수는 평균 743.19rad/s, ESC 측정값은 525.64rad/s였고, 모터별 차이의 RMSE는 217.64rad/s였습니다. 정규화 명령을 실제 회전수와 같은 값으로 취급한 가정이 틀렸습니다.

## 수정

ESC 회전수가 있는 로그는 측정값을 재생 입력으로 사용합니다. 회전수를 현재 기체 설정의 최대 회전수로 나눈 뒤 제곱해 시나리오의 추력 비율로 바꿉니다. 변환된 시나리오에는 입력 출처도 기록합니다. ESC 자료가 없는 로그는 이전처럼 PX4 추력 명령을 사용합니다.

## 결과

같은 공개 [PX4 비행 기록](https://logs.px4.io/plot_app?log=d71cd659-1c9c-49e7-859a-79664657c857)의 100~104초 구간을 60Hz, 241개 표본으로 비교했습니다. 물리 설정과 시작 자세·속도·회전수는 그대로 두고 모터 입력 자료만 바꿨습니다. 양쪽 모두 초기 회전수 전달 수정이 반영된 Release 실행입니다. RMSE는 각 시각의 차이를 하나의 대표 오차값으로 요약한 수치입니다.

| 재생 입력 | 위치 RMSE | 속도 RMSE | 자세 RMSE | 각속도 RMSE | 회전수 RMSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| PX4 추력 명령 | 1.126m | 0.873m/s | 61.46° | 0.822rad/s | 217.16rad/s |
| ESC 측정 회전수 | 0.714m | 0.618m/s | 29.17° | 0.411rad/s | 3.12rad/s |

네 로터의 회전수 오차와 위치·자세 오차는 줄었지만, 시뮬레이션은 최저 0.236m까지 내려가 지면에 닿았습니다. 접촉 뒤 자세 변화도 거의 멈췄습니다. 회전수 입력 문제는 고쳤지만 비행 재현은 끝나지 않았습니다.

남은 차이는 추력 계수와 측정 회전수의 조합에서 드러납니다. 이 구간의 네 로터 평균 회전수는 약 525.64rad/s입니다. 현재 추력 계수 `8.54858×10⁻⁶ N/(rad/s)²`로 계산하면 네 로터의 합산 추력은 약 9.45N입니다. 모델 무게 2.064kg에 중력 가속도를 곱한 힘은 약 20.24N이므로, 현재 계수로는 기록된 회전수에서 기체가 뜰 수 없습니다. 이 모델에서 제자리 비행에 필요한 회전수는 로터당 약 769rad/s입니다. PX4 기록에서는 해당 구간 동안 높이가 거의 유지됐습니다. 따라서 현재 X500 추력 계수 또는 기록된 기체의 모터·프로펠러 제원이 서로 맞지 않습니다. 실제 추력 측정값이 없어 어느 쪽을 바꿔야 하는지는 아직 정하지 않았습니다.

비교에 사용한 위치와 자세는 PX4 추정값이며 외부 측량값이 아닙니다. 회전수 RMSE가 작아진 것은 같은 로그의 ESC 회전수를 시뮬레이션 입력과 비교한 결과입니다. 이 수치만으로 실물 비행 정확도를 판정하지 않습니다.

## 남은 확인

- X500의 실제 무게와 로터별 추력을 측정해, 현재 추력 계수와 로그의 ESC 회전수 중 어느 값이 기록된 기체에 맞는지 확인해야 합니다.
- 추력 계수를 맞춘 뒤 모터 지연과 기체 관성도 별도 자료로 검증해야 합니다.
- 이 결과는 한 비행 기록의 4초 구간에서 얻었습니다. 여러 비행과 다른 비행 조건에서도 같은 개선이 나타나는지 확인해야 합니다.
- ESC 회전수가 없는 로그는 추력 명령을 사용하므로, 그 경로의 실제 회전수 정확도는 확인되지 않았습니다.

이번 변경에서 실행한 Python 변환기 시험 19개는 통과했습니다. Release C++ 재생 시험도 갱신한 오차 기준으로 다시 확인했습니다.
