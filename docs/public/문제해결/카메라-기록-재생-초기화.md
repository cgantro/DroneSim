# 녹화·재생 뒤 카메라 화면이 이전 시점에 머문 문제

## 증상

녹화나 재생을 시작하면 시뮬레이션 시간이 0으로 돌아갑니다. 이때 카메라 영상은 이전 Tick 번호에 머물렀고, 간헐적으로 프로그램 종료 검사에서 영상 Tick과 카메라 Tick이 다르다고 판정했습니다. 반복 실행에서는 영상이 1200 Tick, 카메라가 1170 또는 1230 Tick인 사례가 확인됐습니다.

## 원인

시뮬레이션 Tick은 다시 0부터 시작했지만, GPU가 읽을 화면을 등록할 때 쓰는 마지막 Tick 번호는 이전 값을 유지했습니다. 새 카메라 Tick이 이 번호보다 작으면 화면 읽기를 건너뜁니다. 그 결과 이전 실행의 GPU 읽기 결과가 남고, 새 실행의 화면은 큐에 들어가지 않았습니다.

## 수정과 확인

세션을 초기화하기 전에 진행 중인 GPU 읽기를 모두 마치고, 새 Tick 번호가 이전 값과 비교되지 않도록 기준을 0으로 되돌립니다. 그 뒤 시뮬레이션과 화면 데이터를 초기화합니다.

수정 전 반복 시험에서 같은 불일치가 재현됐습니다. 수정 뒤 녹화·재생 통합 시험 10회가 연속 통과했고, Release 전체 20개 시험도 모두 통과했습니다.
