# 기록을 시작한 뒤 카메라 영상이 멈춘 문제

## 증상

명령 기록이나 재생을 시작한 뒤 새 카메라 영상이 한동안 화면에 반영되지 않을 수 있었습니다.

## 원인과 수정

세션을 시작할 때 시뮬레이션 Tick은 0으로 되돌렸지만, 화면에 보관한 영상의 Tick 번호는 이전 값을 유지했습니다. 이전 영상 번호가 새 영상보다 크면 새 영상이 갱신되지 않는 조건이 생겼습니다. 기록과 재생을 시작할 때 저장된 영상도 함께 비우도록 바꿨습니다.

## 확인 결과

녹화·재생 통합 시험과 Viewer 스모크 검사에서 시뮬레이션 Tick과 카메라 영상 Tick이 다시 맞는지 확인합니다.
