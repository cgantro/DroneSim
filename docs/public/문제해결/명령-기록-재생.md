# 기록한 조종 명령이 재생 중 달라진 문제

## 증상

녹화한 비행을 다시 재생하면 명령 적용 시점이 한 Tick씩 달라지거나, 재생 중 게임패드 입력이 기록된 명령을 덮어쓸 수 있었습니다. 둘 다 같은 입력을 다시 실행했을 때 결과가 달라지는 문제였습니다.

## 원인을 찾은 과정

기록을 시작하고 끝내는 명령도 시뮬레이션 시간을 진행시키지만, 기록 길이와 재생 위치 계산은 그 Tick을 같은 방식으로 세지 않았습니다. 또 입력 차단 조건은 지상통제 상태만 확인해, 기록 재생 중인 게임패드 입력은 걸러내지 못했습니다.

## 수정

각 명령에 적용 Tick을 함께 저장하고, 기록의 시작과 끝도 재생 범위에 포함하도록 정리했습니다. 지상통제나 기록 재생이 진행 중이면 게임패드 명령을 받지 않고 이미 대기 중인 입력도 비웁니다.

## 확인 결과와 한계

자동 시험은 시작·종료 Tick을 포함한 명령이 같은 Tick에 재생되는지, 지상통제와 기록 재생 중 게임패드가 명령을 덮어쓰지 않는지 확인합니다. 이는 메모리에 기록한 입력의 적용 순서를 다룹니다. 외부 게임패드의 입력 지연이나 네트워크 전체를 재현하는 시험은 아닙니다.
