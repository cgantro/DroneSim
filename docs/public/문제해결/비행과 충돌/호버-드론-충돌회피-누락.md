# 임무 없는 호버 드론이 충돌 예측에서 빠진 문제

## 증상

한 드론이 조사 경로를 따라 이동하고 옆의 다른 드론은 연결된 채 호버링하는 상황을 생각해 보세요. 움직이는 드론은 상대의 현재 위치와 속도를 읽고 충돌 위험을 피해야 합니다. 그런데 이전 코드는 두 드론 모두 진행 중인 임무가 있을 때만 쌍을 검사했습니다. 임무가 없는 호버 드론은 연결돼 있어도 위험 판단에서 빠졌습니다.

수정 전에 이 조건을 겨냥한 재현 시험이나 최소 거리 기록은 남아 있지 않습니다. 따라서 수정 전후 충돌 거리를 비교하거나 개선량을 계산하지 않았습니다.

## 원인 확인

기존 충돌 회피 로직은 연결된 두 드론 중 하나라도 미완료 임무를 수행하지 않으면 해당 쌍을 건너뛰었습니다. 임무 목록에 없는 드론은 현재 위치에 머물러도 장애물로 취급되지 않았습니다. 임무를 마친 드론도 같은 조건으로 빠졌습니다.

위험 계산과 회피 명령을 받을 드론을 같은 조건으로 묶은 것이 문제였습니다. 실제 위치를 비교할 때는 두 기체를 모두 봐야 하지만, 회피 경로를 바꿀 대상은 진행 중인 임무가 있는 드론이어야 합니다.

## 수정

연결된 두 드론의 위치와 속도는 임무 유무와 관계없이 비교합니다. 한쪽만 임무 중이면 그 드론이 회피하고, 둘 다 임무 중이면 목록에서 뒤에 있는 드론이 양보합니다. 둘 다 움직일 임무가 없다면 회피 명령은 보내지 않습니다. 통신이 끊긴 드론은 마지막으로 확인한 위치에 멈춘 장애물로 계산합니다.

회피를 끝내는 거리도 상대 상태에 맞췄습니다. 둘 다 임무 중일 때는 설정된 안전거리보다 1.5배 더 벌어진 뒤 회피를 풀어 잦은 전환을 줄입니다. 상대가 정지 장애물일 때는 설정 안전거리까지 떨어지면 회피를 풀어, 목표점 간격이 좁다는 이유로 임무가 계속 멈추지 않게 했습니다.

## 검증 결과와 남은 범위

| 시험 | 결과 |
| --- | --- |
| 운동학 경로에서 임무 없는 호버 드론을 회피 | 회피 이벤트 발생, 두 임무 완료, 실제 최소 중심 간격이 2.5m 이상임을 확인 |
| AirSim 강체 교차 경로 | 기존 시나리오 통과. 최소 중심 간격 합격 기준은 3m |
| Release CTest | 20개 모두 통과 |

이 문서에 적힌 강체 시험의 통과 기준은 당시 3m였습니다. 이후 같은 시험의 시작 위치와 기준을 다시 살핀 내용은 [강체 충돌 회피가 설정 거리보다 가까워진 문제](강체-충돌회피-안전거리-미달.md)에 이어 기록했습니다.

현재 위험 예측은 위치와 속도가 일정하다고 보고 가장 가까워질 거리를 계산합니다. 여러 드론과 장애물의 동시 접근, 이동하는 지형·건물, 두 드론을 모두 수동 조종하는 상황은 시험하지 않았습니다. 다음 회피 시험에서도 임무 완료와 실제 최소 거리를 확인하고, 각 결과를 설정 안전거리와 대조해야 합니다.
