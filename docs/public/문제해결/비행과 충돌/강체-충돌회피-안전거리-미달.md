# 강체 충돌 회피가 설정 거리보다 가까워진 문제

## 증상

강체 물리 교차 경로 시험은 회피 안전거리를 8m로 설정했지만, 두 기체 중심이 가장 가까울 때 5.26m까지 접근했습니다. 기존 시험은 5m 이상이면 통과하도록 작성돼 있어 시험 자체는 성공으로 표시됐습니다. 설정한 거리와 실제 결과가 달랐습니다.

## 원인 확인

충돌 회피는 두 기체의 현재 위치와 현재 속도를 사용해 일정 시간 뒤 가장 가까워질 거리를 계산합니다. 이 계산은 지금 속도가 그대로 이어진다고 가정합니다. 임무 경로가 서로 교차하더라도, 이륙 직후처럼 속도가 거의 0이면 앞으로 접근할 방향을 예측하지 못합니다.

기존 시험은 두 기체를 시작부터 8m 간격으로 놓고 서로의 위치로 이동시켰습니다. 즉, 설정된 안전거리와 같은 경계에서 접근을 시작했습니다. 궤적을 30 Tick 간격으로 기록하자, 이륙하는 동안 두 기체의 수평 위치는 거의 변하지 않았습니다. 경로 이동 뒤에는 서쪽 드론이 먼저 앞으로 나갔고, 동쪽 드론의 옆 이동이 뒤따랐습니다. 표본상 거리는 Tick 300의 8m에서 Tick 420의 약 5.26m까지 줄었습니다. 매 Tick마다 계산한 최소값은 5.25m였습니다. 회피 명령이 적용된 뒤에도 강체 기체가 모터를 돌리고 자세를 기울이는 동안 관성에 따라 더 가까워졌습니다.

이 시험은 속도만으로 계산하는 예측과 실제 강체 응답이 다를 수 있음을 보여줍니다. 충돌 회피 함수가 잘못된 위치를 읽은 문제는 아니며, 경로 목표와 기체가 앞으로 낼 가속도를 계산에 넣지 않는 것이 확인된 한계입니다.

## 수정

시험의 시작 조건을 바꿨습니다. 두 기체를 40m 간격으로 배치하고 서로 교차하는 임무 경로를 줘, 회피 명령이 동작할 공간을 확보했습니다. 안전거리 8m, 예측 시간 6초, 옆 이동 거리 10m는 그대로 두고 실제 최소 거리 기준을 8m로 높였습니다. 강체 시험은 두 임무가 모두 완료돼야 통과하도록 유지했습니다.

| 조건 | 처음 시험 | 수정한 시험 |
| --- | --- | --- |
| 시작 위치 | 서쪽 `(-4, 0, 0)`, 동쪽 `(4, 0, 0)` | 서쪽 `(-20, 0, 0)`, 동쪽 `(20, 0, 0)` |
| 임무 목표 | 서쪽 `(8, 0, 1.5)`, 동쪽 `(-8, 0, 1.5)` | 동일 |
| 회피 설정 | 안전거리 8m, 예측 6초, 옆 이동 10m | 동일 |
| 실제 최소 중심 간격 | 5.25m | 9.72m |
| 통과 기준 | 5m 이상 | 8m 이상 |

수정한 강체 시나리오는 최대 3,600 Tick(60초), 임무 기한 3,590 Tick으로 실행합니다. 시작 위치만 바꾸면 경로가 길어지므로 임무가 완료될 시간을 함께 늘렸습니다.

## 검증 결과와 남은 점

2026년 10월 28일 Release에서 이 강체 교차 경로 시험을 다시 실행했습니다. 두 임무가 완료됐고, 측정한 최소 중심 간 거리는 9.72m였습니다. 당시 전체 CTest는 30개가 통과했습니다. 이 결과는 두 기체를 40m 간격으로 출발시킨 해당 시험에만 해당하며, 현재 네 대 정찰 통합 시험 결과는 [최신 기능 현황](../../../../SPEC.md)에서 확인해야 합니다.

이 결과는 여유를 두고 출발한 한 교차 경로에서 8m 기준을 지킨다는 뜻입니다. 모든 출발 간격·속도·방향에서 8m를 보장한다는 뜻은 아닙니다. 특히 시작 시 이미 안전거리 안에 있거나, 이동 목표가 갑자기 바뀌는 상황은 시험하지 않았습니다. 현재 예측은 경로 의도와 모터·자세 응답을 계산하지 않으므로 일반적인 안전 보증으로 볼 수 없습니다.

## 재발 방지

충돌 회피 시험에는 설정값뿐 아니라 실제 최소 거리를 반드시 검사합니다. 시작 위치, 속도, 목표 경로를 함께 기록하고, 반응 시간이 부족한 조건은 별도 시험으로 다룹니다. 향후에는 임무 경로와 기체 가속 응답을 반영한 예측을 검토해야 합니다.
