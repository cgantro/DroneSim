# 화면 프레임이 길게 멈춘 측정 결과

## 관찰된 현상

숨김 창에서 5초 동안 화면을 측정했을 때 평균은 초당 약 265프레임이었지만, 가장 긴 프레임은 89.33ms였습니다. 60Hz 화면의 한 프레임 예산인 16.67ms보다 길어, 평균 수치만 보면 놓칠 수 있는 끊김이 한 번 이상 있었습니다.

## 조사 결과

같은 측정에서 영상 품질 분석 구간의 p95는 5.57ms였습니다. Tick p95는 35.4µs였습니다. 이 실행에서는 모의 갱신보다 프레임 작업 안의 영상 분석과 화면 처리 지연을 먼저 살펴볼 근거가 있습니다. 다만 한 번 측정한 결과라 특정 작업이 89.33ms 지연을 단독으로 일으켰다고 확정할 수는 없습니다.

별도 물리 계측에서는 가까이 모인 드론의 접촉 정보 생성이 물리 계산 시간 대부분을 차지했습니다. 그래픽 프레임 지연과 물리 충돌 병목은 서로 다른 측정에서 나온 결과이므로 하나의 원인으로 합치면 안 됩니다.

## 다음에 확인할 때

끊김이 반복되면 화면 해상도, 카메라 분석 상태, 드론 수, 장면 배치와 함께 프레임 p50·p95·최댓값을 기록해야 합니다. 현재 자료만으로 특정 GPU, 셰이더 또는 CPU/GPU 동기화가 원인이라고 말할 수 없습니다. 전체 측정 조건은 [기술 검토](../기술검토.md)에 있습니다.
