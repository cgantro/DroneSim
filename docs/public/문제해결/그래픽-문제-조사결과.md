# 그래픽 문제 조사 현황

## 실제로 확인한 문제

- 관찰 화면에서 드론이 너무 작게 보이는 현상은 [관찰 화면 기록](관찰화면-드론-크기.md)에 있습니다.
- 카메라 화면의 비율과 해상도 문제는 [카메라 화면 기록](카메라-화면-비율.md)에 있습니다.
- 드론이 기울 때 영상 위쪽 방향이 맞지 않은 문제는 [카메라 기울기 기록](카메라-기울기.md)에 있습니다.
- 드론 자세와 영상이 어긋나거나 기록을 시작한 뒤 영상이 멈춘 문제는 각각 [자세 동기화 기록](카메라-자세-동기화.md), [기록·재생 초기화 기록](카메라-기록-재생-초기화.md)에 있습니다.
- 한 번 측정한 긴 프레임과 다중 드론 충돌 병목은 [프레임 지연 기록](화면-프레임-지연.md), [충돌 성능 기록](다중드론-충돌-성능.md)에 나눠 적었습니다.

## 아직 사례나 측정이 없는 문제

검은 화면, 화면 찢어짐, Z-파이팅, 그림자 줄무늬는 이 프로젝트의 재현·수정 기록을 찾지 못했습니다. 화면 프레임이 길어진 측정은 있지만 원인을 분리하지 않아 GPU 병목으로 판정하지 않았습니다.

그래픽 엔진에서 자주 확인하는 다른 문제도 현재 저장소에는 실제 사례가 없습니다.

- **GPU 메모리 부족과 누수:** VRAM 사용량을 측정한 기록이 없습니다.
- **CPU와 GPU 사이의 전송 지연:** 픽셀을 CPU로 읽어 오는 시간은 측정했지만, GPU 내부 작업 시간과 업로드 지연을 분리해 측정하지 않았습니다.
- **스레드 충돌과 교착:** 렌더링 스레드에서 멈춤이나 데이터 충돌이 재현됐다는 기록이 없습니다.
- **GPU 작업 순서 문제:** 현재 프로그램은 OpenGL 3.3을 사용하며, Vulkan·DirectX 12처럼 명령 큐와 자원 배리어를 직접 관리하지 않습니다.
- **그래픽 카드별 셰이더 오류:** 다른 제조사의 그래픽 카드에서 비교한 결과가 없습니다.
- **드로우 콜과 오버드로우:** 각각의 횟수나 픽셀 처리량을 잰 기록이 없습니다.

그래서 이 항목들은 발생하거나 해결된 트러블 슈팅으로 적지 않습니다. 프레임 지연과 픽셀 읽기 측정의 조건은 [기술 검토](../기술검토.md)에서 확인할 수 있습니다.
