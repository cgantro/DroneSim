# 그래픽 엔진 문제 유형 조사 결과

아래는 그래픽 엔진에서 자주 생기는 문제를 현재 프로젝트와 대조한 결과입니다. 실제로 관찰하거나 측정한 문제와, 아직 사례가 없는 문제를 나눴습니다.

| 문제 유형 | 현재 확인한 내용 |
| --- | --- |
| 검은 화면 | 화면 전체가 검게 나온 사례를 기록에서 찾지 못했습니다. 다시 발생하면 장면 지우기 색, 카메라 행렬, 셰이더 연결, 프레임버퍼 상태를 차례로 확인해야 합니다. |
| 카메라 구도와 방향 오류 | 실제로 확인해 수정했습니다. 자세한 경위는 [카메라 문제 기록](그래픽-카메라-화면문제.md)에 있습니다. |
| 화면 비율과 프레임 끊김 | 패널 종횡비 개선 이력과 89.33ms 프레임 측정이 있습니다. 끊김 원인별 재현 자료는 부족합니다. |
| 화면 찢어짐 | 실제 사례 기록은 없습니다. 기본 창 설정은 수직 동기화를 요청하지만, 모든 그래픽 카드와 모니터에서 확인하지는 않았습니다. |
| Z-파이팅과 그림자 줄무늬 | 저장소 기록과 현재 확인한 측정에서 발생 사례를 찾지 못했습니다. 그림자 기능이 없어 그림자 아크네는 현재 렌더링 경로에 해당하지 않습니다. |
| 그래픽 메모리 부족·누수 | VRAM 사용량을 측정한 자료가 없습니다. 프로세스 작업 집합 측정은 그래픽 메모리 측정이 아닙니다. 발생했다고 기록할 근거가 없습니다. |
| CPU와 GPU 전송 지연 | 특정 전송 병목을 측정하지 않았습니다. 프레임 측정만으로 원인을 단정할 수 없습니다. |
| 그래픽 작업의 스레드 경쟁·교착 | 현재 렌더링은 한 OpenGL 실행 환경을 현재 창 스레드에서 사용합니다. GPU 명령을 여러 CPU 스레드에서 만들어 제출하는 Vulkan·DirectX 12 구조는 아닙니다. |
| 파이프라인 배리어 문제 | 현재 OpenGL 렌더링 구조에는 사용자가 직접 관리하는 Vulkan·DirectX 12식 배리어 경로가 없습니다. |
| 셰이더 제조사별 오류·조합 폭발 | 여러 GPU 제조사에서 비교한 자료나 셰이더 조합 폭발 사례가 없습니다. 크로스 GPU 호환성이 검증됐다고 볼 수 없습니다. |
| 드로우 콜 병목 | 드로우 콜 수를 기록한 측정은 없습니다. 화면을 그리는 명령 수만으로 병목이라고 판단하지 말고 CPU·GPU 구간을 나눠 측정해야 합니다. |
| 오버드로우와 화면 채우기 한계 | 같은 픽셀을 여러 번 그려 생기는 비용을 측정한 자료가 없습니다. 장면 해상도와 투명 물체 수를 바꾼 비교가 있어야 원인을 좁힐 수 있습니다. |
| 실제 성능 병목 | 드론 충돌 후보 검사와 접촉 생성 비용을 측정했습니다. 자세한 결과는 [다중 드론 충돌 성능 기록](다중드론-충돌-성능.md)에 있습니다. |

현재 코드가 지원하지 않거나 측정하지 않은 문제를 해결된 것으로 보지 않습니다. 그래픽 제조사별 검수, VRAM 계측, 장시간 실행 메모리 측정은 아직 하지 않았습니다.
