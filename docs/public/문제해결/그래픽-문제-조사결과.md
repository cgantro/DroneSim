## 아직 발생을 확인하지 못한 그래픽 문제

아래 항목은 그래픽 엔진에서 점검할 수 있는 문제 유형입니다. 저장소의 수정 기록이나 재현 자료를 찾지 못했으므로, 발생한 문제로 기록하지 않습니다.

| 분야 | 확인할 수 있는 현상 | 현재 확인 상태 |
| --- | --- | --- |
| 화면 출력 | 검은 화면, 화면 찢어짐, 깜빡임 | 재현 기록과 주사 동기화 측정이 없습니다. |
| 깊이와 그림자 | Z-파이팅, 그림자 줄무늬 | 수정 기록이 없습니다. |
| GPU 자원 | VRAM 부족, 사용이 끝난 텍스처·버퍼의 잔류 | VRAM 사용량과 장시간 누적 측정이 없습니다. |
| CPU·GPU 전송 | 픽셀 읽기나 자원 업로드가 프레임을 막는 현상 | 픽셀 읽기 호출 시간은 쟀지만, GPU 실행 시간·업로드 시간과 나눠 재지는 않았습니다. |
| 동시 실행 | 렌더링 데이터 경쟁, 멈춤, 교착 | 재현 기록이 없습니다. |
| GPU 작업 순서 | 화면 자원을 읽고 쓰는 순서가 꼬이는 문제 | 현재 OpenGL 3.3을 사용합니다. Vulkan·DirectX 12식 명령 큐와 명시적 배리어 문제를 다루는 구조는 아닙니다. |
| 셰이더 | 특정 그래픽 카드의 컴파일 오류, 셰이더 조합 증가로 인한 첫 화면 끊김 | 다른 제조사 카드 비교나 셰이더 준비 시간 측정이 없습니다. |
| 화면 성능 | 드로우 콜 증가, 화면 겹침에 따른 픽셀 낭비 | 드로우 콜 수와 오버드로우를 측정하지 않았습니다. |

화면 프레임이 길어진 기록은 있지만, 특정 셰이더나 GPU가 원인이라고 결론내릴 자료는 없습니다. 화면 측정과 픽셀 읽기 시간은 [기술 검토](../기술검토.md)에서 확인할 수 있습니다.
