# 명령 기록 재생에서 Tick 시점이 어긋난 문제

## 증상

기록한 조종 입력을 재생할 때 시작·종료 시점의 명령 적용 Tick이 기록과 달라질 수 있었습니다. 반복 실행 결과를 비교할 때 이 차이가 비행 상태의 차이로 이어집니다.

## 원인과 수정

기록을 시작하거나 끝내는 명령도 시뮬레이션 시간을 한 Tick 진행시키지만, 기존 기록 길이와 재생 위치 계산은 이 Tick을 일관되게 포함하지 않았습니다. 기록된 각 명령을 적용 Tick과 함께 보관하고 시작·종료 Tick도 기록 길이에 넣도록 정리했습니다.

## 확인 결과

시작과 종료 명령이 포함된 기록을 만들고, 각 명령이 같은 Tick에 재생되는지 자동 시험으로 확인합니다. 이 확인은 명령 기록 로직의 결정성을 다루며, 모든 외부 입력이나 네트워크 지연까지 재현한다는 뜻은 아닙니다.
