# 지형 높이와 비행·충돌 기준 문제

## 증상과 처음 세운 가설

지형의 시작점이 경사면에 놓이면 드론이 지면에 박히거나 이륙이 끝나지 않을 수 있었습니다. 착륙 상태와 지형의 실제 높이도 서로 맞지 않았습니다.

먼저 이륙·착륙 목표가 월드 고도 0을 기준으로 잡혀 있는지 의심했습니다. 원인을 확인하는 과정에서 화면용 건물 크기와 물리 충돌 상자의 축 순서도 서로 다르다는 점이 드러났습니다.

## 확인한 원인

기존 이륙·착륙 목표는 지형 높이를 무시하고 월드 높이 0을 기준으로 계산했습니다. 평평한 시험장에서는 드러나지 않지만, 실제 지형 높이를 넣은 뒤에는 시작 위치와 비행 목표의 기준이 달랐습니다.

화면은 산의 높낮이를 보기 쉽도록 지형을 두 배로 크게 그립니다. 비행과 충돌 계산은 원래 높이를 사용합니다. 이 차이는 화면용 표현이며 물리 좌표의 변환 오류와 구분해야 합니다.

충돌 상자는 동쪽·북쪽·위쪽 순서여야 했지만, 화면의 동쪽·위쪽·북쪽 순서 값을 그대로 사용하고 있었습니다. 화면에서 산을 크게 보이게 늘린 높이도 충돌 크기에 섞였습니다. 운동학 경로도 지형 높이 대신 고도 0을 지면으로 간주했습니다.

## 수정

드론마다 시작 지점의 지면 높이를 저장하고, 이륙·착륙 목표를 해당 지면 높이에 더하도록 바꿨습니다. 시연 시작점도 급한 경사 대신 완만한 곳을 선택했습니다. 생성·초기 자세 설정·초기화에 흩어져 있던 같은 위치 설정은 한 경로에서 처리하도록 정리했습니다.

## 확인 결과와 남은 한계

지형을 기준으로 이륙·착륙하고 초기화하는 자동 시험을 추가했습니다. 지형 자료는 약 30m 간격이므로 작은 경사와 시설물을 정확히 나타내지 못합니다. 화면 형상과 충돌 형상도 다르며, 경사면 충돌점은 근사값입니다. 정확한 지형 충돌을 확인하려면 더 촘촘한 높이 자료와 별도의 충돌 검증이 필요합니다.

축 변환은 서로 다른 동·북 폭과 높이를 가진 상자로 확인했고, 건물 옆면 접촉 시험도 통과했습니다. 실제 건물 외곽은 직사각형으로 감싸고, 높이 자료가 없는 건물은 시연용 3m로 둡니다. 그래서 모서리 모양과 실제 높이는 재현하지 않습니다.
