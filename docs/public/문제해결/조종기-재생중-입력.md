# 기록 재생 중 게임패드가 명령을 덮어쓰던 문제

## 증상

기록한 비행을 재생하는 동안에도 게임패드 입력이 들어오면, 저장된 명령과 실시간 조종 명령이 서로 경쟁할 수 있었습니다. 그러면 재생 결과가 기록과 달라집니다.

## 원인과 수정

게임패드 입력을 막는 조건이 지상통제 사용 여부만 확인하고 기록 재생 상태는 확인하지 않았습니다. 재생 중에는 조종기 입력을 받지 않고, 대기 중인 조종 명령도 비우도록 바꿨습니다. 지상통제 중에도 같은 입력 차단 규칙을 적용합니다.

## 확인 결과와 한계

자동 시험은 지상통제 중과 기록 재생 중에 게임패드 조종을 허용하지 않는지 확인합니다. 게임패드 입력을 기록하는 기능이나 외부 장치의 입력 지연까지 확인한 것은 아닙니다.
