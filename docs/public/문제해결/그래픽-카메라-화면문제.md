# 카메라 방향과 화면 구성 문제

## 드론이 관찰 화면에서 너무 작거나 안 보임

### 증상

장면 카메라가 드론에서 너무 멀리 떨어져 있어 기체가 작게 보였습니다. 사용자는 화면 왼쪽의 장면에서 드론을 찾기 어려웠습니다.

### 원인과 수정

관찰 카메라가 드론에서 80m 떨어진 위치를 바라보고 있었습니다. 위치를 약 8m 거리로 옮기고 바라보는 지점을 조금 높여 화면에서 기체가 잘 보이도록 바꿨습니다.

### 확인 결과

코드 변경은 확인했지만, 이 변경을 Windows 화면에서 직접 검수했다는 기록은 찾지 못했습니다. 다시 보이지 않으면 현재 비행 상태와 화면을 함께 캡처해 비교해야 합니다.

## 드론이 기울 때 EO 영상도 이상하게 돌아감

### 증상

드론의 앞을 보는 방향은 자세에 맞춰 돌았지만, 화면의 위쪽 방향은 월드의 위쪽에 고정되어 있었습니다. 그래서 기체가 기울거나 회전하면 영상 구도가 기체와 어긋날 수 있었습니다.

### 원인과 수정

카메라의 시선 방향만 드론 자세에서 계산하고, 영상의 위쪽 방향은 기본값으로 남겨 둔 것이 원인이었습니다. 시선과 위쪽 방향을 모두 드론의 자세로 돌리도록 수정했습니다.

### 확인 결과

카메라 방향을 검사하는 자동 시험을 추가했습니다. 실시간 카메라를 모든 자세로 움직이는 화면 시험 결과는 따로 남아 있지 않습니다.

## 카메라 화면이 늘어나거나 너무 크게 보임

### 증상

카메라 패널 크기를 바꾸면 영상이 패널에 맞춰 늘어나거나 화면에서 너무 큰 비중을 차지했습니다.

### 원인과 수정

화면 패널 크기와 카메라 센서의 실제 해상도를 같은 값처럼 다뤘습니다. 지금은 X500 카메라 해상도 1280×960으로 영상을 만들고, 패널 안에서는 비율을 유지해 표시합니다. 장면과 카메라는 한 창의 별도 패널이며 크기를 직접 조절할 수 있습니다.

### 확인 결과와 남은 점

해상도와 표시 비율을 코드에 반영했습니다. 사용자가 창 크기를 바꾸며 확인한 결과는 버전과 화면 크기를 함께 기록하지 않아 재현 가능한 검수 기록으로 보기는 어렵습니다. 실제 모니터에서 패널 배치와 표시 비율을 다시 확인할 필요가 있습니다.
