# 로터 힘 계산 결과가 유한하지 않은 문제

## 증상

극단적인 입력값을 넣으면 로터가 만드는 힘이나 토크가 무한대 또는 숫자가 아닌 값이 될 수 있었습니다. 이런 값은 이후 강체 계산을 망가뜨릴 수 있습니다.

## 원인과 수정

로터 힘과 토크 계산 결과가 표현 가능한 유한한 값인지 확인하지 않고 다음 물리 단계로 넘기고 있었습니다. 계산 결과가 유효하지 않으면 물리 입력으로 보내지 않고 오류로 거부하도록 했습니다.

## 확인 결과

계산 결과가 double 범위를 넘는 경계값을 넣어 거부되는지 자동 시험으로 확인합니다. 정상 범위의 비행 정확도나 모든 물리 입력의 안정성을 입증한 것은 아닙니다.
