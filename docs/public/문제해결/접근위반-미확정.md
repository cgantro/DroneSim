# 접근 위반 오류, 원인 미확인

## 보고된 증상

Visual Studio에서 시뮬레이터가 `0xC0000005` 접근 위반으로 종료됐다는 보고가 있었습니다. 주소만으로는 어느 코드가 잘못된 메모리를 읽었는지 알 수 없습니다.

## 현재 확인 상태

이 오류의 호출 스택, 덤프, 재현 순서가 저장소에 남아 있지 않아 원인을 확정하거나 수정 완료로 기록할 근거가 없습니다. 물리 입력의 잘못된 수치를 거르는 수정도 별도로 있지만, 이 접근 위반과 관련 있다는 증거는 없습니다.

## 원인 추적에 필요한 자료

1. 오류가 난 시점의 호출 스택 전체를 저장합니다.
2. Visual Studio가 멈춘 코드 위치와 읽으려던 주소를 기록합니다.
3. 오류 직전에 한 입력과 프로그램 상태, 화면을 함께 남깁니다.
4. 같은 순서로 재현되는지 확인합니다.

이 자료가 있어야 해당 줄의 객체 수명, 인덱스 범위, 비동기 작업 종료 순서를 확인할 수 있습니다. 확인 전에는 수정했다고 말할 수 없습니다.
