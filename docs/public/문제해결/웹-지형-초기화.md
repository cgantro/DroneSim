# 웹 빌드에서 지형 초기화가 실패한 문제

## 증상

웹 빌드는 운동학 방식으로 실행하지만, 시작 과정에서 강체 물리용 지형 설정까지 호출하고 있었습니다. 이 설정은 웹 빌드가 지원하지 않는 동작이라 초기화가 실패할 수 있었습니다.

## 원인과 수정

지형 자료는 화면 표시와 물리 충돌 양쪽에서 쓰입니다. 화면을 그리는 데 필요한 지형 자료와 강체 물리에 넘기는 지형 설정을 구분하지 않은 것이 원인이었습니다. 웹 빌드에서는 화면용 지형은 계속 읽고, 강체 물리 월드에 지형을 등록하는 단계만 건너뛰도록 바꿨습니다.

## 확인 상태

현재 코드에는 웹 빌드에서 물리 지형 등록을 건너뛰는 조건이 있습니다. 코드 변경 이력은 확인했지만, 브라우저에서 실행해 시작부터 화면 표시까지 직접 확인한 기록은 찾지 못했습니다.
