# 카메라 화면 비율과 해상도 문제

## 증상

카메라 영역을 넓히거나 줄이면 영상이 늘어나 보이거나, 화면에서 차지하는 크기가 지나치게 컸습니다.

## 원인과 수정

카메라 영상의 해상도와 화면 패널 크기를 같은 기준으로 다루고 있었습니다. X500 카메라 모델의 1280×960 해상도로 영상을 만들고, 패널 안에는 원래 비율을 유지해 표시하도록 바꿨습니다.

## 확인 결과와 남은 점

해상도와 비율 유지 동작은 코드에 반영했습니다. 다양한 창 크기에서 직접 확인한 기록은 남아 있지 않아 실제 화면 비율 검수는 미완료입니다.
