# 운동학 모드에서 지면 아래로 내려간 문제

## 증상

간단한 운동학 모드에서는 하강 명령이 이어질 때 드론 위치가 지면 높이 아래로 내려갈 수 있었습니다.

## 원인과 수정

이 모드는 강체 충돌 계산을 하지 않으므로 땅에 닿았을 때 속도를 멈추는 처리가 따로 필요했습니다. 지면에 닿은 뒤 높이를 0으로 고정하고 비행 상태를 지상으로 바꾸도록 했습니다.

## 확인 결과와 범위

이륙 뒤 계속 하강시켜 지면 높이에서 멈추는 자동 시험이 있습니다. 운동학 기준 모드의 단순한 지면 처리이며, AirSim 강체 충돌이나 경사진 지형의 접촉 정확도를 대신하지 않습니다.
