# 큰 자세값을 변환하다 방향이 깨진 문제

## 증상

수치상 유한한 큰 쿼터니언을 물리 엔진에 전달하면 방향이 영벡터처럼 바뀔 수 있었습니다. 쿼터니언은 회전을 나타내는 네 개의 값입니다.

## 원인과 수정

큰 값을 먼저 32비트 실수로 바꾸면 정규화에 필요한 길이 계산에서 제곱이 범위를 넘을 수 있었습니다. 가장 큰 성분으로 먼저 크기를 줄이고, 64비트 실수에서 정규화한 뒤 물리 엔진 자료형으로 바꾸도록 수정했습니다.

## 확인 결과

큰 유한 쿼터니언을 넣었을 때 방향이 유지되는 자동 시험이 있습니다. 이 사례는 입력 경계의 수치 변환 문제이며, 사용자에게 보고된 접근 위반의 원인으로 확인된 것은 아닙니다.
