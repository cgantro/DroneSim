# 건물 충돌 상자의 세로축이 바뀐 문제

## 발견한 내용

코드 검토 중 화면용 건물 크기를 물리 충돌 계산에도 그대로 넘기는 부분을 찾았습니다. 화면은 위쪽을 Y축으로 그리지만, 비행 계산은 위쪽을 Z축으로 씁니다. 두 좌표 기준을 바꾸지 않으면 건물 높이와 북쪽 폭이 서로 뒤바뀝니다.

## 원인

건물 상자는 지도에서 동쪽·북쪽·위쪽 순서로 만들어야 합니다. 그런데 화면에서 쓰는 크기는 동쪽·위쪽·북쪽 순서였습니다. 이 값을 충돌 계산에 그대로 전달했습니다. 화면에서 산 높이를 두 배로 늘리는 표현까지 충돌 크기에 적용해 실제 높이와 화면 높이도 섞여 있었습니다.

## 수정

건물 외곽선과 지면 높이에서 충돌 상자의 중심과 반 크기를 한 번 계산하도록 정리했습니다. 충돌 계산에는 동쪽·북쪽·위쪽 순서와 원래 건물 높이를 사용하고, 화면에 그릴 때만 위쪽 크기를 보기 좋게 늘립니다. 높이 자료가 없는 건물에는 기존 시연 가정인 3m를 계속 사용합니다.

## 확인 결과와 남은 한계

서로 다른 동·북 폭과 높이를 가진 예시로 축 순서와 높이 가정을 검사했습니다. 실제 지도 건물 하나를 물리 월드에 넣고 드론이 옆면에 닿을 때 움직임이 줄어드는 시험도 통과했습니다. 건물은 실제 다각형 대신 외곽을 감싼 직사각형으로 충돌을 계산하므로, 건물 모서리와 높이의 정확한 형상을 재현하지는 않습니다.
