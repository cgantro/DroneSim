# 로봇 자세 이동과 그리퍼 파지

처음 IK와 Cartesian 이동을 따라가려면 [HCR-12A TCP 이동 튜토리얼](IK_MOVEL_TUTORIAL.md)을 참고한다. 이 문서는 API 계약과 전체 동작·파지 정책의 상세 참조다.

`DampedLeastSquaresIk`는 목표 TCP 자세와 현재 관절각에서 목표 관절각을 찾는다. TCP는 공구에서 작업 위치와 방향을 지정하는 기준점이고, ToolFrame은 모델의 공구 장착 기준점이다. 생성자에 `tcpInToolFrame`을 전달해 두 기준점을 연결한다. 기본값은 항등 변환이므로 공구 보정을 지정하지 않으면 TCP가 ToolFrame에 놓인다.

목표 위치는 Robot base 기준 미터이고 관절각은 라디안이다. 공개 `CartesianPose`의 quaternion은 `[x,y,z,w]`, 모델 `Pose3`의 quaternion은 `[w,x,y,z]`다. Scene에서 로봇 전체를 옮기거나 돌렸다면 World 목표를 Robot base 기준으로 바꾼 뒤 요청해야 한다.

## IK의 계산 원리

FK는 관절각에서 TCP 자세를 구한다. IK는 FK 결과와 목표의 위치 차이, 목표 방향까지의 최단 회전 차이를 줄이도록 관절각을 반복 수정한다. 회전 오차에 `orientationWeightMetersPerRadian`을 곱해 위치 오차와 함께 계산하되, 성공은 위치와 방향의 개별 허용 오차를 모두 만족해야 한다.

Jacobian은 각 관절각을 조금 바꿀 때 TCP 위치와 방향이 어떻게 변하는지 나타내는 표다. 회전 관절의 위치 변화율은 `axis × (TCP - pivot)`이고 방향 변화율은 Robot base에서 본 관절축이다. 공구 보정이 있는 경우에도 장착면이 아니라 실제 TCP까지의 거리를 사용한다.

관절 수정량은 `Δq = Jᵀ (J Jᵀ + λ² I)⁻¹ e`로 계산한다. `e`는 오차, `λ`는 damping이다.

팔이 펴져 일부 방향으로 움직이기 어려운 자세에서도 관절 수정량이 폭증하지 않도록 damping을 더한다. 오차가 줄면 damping을 초기값의 1% 이상에서 절반으로 줄이고, 오차가 줄지 않으면 4배로 키워 다시 계산한다.

한계에 닿은 관절이 바깥쪽으로 더 움직이려 하면 해당 Jacobian 열을 잠시 제외하고 남은 관절로 다시 푼다. 나머지 관절의 수정량은 공동 비율로 축소해 모든 관절이 한계를 넘지 않게 하고, clamp는 부동소수점 오차에 대한 마지막 안전장치로만 사용한다.

여러 반복에서 관절 변화와 오차 감소가 모두 정체되면 반복 한도 전에 멈춘다. 실패 시 weighted Jacobian의 최소 특이값과 조건수를 진단값으로 계산하지만, 조건수가 크다는 이유만으로 해를 거부하지는 않는다.

`Unreachable`은 링크 길이로 계산한 보수적인 거리 상한 밖의 목표다. `JointLimitReached`는 현재 시작점에서 관절 경계 때문에 오차를 줄이지 못한 결과이고, `DidNotConverge`는 반복 한도 또는 국소 정체다. 거리 상한 안의 모든 목표가 도달 가능하다는 뜻은 아니며, 국소 실패가 다른 관절 시작점에서도 해가 없다는 증명은 아니다. 실패 결과의 관절각은 진단용이며 이동 목표로 실행하지 않는다.

## MoveJ 관절 이동과 MoveL 직선 이동

`MovePose`는 현재 관절각을 seed로 목표 TCP의 IK를 풀고, 결과까지 관절각을 직접 보간해 표본을 검사한 뒤 실행한다. UI 미션은 같은 동작을 `BeginPosePlanning`으로 요청한다. 이 경로는 IK와 검사를 여러 프레임으로 나누며, TCP 직선은 보장하지 않는다. 경로 표본이 충돌하면 다른 관절 경로를 찾지 않고 실패한다. MoveL 실패도 자동으로 MoveJ로 바뀌지 않는다.

Pick-and-Place 미션은 물체에서 멀리 떨어진 접근점과 작업 구역 사이의 이동에 MoveJ를 사용한다. 물체에 접근하는 하강·들기와 목표판 위 하강·후퇴는 MoveL로 수행한다. MoveJ는 직선 관절 보간의 검사 표본에서 joint limit 및 등록된 충돌을 확인하지만, 우회 경로는 찾지 않는다. 연속적인 동역학도 계산하지 않는다.

`MoveLinear`은 목표 자세 하나를 담은 `MoveLinearPath` 요청이다. waypoint 사이에서 TCP 위치는 직선으로 보간하고 방향은 quaternion의 최단 회전 경로를 따른다. 기본 표본 간격은 위치 10 mm, 회전 0.05 rad다. 경로 전체의 IK와 표본 관절 경로 충돌을 실행 전에 확인하며, 전체 구간 수는 최대 4096개다. 실행 전에 검증이나 계획이 실패하면 기존 목표와 현재 상태를 유지한다. `MoveLinearPath`는 입력 순서대로 모든 waypoint를 지나고 경로 전체에 가속·감속 프로파일 하나를 적용한다. waypoint마다 멈추거나 waypoint 사이를 곡선으로 잇는 동작은 보장하지 않는다.

MoveL은 직전 TCP 표본의 관절 해를 다음 IK의 첫 seed로 사용한다. 이 연속 해가 실패하거나 관절 경로 검사에 막히는 경우에만 제한된 대체 seed를 탐색한다. 동일한 관절 후보와 이미 검사한 TCP/경로 결과는 중복 계산을 피하도록 재사용한다. 표본 사이 간격을 늘려 충돌 검사를 생략하지 않는다. 연속된 Cartesian 경로에서 같은 IK 분기를 유지할 수 없거나 허용 오차·관절 제한·충돌 검사에 실패하면 MoveL을 실패시킨다. 다른 IK 분기로 순간 이동하거나 다른 관절 경로로 바꾸지 않는다.

IK seed 수, 후보 수, TCP 세분화와 검사 간격은 `PlanningPolicy`로 제한한다. 기본값은 경로 정확도를 위한 상한이며, 일반 UI 요청은 `BeginLinearPathPlanning`이 계산을 작은 작업 단위로 나눠 진행한다. 별도 스트레스 벤치마크는 더 큰 고정 case 집합으로 오프라인 탐색 비용과 실패 유형을 측정한다. 작업 예산은 계산을 다음 프레임으로 넘기며 충돌 간격이나 TCP 직선 허용 오차를 완화하지 않는다.

경로를 수락할 때 각 표본의 IK 관절각을 저장한다. 고정 갱신에서는 표본 사이를 보간하고 FK로 계산한 TCP 이동량과 관절 속도가 한계 안에 있는지 확인한다. 일반 경로 추종에서는 매 tick마다 IK를 다시 풀지 않는다. 특이 자세에서 보간한 관절 이동이 속도 제한을 넘을 때만 TCP를 거의 고정하는 작은 재정렬 IK를 시도한다. 재정렬도 실패하면 마지막 유효한 자세에서 Fault로 멈춘다.

Jolt의 Kinematic Body는 목표 자세를 장애물 앞에서 자동으로 멈추지 않으므로 Viewer는 매 고정 갱신에서 Robot과 Gripper의 다음 목표 충돌 모양을 물리 계산 전에 Environment와 겹쳐 본다. 다음 자세가 바닥이나 벽과 겹치면 직전 관절 자세를 복원하고 오류 code를 기록한 뒤 Controller를 `Idle`로 둔다.

이는 `Fault` 상태 전이가 아니며 이 검사만으로 장애물을 미리 돌아가는 경로를 만들지도 않는다. 또한 고정 갱신의 목표 자세를 검사하는 것이므로 이동 구간 안의 모든 지점을 연속 검사한다고 보장하지 않는다.

계획 단계의 여러 IK 시작각 검색도 정해 둔 표본에 한정되므로 전역적으로 충돌 없는 해가 없다고 증명하지는 않는다.

## 접촉과 파지

`GripperGraspAdapter`는 물리 계산 후 접촉 정보를 읽는다. 한쪽 손끝이 먼저 닿으면 반대 손끝은 물체를 끼울 때까지 계속 닫힌다. 양쪽 손끝이 같은 Dynamic 물체의 서로 반대 면에 닿으면 닫힘을 멈추고 그리퍼와 물체 사이에 고정 constraint를 만든다. 접촉 방향도 비교해 같은 면을 두 번 만진 상태를 파지로 오인하지 않는다. 접촉 조건을 만족하면 물체를 붙이는 시뮬레이션 동작이며 손끝 힘은 계산하지 않는다.

파지하면 그리퍼 본체와 물체 사이에 고정 constraint를 만든다. Constraint는 물리 계산에서 두 물체의 상대 위치와 방향을 유지하는 연결이므로 로봇을 옮기면 물체도 따라 움직인다. 이는 마찰과 힘으로 물체를 지탱하는 계산을 대신하는 시뮬레이션 모델이다. `forceRequest`의 실제 힘과 개별 손가락의 접촉 적응은 계산하지 않는다.

열기, Reset, 연결 해제, Body 삭제나 교체에서는 연결을 해제한다. 물체는 Dynamic 상태를 유지하므로 놓은 뒤 중력과 충돌 결과로 움직인다. 독립 손가락 적응은 지원하지 않으므로 손끝 사이에 들어오지 않는 비대칭 물체는 파지되지 않을 수 있다.

고정 갱신은 파지 해제 확인, Controller 갱신, FK와 장면 World 변환 계산, 물리 계산, 접촉 피드백, 장면 World 변환 재계산 순서다. 물리 계산 작업자 안에서 직접 Controller나 constraint를 수정하지 않는다.

## Viewer에서 확인하기

고정된 오른쪽 제어 패널의 `Run random pick and place`는 상자 위 접근(MoveJ), J6 방향 맞춤, 하강과 접촉 파지, 들어 올리기(MoveL), 목표판 위 장거리 이동(MoveJ), 목표 방향 맞춤, 하강과 해제 순서로 동작한다. 작업은 Robot base 좌표로 계획하며 화면의 `Box X/Z`와 `Goal X/Z`는 각각 상자와 목표판의 위치다. 이 값들은 그리퍼 기준 오프셋이 아니다. 파지 오프셋은 파지 순간 TCP와 상자 중심 사이의 실제 상대 위치에서 계산한다.

`Stop robot`은 Controller를 현재 관절각에서 멈추고 작업 단계를 보존한다. `Resume task`는 상자를 들고 있을 때 TCP와 상자 사이 오프셋을 다시 측정하고, 상자를 운반 높이까지 올린 뒤 목적지 경로를 새로 계산한다. 작업 상태는 `Moving to goal`, `Lowering box`, `Unwinding J6`처럼 현재 단계 이름으로 표시되며, 일시정지 중에는 멈춘 단계도 함께 표시한다.

작업을 시작할 때와 성공적으로 놓은 뒤에는 J6을 지정된 등가각으로 자동 정렬하는 동작을 수행한다. 각도 목표는 보통 현재 위치에서 가장 가까운 2π 등가값을 사용해 불필요한 회전을 줄인다. 이 동작과 달리 언와인드는 회전수를 보존해 J6의 목표를 정확히 0 rad로 둔다. 목표 yaw는 상자와 목표판마다 −90°에서 +90° 사이에서 무작위로 고르며, 목표판 위에서는 정사각형의 네 방향 대칭 중 현재 TCP 방향에 가장 가까운 방향을 선택한다.

J6 회전축은 보통 파지한 상자 중심을 지나지 않는다. 따라서 작은 J6 회전에서도 상자 중심이 원호를 그릴 수 있다. 손목 계획은 TCP 오프셋 2 mm와 회전 중 상자 중심의 예상 원호 이동 20 mm를 각각 검사한다. 예상 이동이 20 mm 이내면 J6만 회전한 뒤 상자 중심을 목표에 보정하는 자세 이동을 완료하고 하강한다. 예상 이동이 더 크거나 J6만으로 방향을 만들 수 없으면 목표 높이에서 상자 중심을 유지하는 보정된 TCP 자세 이동을 시도한다. 이 예상 원호는 로봇·그리퍼의 Environment 충돌 검사와 별도이므로, 상자가 지나갈 공간에도 여유가 있어야 한다.

상자가 목표판 위에 놓인 뒤에는 상자의 네 모서리가 목표 영역 안에 있는지 검사한다. 성공한 경우에만 Viewer가 상자와 목표판의 새 위치와 회전을 선택해 다음 임무를 준비한다. UI의 J1..J6 표는 모델 사양의 각 관절 최소·최대각과 Controller가 보고한 현재각을 도 단위로 표시한다.

Viewer의 TCP는 열린 손끝 메시 두 개의 중심 사이로 정하고 방향은 Gripper 축을 사용한다. GLB의 실제 장착 변환을 반영한 고정 기준이며 제조사 보정값이 아니다. 그리퍼를 닫아도 이 보정값은 변하지 않는다.

수식과 독립 C++ 호출 예제를 따라가려면 [HCR-12A TCP 이동 튜토리얼](IK_MOVEL_TUTORIAL.md)을 참고한다. Controller 요청·상태 계약은 [Controller Interface](CONTROLLER_INTERFACE.md), 접촉 상태 전이는 [Gripper Runtime Design](GRIPPER_RUNTIME_DESIGN.md)에 정리돼 있다.

장면에는 한 변 40 mm의 파란 `GraspBox`를 추가했다. 먼저 상자 위 접근점을 골라 이동하고, 상자 중심을 골라 직선으로 내려간 뒤 `Gripper control`에서 Close를 누른다. 양쪽 접촉과 `Object held`를 확인한 다음 목표를 100 mm 올려 이동하고 Open으로 놓는다. 실제로 잡은 물체는 팔과 함께 이동하며 Open 후에는 중력으로 떨어진다. 기존 물리 시연의 한 변 120 mm 상자는 열린 손끝 간격 85 mm보다 크므로 이 파지 확인용 상자와 구별한다.
