# GraspLink 사용 안내

GraspLink는 로봇 팔의 움직임과 충돌을 화면에서 확인하는 시뮬레이터입니다. GLB는 화면에 로봇을 그리고, URDF는 관절과 충돌 도형을 정합니다.

## 실행과 모델 준비

프로그램을 실행하면 기본 로봇이 열립니다. 다른 모델 폴더를 선택하려면 `--robot <모델 폴더>`를 사용합니다. `--help`는 실행 방법을 보여 주고 `--smoke-test`는 화면이 시작되는지 확인합니다.

URDF에는 링크와 관절의 연결, 관절 종류와 축, 움직임 범위를 적습니다. 팔 시작 링크 이름은 `base_link`, 도구 끝 기준 링크 이름은 `tool0`로 정합니다. GLB의 링크와 관절 노드 이름은 URDF에 적은 이름과 맞춰야 합니다.

각 로봇 링크에는 충돌 도형을 적습니다. 상자는 그대로 쓰며, 구와 원기둥은 물리 계산에서 볼록한 다각형으로 근사합니다. 도형의 위치와 방향도 URDF에서 읽습니다. 화면 모델에서 충돌 모양을 가져오지 않습니다. 제조사 자료를 확인해 관절 축과 허용 범위를 정하고, 확인할 수 없는 값은 추정하지 않습니다.

## 지원하는 로봇

이번 범위는 단일 팔입니다. 고정·회전·연속 회전·직선 관절을 지원합니다. 관절 원점의 위치와 회전, 관절 축과 허용 범위는 모델에서 읽습니다. 4축처럼 6축 미만인 팔은 기본적으로 위치를 맞추고, 6축 이상은 위치와 방향을 함께 맞춥니다. 듀얼 암은 아직 지원하지 않습니다.

기본 예제로 HCR-12A와 2F-85 그리퍼, 집기 시연을 제공합니다. 새로운 모델을 준비할 때는 URDF의 충돌 도형과 제조사 사양을 확인해야 합니다.

## 역기구학 방식 비교

역기구학(IK)은 도구 끝의 목표 위치와 방향을 관절 값으로 바꾸는 계산입니다. 모델별 수식을 따로 만들지 않아도 되도록 여러 방법을 비교해 LM을 기본 방식으로 선택했습니다.

| 방식 | 여러 로봇 모델 | 장점 | 주의할 점 |
| --- | --- | --- | --- |
| 해석식 | 로봇 구조마다 수식이 필요함 | 조건이 맞으면 빠르고 정확함 | 구조가 바뀌면 수식을 다시 만들어야 함 |
| 야코비안 전치 | 관절 수가 달라도 적용 가능 | 계산이 단순하고 가벼움 | 수렴이 느리거나 설정에 민감할 수 있음 |
| 의사역행렬 | 관절 수가 달라도 적용 가능 | 목표 오차를 빠르게 줄일 수 있음 | 특이 자세에서 수치가 불안정해질 수 있음 |
| DLS | 관절 수가 달라도 적용 가능 | 감쇠를 더해 특이 자세의 큰 움직임을 줄임 | 감쇠를 고정하면 느리거나 정확도가 떨어질 수 있음 |
| LM | 관절 수가 달라도 적용 가능 | 목표 오차가 줄었는지 보고 감쇠를 조절함 | 반복마다 행렬을 풀어 계산 비용이 듦 |
| CCD·FABRIK | 연결된 팔 구조에 적용 가능 | 구현과 계산이 비교적 단순함 | 방향 맞추기와 관절 제한은 따로 처리해야 함 |
| 일반 최적화 | 다양한 모델과 목표에 적용 가능 | 관절 제한과 여러 목표를 함께 다루기 좋음 | 구현과 설정이 더 복잡함 |

### DLS와 LM은 어떻게 다른가요?

DLS는 야코비안 계산에 감쇠를 더해 관절 변화량을 구합니다. LM은 목표 오차가 줄었는지 확인하고, 다음 계산의 감쇠를 조절합니다. 로봇 IK에서는 LM의 계산 안에 DLS 형태의 선형 방정식이 들어갈 수 있습니다. GraspLink는 오차 변화에 따라 감쇠를 바꾸는 LM 절차를 사용합니다.

LM도 모든 목표를 풀지는 못합니다. 목표가 로봇이 닿을 수 있는 범위 밖에 있거나 관절 제한에 막히면 실패할 수 있습니다. 7축 팔의 여유 관절로 팔꿈치 자세를 고르는 기능은 아직 없습니다. [Orocos KDL의 LM 구현](https://docs.ros.org/en/melodic/api/orocos_kdl/html/chainiksolverpos__lma_8cpp.html), [MoveIt의 KDL LM 사용 예](https://moveit.picknik.ai/humble/api/html/lma__kinematics__plugin_8cpp_source.html), [야코비안 기반 방법 비교 연구](https://doi.org/10.2478/amcs-2013-0028)

## 확인 방법

빌드 뒤 핵심 모델 읽기·IK 테스트와 Viewer 실행 검사를 합니다. 성능은 같은 컴퓨터와 입력으로 측정한 결과만 비교합니다.
