## 아직 남은 범위

화면 모델은 상자 도형만 사용합니다. RGB 프레임은 메모리에만 두며 파일 저장 기능은 없습니다. OpenCV 분석은 현재 화면 앱과 같은 스레드에서 실행합니다. 실제 UDP 네트워크에서 패킷 손실·지연을 일으키는 시험도 없습니다. 시뮬레이터와 지상통제 프로그램은 현재 한 번에 한 명령만 처리합니다.

현재 측정은 한 Windows Release 컴퓨터에서 숨김 창으로 수행했습니다. 다른 컴퓨터, Debug 빌드, 장시간 실행, 실제 화면에 보이는 FPS는 확인하지 않았습니다. 이 측정만으로 이전 코드보다 빨라졌다고 말할 수는 없습니다.

ONNX 추론은 이후 확장 범위입니다. 게임패드 명령 변환과 비행 경로는 구현했지만 실제 Xbox 기기 연결, 입력 기록과 재생은 확인하지 않았습니다.

## 기존 코드 정리

| 분류 | 처리한 내용 |
| --- | --- |
| 유지 | OpenGL 창·카메라·메시·셰이더와 CMake·CTest 기반 |
| 수정 | 렌더러와 실행 앱을 드론 시뮬레이터에 맞게 단순화 |
| 교체 | 로봇 제어·시뮬레이션 실행부를 드론 모의 코어와 JSON 시나리오로 교체 |
| 제거 | IK·경로 계획·그리퍼·Jolt 물리·로봇 전용 모델과 테스트 |

새 빌드에서 쓰는 외부 라이브러리는 GLM, nlohmann/json, GLFW, OpenGL, OpenCV, GoogleTest입니다. 이전 로봇 성능 기록은 입력과 계산 대상이 달라 현재 드론 성능의 기준값으로 쓰지 않았습니다.
