# 요구사항 상태

GraspLink는 HCR-12A와 Robotiq 2F-85의 시뮬레이션 제어, 장면·물리 연동, 픽앤플레이스 동작을 제공한다. 이 문서는 구현 범위와 확인 상태만 요약한다. 모듈 흐름은 [아키텍처](ARCHITECTURE.md), 제어 계약은 [Controller 인터페이스](CONTROLLER_INTERFACE.md), 상세 설계는 [제어·시뮬레이션 목표](CONTROL_SIMULATION_GOALS.md)를 참고한다.

| 요구사항 | 현재 구현 | 검증 범위와 한계 |
| --- | --- | --- |
| FK·IK와 관절 제한 | HCR-12A 관절에서 링크 및 ToolFrame 자세를 계산하고, 관절 제한을 적용한다. | Robotics 단위 테스트가 수치 계약을 검사한다. 시험한 자세가 모든 목표의 도달성을 뜻하지 않는다. |
| MoveJ·MoveL | MoveJ는 관절 경로를 검사하고, MoveL은 TCP 경로 표본을 검사한다. | 요청 수락, 계획 완료, 목표 도달은 별도 상태다. 표본 검사는 연속 공간 전체의 충돌 증명이 아니다. |
| 고정 시간 시뮬레이션 | Viewer가 4 ms 간격의 고정 tick을 누적해 실행한다. | 이는 시뮬레이션 시간 간격이며 OS가 보장하는 250 Hz 실시간 주기가 아니다. 측정 현황은 [성능 기록](PERFORMANCE.md)에 둔다. |
| Jolt·Flecs 연동 | Static·Kinematic 목표를 Jolt에 보내고 Dynamic 결과를 장면에 반영한다. Body 수명은 연동 모듈이 관리한다. | 통합 테스트는 충돌, 동기화, 삭제 수명을 검사한다. 지원하지 않는 계층 변환 제약은 [Physics와 Flecs 연결](PHYSICS_ECS_INTEGRATION.md)에 설명한다. |
| 그리퍼 파지 | 두 손끝의 접촉을 감지해 개폐를 멈추고 조건이 맞으면 물체를 연결한다. | 통합 테스트가 접촉·파지·해제를 검사한다. 힘 기반 파지 안정성이나 실제 장비 동작은 보장하지 않는다. |
| 픽앤플레이스 | 미션 상태 기계가 접근, 파지, 운반, 배치와 복구를 실행한다. | 시나리오 결과는 seed와 시도 수를 함께 보고한다. 과거 Debug 실행 기록은 현재 Release 성능 수치가 아니다. |
| 실제 로봇 안전 | 이 저장소에는 시뮬레이션 Controller와 소프트웨어 Stop이 있다. | Hardware backend, E-Stop 회로, watchdog, 장비 인증은 구현·검증 범위에 포함하지 않는다. |

테스트 정의가 존재한다는 사실만으로 최근 통과를 뜻하지 않는다. 실행한 빌드와 CTest 결과는 변경 검증 보고에 기록한다.
