# 현재 구현 범위

| 기능 | 현재 동작 | 알아둘 점 |
| --- | --- | --- |
| FK와 IK | 관절각에서 로봇 자세를 계산하고, DLS로 TCP 목표에 맞는 관절각을 찾는다. | 현재 모델은 HCR-12A 직렬 회전 관절이다. 임의 URDF나 듀얼 암을 자동으로 읽지 않는다. |
| MoveJ와 MoveL | 관절 경로 또는 TCP 직선 경로를 검사하고 실행한다. | 계획 수락과 목표 도착은 다르다. 경로 검사는 일정 간격의 표본에 기반한다. |
| 물리 시뮬레이션 | Jolt가 충돌을 계산하고 Dynamic 물체를 움직인다. | 로봇 팔은 Kinematic으로 움직이며 실제 관절 토크는 계산하지 않는다. |
| 그리퍼 | 손끝 접촉에서 닫힘을 멈추고 조건이 맞으면 물체를 constraint로 잡는다. | 실제 마찰 파지력, 손가락별 적응, 전류는 계산하지 않는다. |
| 고정 시간 간격 | 물리와 로봇 제어 계산은 4 ms 단위로 진행한다. | OS가 보장하는 실제 250 Hz 주기는 아니다. |
| 픽앤플레이스 | 시뮬레이션에서 물체를 집어 놓는 순서를 실행한다. | 성공 표본이 모든 배치와 장애물에서 성공한다는 보장은 아니다. |

이 프로젝트는 시뮬레이터다. 실제 로봇의 비상 정지, 안전 인증, 하드웨어 제어 backend는 포함하지 않는다. 테스트나 성능 기록은 그 항목에 적힌 환경에서 실행한 결과만 뜻한다.
