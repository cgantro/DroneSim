# 요구사항

각 항목의 상태는 현재 코드와 시험으로 확인한 범위를 나타냅니다.

| 번호 | 요구사항 | 완료 기준 | 상태 |
| --- | --- | --- | --- |
| SIM-01 | 고정 간격 모의 | 한 번의 갱신이 1/60초이고 일시정지 중 상태가 바뀌지 않음 | 완료 |
| SIM-02 | 드론 기본 비행 | 이륙·호버링·이동·경유점·착륙을 실행 | 완료 |
| SIM-03 | 명령 검사 | 잘못된 숫자와 현재 상태에서 불가능한 명령을 거부 | 완료 |
| SIM-04 | 같은 입력 재현 | 같은 명령 순서가 같은 최종 상태를 만듦 | 완료 |
| SCN-01 | JSON 시나리오 | 명령을 Tick 순서대로 재생하고 예상 상태를 비교 | 완료 |
| VIS-01 | 드론 3D 화면 | 모의 위치에 맞춰 드론과 주변 환경을 표시 | 일부 완료: 단순 도형만 사용 |
| VIS-02 | 탑재 RGB 시점 | 드론 방향에 맞춘 카메라 화면을 함께 표시 | 일부 완료: 화면 렌더링만 지원 |
| VIS-03 | 센서 상태 | 활성·비활성·오류와 복구를 모의 | 대기 |
| GCS-01 | 별도 지상통제 | 외부 프로그램에서 비행·카메라 명령 전송 | 대기 |
| COM-01 | UDP 메시지 | 버전·크기·순서·중복·시간 초과를 검증 | 대기 |
| SCN-02 | 장애 시험 | 지연·손실·중복·센서 고장을 재현하고 판정 | 대기 |
| VER-01 | 성능·재현 검증 | 실행 환경과 반복 조건을 기록해 지연 분포 비교 | 대기 |

기본 범위는 SIM, SCN-01, VIS의 완료 기준과 GCS·UDP 장애 시험까지입니다. OpenCV 영상 처리, AI 추론, 게임패드는 기본 범위 이후 단계입니다.

## 현재 모델의 한계

드론은 한 대이며 상태는 위치, 속도, 수평면 방향각과 비행 모드로 표현합니다. 모델은 명령을 시험하기 위한 운동학적 모형입니다. 공기역학이나 실제 장비의 성능을 재현하지 않습니다.
