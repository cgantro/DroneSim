## 어떤 시험의 자료인가요?

## 과거 원자료

이전 기준선, 중간 진단 실행, 같은 시험의 추가 반복은 [보관 자료](archive/)에 옮겼습니다. 원본 JSON은 삭제하거나 내용을 고치지 않았습니다. 기존 기술 문서의 링크도 새 위치로 연결됩니다.

결과를 비교할 때는 파일에 적힌 코드 리비전, 빌드 종류, 입력, 장면과 측정 방법을 함께 확인해 주세요. `dirty` 표식은 실행 당시 작업 폴더가 Git 기준으로 깨끗하지 않았다는 뜻입니다. 조건이나 코드 리비전이 다르면 숫자만으로 성능이 나아졌다고 판단할 수 없습니다.
