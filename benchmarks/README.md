# 성능 측정 요약

2026년 10월 21일 Windows Release 빌드에서 250 Hz 제어·물리 계산을 10회 측정했습니다. 최신 실행은 약 2,240 tick씩 처리했습니다.

| 항목 | 중앙값 |
| --- | ---: |
| tick p50 | 307.25 μs |
| tick p95 | 384.40 μs |
| tick p99 | 436.75 μs |
| 4 ms 초과 tick | 0회 |

250 Hz 한 주기는 4 ms입니다. 이번 측정에서는 4 ms를 넘긴 계산이 없었습니다. 같은 날 리팩터링 전 측정의 p95 중앙값은 417.9 μs였지만, 반복 간 변동이 12.69%였습니다. 리팩터링 뒤 세 번 잰 p95 중앙값은 372.50 μs, 382.95 μs, 384.40 μs였습니다. 변동 폭을 고려해 성능이 빨라졌다고 결론내리지 않습니다.

결과는 현재 컴퓨터와 HCR 예제 장면에 한정됩니다. 이전 측정의 원본도 날짜별 보관 자료에 남아 있습니다. 다른 입력이나 시나리오의 수치는 직접 비교하지 않습니다.
