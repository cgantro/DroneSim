# 성능 측정 요약

2026년 10월 21일 같은 Windows 컴퓨터에서 Release 빌드로 250 Hz 제어·물리 계산을 10회 측정했습니다. 최신 실행은 회당 약 2,140 tick을 처리했습니다.

| 항목 | 중앙값 |
| --- | ---: |
| tick p50 | 316.30 μs |
| tick p95 | 393.85 μs |
| tick p99 | 453.00 μs |
| 4 ms 초과 tick | 0회 |

250 Hz 한 주기는 4 ms입니다. 이번 측정에서는 4 ms를 넘긴 계산이 없었습니다. 직전 10회 측정은 p50 304.60 μs, p95 378.20 μs, p99 436.30 μs였습니다. 측정마다 tick 수와 단계별 시간이 달라졌으므로 코드 변경이 성능을 높이거나 낮췄다고 결론내리지 않습니다.

경로 계획 벤치마크는 현재 10회 반복에서 한 경로를 만드는 데 일반 계획기는 중앙값 50.00 μs, 증분 계획기는 65.63 μs가 걸렸습니다. 두 방식 모두 반복마다 관절 경로 검사 6회를 했고 증분 계획은 모든 반복에서 성공했습니다. 기존 값은 각각 한 번만 측정한 47.08 μs와 62.00 μs이므로, 반복 수가 달라 직접적인 성능 변화로 해석하지 않습니다.

결과는 현재 컴퓨터와 HCR 예제 장면에 한정됩니다. 원본 측정값은 날짜별 보관 자료에 남아 있습니다. 다른 입력이나 시나리오의 수치는 직접 비교하지 않습니다.
